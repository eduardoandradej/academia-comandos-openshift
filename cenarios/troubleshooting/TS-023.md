# TS-023 — HostAlreadyClaimed: a Route nova não recebe tráfego

- **Trilha:** [07 — Routes e Ingress](../../trilhas/07-rotas/README.md)
- **Nível:** Intermediário
- **Perfil:** developer
- **Impacto da reprodução:** MUTAÇÃO LOCAL REVERSÍVEL (1 Route conflitante)
- **Status:** proposto — ainda não reproduzido contra o cluster pelo autor

## Sintoma

Você criou a Route `loja-nova` com o host `disputa-ac07.apps.ocp.example.lab` para o `web-verde`, mas o `curl` continua
respondendo `azul`.

## Contexto

Projeto `ac07-rotas`. Já existe uma Route mais antiga com o mesmo host.

## Como reproduzir com segurança

```bash
oc expose svc/web-azul --name=loja-antiga --hostname=disputa-ac07.apps.ocp.example.lab -n ac07-rotas
sleep 2
oc expose svc/web-verde --name=loja-nova --hostname=disputa-ac07.apps.ocp.example.lab -n ac07-rotas
curl -sS http://disputa-ac07.apps.ocp.example.lab/      # azul
```

## Hipóteses a testar

1. Outra Route já reivindicou o host (e caminho).
2. Cache do cliente.
3. A Route nova aponta para o Service errado.

## Investigação orientada

- `oc get route loja-nova -n ac07-rotas -o jsonpath='{range .status.ingress[*].conditions[*]}{.type}={.status} {.reason}: {.message}{"\n"}{end}'`
- `oc get routes -n ac07-rotas -o custom-columns=NOME:.metadata.name,HOST:.spec.host,CRIADA:.metadata.creationTimestamp`
- `oc get route loja-nova -n ac07-rotas -o jsonpath='{.spec.to.name}{"\n"}'`

## Critério de resolução

Você mostra o motivo `HostAlreadyClaimed` e resolve o conflito sem apagar nada que não seja seu.

## Limpeza

```bash
oc delete route loja-antiga loja-nova -n ac07-rotas --ignore-not-found
```
