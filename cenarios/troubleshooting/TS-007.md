# TS-007 — the server doesn't have a resource type

- **Trilha:** [02 — Leitura e inspeção](../../trilhas/02-consultas/README.md)
- **Nível:** Iniciante
- **Perfil:** developer
- **Impacto da reprodução:** LEITURA
- **Status:** proposto — ainda não reproduzido contra o cluster pelo autor

## Sintoma

```text
error: the server doesn't have a resource type "deploymnet"
error: the server doesn't have a resource type "imagecontentsourcepolicies"
```

## Contexto

Uma linha tem digitação errada; a outra pede um tipo que pode não existir (ou estar obsoleto) no cluster.

## Como reproduzir com segurança

```bash
oc get deploymnet -n ac02-consultas
oc get imagecontentsourcepolicies
```

## Hipóteses a testar

1. Digitação.
2. Tipo não servido por este cluster (CRD/operador ausente ou API removida).
3. Falta de permissão.

## Investigação orientada

- `oc api-resources | grep -i deploy`
- `oc api-resources | grep -i -E 'imagecontentsource|imagedigestmirror'`
- `oc auth can-i list deployments -n ac02-consultas`

## Critério de resolução

Você distingue o caso de digitação do caso de tipo ausente e cita o tipo substituto quando houver.

## Limpeza

Nada é criado.
