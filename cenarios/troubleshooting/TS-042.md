# TS-042 — Template que renderiza, mas o servidor recusa

- **Trilha:** [13 — Kustomize e Templates](../../trilhas/13-kustomize/README.md)
- **Nível:** Intermediário
- **Perfil:** developer
- **Impacto da reprodução:** LEITURA (dry-run de servidor)
- **Status:** proposto — ainda não reproduzido contra o cluster pelo autor

## Sintoma

Uma cópia do template `ac13-web` processa sem erro, mas o `oc apply` falha com
`cannot unmarshal string into Go struct field DeploymentSpec.spec.replicas of type int32`.

## Contexto

Projeto `ac13-kustomize`. Template do repositório: `manifests/templates/ac13-template.yaml`.

## Como reproduzir com segurança

```bash
sed 's/replicas: \${{REPLICAS}}/replicas: ${REPLICAS}/' manifests/templates/ac13-template.yaml > /tmp/ac13/tpl-errado.yaml
oc process -f /tmp/ac13/tpl-errado.yaml -p NOME=ac13-ts042 | oc apply --dry-run=server -n ac13-kustomize -f -
```

## Hipóteses a testar

1. `${REPLICAS}` gera texto (`"1"`), e `replicas` exige número.
2. O parâmetro `REPLICAS` não foi informado.
3. O valor padrão de `REPLICAS` é inválido.

## Investigação orientada

- `oc process -f /tmp/ac13/tpl-errado.yaml -p NOME=ac13-ts042 -o json | jq '.items[] | select(.kind=="Deployment") | .spec.replicas'`
- `diff manifests/templates/ac13-template.yaml /tmp/ac13/tpl-errado.yaml`

## Critério de resolução

Você mostra o tipo do valor gerado e corrige a sintaxe no template.

## Limpeza

```bash
rm -f /tmp/ac13/tpl-errado.yaml
```
