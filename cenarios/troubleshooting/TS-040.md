# TS-040 — apply -k recusado: o namespace que não bate

- **Trilha:** [13 — Kustomize e Templates](../../trilhas/13-kustomize/README.md)
- **Nível:** Iniciante
- **Perfil:** developer
- **Impacto da reprodução:** LEITURA (o cliente recusa antes de aplicar)
- **Status:** proposto — ainda não reproduzido contra o cluster pelo autor

## Sintoma

Um colega roda o mesmo comando de sempre, agora para o overlay de desenvolvimento, e recebe
`the namespace from the provided object "ac13-dev" does not match the namespace "ac13-kustomize"`.

## Contexto

Projeto atual `ac13-kustomize`; overlay `manifests/kustomize/overlays/dev` (define `namespace: ac13-dev`).

## Como reproduzir com segurança

```bash
oc project ac13-kustomize
oc apply -k manifests/kustomize/overlays/dev -n ac13-kustomize --dry-run=client
```

## Hipóteses a testar

1. O overlay define `namespace` e o comando força outro com `-n`.
2. O projeto `ac13-dev` não existe.
3. O usuário não tem permissão em `ac13-dev`.

## Investigação orientada

- `grep -n '^namespace:' manifests/kustomize/overlays/dev/kustomization.yaml`
- `oc kustomize manifests/kustomize/overlays/dev | grep -m3 'namespace:'`
- `oc get project ac13-dev`

## Critério de resolução

Você explica qual dos dois namespaces vence e aplica no lugar certo sem `-n`.

## Limpeza

Nada a limpar (o cliente recusou).
