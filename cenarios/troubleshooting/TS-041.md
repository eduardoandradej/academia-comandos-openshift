# TS-041 — Patch que não encontra o alvo

- **Trilha:** [13 — Kustomize e Templates](../../trilhas/13-kustomize/README.md)
- **Nível:** Intermediário
- **Perfil:** developer
- **Impacto da reprodução:** LEITURA (erro de renderização)
- **Status:** proposto — ainda não reproduzido contra o cluster pelo autor

## Sintoma

Depois de um "renomear tudo para o padrão novo" na base, o overlay de produção deixou de renderizar:
`no matches for Id Deployment.v1.apps/ac13-loja.[noNs]; failed to find unique target for patch`.

## Contexto

Cópia `/tmp/ac13/kustomize` (Trilha 13).

## Como reproduzir com segurança

```bash
rm -rf /tmp/ac13/ts041 && cp -r manifests/kustomize /tmp/ac13/ts041
sed -i 's/name: ac13-loja$/name: loja/' /tmp/ac13/ts041/base/deployment.yaml
oc kustomize /tmp/ac13/ts041/overlays/prod
```

## Hipóteses a testar

1. O Deployment da base mudou de nome; o patch e o transformador `replicas` ainda citam o nome antigo.
2. O arquivo de patch não existe.
3. O `apiVersion` do patch está errado.

## Investigação orientada

- `oc kustomize /tmp/ac13/ts041/base | grep -A1 '^kind: Deployment'`
- `grep -n 'name:' /tmp/ac13/ts041/overlays/prod/patch-recursos.yaml /tmp/ac13/ts041/overlays/prod/kustomization.yaml`

## Critério de resolução

Você encontra todas as referências ao nome antigo no overlay e corrige de forma consistente.

## Limpeza

```bash
rm -rf /tmp/ac13/ts041
```
