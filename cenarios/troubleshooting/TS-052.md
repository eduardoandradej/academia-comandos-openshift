# TS-052 — failed quota: must specify — o pod sem resources

- **Trilha:** [17 — Administração de recursos](../../trilhas/17-admin/README.md)
- **Nível:** Iniciante
- **Perfil:** admin
- **Impacto da reprodução:** MUTAÇÃO LOCAL REVERSÍVEL (projeto de treino)
- **Status:** proposto — ainda não reproduzido contra o cluster pelo autor

## Sintoma

Num projeto novo, o admin aplicou uma ResourceQuota de computação. Desde então, `oc run` e `oc create deployment` sem
resources falham (ou o Deployment fica sem pods) com `must specify limits.cpu ... requests.memory`.

## Contexto

Perfil `admin`. Projeto `ac17-ts052`, criado só para o cenário.

## Como reproduzir com segurança

```bash
source scripts/perfis.sh && ac-admin
oc new-project ac17-ts052 --skip-config-write >/dev/null
oc apply -f manifests/admin/quota-completa.yaml -n ac17-ts052
oc run x --image=registry.access.redhat.com/ubi9/httpd-24:latest -n ac17-ts052
```

## Hipóteses a testar

1. A quota limita requests/limits e o pod não declara nenhum; não há LimitRange com padrões.
2. A quota já está esgotada.
3. Falta permissão para criar pods.

## Investigação orientada

- a mensagem completa (`failed quota: ac17-computacao: must specify ...`)
- `oc describe quota -n ac17-ts052` (uso zero)
- `oc get limitrange -n ac17-ts052`

## Critério de resolução

Você explica por que a quota exige os valores e corrige sem remover a quota.

## Limpeza

```bash
oc delete project ac17-ts052 --ignore-not-found
ac-dev
```
