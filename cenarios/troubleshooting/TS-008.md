# TS-008 — JSONPath que não imprime nada

- **Trilha:** [02 — Leitura e inspeção](../../trilhas/02-consultas/README.md)
- **Nível:** Intermediário
- **Perfil:** developer
- **Impacto da reprodução:** LEITURA
- **Status:** proposto — ainda não reproduzido contra o cluster pelo autor

## Sintoma

Os comandos terminam sem erro e sem saída:

```bash
oc get pods -n ac02-consultas -o jsonpath='{.metadata.name}'
oc get pods -n ac02-consultas -o jsonpath='{.items[*].status.podIp}'
oc get pods -n ac02-consultas -o jsonpath='{.items[?(@.status.phase=="running")].metadata.name}'
```

## Contexto

O alvo de observação está no ar com 2 pods (CON-003).

## Como reproduzir com segurança

Execute os três comandos acima (somente leitura).

## Hipóteses a testar

1. Falta `.items` (a resposta de uma listagem é uma `List`).
2. Caixa errada no nome do campo.
3. Valor do filtro com caixa errada.

## Investigação orientada

- `oc get pods -n ac02-consultas -o json | jq 'keys'`
- `oc get pods -n ac02-consultas -o json | jq '.items[0].status | keys'`
- `oc get pods -n ac02-consultas -o jsonpath='{.items[*].status.phase}'`

## Critério de resolução

Os três comandos corrigidos imprimem nomes, IPs e pods Running.

## Limpeza

Nada é criado.
