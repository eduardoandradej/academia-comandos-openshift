# TS-004 — KUBECONFIG apontando para o vazio

- **Trilha:** [01 — Navegação e CLI](../../trilhas/01-cli/README.md)
- **Nível:** Iniciante
- **Perfil:** developer
- **Impacto da reprodução:** LEITURA
- **Status:** proposto — ainda não reproduzido contra o cluster pelo autor

## Sintoma

```text
error: Missing or incomplete configuration info.  Please point to an existing, complete config file
```

ou

```text
The connection to the server localhost:8080 was refused - did you specify the right host or port?
```

## Contexto

Alguém editou o `~/.bashrc` e trocou o caminho do perfil, ou o arquivo do perfil foi apagado.

## Como reproduzir com segurança

```bash
KUBECONFIG=/tmp/nao-existe oc get pods
KUBECONFIG=/tmp/nao-existe oc config view --minify
```

## Hipóteses a testar

1. Arquivo inexistente/vazio.
2. Arquivo sem `current-context`.
3. Servidor errado dentro do arquivo.

## Investigação orientada

- `printenv KUBECONFIG`; `ls -l "$KUBECONFIG"`
- `oc config current-context`; `oc config get-contexts`
- `oc whoami --show-server`

## Critério de resolução

Você identifica qual das hipóteses vale e restaura o perfil correto sem copiar o kubeconfig do instalador.

## Limpeza

Nada é criado; a variável vale só para o comando de reprodução.
