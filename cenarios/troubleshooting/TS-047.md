# TS-047 — cannot change roleRef: trocar o papel de um binding

- **Trilha:** [15 — Usuários, identidade e RBAC](../../trilhas/15-rbac/README.md)
- **Nível:** Intermediário
- **Perfil:** developer
- **Impacto da reprodução:** MUTAÇÃO LOCAL REVERSÍVEL
- **Status:** proposto — ainda não reproduzido contra o cluster pelo autor

## Sintoma

Para promover a SA `ac15-robo` de leitura para edição, alguém tentou `oc edit rolebinding ac15-robo-acesso` trocando
`roleRef.name: view` por `edit`. A gravação é recusada.

## Contexto

Projeto `ac15-rbac`.

## Como reproduzir com segurança

```bash
oc create rolebinding ac15-robo-acesso --clusterrole=view --serviceaccount=ac15-rbac:ac15-robo -n ac15-rbac
oc patch rolebinding ac15-robo-acesso -n ac15-rbac --type=merge -p '{"roleRef":{"name":"edit"}}'
```

## Hipóteses a testar

1. `roleRef` é imutável depois da criação.
2. Falta permissão para alterar RoleBindings.
3. A ClusterRole `edit` não existe.

## Investigação orientada

- a mensagem (`cannot change roleRef`)
- `oc auth can-i patch rolebindings -n ac15-rbac`
- `oc get clusterrole edit -o name`

## Critério de resolução

Você troca o papel sem deixar a SA sem acesso em nenhum momento.

## Limpeza

```bash
oc delete rolebinding ac15-robo-acesso ac15-robo-acesso-edit -n ac15-rbac --ignore-not-found
```
