# TS-022 — Application is not available: o 503 do router

- **Trilha:** [07 — Routes e Ingress](../../trilhas/07-rotas/README.md)
- **Nível:** Iniciante
- **Perfil:** developer
- **Impacto da reprodução:** MUTAÇÃO LOCAL REVERSÍVEL (escala um backend a zero)
- **Status:** proposto — ainda não reproduzido contra o cluster pelo autor

## Sintoma

O navegador mostra a página **"Application is not available"** (HTTP 503) para `web-verde-ac07-rotas.apps.ocp.example.lab`.
A Route existe e está admitida.

## Contexto

Projeto `ac07-rotas` com os backends e Routes do RTE-001.

## Como reproduzir com segurança

```bash
oc expose svc/web-verde -n ac07-rotas 2>/dev/null
oc scale deployment/web-verde --replicas=0 -n ac07-rotas
curl -sS -o /dev/null -w '%{http_code}\n' "http://$(oc get route web-verde -n ac07-rotas -o jsonpath='{.spec.host}')/"
```

## Hipóteses a testar

1. Service sem endpoints prontos.
2. Route apontando para Service inexistente.
3. Host sem Route correspondente.

## Investigação orientada

- `oc get route web-verde -n ac07-rotas -o jsonpath='{.spec.to.name} admitida={.status.ingress[0].conditions[0].status}{"\n"}'`
- `oc get svc web-verde -n ac07-rotas`
- `oc get endpointslices -n ac07-rotas -l kubernetes.io/service-name=web-verde -o jsonpath='{.items[*].endpoints}{"\n"}'`
- `oc get deploy web-verde -n ac07-rotas`

## Critério de resolução

Você aponta qual elo da cadeia Route → Service → endpoints está vazio e restaura o acesso.

## Limpeza

```bash
oc scale deployment/web-verde --replicas=1 -n ac07-rotas
```
