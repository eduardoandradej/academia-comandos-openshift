# TS-012 — oc label recusou: --overwrite e valores inválidos

- **Trilha:** [03 — Projetos e metadados](../../trilhas/03-projetos/README.md)
- **Nível:** Iniciante
- **Perfil:** developer
- **Impacto da reprodução:** LEITURA (as requisições são recusadas)
- **Status:** proposto — ainda não reproduzido contra o cluster pelo autor

## Sintoma

Três comandos de rótulo falham:

```text
error: 'ambiente' already has a value (treino), and --overwrite is false
The ConfigMap "ac03-x" is invalid: metadata.labels: Invalid value: "versão": ...
The ConfigMap "ac03-x" is invalid: metadata.labels: Invalid value: "dois termos": ...
```

## Contexto

ConfigMap `ac03-x` com o rótulo `ambiente=treino`, em `ac03-projetos`.

## Como reproduzir com segurança

```bash
oc create configmap ac03-x --from-literal=a=1 --dry-run=client -o yaml \
  | oc label --local -f - academy.openshift.dev/managed-by=academia ambiente=treino -o yaml | oc apply -n ac03-projetos -f -
oc label cm/ac03-x ambiente=prod -n ac03-projetos
oc label cm/ac03-x 'versão=1' -n ac03-projetos
oc label cm/ac03-x nota='dois termos' -n ac03-projetos
```

## Hipóteses a testar

1. Proteção contra sobrescrita.
2. Caractere fora do permitido na chave.
3. Caractere fora do permitido no valor.

## Investigação orientada

- `oc label cm/ac03-x --list -n ac03-projetos`
- releia a mensagem: ela diz se o problema está na **chave** ou no **valor** e mostra a expressão regular aceita.

## Critério de resolução

Os três comandos corrigidos funcionam, cada um por um motivo diferente.

## Limpeza

```bash
oc delete cm ac03-x -n ac03-projetos
```
