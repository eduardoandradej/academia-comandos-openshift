# TS-005 — Unauthorized depois do almoço

- **Trilha:** [01 — Navegação e CLI](../../trilhas/01-cli/README.md)
- **Nível:** Iniciante
- **Perfil:** developer
- **Impacto da reprodução:** MUTAÇÃO LOCAL REVERSÍVEL (logout/login)
- **Status:** proposto — ainda não reproduzido contra o cluster pelo autor

## Sintoma

```text
error: You must be logged in to the server (Unauthorized)
```

Pela manhã tudo funcionava no mesmo terminal.

## Contexto

Tokens OAuth expiram; `oc logout` em outro terminal com o mesmo arquivo também invalida a sessão.

## Como reproduzir com segurança

```bash
source scripts/perfis.sh && ac-dev
oc logout          # simula a expiração revogando o token
oc get pods -n ac01-cli
```

## Hipóteses a testar

1. Token expirado ou revogado.
2. Usuário removido do HTPasswd.
3. Permissão retirada.

## Investigação orientada

- `oc whoami` (Unauthorized → sessão; Forbidden → permissão)
- `oc whoami -t | wc -c` (há token no arquivo?)
- `oc login -u developer` e repita.

## Critério de resolução

A sessão volta a funcionar e você explica por que não era problema de RBAC.

## Limpeza

Nenhum recurso de cluster é criado. O novo token fica no seu perfil.
