# TS-025 — CreateContainerConfigError: a configuração que não existe

- **Trilha:** [08 — ConfigMaps e Secrets](../../trilhas/08-config/README.md)
- **Nível:** Iniciante
- **Perfil:** developer
- **Impacto da reprodução:** MUTAÇÃO LOCAL REVERSÍVEL (1 Deployment)
- **Status:** proposto — ainda não reproduzido contra o cluster pelo autor

## Sintoma

O Deployment `ac08-sem-config` foi aplicado sem erro, mas o pod nunca inicia: `STATUS` mostra
`CreateContainerConfigError` e nenhum log é produzido.

## Contexto

Projeto `ac08-config` (Trilha 08). Manifesto `manifests/apps-exemplo/cenario-config-ausente.yaml`, já revisado.

## Como reproduzir com segurança

```bash
oc apply -f manifests/apps-exemplo/cenario-config-ausente.yaml -n ac08-config
oc get pods -n ac08-config -l app=ac08-sem-config -w     # Ctrl+C após ver CreateContainerConfigError
```

## Hipóteses a testar

1. Um ConfigMap referenciado não existe.
2. Um Secret referenciado não existe (ou falta uma chave).
3. Falha da imagem.

## Investigação orientada

- `oc describe pod -n ac08-config -l app=ac08-sem-config | sed -n '/Events:/,$p'`
- `oc get deployment ac08-sem-config -n ac08-config -o json | jq '.spec.template.spec.containers[0].env'`
- `oc get configmap,secret -n ac08-config -o name`

## Critério de resolução

Você nomeia **todas** as referências ausentes (não só a primeira mensagem) e faz o pod iniciar sem inventar valores sensíveis.

## Limpeza

```bash
oc delete -f manifests/apps-exemplo/cenario-config-ausente.yaml -n ac08-config --ignore-not-found
oc delete configmap ac08-config-que-nao-existe -n ac08-config --ignore-not-found
oc delete secret ac08-secret-que-nao-existe -n ac08-config --ignore-not-found
```
