# TS-016 — Rollout travado: a versão nova nunca fica pronta

- **Trilha:** [05 — Deployments e workloads](../../trilhas/05-deployments/README.md)
- **Nível:** Intermediário
- **Perfil:** developer
- **Impacto da reprodução:** MUTAÇÃO LOCAL REVERSÍVEL (1 pod que não sobe; os antigos continuam atendendo)
- **Status:** proposto — ainda não reproduzido contra o cluster pelo autor

## Sintoma

Depois de uma atualização, `oc rollout status deployment/ac05-web` fica esperando e termina com
`error: deployment "ac05-web" exceeded its progress deadline`. A aplicação continua respondendo.

## Contexto

Projeto `ac05-deploy`, Deployment `ac05-web` com 2 réplicas saudáveis (DEP-001).

## Como reproduzir com segurança

```bash
oc patch deployment ac05-web -n ac05-deploy --type=merge -p '{"spec":{"progressDeadlineSeconds":60}}'
C=$(oc get deployment ac05-web -n ac05-deploy -o jsonpath='{.spec.template.spec.containers[0].name}')
oc set image deployment/ac05-web "$C=registry.access.redhat.com/ubi9/httpd-24:tag-que-nao-existe-ac" -n ac05-deploy
oc rollout status deployment/ac05-web -n ac05-deploy --timeout=120s
```

## Hipóteses a testar

1. A imagem nova não pode ser baixada.
2. A revisão nova não passa na readiness probe.
3. A quota impede criar o pod novo.

## Investigação orientada

- `oc get deployment ac05-web -n ac05-deploy -o jsonpath='{.status.conditions[?(@.type=="Progressing")].reason}: {.status.conditions[?(@.type=="Progressing")].message}{"\n"}'`
- `oc get rs -n ac05-deploy -l app=ac05-web` (qual ReplicaSet está tentando subir?)
- `oc get pods -n ac05-deploy -l app=ac05-web` e `oc describe pod <pod novo> | sed -n '/Events:/,$p'`
- `oc get events -n ac05-deploy --field-selector reason=FailedCreate` (quota)

## Critério de resolução

Você identifica a causa, desfaz o rollout e explica por que a aplicação não caiu durante o problema.

## Limpeza

```bash
oc rollout undo deployment/ac05-web -n ac05-deploy
oc rollout status deployment/ac05-web -n ac05-deploy
oc patch deployment ac05-web -n ac05-deploy --type=merge -p '{"spec":{"progressDeadlineSeconds":600}}'
```
