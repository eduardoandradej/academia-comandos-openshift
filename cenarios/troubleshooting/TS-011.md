# TS-011 — Projeto preso em Terminating

- **Trilha:** [03 — Projetos e metadados](../../trilhas/03-projetos/README.md)
- **Nível:** Intermediário
- **Perfil:** developer (criação) e admin (condições)
- **Impacto da reprodução:** MUTAÇÃO LOCAL REVERSÍVEL (um projeto descartável com 1 pod pequeno)
- **Status:** proposto — ainda não reproduzido contra o cluster pelo autor

## Sintoma

`oc delete project ac03-terminacao` retornou na hora, mas o projeto continua aparecendo como `Terminating` por mais de um minuto.

## Contexto

Um pod do projeto ignora o sinal de término e tem `terminationGracePeriodSeconds: 90`.

## Como reproduzir com segurança

```bash
oc new-project ac03-terminacao --skip-config-write
oc apply -f manifests/apps-exemplo/cenario-terminacao-lenta.yaml -n ac03-terminacao
oc wait --for=condition=Ready pod/termina-devagar -n ac03-terminacao --timeout=120s
oc delete project ac03-terminacao --wait=false
oc get project ac03-terminacao -o jsonpath='{.status.phase}{"\n"}'     # Terminating
```

## Hipóteses a testar

1. Conteúdo ainda sendo removido (pod em período de graça).
2. Finalizer pendente de um controlador indisponível.
3. API agregada indisponível impedindo a descoberta de tipos.

## Investigação orientada

- `oc get pods -n ac03-terminacao -o jsonpath='{range .items[*]}{.metadata.name} {.metadata.deletionTimestamp} {.spec.terminationGracePeriodSeconds}{"\n"}{end}'`
- (admin) `oc get namespace ac03-terminacao -o jsonpath='{range .status.conditions[*]}{.type}={.status} {.message}{"\n"}{end}'`
- (admin) `oc get apiservices | grep -v True`

## Critério de resolução

Você identifica a causa pelas condições do namespace e vê o projeto sumir sozinho, sem editar finalizers.

## Limpeza

O projeto some sozinho após ~90 s. Confirme: `oc get project ac03-terminacao` → `NotFound`.
