# TS-033 — InvalidImageName: o pod que nem tenta baixar

- **Trilha:** [10 — Imagens e registries](../../trilhas/10-imagens/README.md)
- **Nível:** Iniciante
- **Perfil:** developer
- **Impacto da reprodução:** MUTAÇÃO LOCAL REVERSÍVEL (1 pod)
- **Status:** proposto — ainda não reproduzido contra o cluster pelo autor

## Sintoma

Um pod criado a partir de uma planilha de inventário fica em `InvalidImageName`. Não há eventos de `Pulling`.

## Contexto

Projeto `ac10-imagens`.

## Como reproduzir com segurança

```bash
oc run ac10-planilha --image='Registry.Access.RedHat.com/UBI9/httpd-24:latest' -n ac10-imagens \
  --labels=academy.openshift.dev/managed-by=academia
sleep 10; oc get pod ac10-planilha -n ac10-imagens
```

## Hipóteses a testar

1. Letras maiúsculas no nome do repositório.
2. Espaço ou caractere invisível copiado da planilha.
3. Tag inexistente.

## Investigação orientada

- `oc get pod ac10-planilha -n ac10-imagens -o jsonpath='{.spec.containers[0].image}' | od -c | head -3`
- `oc describe pod ac10-planilha -n ac10-imagens | sed -n '/Events:/,$p'`

## Critério de resolução

Você aponta o caractere problemático e explica por que não há tentativa de pull.

## Limpeza

```bash
oc delete pod ac10-planilha -n ac10-imagens --ignore-not-found
```
