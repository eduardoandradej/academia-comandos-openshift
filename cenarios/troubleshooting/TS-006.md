# TS-006 — No resources found: o namespace errado

- **Trilha:** [01 — Navegação e CLI](../../trilhas/01-cli/README.md)
- **Nível:** Iniciante
- **Perfil:** developer
- **Impacto da reprodução:** LEITURA
- **Status:** proposto — ainda não reproduzido contra o cluster pelo autor

## Sintoma

Você acabou de aplicar o alvo de observação, mas:

```text
No resources found in default namespace.
```

## Contexto

O contexto atual não tem namespace ou aponta para outro projeto.

## Como reproduzir com segurança

```bash
oc config set-context --current --namespace=default
oc get pods
oc project ac01-cli      # restaura
```

## Hipóteses a testar

1. Namespace do contexto diferente do esperado.
2. Recursos aplicados em outro projeto.
3. Recursos apagados.

## Investigação orientada

- `oc project -q`
- `oc config view --minify -o jsonpath='{.contexts[0].context.namespace}{"\n"}'`
- `oc get pods -n ac01-cli -l app=obs-web`

## Critério de resolução

Você encontra os pods e ajusta o hábito (sempre `-n` em exercícios).

## Limpeza

Restaure o contexto: `oc project ac01-cli`.
