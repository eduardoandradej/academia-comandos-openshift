# TS-018 — Deployment com menos pods que o pedido: a quota barrou

- **Trilha:** [05 — Deployments e workloads](../../trilhas/05-deployments/README.md)
- **Nível:** Intermediário
- **Perfil:** developer (o admin aplica a baseline antes)
- **Impacto da reprodução:** MUTAÇÃO LOCAL REVERSÍVEL (1 pod; os demais são recusados antes de existir)
- **Status:** proposto — ainda não reproduzido contra o cluster pelo autor

## Sintoma

O Deployment `ac05-guloso` pede 3 réplicas, mas `oc get deployment` mostra `1/3` e não há pods `Pending`.

## Contexto

Projeto `ac05-deploy` **com** a baseline de quota da Academia (`requests.cpu: 500m`). Cada réplica pede 300m.

## Como reproduzir com segurança

```bash
oc get resourcequota ac-quota -n ac05-deploy -o name || echo "aplique a baseline (perfil admin, ORI-012)"
oc apply -f manifests/apps-exemplo/cenario-quota-deploy.yaml -n ac05-deploy
oc get deployment ac05-guloso -n ac05-deploy
```

## Hipóteses a testar

1. A quota do projeto recusa a criação dos pods extras.
2. Os pods extras estão `Pending` por falta de CPU no nó.
3. O LimitRange recusa os pods.

## Investigação orientada

- `oc get pods -n ac05-deploy -l app=ac05-guloso` (há pods Pending?)
- `oc describe rs -n ac05-deploy -l app=ac05-guloso | sed -n '/Events:/,$p'` (procure `FailedCreate`)
- `oc describe resourcequota ac-quota -n ac05-deploy`
- `oc get deployment ac05-guloso -n ac05-deploy -o jsonpath='{.status.conditions[?(@.type=="ReplicaFailure")].message}{"\n"}'`

## Critério de resolução

Você cita o evento `FailedCreate` com `exceeded quota` e calcula quantas réplicas cabem na quota.

## Limpeza

```bash
oc delete deployment -l academy.openshift.dev/cenario=ts-018 -n ac05-deploy
```
