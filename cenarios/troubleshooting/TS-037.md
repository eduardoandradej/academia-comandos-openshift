# TS-037 — field is immutable: mudei o seletor do Deployment

- **Trilha:** [12 — Manifestos declarativos](../../trilhas/12-declarativo/README.md)
- **Nível:** Intermediário
- **Perfil:** developer
- **Impacto da reprodução:** LEITURA (a mudança é recusada; nada é alterado)
- **Status:** proposto — ainda não reproduzido contra o cluster pelo autor

## Sintoma

Para separar versões, alguém acrescentou `ver: "2"` ao `spec.selector.matchLabels` e aos rótulos do template no
manifesto do `ac12-web`. O pipeline agora falha em todo `oc apply`.

## Contexto

Projeto `ac12-declarativo` com a aplicação do DCL-003 aplicada.

## Como reproduzir com segurança

```bash
python3 - <<'EOF' > /tmp/ac12/seletor.yaml
s = open('/tmp/ac12/app.yaml').read()
s = s.replace('    matchLabels:\n      app: ac12-web\n', '    matchLabels:\n      app: ac12-web\n      ver: "2"\n', 1)
s = s.replace('      labels:\n        app: ac12-web\n', '      labels:\n        app: ac12-web\n        ver: "2"\n', 1)
print(s)
EOF
oc apply -f /tmp/ac12/seletor.yaml -n ac12-declarativo
```

## Hipóteses a testar

1. `spec.selector` de um Deployment é imutável.
2. O rótulo do template não casa com o seletor.
3. Falta permissão para alterar Deployments.

## Investigação orientada

- a mensagem completa do `oc apply`
- `oc diff -f /tmp/ac12/seletor.yaml -n ac12-declarativo`
- `oc explain deployment.spec.selector`

## Critério de resolução

Você explica por que o seletor é imutável e escolhe a correção que não derruba a aplicação.

## Limpeza

```bash
rm -f /tmp/ac12/seletor.yaml
```
