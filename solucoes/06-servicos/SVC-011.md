# Gabarito SVC-011 — ExternalName: um apelido DNS

> Consulte só depois de tentar. Enunciado: [trilhas/06-servicos/exercicios/SVC-011.md](../../trilhas/06-servicos/exercicios/SVC-011.md)

## Desafio sem pista — uma solução possível

```bash
IP=$(oc get pod -n ac06-servicos -l cor=azul -o jsonpath='{.items[0].status.podIP}')
cat <<EOF | oc apply -n ac06-servicos -f -
apiVersion: v1
kind: Service
metadata: {name: loja-manual, labels: {academy.openshift.dev/managed-by: academia}}
spec:
  ports: [{name: http, port: 8080, targetPort: 8080}]
---
apiVersion: discovery.k8s.io/v1
kind: EndpointSlice
metadata:
  name: loja-manual-1
  labels: {kubernetes.io/service-name: loja-manual, academy.openshift.dev/managed-by: academia}
addressType: IPv4
ports: [{name: http, port: 8080}]
endpoints: [{addresses: ["$IP"]}]
EOF
http loja-manual     # azul
```

Se a criação da EndpointSlice for negada (`Forbidden`) para o seu perfil, use o objeto legado `Endpoints` com o mesmo nome do Service (`subsets[].addresses[].ip` e `subsets[].ports[]`).

Diferença: o Service sem seletor tem ClusterIP e proxy para IPs que você mantém à mão; o ExternalName só responde um
CNAME. Atenção: o IP fixado aqui deixa de valer quando o pod for recriado.

## Diagnóstico controlado — explicação

TLS valida o nome pedido pelo cliente; um CNAME não muda esse nome.
