# Gabarito SVC-006 — Seletores e troca azul/verde

> Consulte só depois de tentar. Enunciado: [trilhas/06-servicos/exercicios/SVC-006.md](../../trilhas/06-servicos/exercicios/SVC-006.md)

## Desafio sem pista — uma solução possível

```bash
oc create service clusterip loja-verde-teste --tcp=8080:8080 -n ac06-servicos --dry-run=client -o yaml \
  | oc set selector --local -f - app=loja,cor=verde -o yaml | oc apply -n ac06-servicos -f -
http loja-verde-teste                                       # verde: versão nova validada
oc set selector svc/loja app=loja,cor=verde -n ac06-servicos && http loja   # verde em produção
VOLTA='oc set selector svc/loja app=loja,cor=azul -n ac06-servicos'
echo "para voltar: $VOLTA"
```

## Diagnóstico controlado — explicação

Seletor sem pods = Service sem endpoints. O tráfego só é seguro quando o novo seletor tem endpoints prontos — por isso
o teste prévio por um Service próprio.
