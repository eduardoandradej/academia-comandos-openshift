# Gabarito SVC-010 — Variáveis de ambiente de Services

> Consulte só depois de tentar. Enunciado: [trilhas/06-servicos/exercicios/SVC-010.md](../../trilhas/06-servicos/exercicios/SVC-010.md)

## Desafio sem pista — uma solução possível

```bash
oc run ac06-var --image=registry.access.redhat.com/ubi9/httpd-24:latest -n ac06-servicos --restart=Never \
  --command -- sh -c 'echo "$WEB_VERDE_SERVICE_HOST:$WEB_VERDE_SERVICE_PORT"'
oc run ac06-dns --image=registry.access.redhat.com/ubi9/httpd-24:latest -n ac06-servicos --restart=Never \
  --command -- sh -c 'getent hosts web-verde'
sleep 10; oc logs ac06-var -n ac06-servicos; oc logs ac06-dns -n ac06-servicos
oc delete pod ac06-var ac06-dns -n ac06-servicos
```

Variáveis falham para Services criados depois do pod e para outros namespaces; DNS falha se o DNS do cluster estiver
indisponível (raro) ou se o nome curto for usado fora do namespace.

## Diagnóstico controlado — explicação

As variáveis são montadas no instante da criação do pod. Um Service mais novo que o pod não aparece nelas.
