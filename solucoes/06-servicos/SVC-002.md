# Gabarito SVC-002 — Anatomia de um Service: port, targetPort e portas nomeadas

> Consulte só depois de tentar. Enunciado: [trilhas/06-servicos/exercicios/SVC-002.md](../../trilhas/06-servicos/exercicios/SVC-002.md)

## Desafio sem pista — uma solução possível

```bash
cat <<'EOF' | oc apply -n ac06-servicos -f -
apiVersion: v1
kind: Service
metadata: {name: loja-https, labels: {academy.openshift.dev/managed-by: academia}}
spec:
  selector: {app: loja, cor: azul}
  ports: [{name: tls, port: 443, targetPort: https}]
EOF
oc exec ac06-cliente -n ac06-servicos -- bash -c 'timeout 3 bash -c "</dev/tcp/loja-https/443" && echo "porta 443 aberta"'
```

## Diagnóstico controlado — explicação

O `targetPort` nomeado é resolvido por pod; se nenhum contêiner declara aquele nome, o pod não entra como endpoint
com aquela porta.
