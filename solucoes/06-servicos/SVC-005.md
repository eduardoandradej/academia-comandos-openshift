# Gabarito SVC-005 — DNS interno: nomes curtos, namespaces e FQDN

> Consulte só depois de tentar. Enunciado: [trilhas/06-servicos/exercicios/SVC-005.md](../../trilhas/06-servicos/exercicios/SVC-005.md)

## Desafio sem pista — uma solução possível

```bash
oc new-project ac06-outro --skip-config-write
oc run cliente --image=registry.access.redhat.com/ubi9/httpd-24:latest -n ac06-outro --command -- sleep 600
oc wait --for=condition=Ready pod/cliente -n ac06-outro --timeout=120s
oc exec cliente -n ac06-outro -- getent hosts web-azul || echo "curto: não resolve"
oc exec cliente -n ac06-outro -- bash -c "exec 3<>/dev/tcp/web-azul.ac06-servicos/8080; printf 'GET / HTTP/1.0\r\n\r\n' >&3; tail -1 <&3"   # azul
oc delete project ac06-outro
```

Sem NetworkPolicy, pods de namespaces diferentes se alcançam (Trilha 16 trata de isolamento).

## Diagnóstico controlado — explicação

O `search` do pod em `ac06-outro` começa por `ac06-outro.svc.cluster.local`; `web-azul.ac06-outro.svc...` não existe,
e nenhum outro sufixo completa o nome.
