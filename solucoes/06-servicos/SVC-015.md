# Gabarito SVC-015 — Circuito de Services e encerramento da trilha

> Consulte só depois de tentar. Enunciado: [trilhas/06-servicos/exercicios/SVC-015.md](../../trilhas/06-servicos/exercicios/SVC-015.md)

## Desafio sem pista — uma solução possível

```bash
oc expose deployment/web-verde --port=8080 -n ac06-servicos                                     # 1
oc create service clusterip c2 --tcp=80:8080 -n ac06-servicos                                   # 2
oc get svc web-azul -n ac06-servicos -o jsonpath='{.spec.selector} {.spec.clusterIP} {.spec.ports}{"\n"}'   # 3
oc get endpointslices -n ac06-servicos -l kubernetes.io/service-name=web-azul \
  -o jsonpath='{range .items[*].endpoints[*]}{.addresses[0]} {.targetRef.name} {.conditions.ready}{"\n"}{end}'   # 4
http web-azul                                                                                    # 5
oc exec ac06-cliente -n ac06-servicos -- getent hosts web-azul.ac06-servicos.svc.cluster.local  # 6
oc exec ac06-cliente -n ac06-servicos -- grep search /etc/resolv.conf                           # 7
oc set selector svc/loja app=loja,cor=verde -n ac06-servicos                                    # 8
oc set selector svc/loja app=loja -n ac06-servicos; for i in $(seq 20); do http loja; done | sort | uniq -c   # 9
oc create service clusterip c10 --clusterip=None --tcp=8080:8080 -n ac06-servicos && oc set selector svc/c10 app=loja -n ac06-servicos; \
  oc exec ac06-cliente -n ac06-servicos -- getent ahosts c10 | awk '{print $1}' | sort -u      # 10
oc create service clusterip c11 --tcp=8080:8080 --tcp=8443:8443 -n ac06-servicos                # 11
oc create service externalname c12 --external-name=kubernetes.default.svc.cluster.local -n ac06-servicos   # 12
oc patch svc loja -n ac06-servicos --type=merge -p '{"spec":{"sessionAffinity":"ClientIP"}}'; \
  oc patch svc loja -n ac06-servicos --type=merge -p '{"spec":{"sessionAffinity":"None","sessionAffinityConfig":null}}'   # 13
oc create service nodeport c14 --tcp=8080:8080 -n ac06-servicos                                 # 14 (recusado pela quota)
diag quebrado                                                                                    # 15
```

## Diagnóstico controlado — explicação

`oc expose` e `oc create service` não aplicam o rótulo da Academia; apagar o projeto remove tudo.
