## Desafio sem pista — uma solução possível

```bash
for ip in $(oc exec ac06-cliente -n ac06-servicos -- getent ahosts loja-headless | awk '{print $1}' | sort -u); do
  printf '%s: ' "$ip"; http "$ip"
done
```

## Diagnóstico controlado — explicação

O tipo do endereçamento do Service é decidido na criação; mudar exige apagar e recriar (com novo nome ou após remover).
