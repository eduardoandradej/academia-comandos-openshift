# Gabarito SVC-003 — EndpointSlices: quem está por trás do Service

> Consulte só depois de tentar. Enunciado: [trilhas/06-servicos/exercicios/SVC-003.md](../../trilhas/06-servicos/exercicios/SVC-003.md)

## Desafio sem pista — uma solução possível

```bash
pronto() { oc get endpointslices -n ac06-servicos -l kubernetes.io/service-name="$1" -o json \
  | jq -e '[.items[].endpoints[]? | select(.conditions.ready==true)] | length > 0' >/dev/null && echo pronto || echo "sem backend pronto"; }
pronto web-azul
```

## Diagnóstico controlado — explicação

O tipo `Endpoints` continua servido por compatibilidade, mas a fonte moderna é `EndpointSlice` (`discovery.k8s.io/v1`).
