# Gabarito SVC-007 — Vários backends: balanceamento entre pods

> Consulte só depois de tentar. Enunciado: [trilhas/06-servicos/exercicios/SVC-007.md](../../trilhas/06-servicos/exercicios/SVC-007.md)

## Desafio sem pista — uma solução possível

```bash
for i in $(seq 40); do http loja; done | sort | uniq -c | awk '{printf "%s | %d | %.0f%%\n", $2, $1, $1*100/40}'
```

Com dois endpoints, a expectativa é perto de 50% cada, com variação natural da escolha aleatória.

## Diagnóstico controlado — explicação

Um seletor com `cor=azul` exclui a verde (a); endpoints não prontos não recebem tráfego (b); `sessionAffinity: ClientIP`
fixa o cliente em um backend (c).
