# Gabarito SVC-012 — Afinidade de sessão

> Consulte só depois de tentar. Enunciado: [trilhas/06-servicos/exercicios/SVC-012.md](../../trilhas/06-servicos/exercicios/SVC-012.md)

## Desafio sem pista — uma solução possível

```bash
oc patch svc loja -n ac06-servicos --type=merge -p '{"spec":{"sessionAffinity":"ClientIP"}}'
oc run ac06-cliente2 --image=registry.access.redhat.com/ubi9/httpd-24:latest -n ac06-servicos \
  --labels=academy.openshift.dev/managed-by=academia --command -- sleep 600
oc wait --for=condition=Ready pod/ac06-cliente2 -n ac06-servicos --timeout=120s
http2() { oc exec ac06-cliente2 -n ac06-servicos -- bash -c "exec 3<>/dev/tcp/loja/8080; printf 'GET / HTTP/1.0\r\n\r\n' >&3; tail -1 <&3"; }
echo "cliente1: $(for i in $(seq 10); do http loja; done | sort -u | tr '\n' ' ')"
echo "cliente2: $(for i in $(seq 10); do http2; done | sort -u | tr '\n' ' ')"
oc delete pod ac06-cliente2 -n ac06-servicos
```

Cada cliente vê uma única cor; elas podem coincidir ou não (escolha inicial aleatória). Repita até ver cores diferentes.

## Diagnóstico controlado — explicação

A afinidade mantém o mapeamento cliente → endpoint enquanto não expira.
