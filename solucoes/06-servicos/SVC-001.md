# Gabarito SVC-001 — Por que Services existem: IPs de pod mudam

> Consulte só depois de tentar. Enunciado: [trilhas/06-servicos/exercicios/SVC-001.md](../../trilhas/06-servicos/exercicios/SVC-001.md)

## Desafio sem pista — uma solução possível

```bash
antes=$(oc get svc web-azul -n ac06-servicos -o jsonpath='{.spec.clusterIP}')
ips_antes=$(oc get pods -n ac06-servicos -l cor=azul -o jsonpath='{.items[*].status.podIP}')
oc rollout restart deployment/web-azul -n ac06-servicos && oc rollout status deployment/web-azul -n ac06-servicos
depois=$(oc get svc web-azul -n ac06-servicos -o jsonpath='{.spec.clusterIP}')
ips_depois=$(oc get pods -n ac06-servicos -l cor=azul -o jsonpath='{.items[*].status.podIP}')
echo "ClusterIP: $antes -> $depois | pods: $ips_antes -> $ips_depois"
```

## Diagnóstico controlado — explicação

`ls -l /var/www/html` deve mostrar `index.html` (um link para `..data/index.html`, típico de ConfigMap montado). Se o
diretório estiver vazio ou o `DocumentRoot` for outro, a página padrão do httpd responde.
