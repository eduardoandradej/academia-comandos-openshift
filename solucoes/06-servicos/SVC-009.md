# Gabarito SVC-009 — Várias portas em um Service

> Consulte só depois de tentar. Enunciado: [trilhas/06-servicos/exercicios/SVC-009.md](../../trilhas/06-servicos/exercicios/SVC-009.md)

## Desafio sem pista — uma solução possível

```bash
oc exec ac06-cliente -n ac06-servicos -- sh -c 'command -v openssl' \
  && oc exec ac06-cliente -n ac06-servicos -- sh -c 'openssl s_client -connect loja-multi:8443 </dev/null 2>/dev/null | openssl x509 -noout -issuer -enddate' \
  || echo "sem openssl na imagem: use oc port-forward svc/loja-multi 18443:8443 e rode openssl s_client na ocp-admin"
```

## Diagnóstico controlado — explicação

Com várias portas, o nome é o que diferencia cada uma nas EndpointSlices e no DNS; a API exige.
