# Gabarito SVC-004 — Testar um Service de dentro do cluster

> Consulte só depois de tentar. Enunciado: [trilhas/06-servicos/exercicios/SVC-004.md](../../trilhas/06-servicos/exercicios/SVC-004.md)

## Desafio sem pista — uma solução possível

```bash
testa() {
  oc exec ac06-cliente -n ac06-servicos -- bash -c "
    getent hosts $1 >/dev/null || { echo 'DNS falhou'; exit; }
    exec 3<>/dev/tcp/$1/$2 2>/dev/null || { echo 'porta fechada'; exit; }
    printf 'GET / HTTP/1.0\r\n\r\n' >&3; echo \"HTTP \$(head -1 <&3 | cut -d' ' -f2)\""
}
testa web-azul 8080; testa web-azul 9999; testa nao-existe 8080
```

Para IPs, `getent hosts <ip>` pode não resolver nome reverso; nesse caso, teste só a porta.

## Diagnóstico controlado — explicação

ClusterIPs são virtuais e só existem dentro do cluster (implementados pela rede OVN-Kubernetes no nó). A `ocp-admin`, na
rede NAT do libvirt, não tem rota para eles.
