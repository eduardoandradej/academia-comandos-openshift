# Gabarito RTE-002 — O caminho da requisição: DNS, router e cabeçalho Host

> Consulte só depois de tentar. Enunciado: [trilhas/07-rotas/exercicios/RTE-002.md](../../trilhas/07-rotas/exercicios/RTE-002.md)

## Desafio sem pista — uma solução possível

```bash
curl -sS -H "Host: $HA" http://192.168.10.200/                       # 1: muda só o cabeçalho
curl -sS --resolve "$HA:80:192.168.10.200" "http://$HA/"             # 2: muda a resolução de nome do curl
```

`-H Host` mantém a URL com IP e troca o cabeçalho; `--resolve` usa a URL com o nome e força o IP — por isso também
funciona para HTTPS (o SNI acompanha o nome da URL).

## Diagnóstico controlado — explicação

Sem um `Host` que corresponda a alguma Route, o router responde com o backend padrão (503).
