# Gabarito RTE-001 — Primeira Route: do navegador ao pod

> Consulte só depois de tentar. Enunciado: [trilhas/07-rotas/exercicios/RTE-001.md](../../trilhas/07-rotas/exercicios/RTE-001.md)

## Desafio sem pista — uma solução possível

```bash
H=$(oc get route web-azul -n ac07-rotas -o jsonpath='{.spec.host}')
getent ahostsv4 "$H" | head -1                                   # (1) 192.168.10.200
timeout 3 bash -c '</dev/tcp/192.168.10.200/80' && echo "porta 80 aberta"   # (2)
curl -sS "http://$H/"                                            # (3) azul
```

## Diagnóstico controlado — explicação

Se `getent` falha para qualquer nome em `*.apps`, o problema é DNS do cliente (a/b), não a Route. O teste com
cabeçalho `Host` separa as duas coisas.
