# Gabarito RTE-012 — Ingress do Kubernetes vira Route

> Consulte só depois de tentar. Enunciado: [trilhas/07-rotas/exercicios/RTE-012.md](../../trilhas/07-rotas/exercicios/RTE-012.md)

## Desafio sem pista — uma solução possível

```bash
oc create ingress loja-ing2 -n ac07-rotas \
  --rule="ing2-ac07.apps.ocp.example.lab/azul*=web-azul:8080" \
  --rule="ing2-ac07.apps.ocp.example.lab/verde*=web-verde:8080"
oc get routes -n ac07-rotas -o json | jq -r '.items[] | select(.metadata.ownerReferences[0].name=="loja-ing2") | .metadata.name + " " + .spec.path'
```

Uma Route por regra (duas). Sem reescrita, os caminhos `/azul` e `/verde` chegam ao httpd e respondem 404 — o mesmo
efeito do RTE-004.

## Diagnóstico controlado — explicação

A Route gerada pertence ao Ingress (`ownerReferences`); o controlador a mantém igual ao que o Ingress declara.
