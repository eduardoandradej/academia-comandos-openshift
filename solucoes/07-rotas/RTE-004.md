## Desafio sem pista — uma solução possível

```bash
H=cores-ac07.apps.ocp.example.lab
oc expose svc/web-verde --name=cores-raiz --hostname=$H --path=/ -n ac07-rotas
curl -sS "http://$H/"         # verde
curl -sS "http://$H/azul"     # azul (Route com path mais longo)
```

## Diagnóstico controlado — explicação

O router entrega o caminho original; sem reescrita, o backend procura `/azul` no seu `DocumentRoot`.
