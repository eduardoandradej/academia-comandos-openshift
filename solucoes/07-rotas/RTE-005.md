# Gabarito RTE-005 — Status da Route: admitida, por qual router, com qual host

> Consulte só depois de tentar. Enunciado: [trilhas/07-rotas/exercicios/RTE-005.md](../../trilhas/07-rotas/exercicios/RTE-005.md)

## Desafio sem pista — uma solução possível

```bash
oc get routes -n ac07-rotas -o json | jq -r '.items[]
  | select(any(.status.ingress[]?.conditions[]?; .type=="Admitted" and .status!="True"))
  | .metadata.name + ": " + ([.status.ingress[].conditions[] | .reason] | join(","))'
```

Repetição 3: a mais antiga mantém o host; a nova fica não admitida.

## Diagnóstico controlado — explicação

O router só publica uma Route por par host+caminho. A recusada continua existindo como objeto, mas não recebe tráfego.
