# Gabarito RTE-015 — Circuito de Routes e encerramento da trilha

> Consulte só depois de tentar. Enunciado: [trilhas/07-rotas/exercicios/RTE-015.md](../../trilhas/07-rotas/exercicios/RTE-015.md)

## Desafio sem pista — uma solução possível

```bash
oc expose svc/web-azul -n ac07-rotas                                                                         # 1
H=$(oc get route web-azul -n ac07-rotas -o jsonpath='{.spec.host}'); curl -sS "http://$H/"                   # 2
curl -sS -H "Host: $H" http://192.168.10.200/                                                                # 3
oc expose svc/web-azul --name=c4 --hostname=c4-ac07.apps.ocp.example.lab -n ac07-rotas                        # 4
oc expose svc/web-azul --name=c5a --hostname=c5-ac07.apps.ocp.example.lab --path=/azul -n ac07-rotas; \
  oc expose svc/web-verde --name=c5v --hostname=c5-ac07.apps.ocp.example.lab --path=/verde -n ac07-rotas; \
  oc annotate route c5a c5v haproxy.router.openshift.io/rewrite-target=/ -n ac07-rotas                        # 5
oc get route c4 -n ac07-rotas -o jsonpath='{.status.ingress[0].conditions[0].type}={.status.ingress[0].conditions[0].status}{"\n"}'   # 6
oc create route edge c7 --service=web-azul --hostname=c7-ac07.apps.ocp.example.lab --insecure-policy=Redirect -n ac07-rotas   # 7
openssl s_client -connect 192.168.10.200:443 -servername c7-ac07.apps.ocp.example.lab </dev/null 2>/dev/null | openssl x509 -noout -issuer -ext subjectAltName   # 8
# 9: veja RTE-007 (openssl req ... + oc create route edge --cert --key; curl --cacert)
oc expose deployment/web-azul --name=web-azul-tls --port=8443 -n ac07-rotas 2>/dev/null; \
  oc create route passthrough c10 --service=web-azul-tls --hostname=c10-ac07.apps.ocp.example.lab -n ac07-rotas   # 10
oc create route reencrypt c11 --service=web-azul --port=8443 -n ac07-rotas --dry-run=client -o yaml           # 11
oc expose svc/web-azul --name=c12 -n ac07-rotas; oc set route-backends c12 web-azul=70 web-verde=30 -n ac07-rotas   # 12
oc annotate route c12 haproxy.router.openshift.io/disable_cookies=true -n ac07-rotas                          # 13
oc create ingress c14 --rule="c14-ac07.apps.ocp.example.lab/*=web-azul:8080" -n ac07-rotas; \
  oc get routes -n ac07-rotas -o custom-columns=NOME:.metadata.name,DONO:.metadata.ownerReferences[0].name | grep c14   # 14
rdiag web-verde                                                                                              # 15
```

## Diagnóstico controlado — explicação

Sem Route para o host, o router responde 503; o navegador só "funciona" por cache.
