# Gabarito RTE-003 — Hostname próprio e o arquivo hosts do Windows

> Consulte só depois de tentar. Enunciado: [trilhas/07-rotas/exercicios/RTE-003.md](../../trilhas/07-rotas/exercicios/RTE-003.md)

## Desafio sem pista — uma solução possível

```bash
oc expose svc/web-azul --name=www-loja --hostname=www-loja-ac07.apps.ocp.example.lab -n ac07-rotas
curl -sS http://loja-ac07.apps.ocp.example.lab/; curl -sS http://www-loja-ac07.apps.ocp.example.lab/
```

Uma Route tem um único host; para dois nomes, use duas Routes.

## Diagnóstico controlado — explicação

O Windows resolve pelo `hosts` antes do DNS; sem curinga, cada nome precisa de uma linha.
