# Gabarito RTE-014 — Roteiro de diagnóstico de Route

> Consulte só depois de tentar. Enunciado: [trilhas/07-rotas/exercicios/RTE-014.md](../../trilhas/07-rotas/exercicios/RTE-014.md)

## Desafio sem pista — uma solução possível

```bash
rdiag_tls() {
  r=$1; ns=${2:-ac07-rotas}
  t=$(oc get route "$r" -n "$ns" -o jsonpath='{.spec.tls.termination}')
  h=$(oc get route "$r" -n "$ns" -o jsonpath='{.spec.host}')
  if [ -n "$t" ]; then
    echo "terminação: $t"
    curl -sSk -o /dev/null -w "HTTPS %{http_code}\n" --resolve "$h:443:192.168.10.200" "https://$h/"
  else rdiag "$r" "$ns"; fi
}
rdiag_tls seguro
```

## Diagnóstico controlado — explicação

O 503 é a resposta padrão do router quando a Route é conhecida, mas não há destino utilizável — ou quando o host não
corresponde a nenhuma Route.
