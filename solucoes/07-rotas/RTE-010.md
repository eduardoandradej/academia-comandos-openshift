# Gabarito RTE-010 — A/B com pesos: dividir o tráfego entre Services

> Consulte só depois de tentar. Enunciado: [trilhas/07-rotas/exercicios/RTE-010.md](../../trilhas/07-rotas/exercicios/RTE-010.md)

## Desafio sem pista — uma solução possível

```bash
for p in 10 50 90 100; do
  oc set route-backends ab web-azul=$((100-p)) web-verde=$p -n ac07-rotas >/dev/null; sleep 5
  printf '%3s%% verde: ' "$p"; for i in $(seq 40); do curl -sS http://ab-ac07.apps.ocp.example.lab/; done | sort | uniq -c | tr '\n' ' '; echo
done
```

## Diagnóstico controlado — explicação

O router grava um cookie que fixa o cliente em um backend; com ele, pesos só se manifestam entre clientes diferentes.
