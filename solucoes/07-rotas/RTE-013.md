# Gabarito RTE-013 — O Ingress Controller visto pelo admin (somente leitura)

> Consulte só depois de tentar. Enunciado: [trilhas/07-rotas/exercicios/RTE-013.md](../../trilhas/07-rotas/exercicios/RTE-013.md)

## Desafio sem pista — uma solução possível

```bash
oc get ingresscontroller default -n openshift-ingress-operator -o jsonpath='domínio: {.status.domain}{"\n"}estratégia: {.status.endpointPublishingStrategy.type}{"\n"}'
oc get pods -n openshift-ingress -o jsonpath='{range .items[*]}router: {.spec.nodeName} {.status.hostIP} hostNetwork={.spec.hostNetwork}{"\n"}{end}'
N=$(oc get ingresscontroller default -n openshift-ingress-operator -o jsonpath='{.spec.defaultCertificate.name}')
echo "certificado: ${N:-router-certs-default (gerado pelo operador)}"
```

O nome `router-certs-default` é o padrão quando nenhum certificado próprio foi configurado; confirme na listagem de Secrets.

## Diagnóstico controlado — explicação

Se a Console também caiu, o problema é comum a todas as Routes: router, Ingress Operator ou o próprio nó.
