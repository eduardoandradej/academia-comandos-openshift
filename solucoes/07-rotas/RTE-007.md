# Gabarito RTE-007 — Edge com certificado próprio

> Consulte só depois de tentar. Enunciado: [trilhas/07-rotas/exercicios/RTE-007.md](../../trilhas/07-rotas/exercicios/RTE-007.md)

## Desafio sem pista — uma solução possível

```bash
cd /tmp/ac07
openssl req -x509 -newkey rsa:2048 -nodes -days 30 -keyout ca.key -out ca.crt -subj "/CN=Academia CA de treino"
openssl req -newkey rsa:2048 -nodes -keyout site.key -out site.csr -subj "/CN=ca-ac07.apps.ocp.example.lab"
printf 'subjectAltName=DNS:ca-ac07.apps.ocp.example.lab\n' > site.ext
openssl x509 -req -in site.csr -CA ca.crt -CAkey ca.key -CAcreateserial -days 30 -extfile site.ext -out site.crt
oc create route edge ca-ac07 --service=web-azul --hostname=ca-ac07.apps.ocp.example.lab \
  --cert=site.crt --key=site.key --ca-cert=ca.crt -n ac07-rotas
curl -sS --cacert ca.crt https://ca-ac07.apps.ocp.example.lab/      # azul
cd - >/dev/null
```

## Diagnóstico controlado — explicação

O cliente compara o nome pedido com o SAN do certificado; o CN sozinho não basta para clientes modernos.
