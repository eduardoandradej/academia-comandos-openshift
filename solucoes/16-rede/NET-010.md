# Gabarito NET-010 — Quais políticas valem para este pod?

> Consulte só depois de tentar. Enunciado: [trilhas/16-rede/exercicios/NET-010.md](../../trilhas/16-rede/exercicios/NET-010.md)

## Desafio sem pista — uma solução possível

```bash
politicas_de() {
  local p=$1 ns=${2:-ac16-rede} rot
  rot=$(oc get pod "$p" -n "$ns" -o json | jq -c '.metadata.labels // {}')
  oc get networkpolicy -n "$ns" -o json | jq -r --argjson r "$rot" '
    .items[] | select((.spec.podSelector.matchLabels // {}) as $m | all($m | to_entries[]; $r[.key] == .value))
    | "\(.spec.policyTypes | join(","))\t\(.metadata.name)"' | sort
}
politicas_de ac16-local
politicas_de "$(oc get pod -n ac16-rede -l cor=azul -o jsonpath='{.items[0].metadata.name}')"
```

A função trata só `matchLabels` (o caso dos manifestos da trilha); `matchExpressions` exigiria mais lógica.

## Diagnóstico controlado — explicação

A seleção é dinâmica: mudar rótulos muda imediatamente quais políticas valem.
