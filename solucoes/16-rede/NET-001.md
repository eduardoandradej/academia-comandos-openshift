# Gabarito NET-001 — A rede do cluster vista pelo admin (somente leitura)

> Consulte só depois de tentar. Enunciado: [trilhas/16-rede/exercicios/NET-001.md](../../trilhas/16-rede/exercicios/NET-001.md)

## Desafio sem pista — uma solução possível

```bash
ac-admin
oc get network.config.openshift.io cluster -o jsonpath='{.status.clusterNetwork[0].cidr} {.status.serviceNetwork[0]}{"\n"}'
oc get svc kubernetes -n default -o jsonpath='{.spec.clusterIP}{"\n"}'
oc get pods -n openshift-console -o jsonpath='{.items[0].status.podIP}{"\n"}'
python3 -c 'import ipaddress,sys; print(ipaddress.ip_address(sys.argv[1]) in ipaddress.ip_network(sys.argv[2]))' <IP-do-pod> <clusterNetwork>
ac-dev
```

## Diagnóstico controlado — explicação

As faixas de pods e Services são parte da instalação; sobrepor redes locais causa rotas ambíguas.
