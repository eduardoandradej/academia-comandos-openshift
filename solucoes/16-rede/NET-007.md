# Gabarito NET-007 — Routes depois do isolamento: liberar o router

> Consulte só depois de tentar. Enunciado: [trilhas/16-rede/exercicios/NET-007.md](../../trilhas/16-rede/exercicios/NET-007.md)

## Desafio sem pista — uma solução possível

```bash
H=$(oc get route web-azul -n ac16-rede -o jsonpath='{.spec.host}')
[ "$(curl -sS -m 5 "http://$H/")" = azul ] && [ "$(t ac16-intruso ac16-vizinho web-azul.ac16-rede.svc)" = FALHOU ] && echo OK || echo "contrato violado"
```

## Diagnóstico controlado — explicação

O router é um cliente como outro qualquer: precisa ser permitido pela política do destino.
