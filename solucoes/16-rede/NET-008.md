# Gabarito NET-008 — Negar a saída sem quebrar o DNS

> Consulte só depois de tentar. Enunciado: [trilhas/16-rede/exercicios/NET-008.md](../../trilhas/16-rede/exercicios/NET-008.md)

## Desafio sem pista — uma solução possível

```bash
oc delete networkpolicy ac16-dns -n ac16-rede
sed 's/port: 5353/port: 53/; s/name: ac16-dns/name: ac16-dns-53/' manifests/networkpolicies/50-permitir-dns.yaml | oc apply -n ac16-rede -f -
oc exec ac16-local -n ac16-rede -- timeout 5 getent hosts web-azul || echo "com 53: FALHOU"
oc delete networkpolicy ac16-dns-53 -n ac16-rede
oc apply -f manifests/networkpolicies/50-permitir-dns.yaml -n ac16-rede
oc exec ac16-local -n ac16-rede -- getent hosts web-azul && echo "com 5353: ok"
```

## Diagnóstico controlado — explicação

A política é avaliada no pacote já traduzido para o pod de DNS, que escuta na 5353.
