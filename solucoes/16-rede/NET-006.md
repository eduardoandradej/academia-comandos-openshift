# Gabarito NET-006 — Portas, nomes de porta e protocolos

> Consulte só depois de tentar. Enunciado: [trilhas/16-rede/exercicios/NET-006.md](../../trilhas/16-rede/exercicios/NET-006.md)

## Desafio sem pista — uma solução possível

```bash
oc expose deployment/web-verde --name=web-verde-80 --port=80 --target-port=8080 -n ac16-rede
mk() { cat <<EOF | oc apply -n ac16-rede -f -
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata: {name: ac16-porta-$1, labels: {academy.openshift.dev/managed-by: academia}}
spec:
  podSelector: {matchLabels: {cor: verde}}
  policyTypes: [Ingress]
  ingress:
    - from: [{namespaceSelector: {matchLabels: {kubernetes.io/metadata.name: ac16-vizinho}}}]
      ports: [{protocol: TCP, port: $1}]
EOF
}
mk 80;   t ac16-intruso ac16-vizinho web-verde-80.ac16-rede.svc 80     # FALHOU
oc delete networkpolicy ac16-porta-80 -n ac16-rede
mk 8080; t ac16-intruso ac16-vizinho web-verde-80.ac16-rede.svc 80     # verde
```

## Diagnóstico controlado — explicação

O Service traduz 80 → 8080 antes de a política ser avaliada no pod de destino.
