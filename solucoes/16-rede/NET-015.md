## Desafio sem pista — uma solução possível

```bash
oc get network.config.openshift.io cluster -o jsonpath='{.status.networkType}'        # 1 (admin)
matriz                                                                                # 2 (NET-002)
oc apply -f manifests/networkpolicies/00-negar-entrada.yaml -n ac16-rede                                   # 3
oc apply -f manifests/networkpolicies/10-permitir-mesmo-projeto.yaml -n ac16-rede                          # 4
oc apply -f manifests/networkpolicies/20-permitir-cliente-vizinho.yaml -n ac16-rede                        # 5
# 6: separar namespaceSelector e podSelector em itens diferentes de from (NET-005)
# 7: ports: [{port: http}] (NET-006)
oc apply -f manifests/networkpolicies/30-permitir-router.yaml -n ac16-rede                                 # 8
oc apply -f manifests/networkpolicies/40-negar-saida.yaml -f manifests/networkpolicies/50-permitir-dns.yaml -n ac16-rede          # 9
oc apply -f manifests/networkpolicies/60-permitir-saida-loja.yaml -n ac16-rede                             # 10
# 11: politicas_de (NET-010); 12: NET-011
openssl s_client -connect 192.168.10.200:443 -servername <host> </dev/null | openssl x509 -noout -subject -enddate   # 13
oc annotate svc web-verde service.beta.openshift.io/serving-cert-secret-name=web-verde-tls   # 14
# 15: diag_con (NET-014)
```

## Diagnóstico controlado — explicação

Sem `-n`, o `oc apply` usa o projeto atual — o motivo de a Academia sempre informar o projeto.
