# Gabarito NET-005 — Liberar um cliente de outro projeto (e o AND × OR)

> Consulte só depois de tentar. Enunciado: [trilhas/16-rede/exercicios/NET-005.md](../../trilhas/16-rede/exercicios/NET-005.md)

## Desafio sem pista — uma solução possível

```bash
cat <<'EOF' | oc apply -n ac16-rede -f -
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata:
  name: ac16-clientes-qualquer-projeto
  labels:
    academy.openshift.dev/managed-by: academia
spec:
  podSelector:
    matchLabels:
      app: loja
  policyTypes: [Ingress]
  ingress:
    - from:
        - namespaceSelector: {}
          podSelector:
            matchLabels:
              app: ac16-cliente
      ports:
        - {protocol: TCP, port: 8080}
EOF
t ac16-local ac16-rede web-azul; t ac16-cliente ac16-vizinho web-azul.ac16-rede.svc; t ac16-intruso ac16-vizinho web-azul.ac16-rede.svc
oc delete networkpolicy ac16-clientes-qualquer-projeto -n ac16-rede
```

`namespaceSelector: {}` no mesmo item = "em qualquer projeto"; o `podSelector` restringe aos clientes.

## Diagnóstico controlado — explicação

Cada item da lista `from` é uma alternativa; dentro de um item, os seletores se somam como condições.
