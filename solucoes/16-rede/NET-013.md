# Gabarito NET-013 — Certificados de serviço: TLS dentro do cluster

> Consulte só depois de tentar. Enunciado: [trilhas/16-rede/exercicios/NET-013.md](../../trilhas/16-rede/exercicios/NET-013.md)

## Desafio sem pista — uma solução possível

```bash
oc get configmap ac16-ca -n ac16-rede -o jsonpath='{.data.service-ca\.crt}' > /tmp/ac16-ca.crt
oc get secret web-verde-tls -n ac16-rede -o jsonpath='{.data.tls\.crt}' | base64 -d > /tmp/ac16-svc.crt
openssl verify -CAfile /tmp/ac16-ca.crt -untrusted /tmp/ac16-svc.crt /tmp/ac16-svc.crt
rm -f /tmp/ac16-ca.crt /tmp/ac16-svc.crt
```

O `tls.crt` pode conter a cadeia (certificado + intermediária); `-untrusted` a usa para montar o caminho até a CA.

## Diagnóstico controlado — explicação

O controlador `service-ca` não sobrescreve Secrets que não criou.
