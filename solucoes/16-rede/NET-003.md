# Gabarito NET-003 — Negar toda a entrada (default deny)

> Consulte só depois de tentar. Enunciado: [trilhas/16-rede/exercicios/NET-003.md](../../trilhas/16-rede/exercicios/NET-003.md)

## Desafio sem pista — uma solução possível

```bash
oc delete networkpolicy ac16-negar-entrada -n ac16-rede
sed 's/podSelector: {}/podSelector:\n    matchLabels:\n      app: loja/; s/name: ac16-negar-entrada/name: ac16-negar-loja/' manifests/networkpolicies/00-negar-entrada.yaml \
  | oc apply -n ac16-rede -f -
oc get networkpolicy ac16-negar-loja -n ac16-rede -o jsonpath='{.spec.podSelector}{"\n"}'
matriz 2>/dev/null || t ac16-cliente ac16-vizinho web-azul.ac16-rede.svc
oc delete networkpolicy ac16-negar-loja -n ac16-rede && oc apply -f manifests/networkpolicies/00-negar-entrada.yaml -n ac16-rede
```

## Diagnóstico controlado — explicação

O OVN descarta silenciosamente pacotes não permitidos; o cliente espera até o timeout.
