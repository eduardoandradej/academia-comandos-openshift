# Gabarito NET-011 — Políticas do administrador e EgressFirewall (somente leitura)

> Consulte só depois de tentar. Enunciado: [trilhas/16-rede/exercicios/NET-011.md](../../trilhas/16-rede/exercicios/NET-011.md)

## Desafio sem pista — uma solução possível

```bash
ac-admin
cat <<'EOF' | oc apply --dry-run=server -n ac16-rede -f -
apiVersion: k8s.ovn.org/v1
kind: EgressFirewall
metadata:
  name: default            # o OVN exige este nome; um por namespace
spec:
  egress:
    - type: Allow
      to:
        dnsName: registry.access.redhat.com
    - type: Deny
      to:
        cidrSelector: 0.0.0.0/0
EOF
ac-dev
```

Validado sem criar. Aplicado de verdade, ele bloquearia também qualquer outra saída externa do projeto.

## Diagnóstico controlado — explicação

A ANP é avaliada antes das NetworkPolicies; um `Deny` dela é final.
