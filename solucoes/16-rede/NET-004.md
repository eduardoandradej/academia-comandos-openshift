# Gabarito NET-004 — Liberar o próprio projeto

> Consulte só depois de tentar. Enunciado: [trilhas/16-rede/exercicios/NET-004.md](../../trilhas/16-rede/exercicios/NET-004.md)

## Desafio sem pista — uma solução possível

```bash
oc delete networkpolicy ac16-negar-entrada -n ac16-rede
t ac16-local   ac16-rede    web-azul                       # azul
t ac16-cliente ac16-vizinho web-azul.ac16-rede.svc         # FALHOU
oc apply -f manifests/networkpolicies/00-negar-entrada.yaml -n ac16-rede
```

A `ac16-mesmo-projeto` já seleciona **todos** os pods (`podSelector: {}`) para `Ingress`: eles passam a aceitar
apenas o que ela libera. A negação explícita é redundante aqui, mas documenta a intenção e protege contra
alguém apagar ou estreitar a política de liberação.

## Diagnóstico controlado — explicação

O router e o monitoramento ficam em outros namespaces: "só o próprio projeto" também os bloqueia.
