# Gabarito RES-015 — Circuito de resiliência e encerramento da trilha

> Consulte só depois de tentar. Enunciado: [trilhas/11-resiliencia/exercicios/RES-015.md](../../trilhas/11-resiliencia/exercicios/RES-015.md)

## Desafio sem pista — uma solução possível

```bash
oc set resources deployment/ac11-app --requests=cpu=50m,memory=64Mi --limits=cpu=100m,memory=128Mi    # 1
oc adm top pods --containers                                                                          # 2
oc exec deploy/ac11-app -- cat /sys/fs/cgroup/cpu.stat                                                # 3
oc set probe deployment/ac11-app --readiness --open-tcp=8080                                          # 4
oc set probe deployment/ac11-app --liveness -- test -f /tmp/vivo                                      # 5 (crie o arquivo antes)
oc set probe deployment/ac11-lento --startup --open-tcp=8080 --period-seconds=2 --failure-threshold=30   # 6
# 7: periodSeconds x failureThreshold
oc exec deploy/ac11-app -- sh -c 'kill 1'; oc delete pod <pod>                                        # 8
oc patch deployment ac11-app --type=json -p '[{"op":"add","path":"/spec/template/spec/containers/0/lifecycle","value":{"preStop":{"exec":{"command":["sh","-c","sleep 10"]}}}}]'   # 9
oc patch deployment ac11-app --type=merge -p '{"spec":{"strategy":{"rollingUpdate":{"maxUnavailable":0,"maxSurge":1}}}}'   # 10
oc autoscale deployment/ac11-app --min=1 --max=2 --cpu-percent=50                                     # 11
oc get hpa ac11-app -o jsonpath='{.status.conditions}'                                              # 12
oc create poddisruptionbudget ac11-pdb --selector=app=ac11-app --min-available=1                      # 13
# 14: roteiro do RES-014; 15: limpeza acima
```

## Diagnóstico controlado — explicação

Um `oc exec` em segundo plano continua rodando no pod até terminar ou até o pod sumir.
