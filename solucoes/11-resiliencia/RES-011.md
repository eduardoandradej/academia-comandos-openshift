# Gabarito RES-011 — HPA: escalar por CPU (até 2 réplicas)

> Consulte só depois de tentar. Enunciado: [trilhas/11-resiliencia/exercicios/RES-011.md](../../trilhas/11-resiliencia/exercicios/RES-011.md)

## Desafio sem pista — uma solução possível

```bash
oc patch hpa ac11-app -n ac11-resiliencia --type=merge -p '{"spec":{"behavior":{"scaleDown":{"stabilizationWindowSeconds":60,"policies":[{"type":"Pods","value":1,"periodSeconds":30}]}}}}'
oc exec deploy/ac11-app -n ac11-resiliencia -- timeout 90 sh -c 'while :; do :; done'
t0=$(date +%s)
until [ "$(oc get hpa ac11-app -n ac11-resiliencia -o jsonpath='{.status.currentReplicas}')" = 1 ]; do sleep 10; done
echo "voltou a 1 em $(( $(date +%s) - t0 )) s"
```

## Diagnóstico controlado — explicação

O HPA precisa de um denominador: porcentagem de CPU é sempre relativa ao `requests.cpu`.
