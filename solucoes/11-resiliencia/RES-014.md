# Gabarito RES-014 — Roteiro de diagnóstico de resiliência

> Consulte só depois de tentar. Enunciado: [trilhas/11-resiliencia/exercicios/RES-014.md](../../trilhas/11-resiliencia/exercicios/RES-014.md)

## Desafio sem pista — uma solução possível

```bash
diag_res() {
  local d=$1 ns=${2:-ac11-resiliencia} sel
  sel=$(oc get deployment "$d" -n "$ns" -o json | jq -r '.spec.selector.matchLabels | to_entries | map("\(.key)=\(.value)") | join(",")')
  echo "1 reinícios: $(oc get pods -n "$ns" -l "$sel" -o jsonpath='{range .items[*]}{.status.containerStatuses[0].restartCount} {end}')"
  echo "2 último término: $(oc get pods -n "$ns" -l "$sel" -o jsonpath='{.items[0].status.containerStatuses[0].lastState.terminated.reason} {.items[0].status.containerStatuses[0].lastState.terminated.exitCode}')"
  echo "3 probes: $(oc get events -n "$ns" --field-selector reason=Unhealthy -o json | jq -r --arg d "$d" '[.items[] | select(.involvedObject.name|startswith($d))] | last | .message // "sem falhas"' | cut -c1-80)"
  echo "4 recursos: $(oc adm top pods -n "$ns" -l "$sel" --no-headers 2>/dev/null | head -1 || echo 'sem métricas')"
  echo "5 hpa: $(oc get hpa -n "$ns" -o json | jq -r --arg d "$d" '[.items[] | select(.spec.scaleTargetRef.name==$d) | .status.conditions[]? | select(.type=="ScalingActive") | "\(.status) \(.reason)"] | first // "sem HPA"')"
  echo "6 pdb: $(oc get pdb -n "$ns" -o json | jq -r '[.items[] | "\(.metadata.name)=\(.status.disruptionsAllowed)"] | join(" ") // ""')"
}
diag_res ac11-agressivo
```

## Diagnóstico controlado — explicação

Uma liveness com timeout menor que o próprio comando falha sempre — o contêiner nunca chega a ficar estável.
