# Gabarito RES-003 — CPU estrangulada × memória morta

> Consulte só depois de tentar. Enunciado: [trilhas/11-resiliencia/exercicios/RES-003.md](../../trilhas/11-resiliencia/exercicios/RES-003.md)

## Desafio sem pista — uma solução possível

```bash
le() { oc exec deploy/ac11-app -n ac11-resiliencia -- awk '/^nr_periods|^nr_throttled/{print $2}' /sys/fs/cgroup/cpu.stat | paste -sd' '; }
read -r p0 t0 <<<"$(le)"
oc exec deploy/ac11-app -n ac11-resiliencia -- timeout 20 sh -c 'while :; do :; done'
read -r p1 t1 <<<"$(le)"
echo "estrangulado em $(( (t1-t0) * 100 / (p1-p0) ))% dos períodos"
```

Perto de 100%: o laço quer 1 vCPU e recebe 0,1.

## Diagnóstico controlado — explicação

CPU é recurso compressível (pode ser racionado); memória não é.
