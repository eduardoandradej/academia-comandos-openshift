# Gabarito RES-009 — Desligamento gracioso: preStop e terminationGracePeriod

> Consulte só depois de tentar. Enunciado: [trilhas/11-resiliencia/exercicios/RES-009.md](../../trilhas/11-resiliencia/exercicios/RES-009.md)

## Desafio sem pista — uma solução possível

```bash
oc patch deployment ac11-app -n ac11-resiliencia --type=json -p '[{"op":"replace","path":"/spec/template/spec/containers/0/lifecycle/preStop/exec/command","value":["sh","-c","sleep 30"]}]'
oc rollout status deployment/ac11-app -n ac11-resiliencia
P=$(oc get pod -n ac11-resiliencia -l app=ac11-app -o jsonpath='{.items[0].metadata.name}')
t0=$(date +%s); oc delete pod "$P" -n ac11-resiliencia; echo "levou $(( $(date +%s) - t0 )) s"     # ~20
oc get events -n ac11-resiliencia --field-selector involvedObject.name="$P" | grep -i prestop
oc patch deployment ac11-app -n ac11-resiliencia --type=json -p '[{"op":"replace","path":"/spec/template/spec/containers/0/lifecycle/preStop/exec/command","value":["sh","-c","sleep 10"]}]'
```

## Diagnóstico controlado — explicação

O shell como PID 1 não repassa SIGTERM ao filho; o contêiner só termina no SIGKILL.
