# Gabarito RES-012 — Ler as decisões do HPA

> Consulte só depois de tentar. Enunciado: [trilhas/11-resiliencia/exercicios/RES-012.md](../../trilhas/11-resiliencia/exercicios/RES-012.md)

## Desafio sem pista — uma solução possível

```bash
oc get hpa ac11-app -n ac11-resiliencia -o json | jq -r '
  "CPU \(.status.currentMetrics[0].resource.current.averageUtilization // "?")%/\(.spec.metrics[0].resource.target.averageUtilization)%"
  + " réplicas \(.status.currentReplicas)/\(.status.desiredReplicas)"
  + " motivo: " + ([.status.conditions[] | select(.status!="True" or .type=="ScalingLimited") | "\(.type)=\(.status) \(.reason)"] | join("; "))'
```

## Diagnóstico controlado — explicação

`TooManyReplicas` significa que o cálculo pedia mais réplicas que o máximo permitido.
