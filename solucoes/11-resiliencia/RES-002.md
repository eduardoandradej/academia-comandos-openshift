# Gabarito RES-002 — Medir consumo: oc adm top e a Metrics API

> Consulte só depois de tentar. Enunciado: [trilhas/11-resiliencia/exercicios/RES-002.md](../../trilhas/11-resiliencia/exercicios/RES-002.md)

## Desafio sem pista — uma solução possível

```bash
oc get --raw "/apis/metrics.k8s.io/v1beta1/namespaces/ac11-resiliencia/pods" > /tmp/ac11-uso.json
oc get pods -n ac11-resiliencia -o json | jq -r --slurpfile u /tmp/ac11-uso.json '
  def m: if test("n$") then (.[:-1]|tonumber/1000000) elif test("m$") then (.[:-1]|tonumber) else (tonumber*1000) end;
  .items[] | .metadata.name as $p | (.spec.containers[0].resources.requests.cpu // "0") as $r
  | ($u[0].items[] | select(.metadata.name==$p) | .containers[0].usage.cpu) as $c
  | "\($p)\tuso=\($c|m|floor)m\treq=\($r|m)m\t\(if ($r|m)>0 then (($c|m)/($r|m)*100|floor|tostring)+"%" else "-" end)"'
rm -f /tmp/ac11-uso.json
```

## Diagnóstico controlado — explicação

A Metrics API é um serviço agregado; quando o backend não responde, `oc adm top` e o HPA ficam sem dados.
