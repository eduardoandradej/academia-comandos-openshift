# Gabarito RES-008 — Autocura: quem recria o quê

> Consulte só depois de tentar. Enunciado: [trilhas/11-resiliencia/exercicios/RES-008.md](../../trilhas/11-resiliencia/exercicios/RES-008.md)

## Desafio sem pista — uma solução possível

```bash
for i in $(seq 8); do
  oc get pod ac11-quebra -n ac11-resiliencia -o json | jq -r '.status.containerStatuses[0] | "\(.restartCount)\t\(.lastState.terminated.finishedAt // "-")\t\(.state | keys[0])"'
  sleep 30
done | uniq
```

Cada nova linha de `restartCount` mostra o momento do término; a diferença entre términos dobra até o teto de 5 min.

## Diagnóstico controlado — explicação

`ownerReferences` diz quem recriará o pod; sem dono, a remoção é definitiva.
