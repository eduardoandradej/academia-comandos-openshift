# Gabarito RES-005 — Liveness probe: reiniciar o que travou

> Consulte só depois de tentar. Enunciado: [trilhas/11-resiliencia/exercicios/RES-005.md](../../trilhas/11-resiliencia/exercicios/RES-005.md)

## Desafio sem pista — uma solução possível

```bash
oc get pods -n ac11-resiliencia -l app=ac11-app -o jsonpath='{.items[0].status.containerStatuses[0].lastState.terminated}{"\n"}'
```

O kubelet envia SIGTERM (143 = 128+15 se o processo sai com o sinal) e, após o `terminationGracePeriodSeconds`,
SIGKILL (137 = 128+9). O motivo aparece como `Error` ou `Completed`; o evento conta que foi a liveness.

## Diagnóstico controlado — explicação

O padrão de `timeoutSeconds` é 1 s: um comando lento parece "morto" para a probe.
