# Gabarito ORI-012 — Baseline de cotas e limites no projeto de treino

> Consulte só depois de tentar. Enunciado: [trilhas/00-orientacao/exercicios/ORI-012.md](../../trilhas/00-orientacao/exercicios/ORI-012.md)

## Desafio sem pista — uma solução possível

```bash
cp manifests/baseline-seguro/quota-limitrange.yaml /tmp/ac-quota-8.yaml
sed -i 's/pods: "6"/pods: "8"/' /tmp/ac-quota-8.yaml
oc diff -f /tmp/ac-quota-8.yaml -n ac00-orientacao     # mostra -pods: "6" / +pods: "8"
rm -f /tmp/ac-quota-8.yaml
```

## Diagnóstico controlado — explicação

`oc diff` segue a convenção do `diff`: 0 = sem diferenças, 1 = há diferenças, >1 = erro. Hipótese (a).

## Erros comuns

- Editar o manifesto do repositório em vez de uma cópia.
- Aplicar a baseline com `developer`: a criação de ResourceQuota é negada.
