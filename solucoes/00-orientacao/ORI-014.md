# Gabarito ORI-014 — Pensar antes de mutar: can-i, dry-run e rótulos

> Consulte só depois de tentar. Enunciado: [trilhas/00-orientacao/exercicios/ORI-014.md](../../trilhas/00-orientacao/exercicios/ORI-014.md)

## Desafio sem pista — uma solução possível

```bash
NS=ac00-orientacao
for n in a b c; do
  oc create configmap "ac00-$n" --from-literal=X="$n" --dry-run=client -o yaml \
    | oc label --local -f - academy.openshift.dev/managed-by=academia -o yaml \
    | oc apply -n "$NS" -f -
done
oc create configmap ac00-sem-rotulo --from-literal=X=d -n "$NS"
oc delete configmap -l academy.openshift.dev/managed-by=academia -n "$NS"
oc get configmap ac00-sem-rotulo -n "$NS" -o name      # sobreviveu
oc delete configmap ac00-sem-rotulo -n "$NS"
```

## Diagnóstico controlado — explicação

O `creationTimestamp` diz se o objeto é de agora ou antigo; o rótulo diz se ele é da Academia. Em ambos os casos, a
forma `apply` evita o erro nas próximas repetições.

## Erros comuns

- `oc delete configmap --all -n ac00-orientacao`: apagaria também os ConfigMaps injetados pelo sistema (que voltam, mas a prática é errada).
- Esquecer `-n` e apagar por rótulo no projeto atual errado.
