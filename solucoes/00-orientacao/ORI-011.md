# Gabarito ORI-011 — Criar o projeto de treino ac00-orientacao

> Consulte só depois de tentar. Enunciado: [trilhas/00-orientacao/exercicios/ORI-011.md](../../trilhas/00-orientacao/exercicios/ORI-011.md)

## Desafio sem pista — uma solução possível

```bash
oc get project ac00-orientacao -o name >/dev/null 2>&1 \
  && oc project ac00-orientacao \
  || oc new-project ac00-orientacao --display-name='Academia 00 - Orientação'
```

Na segunda execução, o `get` encontra o projeto e apenas o seleciona com `oc project`.

## Diagnóstico controlado — explicação

`oc auth can-i patch namespaces/ac00-orientacao` responde `no`: o papel `admin` concedido pelo autoprovisionamento tem
efeito *dentro* do namespace (pods, services, rolebindings), mas o objeto Namespace em si é de cluster. Hipótese (a).

## Alternativas válidas

- `oc new-project ac00-orientacao 2>/dev/null || oc project ac00-orientacao` — mais curta, mas esconde outros erros além de `AlreadyExists`.

## Erros comuns

- Usar `oc create namespace` como developer: em geral é negado; o caminho do usuário comum é `oc new-project`.
- Não esperar a exclusão terminar e tentar recriar o mesmo nome (erro de namespace em `Terminating`).
