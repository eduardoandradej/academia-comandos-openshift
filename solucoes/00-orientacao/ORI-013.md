> Consulte só depois de tentar. Enunciado: [trilhas/00-orientacao/exercicios/ORI-013.md](../../trilhas/00-orientacao/exercicios/ORI-013.md)

## Desafio sem pista — uma solução possível

```bash
oc get resourcequota ac-quota -n ac00-orientacao -o json \
  | jq -r '.status as $s | $s.hard | keys[] | "\(.): \($s.used[.] // "0")/\($s.hard[.])"' | sort
```

## Diagnóstico controlado — explicação

A mensagem cita `exceeded quota: ac-quota` e `limited: services.loadbalancers=0`: a quota (hipótese a) recusou antes
da gravação. Se fosse permissão, a mensagem seria `Forbidden ... cannot create resource "services"`.
