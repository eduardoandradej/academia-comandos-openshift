# Gabarito OPS-014 — Roteiro de diagnóstico de operador degradado

> Consulte só depois de tentar. Enunciado: [trilhas/18-operadores/exercicios/OPS-014.md](../../trilhas/18-operadores/exercicios/OPS-014.md)

## Desafio sem pista — uma solução possível

```bash
incidente_co() {
  local co=$1 nss opns
  echo "1 condição: $(oc get co "$co" -o json | jq -r '[.status.conditions[] | select((.type=="Degraded" and .status=="True") or (.type=="Available" and .status!="True") or (.type=="Progressing" and .status=="True")) | "\(.type)=\(.status) \(.reason // "")"] | join("; ") | if .=="" then "estado ideal" else . end')"
  nss=$(oc get co "$co" -o json | jq -r '[.status.relatedObjects[] | select(.resource=="namespaces") | .name] | unique | join(" ")')
  echo "2 namespaces: $nss"
  echo "3 pods não Running: $(for n in $nss; do oc get pods -n "$n" --no-headers 2>/dev/null | awk -v n="$n" '$3!="Running" && $3!="Completed" {printf "%s/%s(%s) ", n, $1, $3}'; done)"
  echo "4 último aviso: $(for n in $nss; do oc get events -n "$n" --field-selector type=Warning -o json 2>/dev/null | jq -r '.items[-1] | select(.) | "\(.lastTimestamp) \(.reason) \(.message | .[0:80])"'; done | sort | tail -1)"
  opns=$(tr ' ' '\n' <<<"$nss" | grep -m1 -- '-operator$')
  echo "5 último erro do operador: $( [ -n "$opns" ] && oc logs -n "$opns" "$(oc get deploy -n "$opns" -o name | head -1)" --tail=200 2>/dev/null | grep -iE '^E[0-9]|error' | tail -1 | cut -c1-120)"
  echo "6 coleta (com autorização): oc adm inspect co/$co --dest-dir=<HD>/inspect-$co-$(date +%F)"
}
incidente_co ingress
```

## Diagnóstico controlado — explicação

O operador de autenticação testa a própria Route; problemas de DNS do curinga aparecem como degradação dele.
