# Gabarito OPS-004 — managementState e overrides: o que não se deve tocar (leitura)

> Consulte só depois de tentar. Enunciado: [trilhas/18-operadores/exercicios/OPS-004.md](../../trilhas/18-operadores/exercicios/OPS-004.md)

## Desafio sem pista — uma solução possível

```bash
for r in $(oc api-resources --api-group=operator.openshift.io -o name); do
  oc get "$r" cluster -o json 2>/dev/null | jq -r --arg r "$r" '
    select((.spec.managementState // "Managed") != "Managed" or ((.spec.unsupportedConfigOverrides // {}) | length) > 0)
    | "\($r)\tstate=\(.spec.managementState // "-")\toverrides=\(.spec.unsupportedConfigOverrides | tostring)"'
done
```

## Diagnóstico controlado — explicação

`overrides` no ClusterVersion faz o CVO ignorar um componente — e por isso ele bloqueia atualizações.
