# Gabarito OPS-001 — ClusterVersion: versão, canal, histórico e atualizações disponíveis

> Consulte só depois de tentar. Enunciado: [trilhas/18-operadores/exercicios/OPS-001.md](../../trilhas/18-operadores/exercicios/OPS-001.md)

## Desafio sem pista — uma solução possível

```bash
oc get clusterversion version -o json | jq -r '
  "versão: \(.status.desired.version)",
  "desde: \(.status.history[0].completionTime // .status.history[0].startedTime)",
  "canal: \(.spec.channel // "(nenhum)")",
  "próxima recomendada: \(((.status.availableUpdates // []) | map(.version) | sort | last) // "nenhuma")"'
```

## Diagnóstico controlado — explicação

O CVO consulta um serviço externo para conhecer o grafo de atualizações; sem ele, apenas não sugere versões.
