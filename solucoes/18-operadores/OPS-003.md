# Gabarito OPS-003 — Do operador ao operand: seguir os relatedObjects

> Consulte só depois de tentar. Enunciado: [trilhas/18-operadores/exercicios/OPS-003.md](../../trilhas/18-operadores/exercicios/OPS-003.md)

## Desafio sem pista — uma solução possível

```bash
cadeia() {
  local co=$1 ns
  oc get co "$co" -o json | jq -r '.status.relatedObjects[] | "\(.resource)/\(.name) (\(.namespace // "cluster"))"'
  for ns in $(oc get co "$co" -o json | jq -r '[.status.relatedObjects[] | select(.resource=="namespaces") | .name] | unique[]'); do
    echo "== $ns"; oc get deployment -n "$ns" -o custom-columns=DEPLOY:.metadata.name,PRONTOS:.status.readyReplicas,DESEJADOS:.spec.replicas 2>/dev/null
  done
}
cadeia dns
```

## Diagnóstico controlado — explicação

O operador é a fonte da verdade do operand; edições diretas são desfeitas na próxima reconciliação.
