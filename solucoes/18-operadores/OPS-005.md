# Gabarito OPS-005 — OLM: catálogos e pacotes disponíveis

> Consulte só depois de tentar. Enunciado: [trilhas/18-operadores/exercicios/OPS-005.md](../../trilhas/18-operadores/exercicios/OPS-005.md)

## Desafio sem pista — uma solução possível

```bash
oc get packagemanifests -n openshift-marketplace -o json | jq -r '.items[] | select(.status.catalogSource=="redhat-operators")
  | .status.defaultChannel as $d | "\(.metadata.name)\t\($d)\t\((.status.channels[] | select(.name==$d) | .currentCSV) // "-")"' | sort | head -10 | column -t
```

## Diagnóstico controlado — explicação

PackageManifests são gerados a partir dos catálogos em execução; sem catálogos prontos, não há pacotes.
