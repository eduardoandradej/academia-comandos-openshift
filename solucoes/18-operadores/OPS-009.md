# Gabarito OPS-009 — MachineConfig e MachineConfigPool: o que reinicia o nó

> Consulte só depois de tentar. Enunciado: [trilhas/18-operadores/exercicios/OPS-009.md](../../trilhas/18-operadores/exercicios/OPS-009.md)

## Desafio sem pista — uma solução possível

```bash
R=$(oc get mcp master -o jsonpath='{.status.configuration.name}')
for m in $(oc get mcp master -o jsonpath='{.status.configuration.source[*].name}'); do
  printf '%s\t%s\n' "$(oc get mc "$m" -o jsonpath='{.metadata.creationTimestamp}')" "$m"
done | sort | tail -5
echo "renderizado: $R"
```

## Diagnóstico controlado — explicação

O MCO só termina de aplicar quando o nó reinicia com a configuração nova e reporta `Done`.
