# Gabarito OPS-013 — Monitoramento: alertas ativos pela API (leitura)

> Consulte só depois de tentar. Enunciado: [trilhas/18-operadores/exercicios/OPS-013.md](../../trilhas/18-operadores/exercicios/OPS-013.md)

## Desafio sem pista — uma solução possível

```bash
alertas() {
  local tq t; tq=$(oc get route thanos-querier -n openshift-monitoring -o jsonpath='{.spec.host}'); t=$(oc whoami -t)
  curl -sSk -H "Authorization: Bearer $t" "https://$tq/api/v1/alerts" | jq -r --arg agora "$(date -u +%s)" '
    .data.alerts[] | select(.labels.alertname != "Watchdog")
    | (((($agora|tonumber) - (.activeAt | sub("\\.[0-9]+Z$"; "Z") | fromdateiso8601)) / 60) | floor) as $m
    | "\(.labels.severity)\t\(.labels.alertname)\t\(.labels.namespace // "-")\t\($m) min"' | sort | column -t
}
alertas
```

## Diagnóstico controlado — explicação

A API do monitoramento exige um token com permissão; o admin do HomeLab tem, o developer só vê o próprio projeto.
