# Gabarito OPS-008 — CRDs: as APIs que os operadores acrescentam

> Consulte só depois de tentar. Enunciado: [trilhas/18-operadores/exercicios/OPS-008.md](../../trilhas/18-operadores/exercicios/OPS-008.md)

## Desafio sem pista — uma solução possível

```bash
for c in $(oc get crd -o json | jq -r '.items[] | select(.spec.group|endswith("openshift.io")) | .metadata.name'); do
  n=$(oc get "$c" -A --no-headers 2>/dev/null | wc -l); echo "$n $c"
done | sort -rn | head -5
```

Leva algum tempo (um `get` por tipo); rode uma vez e anote.

## Diagnóstico controlado — explicação

Sem o CRD, a API não conhece o tipo: o erro é de descoberta, não de permissão.
