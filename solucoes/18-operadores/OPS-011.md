# Gabarito OPS-011 — Planejar uma atualização (sem atualizar)

> Consulte só depois de tentar. Enunciado: [trilhas/18-operadores/exercicios/OPS-011.md](../../trilhas/18-operadores/exercicios/OPS-011.md)

## Desafio sem pista — uma solução possível

```bash
pronto_para_atualizar() {
  local p=()
  oc get clusterversion version -o jsonpath='{.status.conditions[?(@.type=="Failing")].status}' | grep -q False || p+=("CVO com falha")
  oc get clusterversion version -o jsonpath='{.status.conditions[?(@.type=="Progressing")].status}' | grep -q False || p+=("CVO em progresso")
  [ -z "$(oc get co -o json | jq -r '.items[] | select(any(.status.conditions[]; .type=="Degraded" and .status=="True")) | .metadata.name')" ] || p+=("operador degradado")
  [ -z "$(oc get co -o json | jq -r '.items[] | select(any(.status.conditions[]; .type=="Upgradeable" and .status=="False")) | .metadata.name')" ] || p+=("Upgradeable=False")
  oc get mcp master -o jsonpath='{.status.conditions[?(@.type=="Updated")].status}' | grep -q True || p+=("MCP não atualizado")
  [ "$(oc get pdb -A -o json | jq '[.items[] | select(.status.disruptionsAllowed==0)] | length')" -eq 0 ] || p+=("PDB bloqueando")
  printf 'pendente: %s\n' "${p[@]:-nenhuma pendência observável}"
  echo "confirmar manualmente: backup do etcd, cópia da VM no HD, janela de indisponibilidade, espaço em /var do kvm-server"
}
pronto_para_atualizar
```

## Diagnóstico controlado — explicação

`Upgradeable=False` bloqueia atualizações de versão menor até a condição ser resolvida ou reconhecida.
