# Gabarito OPS-007 — Instalar um operador: só no papel (dry-run de servidor)

> Consulte só depois de tentar. Enunciado: [trilhas/18-operadores/exercicios/OPS-007.md](../../trilhas/18-operadores/exercicios/OPS-007.md)

## Desafio sem pista — uma solução possível

```bash
oc get packagemanifest "$P" -n openshift-marketplace -o json | jq --arg ch "$CH" '
  .status.channels[] | select(.name==$ch) | .currentCSVDesc
  | {versao: .version, installModes: [.installModes[] | select(.supported) | .type],
     crds: [.customresourcedefinitions.owned[]?.name],
     apis: [.apiservicedefinitions.owned[]?.name]}'
```

Os Deployments e as permissões de cluster (`clusterPermissions`) ficam no CSV completo, visível só depois do
InstallPlan; a lista de CRDs e os modos de instalação já dão a dimensão do impacto.

## Diagnóstico controlado — explicação

O OperatorGroup define quais namespaces o operador observa; ele precisa casar com um modo suportado pelo CSV.
