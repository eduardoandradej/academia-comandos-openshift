> Consulte só depois de tentar. Enunciado: [trilhas/18-operadores/exercicios/OPS-006.md](../../trilhas/18-operadores/exercicios/OPS-006.md)

## Desafio sem pista — uma solução possível

```bash
operadores_olm() {
  oc get subscriptions -A -o json | jq -r '.items[] | [.metadata.namespace, .spec.name, .spec.channel, .spec.installPlanApproval, (.status.installedCSV // "-")] | @tsv' \
  | while IFS=$'\t' read -r ns pkg ch ap csv; do
      fase=$(oc get csv "$csv" -n "$ns" -o jsonpath='{.status.phase}' 2>/dev/null || echo "-")
      printf '%s\t%s\t%s\t%s\t%s\t%s\n' "$pkg" "$ns" "$ch" "$ap" "$csv" "${fase:--}"
    done | column -t
}
operadores_olm
```

## Diagnóstico controlado — explicação

O CSV descreve o operador e seus requisitos; a fase `Failed` resume por que ele não ficou pronto.
