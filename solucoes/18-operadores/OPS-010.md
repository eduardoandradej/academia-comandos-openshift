# Gabarito OPS-010 — O que drain, cordon e reboot fariam no SNO (conceitual)

> Consulte só depois de tentar. Enunciado: [trilhas/18-operadores/exercicios/OPS-010.md](../../trilhas/18-operadores/exercicios/OPS-010.md)

## Desafio sem pista — uma solução possível

```bash
proibidos() {
  local f=$1
  if grep -nE 'adm (drain|cordon|uncordon)|adm upgrade --to|(^|[^a-z])reboot([^a-z]|$)|machineconfig|MachineConfig' "$f"; then
    echo "VERMELHO: $f contém comandos proibidos na Academia"; return 1
  fi
  echo "ok: $f"
}
proibidos scripts/safe-cleanup.sh
```

O `scripts/dev/check-repo.sh` da Academia faz verificação parecida para o repositório.
