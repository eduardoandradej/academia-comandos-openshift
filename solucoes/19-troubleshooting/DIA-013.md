# Gabarito DIA-013 — Linha do tempo de um incidente

> Consulte só depois de tentar. Enunciado: [trilhas/19-troubleshooting/exercicios/DIA-013.md](../../trilhas/19-troubleshooting/exercicios/DIA-013.md)

## Desafio sem pista — uma solução possível

```bash
linha_do_tempo ac19-casos ac19-c7 > /tmp/ac19-lt.tsv
T0=$(awk -F'\t' '$2=="rs" {print $1}' /tmp/ac19-lt.tsv | sort | tail -1)      # criação do RS da versão nova = gatilho
while IFS=$'\t' read -r h tipo o d; do
  [ -z "$h" ] && continue
  printf 'T%+5ds  %-9s %-28s %s\n' $(( $(date -d "$h" +%s) - $(date -d "$T0" +%s) )) "$tipo" "$o" "$d"
done < /tmp/ac19-lt.tsv
rm -f /tmp/ac19-lt.tsv
```

## Diagnóstico controlado — explicação

Eventos repetidos são agregados em um só objeto com contagem; o horário exibido é o da última repetição.
