# Gabarito DIA-012 — Caso 10: o overlay de produção que não entrega o que promete

> Consulte só depois de tentar. Enunciado: [trilhas/19-troubleshooting/exercicios/DIA-012.md](../../trilhas/19-troubleshooting/exercicios/DIA-012.md)

## Desafio sem pista — uma solução possível

Defeitos: (1) o patch `recursos.yaml` cita `ac19-c10-web`, mas o Deployment é `ac19-c10` (não renderiza);
(2) `images[].name` tem a tag (`...httpd-24:latest`): o transformador não casa e o digest não é aplicado; (3) o
`namespace: ac19-casos-prod` não existe — a renderização passa, mas o servidor recusa.

```bash
O=/tmp/ac19/caso-10/overlays/prod
sed -i 's/name: ac19-c10-web/name: ac19-c10/' $O/recursos.yaml
D=$(oc image info registry.access.redhat.com/ubi9/httpd-24:latest --filter-by-os=linux/amd64 -o json | jq -r .digest)
sed -i "s|  - name: registry.access.redhat.com/ubi9/httpd-24:latest|  - name: registry.access.redhat.com/ubi9/httpd-24|; s|digest: sha256:0*$|digest: $D|" $O/kustomization.yaml
sed -i 's/^namespace: ac19-casos-prod/namespace: ac19-casos/' $O/kustomization.yaml
oc kustomize $O | grep -E 'replicas|image:|cpu'
oc kustomize $O | oc apply --dry-run=server -f -
```

## Diagnóstico controlado — explicação

Defeitos de renderização param tudo; defeitos de "casamento" (imagem) passam em silêncio — por isso leia a saída renderizada.
