## Desafio sem pista — uma solução possível

```bash
recusas() {
  local ns=${1:-$(oc project -q)}
  echo "== recusas de admissão"
  oc get events -n "$ns" --field-selector reason=FailedCreate -o json | jq -r '.items[] | "\(.involvedObject.kind)/\(.involvedObject.name): \(.message | .[0:120])"' | sort -u | tail -5
}
recusas ac19-casos
```

## Diagnóstico controlado — explicação

Endpoints vazios com pods prontos quase sempre é seletor; com pods não prontos, é readiness.
