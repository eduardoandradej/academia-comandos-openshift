# Gabarito DIA-010 — Caso 08: o fechamento diário que não roda

> Consulte só depois de tentar. Enunciado: [trilhas/19-troubleshooting/exercicios/DIA-010.md](../../trilhas/19-troubleshooting/exercicios/DIA-010.md)

## Desafio sem pista — uma solução possível

Defeitos: (1) `suspend: true` — o CronJob nunca dispara (na Academia, isso é **intencional**: CronJobs de treino
ficam suspensos e são disparados à mão); (2) o comando exige `DESTINO`, que não está definido: sai com código 3.

```bash
oc patch cronjob ac19-c8-fechamento -n ac19-casos --type=json -p '[{"op":"add","path":"/spec/jobTemplate/spec/template/spec/containers/0/env","value":[{"name":"DESTINO","value":"arquivo-de-treino"}]}]'
oc create job ac19-c8-corrigido --from=cronjob/ac19-c8-fechamento -n ac19-casos
oc wait --for=condition=complete job/ac19-c8-corrigido -n ac19-casos --timeout=90s
oc logs job/ac19-c8-corrigido -n ac19-casos       # fechado em arquivo-de-treino
oc get cronjob ac19-c8-fechamento -n ac19-casos -o jsonpath='{.spec.suspend}{"\n"}'   # true
```

## Diagnóstico controlado — explicação

O Job copia o modelo no momento da criação: corrigir o CronJob não conserta Jobs já criados.
