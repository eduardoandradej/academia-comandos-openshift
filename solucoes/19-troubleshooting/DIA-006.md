## Desafio sem pista — uma solução possível

Defeitos: (1) `nodeSelector: disktype: nvme` (nenhum nó tem o rótulo); (2) `requests.cpu: 8`, mais que o nó inteiro
(6 vCPU). Ambos no **andar 4**.

```bash
oc patch deployment ac19-c4 -n ac19-casos --type=json -p '[
 {"op":"remove","path":"/spec/template/spec/nodeSelector"},
 {"op":"replace","path":"/spec/template/spec/containers/0/resources","value":{"requests":{"cpu":"25m","memory":"48Mi"},"limits":{"cpu":"100m","memory":"128Mi"}}}]'
oc rollout status deployment/ac19-c4 -n ac19-casos
```

Nunca "resolva" rotulando o nó com `disktype=nvme`: a Academia não altera o nó.
