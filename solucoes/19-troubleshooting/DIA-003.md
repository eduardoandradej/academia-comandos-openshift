# Gabarito DIA-003 — Caso 01: a vitrine que não responde

> Consulte só depois de tentar. Enunciado: [trilhas/19-troubleshooting/exercicios/DIA-003.md](../../trilhas/19-troubleshooting/exercicios/DIA-003.md)

## Desafio sem pista — uma solução possível

Defeitos: (1) **andar 5** — tag de imagem inexistente (`2.4-sem-esta-tag`: `ErrImagePull`/`manifest unknown`);
(2) **andar 7** — o Service seleciona `app=ac19-c1-web`, mas os pods têm `app=ac19-c1` (`Endpoints` vazios).

```bash
oc set image deployment/ac19-c1 web=registry.access.redhat.com/ubi9/httpd-24:latest -n ac19-casos
oc rollout status deployment/ac19-c1 -n ac19-casos
oc set selector service ac19-c1 app=ac19-c1 -n ac19-casos
t ac19-c1          # HTTP/1.1 403 Forbidden (a página padrão da UBI): o Service responde
```

## Diagnóstico controlado — explicação

O primeiro defeito mascarava o segundo: sem pods, um seletor errado e um seletor certo têm o mesmo efeito.
