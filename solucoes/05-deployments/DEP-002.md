# Gabarito DEP-002 — Escalar e autocura

> Consulte só depois de tentar. Enunciado: [trilhas/05-deployments/exercicios/DEP-002.md](../../trilhas/05-deployments/exercicios/DEP-002.md)

## Desafio sem pista — uma solução possível

```bash
oc scale deployment/ac05-web --replicas=1 --current-replicas=2 -n ac05-deploy 2>/dev/null \
  || { [ "$(oc get deployment ac05-web -n ac05-deploy -o jsonpath='{.spec.replicas}')" = 1 ] && echo "já estava em 1"; }
```

## Diagnóstico controlado — explicação

`--current-replicas` compara o valor atual antes de gravar; se diferir, o `oc` recusa sem alterar nada.
