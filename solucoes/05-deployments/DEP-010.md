# Gabarito DEP-010 — Jobs: tarefas que terminam

> Consulte só depois de tentar. Enunciado: [trilhas/05-deployments/exercicios/DEP-010.md](../../trilhas/05-deployments/exercicios/DEP-010.md)

## Desafio sem pista — uma solução possível

```bash
oc create job ac05-conta --image=registry.access.redhat.com/ubi9/httpd-24:latest --dry-run=client -o json \
    -- /bin/sh -c 'for i in 1 2 3 4 5; do echo $i; sleep 1; done' \
  | jq '.metadata.labels={"academy.openshift.dev/managed-by":"academia"}
        | .spec.activeDeadlineSeconds=20 | .spec.ttlSecondsAfterFinished=60' \
  | oc apply -n ac05-deploy -f -
oc wait --for=condition=complete job/ac05-conta -n ac05-deploy --timeout=60s && oc logs job/ac05-conta -n ac05-deploy
sleep 70; oc get job ac05-conta -n ac05-deploy 2>&1 | head -1     # NotFound
```

Repetição 1: Jobs com nome fixo não se repetem; para execuções repetidas, use nomes únicos (ex.: sufixo de data) ou um CronJob.

## Diagnóstico controlado — explicação

`oc logs job/<nome>` resolve para um pod do Job. Para todos: `oc logs -l job-name=ac05-lote -n ac05-deploy --prefix`.
