# Gabarito DEP-005 — restart, pause e resume

> Consulte só depois de tentar. Enunciado: [trilhas/05-deployments/exercicios/DEP-005.md](../../trilhas/05-deployments/exercicios/DEP-005.md)

## Desafio sem pista — uma solução possível

```bash
antes=$(oc get rs -n ac05-deploy -l app=ac05-web --no-headers | wc -l)
oc rollout pause deployment/ac05-web -n ac05-deploy
oc set env deployment/ac05-web VERSAO=v6 COR=roxo MODO=final -n ac05-deploy
oc set resources deployment/ac05-web --limits=memory=96Mi -n ac05-deploy
oc annotate deployment/ac05-web kubernetes.io/change-cause='v6: três variáveis e 96Mi' --overwrite -n ac05-deploy
oc get pods -n ac05-deploy -l app=ac05-web       # mesmos pods de antes
oc rollout resume deployment/ac05-web -n ac05-deploy && oc rollout status deployment/ac05-web -n ac05-deploy
echo "ReplicaSets: $antes -> $(oc get rs -n ac05-deploy -l app=ac05-web --no-headers | wc -l)"
```

## Diagnóstico controlado — explicação

Um Deployment pausado não aceita undo porque o undo é, ele mesmo, uma mudança de template que precisaria de rollout.
