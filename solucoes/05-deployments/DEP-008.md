# Gabarito DEP-008 — ReplicaSets: quem manda em quem

> Consulte só depois de tentar. Enunciado: [trilhas/05-deployments/exercicios/DEP-008.md](../../trilhas/05-deployments/exercicios/DEP-008.md)

## Desafio sem pista — uma solução possível

```bash
oc get rs -n ac05-deploy -l app=ac05-web -o json | jq -r '.items
  | sort_by(.metadata.annotations["deployment.kubernetes.io/revision"] | tonumber)[]
  | [.metadata.annotations["deployment.kubernetes.io/revision"], .metadata.name, (.spec.replicas|tostring),
     .spec.template.spec.containers[0].image, (.metadata.annotations["kubernetes.io/change-cause"] // "-")] | @tsv' | column -t -s $'\t'
```

## Diagnóstico controlado — explicação

O controlador de Deployment detecta que o ReplicaSet atual tem réplicas diferentes das do Deployment e o reescala.
