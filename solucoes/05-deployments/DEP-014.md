# Gabarito DEP-014 — Ler o estado de um Deployment: condições e contadores

> Consulte só depois de tentar. Enunciado: [trilhas/05-deployments/exercicios/DEP-014.md](../../trilhas/05-deployments/exercicios/DEP-014.md)

## Desafio sem pista — uma solução possível

```bash
estado() {
  oc get deployment "$1" -n "${2:-ac05-deploy}" -o json | jq -r '
    if .spec.paused then "pausado"
    elif ([.status.conditions[]? | select(.type=="Progressing" and .reason=="ProgressDeadlineExceeded")] | length) > 0 then "travado"
    elif (.status.updatedReplicas // 0) == .spec.replicas and (.status.availableReplicas // 0) == .spec.replicas
         and (.status.replicas // 0) == .spec.replicas and .metadata.generation == .status.observedGeneration then "estável"
    else "em rollout" end'
}
estado ac05-web
```

## Diagnóstico controlado — explicação

`ProgressDeadlineExceeded` só sinaliza; o controlador continua tentando. A decisão de desfazer é sua (`rollout undo`).
