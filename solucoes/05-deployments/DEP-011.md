# Gabarito DEP-011 — CronJobs: agendar sem sobrecarregar

> Consulte só depois de tentar. Enunciado: [trilhas/05-deployments/exercicios/DEP-011.md](../../trilhas/05-deployments/exercicios/DEP-011.md)

## Desafio sem pista — uma solução possível

```bash
N="ac05-relatorio-$(date +%Y%m%d-%H%M%S)"
oc create job "$N" --from=cronjob/ac05-relatorio -n ac05-deploy
oc wait --for=condition=complete "job/$N" -n ac05-deploy --timeout=120s && oc logs "job/$N" -n ac05-deploy
```

Repetição 1: `30 7 * * 1-5` · `*/15 * * * *` · `0 0 1 * *`.

## Diagnóstico controlado — explicação

Jobs criados por `--from=cronjob/...` recebem uma referência ao CronJob, mas a limpeza por histórico é feita para os
Jobs que o próprio controlador agenda. Trate execuções manuais como suas: apague-as ao terminar.
