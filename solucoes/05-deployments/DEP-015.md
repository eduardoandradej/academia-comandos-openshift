# Gabarito DEP-015 — Circuito de workloads e encerramento da trilha

> Consulte só depois de tentar. Enunciado: [trilhas/05-deployments/exercicios/DEP-015.md](../../trilhas/05-deployments/exercicios/DEP-015.md)

## Desafio sem pista — uma solução possível

```bash
oc create deployment ac05-web --image=registry.access.redhat.com/ubi9/httpd-24:latest --replicas=2 --port=8080 -n ac05-deploy   # 1
oc rollout status deployment/ac05-web -n ac05-deploy                                                     # 2
oc scale deployment/ac05-web --replicas=1 --current-replicas=2 -n ac05-deploy                            # 3
oc set env deployment/ac05-web VERSAO=c1 -n ac05-deploy && \
  oc annotate deployment/ac05-web kubernetes.io/change-cause='c1' --overwrite -n ac05-deploy             # 4
oc rollout history deployment/ac05-web -n ac05-deploy                                                    # 5
oc rollout history deployment/ac05-web --revision=1 -n ac05-deploy                                       # 6
oc rollout undo deployment/ac05-web -n ac05-deploy                                                       # 7
oc rollout restart deployment/ac05-web -n ac05-deploy                                                    # 8
oc rollout pause deployment/ac05-web -n ac05-deploy; oc set env deployment/ac05-web A=1 B=2 -n ac05-deploy; \
  oc set resources deployment/ac05-web --limits=memory=128Mi -n ac05-deploy; oc rollout resume deployment/ac05-web -n ac05-deploy   # 9
D=$(oc get pods -n ac05-deploy -l app=ac05-web -o jsonpath='{.items[0].status.containerStatuses[0].imageID}'); \
  oc set image deployment/ac05-web "httpd-24=$D" -n ac05-deploy                                          # 10
oc patch deployment ac05-web -n ac05-deploy --type=merge -p '{"spec":{"strategy":{"type":"Recreate","rollingUpdate":null}}}'; \
  oc patch deployment ac05-web -n ac05-deploy --type=merge -p '{"spec":{"strategy":{"type":"RollingUpdate"}}}'   # 11
oc create job ac05-c12 --image=registry.access.redhat.com/ubi9/httpd-24:latest -n ac05-deploy -- echo circuito; \
  oc wait --for=condition=complete job/ac05-c12 -n ac05-deploy --timeout=60s; oc logs job/ac05-c12 -n ac05-deploy   # 12
oc create cronjob ac05-c13 --image=registry.access.redhat.com/ubi9/httpd-24:latest --schedule='0 3 * * *' -n ac05-deploy -- date; \
  oc patch cronjob ac05-c13 -n ac05-deploy -p '{"spec":{"suspend":true}}'; oc create job ac05-c13-m --from=cronjob/ac05-c13 -n ac05-deploy   # 13
oc get deployment ac05-web -n ac05-deploy -o jsonpath='{range .status.conditions[*]}{.type}={.status} ({.reason}){"\n"}{end}'   # 14
oc get deployment ac05-web -n ac05-deploy -o json | jq 'del(.status,.metadata.uid,.metadata.resourceVersion,.metadata.creationTimestamp,.metadata.generation,.metadata.managedFields)' > /tmp/ac05-c15.json; \
  oc diff -f /tmp/ac05-c15.json -n ac05-deploy && echo vazio                                             # 15
```

## Diagnóstico controlado — explicação

`oc create deployment` e `oc create job` não aceitam rótulos extras no template; o `safe-cleanup` apaga o que tem o
rótulo, e o resto sai com o projeto.
