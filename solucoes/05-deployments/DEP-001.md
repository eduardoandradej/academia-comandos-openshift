# Gabarito DEP-001 — Criar um Deployment e ver a cadeia Deployment → ReplicaSet → Pods

> Consulte só depois de tentar. Enunciado: [trilhas/05-deployments/exercicios/DEP-001.md](../../trilhas/05-deployments/exercicios/DEP-001.md)

## Desafio sem pista — uma solução possível

```bash
oc create deployment ac05-extra --image=registry.access.redhat.com/ubi9/httpd-24:latest --replicas=1 \
  --dry-run=client -o json \
  | jq '.metadata.labels["academy.openshift.dev/managed-by"]="academia"
        | .spec.template.metadata.labels["academy.openshift.dev/managed-by"]="academia"' \
  | oc apply -n ac05-deploy -f -
oc get pods -n ac05-deploy -l app=ac05-extra,academy.openshift.dev/managed-by=academia -o name
```

`oc label --local` só rotula o `metadata` do objeto; para o template dos pods, edite o JSON (aqui com `jq`).

## Diagnóstico controlado — explicação

`create` falha se o nome existe; `apply` compara e atualiza. Para procedimentos repetíveis, gere o objeto e aplique.
