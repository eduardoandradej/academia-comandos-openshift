# Gabarito DEP-007 — Estratégias: RollingUpdate e Recreate

> Consulte só depois de tentar. Enunciado: [trilhas/05-deployments/exercicios/DEP-007.md](../../trilhas/05-deployments/exercicios/DEP-007.md)

## Desafio sem pista — uma solução possível

```bash
medir() {
  oc rollout restart deployment/ac05-web -n ac05-deploy >/dev/null
  zero=0
  for i in $(seq 60); do
    r=$(oc get deployment ac05-web -n ac05-deploy -o jsonpath='{.status.readyReplicas}')
    [ -z "$r" ] || [ "$r" = 0 ] && zero=$((zero+1))
    oc rollout status deployment/ac05-web -n ac05-deploy --timeout=1s >/dev/null 2>&1 && break
    sleep 1
  done
  echo "segundos (aprox.) com zero prontos: $zero"
}
medir   # RollingUpdate: 0
oc patch deployment ac05-web -n ac05-deploy --type=merge -p '{"spec":{"strategy":{"type":"Recreate","rollingUpdate":null}}}'
medir   # Recreate: alguns segundos
```

## Diagnóstico controlado — explicação

`rollingUpdate` só vale para o tipo RollingUpdate; o merge patch precisa removê-lo explicitamente com `null`.
