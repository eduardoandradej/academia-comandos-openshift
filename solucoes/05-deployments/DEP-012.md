# Gabarito DEP-012 — DaemonSet: um pod por nó

> Consulte só depois de tentar. Enunciado: [trilhas/05-deployments/exercicios/DEP-012.md](../../trilhas/05-deployments/exercicios/DEP-012.md)

## Desafio sem pista — uma solução possível

```bash
oc patch daemonset ac05-ds -n ac05-deploy --type=merge -p '{"spec":{"template":{"spec":{"nodeSelector":{"academy.openshift.dev/pausar":"sim"}}}}}'
oc get daemonset ac05-ds -n ac05-deploy -o jsonpath='desejados={.status.desiredNumberScheduled}{"\n"}'   # 0
oc patch daemonset ac05-ds -n ac05-deploy --type=json -p '[{"op":"remove","path":"/spec/template/spec/nodeSelector"}]'
oc rollout status daemonset/ac05-ds -n ac05-deploy
```

Um `nodeSelector` que nenhum nó atende zera os pods sem apagar o objeto; o patch JSON remove o campo.

## Diagnóstico controlado — explicação

O número de pods de um DaemonSet é derivado dos nós elegíveis; não existe `spec.replicas` para escalar.
