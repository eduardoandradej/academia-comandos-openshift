# Gabarito DEP-013 — Deployment declarativo: gerar, editar, comparar e aplicar

> Consulte só depois de tentar. Enunciado: [trilhas/05-deployments/exercicios/DEP-013.md](../../trilhas/05-deployments/exercicios/DEP-013.md)

## Desafio sem pista — uma solução possível

```bash
oc apply -f /tmp/ac05-web2.json --dry-run=client -o yaml -n ac05-deploy > /tmp/ac05-web.yaml
sed -i 's/^  replicas: .*/  replicas: 1/; s/value: declarativa/value: arquivo/' /tmp/ac05-web.yaml
oc diff -f /tmp/ac05-web.yaml -n ac05-deploy; oc apply -f /tmp/ac05-web.yaml -n ac05-deploy
oc rollout status deployment/ac05-web -n ac05-deploy; oc diff -f /tmp/ac05-web.yaml -n ac05-deploy && echo "em acordo"
sed -i 's/^  replicas: .*/  replicas: 2/' /tmp/ac05-web.yaml && oc apply -f /tmp/ac05-web.yaml -n ac05-deploy
```

Repetição 3: `oc diff` mostra a diferença de `replicas` entre o arquivo e o cluster — mudanças imperativas "desalinham" o arquivo.

## Diagnóstico controlado — explicação

`resourceVersion` no arquivo faz o servidor exigir que o objeto esteja exatamente naquela versão (concorrência
otimista). Manifestos de fonte da verdade não devem carregá-lo.
