# Gabarito DEP-006 — oc set: imagem, recursos e variáveis

> Consulte só depois de tentar. Enunciado: [trilhas/05-deployments/exercicios/DEP-006.md](../../trilhas/05-deployments/exercicios/DEP-006.md)

## Desafio sem pista — uma solução possível

```bash
C=$(oc get deployment ac05-web -n ac05-deploy -o jsonpath='{.spec.template.spec.containers[0].name}')
D=$(oc get pods -n ac05-deploy -l app=ac05-web -o jsonpath='{.items[0].status.containerStatuses[0].imageID}')
oc rollout pause deployment/ac05-web -n ac05-deploy
oc set image deployment/ac05-web "$C=$D" -n ac05-deploy
oc set resources deployment/ac05-web -c "$C" --requests=cpu=30m,memory=40Mi -n ac05-deploy
oc set env deployment/ac05-web VERSAO- COR- MODO- -n ac05-deploy
oc rollout resume deployment/ac05-web -n ac05-deploy && oc rollout status deployment/ac05-web -n ac05-deploy
oc get deployment ac05-web -n ac05-deploy -o jsonpath='{.spec.template.spec.containers[0].image} {.spec.template.spec.containers[0].resources.requests} env={.spec.template.spec.containers[0].env}{"\n"}'
```

## Diagnóstico controlado — explicação

`oc set image` exige o nome exato do contêiner (ou `*`). O nome vem de `spec.template.spec.containers[].name`.
