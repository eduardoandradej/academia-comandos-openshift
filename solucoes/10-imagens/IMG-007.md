# Gabarito IMG-007 — Usar ImageStream em Deployment: image-lookup

> Consulte só depois de tentar. Enunciado: [trilhas/10-imagens/exercicios/IMG-007.md](../../trilhas/10-imagens/exercicios/IMG-007.md)

## Desafio sem pista — uma solução possível

```bash
oc tag ac10-web:minimal ac10-web:prod -n ac10-imagens 2>/dev/null || oc tag registry.access.redhat.com/ubi9/ubi-minimal:latest ac10-web:prod -n ac10-imagens
oc get pod -n ac10-imagens -l app=ac10-app -o jsonpath='{.items[0].spec.containers[0].image}{"\n"}'   # digest antigo
oc tag ac10-web:v1 ac10-web:prod -n ac10-imagens                                                       # volta
```

O template do Deployment diz `ac10-web:prod` — texto que não mudou; portanto nenhuma revisão nova é criada. Um pod
novo (por `rollout restart` ou réplica nova) resolveria o digest **atual**. Para atualizar automaticamente, use um
gatilho de imagem (IMG-008).

## Diagnóstico controlado — explicação

Sem o lookup, o runtime recebe `ac10-web:prod` como nome de registry e tenta os registries de busca do nó.
