# Gabarito IMG-012 — Extrair um arquivo de uma imagem sem rodá-la

> Consulte só depois de tentar. Enunciado: [trilhas/10-imagens/exercicios/IMG-012.md](../../trilhas/10-imagens/exercicios/IMG-012.md)

## Desafio sem pista — uma solução possível

```bash
mkdir -p /tmp/ac10/mods
oc image extract registry.access.redhat.com/ubi9/httpd-24:latest --path /etc/httpd/conf.modules.d/:/tmp/ac10/mods --filter-by-os=linux/amd64 --confirm
grep -h '^LoadModule' /tmp/ac10/mods/*.conf | awk '{print $2}' | sort | head -40
```

## Diagnóstico controlado — explicação

`oc image extract` recusa escrever em diretório não vazio sem `--confirm`.
