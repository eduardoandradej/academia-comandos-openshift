# Gabarito IMG-010 — O registry interno visto pelo admin (somente leitura)

> Consulte só depois de tentar. Enunciado: [trilhas/10-imagens/exercicios/IMG-010.md](../../trilhas/10-imagens/exercicios/IMG-010.md)

## Desafio sem pista — uma solução possível

```bash
ac-admin
cfg=$(oc get configs.imageregistry.operator.openshift.io cluster -o json)
echo "estado: $(jq -r .spec.managementState <<<"$cfg")"
echo "storage: $(jq -r '.spec.storage | keys | join(",") // "nenhum"' <<<"$cfg")"
echo "route padrão: $(jq -r '.spec.defaultRoute // false' <<<"$cfg")"
[ "$(jq -r .spec.managementState <<<"$cfg")" = Managed ] && echo "Local: possível" || echo "Local: não (registry desligado)"
ac-dev
```

## Diagnóstico controlado — explicação

`Local` reescreve a referência para o registry interno; sem ele, não há de onde baixar.
