# Gabarito IMG-006 — Tags: apontar, mover, criar alias e apagar

> Consulte só depois de tentar. Enunciado: [trilhas/10-imagens/exercicios/IMG-006.md](../../trilhas/10-imagens/exercicios/IMG-006.md)

## Desafio sem pista — uma solução possível

```bash
ant=$(oc get is ac10-web -n ac10-imagens -o json | jq -r '.status.tags[] | select(.tag=="v1") | .items[1].image // empty')
[ -n "$ant" ] && oc tag "ac10-web@$ant" ac10-web:prod -n ac10-imagens || echo "v1 ainda não tem histórico anterior"
oc get istag ac10-web:prod -n ac10-imagens -o jsonpath='{.image.metadata.name}{"\n"}'
```

`items[0]` é a imagem atual da tag; `items[1]`, a anterior. Gere histórico na repetição 1 se necessário.

## Diagnóstico controlado — explicação

Sem `--alias`, `oc tag` resolve a origem na hora e grava o digest; mudanças posteriores na origem não se propagam.
