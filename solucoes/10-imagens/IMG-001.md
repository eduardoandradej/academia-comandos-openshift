# Gabarito IMG-001 — Anatomia de uma referência de imagem

> Consulte só depois de tentar. Enunciado: [trilhas/10-imagens/exercicios/IMG-001.md](../../trilhas/10-imagens/exercicios/IMG-001.md)

## Desafio sem pista — uma solução possível

```bash
oc image info registry.access.redhat.com/ubi9/httpd-24:latest -o json | jq '{env: .config.config.Env, entrypoint: .config.config.Entrypoint, cmd: .config.config.Cmd}'
```

## Diagnóstico controlado — explicação

`manifest unknown` vem do registry: o repositório existe, a tag não (ou o nome está errado). `unauthorized` indica credencial.
