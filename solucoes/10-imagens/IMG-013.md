# Gabarito IMG-013 — oc new-app a partir de ImageStream

> Consulte só depois de tentar. Enunciado: [trilhas/10-imagens/exercicios/IMG-013.md](../../trilhas/10-imagens/exercicios/IMG-013.md)

## Desafio sem pista — uma solução possível

```bash
oc new-app --image=registry.access.redhat.com/ubi9/httpd-24:latest --name=teste -n ac10-imagens --dry-run -o yaml | grep -E '^kind: |^- apiVersion|kind: ImageStream' | sort | uniq -c
```

Com `--image`, o `new-app` cria um ImageStream com o mesmo nome da aplicação, que importa a imagem externa, e liga o
Deployment a ele por gatilho. Com `--image-stream`, reutiliza o ImageStream existente e não cria outro.

## Diagnóstico controlado — explicação

`new-app` resolve nomes procurando ImageStreams no projeto (e no `openshift`); um erro de digitação não encontra nada.
