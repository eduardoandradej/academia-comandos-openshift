# Gabarito IMG-004 — Política de pull: Always, IfNotPresent e Never

> Consulte só depois de tentar. Enunciado: [trilhas/10-imagens/exercicios/IMG-004.md](../../trilhas/10-imagens/exercicios/IMG-004.md)

## Desafio sem pista — uma solução possível

```bash
oc run ac10-cache --image=registry.access.redhat.com/ubi9/ubi-minimal:latest --image-pull-policy=Never --command -n ac10-imagens \
  --labels=academy.openshift.dev/managed-by=academia -- sleep 5
sleep 10; oc get pod ac10-cache -n ac10-imagens -o jsonpath='{.status.containerStatuses[0].state}{"\n"}'
# waiting.reason=ErrImageNeverPull -> não está no cache; running/terminated -> está
```

## Diagnóstico controlado — explicação

`Never` só usa o que já existe no nó; é útil justamente para descobrir o que está em cache.
