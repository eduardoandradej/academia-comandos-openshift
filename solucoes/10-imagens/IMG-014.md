# Gabarito IMG-014 — Roteiro de diagnóstico de imagens

## Desafio sem pista — uma solução possível

```bash
classifica_pull() {
  local m
  m=$(oc get events -n ac10-imagens --field-selector "involvedObject.name=$1,type=Warning" -o jsonpath='{.items[-1:].message}')
  case "$m" in
    *InvalidImageName*|*"invalid reference format"*|*"must be lowercase"*) echo "1 nome inválido";;
    *"no such host"*|*"connection refused"*|*timeout*) echo "2 registry inacessível";;
    *"short name"*|*docker.io/library*) echo "5 nome curto sem lookup";;
    *unauthorized*|*"authentication required"*) echo "4 credencial";;
    *"manifest unknown"*|*"not found"*) echo "3 repositório/tag inexistente";;
    *"rejected by policy"*|*NeverPull*) echo "6 política";;
    *) echo "?: $m";;
  esac
}
for p in ac10-f1 ac10-f2 ac10-f3 ac10-f4; do printf '%s: ' $p; classifica_pull $p; done
```

A ordem dos `case` importa: nome curto antes de "not found", porque a mensagem de nome curto pode conter as duas.

## Diagnóstico controlado — explicação

`InvalidImageName` é recusado pelo kubelet antes de qualquer pull.
