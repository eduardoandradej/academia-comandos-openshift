# Gabarito IMG-005 — ImageStream: importar uma imagem externa

> Consulte só depois de tentar. Enunciado: [trilhas/10-imagens/exercicios/IMG-005.md](../../trilhas/10-imagens/exercicios/IMG-005.md)

## Desafio sem pista — uma solução possível

```bash
a=$(oc get istag ac10-web:v1 -n ac10-imagens -o jsonpath='{.image.metadata.name}')
b=$(oc image info registry.access.redhat.com/ubi9/httpd-24:latest --filter-by-os=linux/amd64 -o json | jq -r .digest)
c=$(oc image info registry.access.redhat.com/ubi9/httpd-24:latest -o json 2>/dev/null | jq -r '.listDigest // .digest')
echo "istag=$a origem(amd64)=$b lista=$c"
```

Para imagens multiarquitetura, a istag registra o manifesto da plataforma do cluster (amd64) — compare com `--filter-by-os`.

## Diagnóstico controlado — explicação

A importação acontece no cluster (pelo controlador de imagens), não na `ocp-admin`; o erro fica no status do ImageStream.
