# Gabarito IMG-008 — Gatilho de imagem: atualizar o Deployment quando a tag muda

> Consulte só depois de tentar. Enunciado: [trilhas/10-imagens/exercicios/IMG-008.md](../../trilhas/10-imagens/exercicios/IMG-008.md)

## Desafio sem pista — uma solução possível

```bash
promove() {
  local de=$1 para=${2:-prod} ns=ac10-imagens a b
  a=$(oc get istag "ac10-web:$de" -n "$ns" -o jsonpath='{.image.metadata.name}' 2>/dev/null) || { echo "origem $de não existe"; return 1; }
  b=$(oc get istag "ac10-web:$para" -n "$ns" -o jsonpath='{.image.metadata.name}' 2>/dev/null)
  [ "$a" = "$b" ] && { echo "nada a promover"; return 0; }
  oc tag "ac10-web:$de" "ac10-web:$para" -n "$ns" && sleep 3 && oc rollout status deployment/ac10-app -n "$ns" --timeout=180s
}
promove v1
```

## Diagnóstico controlado — explicação

O controlador de gatilhos só altera o contêiner citado; um nome errado faz a mudança da tag passar despercebida.
