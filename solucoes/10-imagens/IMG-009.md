# Gabarito IMG-009 — Importação periódica e política de referência

> Consulte só depois de tentar. Enunciado: [trilhas/10-imagens/exercicios/IMG-009.md](../../trilhas/10-imagens/exercicios/IMG-009.md)

## Desafio sem pista — uma solução possível

```bash
oc get is -n ac10-imagens -o json | jq -r '.items[] | .metadata.name as $is | .spec.tags[]? | select(.importPolicy.scheduled==true) | "\($is):\(.name) <- \(.from.name)"'
```

## Diagnóstico controlado — explicação

A importação agendada muda a istag; o gatilho transforma essa mudança em rollout. Os dois juntos são deploy contínuo sem teste.
