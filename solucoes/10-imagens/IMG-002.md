# Gabarito IMG-002 — Que imagem está rodando de verdade

> Consulte só depois de tentar. Enunciado: [trilhas/10-imagens/exercicios/IMG-002.md](../../trilhas/10-imagens/exercicios/IMG-002.md)

## Desafio sem pista — uma solução possível

```bash
for p in $(oc get pods -n ac10-imagens -o name); do
  pedido=$(oc get "$p" -n ac10-imagens -o jsonpath='{.spec.containers[0].image}')
  rodando=$(oc get "$p" -n ac10-imagens -o jsonpath='{.status.containerStatuses[0].imageID}' | sed 's/.*@//')
  case "$pedido" in *@sha256:*) continue;; esac
  atual=$(oc image info "$pedido" -o json 2>/dev/null | jq -r .digest)
  [ "$rodando" != "$atual" ] && echo "$p: rodando $rodando, tag agora $atual"
done; echo "fim"
```

Para imagens multiarquitetura, compare com `--filter-by-os=linux/amd64`: o `imageID` é o do manifesto da plataforma.

## Diagnóstico controlado — explicação

A tag é resolvida no momento do pull; cada pod guarda o digest que recebeu.
