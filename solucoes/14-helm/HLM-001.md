## Desafio sem pista — uma solução possível

```bash
hdev() {
  if [ "$(oc whoami 2>/dev/null)" != developer ]; then
    echo "recusado: identidade atual é '$(oc whoami 2>/dev/null)'. Rode: source scripts/perfis.sh && ac-dev" >&2
    return 1
  fi
  helm "$@"
}
hdev version --short
```

## Diagnóstico controlado — explicação

O Helm não tem identidade própria: herda a do kubeconfig ativo.
