# Gabarito HLM-005 — helm upgrade e a precedência de valores

> Consulte só depois de tentar. Enunciado: [trilhas/14-helm/exercicios/HLM-005.md](../../trilhas/14-helm/exercicios/HLM-005.md)

## Desafio sem pista — uma solução possível

```bash
helm get values loja -n ac14-helm -o yaml > /tmp/ac14/atuais.yaml
helm upgrade loja /tmp/ac14/ac14-loja -n ac14-helm -f /tmp/ac14/atuais.yaml --set pagina.conteudo='so a pagina mudou'
helm get values loja -n ac14-helm
```

`helm get values` (sem `--all`) devolve só os valores passados pelo usuário; reaplicá-los com `-f` reproduz a
configuração e ainda recebe os defaults novos do chart — o que `--reuse-values` não faz.

## Diagnóstico controlado — explicação

Cada `upgrade` recalcula os valores do zero a partir do que foi passado nele.
