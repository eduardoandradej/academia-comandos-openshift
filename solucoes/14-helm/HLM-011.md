> Consulte só depois de tentar. Enunciado: [trilhas/14-helm/exercicios/HLM-011.md](../../trilhas/14-helm/exercicios/HLM-011.md)

## Desafio sem pista — uma solução possível

```bash
oc label configmap vitrine-pagina -n ac14-helm app.kubernetes.io/managed-by=Helm --overwrite
oc annotate configmap vitrine-pagina -n ac14-helm meta.helm.sh/release-name=vitrine meta.helm.sh/release-namespace=ac14-helm --overwrite
helm install vitrine /tmp/ac14/ac14-loja -n ac14-helm --set route.enabled=false
oc get configmap vitrine-pagina -n ac14-helm -o jsonpath='{.data.index\.html}{"\n"}'     # agora com o conteúdo do chart
```

Risco: o Helm passa a ser dono do objeto — o conteúdo manual foi substituído, e um `helm uninstall` o apagará.

## Diagnóstico controlado — explicação

As marcas de dono impedem que duas releases (ou uma release e um humano) disputem o mesmo objeto sem saber.
