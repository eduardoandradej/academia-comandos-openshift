# Gabarito HLM-006 — Histórico e rollback

> Consulte só depois de tentar. Enunciado: [trilhas/14-helm/exercicios/HLM-006.md](../../trilhas/14-helm/exercicios/HLM-006.md)

## Desafio sem pista — uma solução possível

```bash
volta_ate() {
  local txt=$1 r
  for r in $(helm history loja -n ac14-helm -o json | jq -r '.[].revision' | sort -rn); do
    if helm get values loja -n ac14-helm --revision "$r" --all -o json | jq -e --arg t "$txt" '.pagina.conteudo | contains($t)' >/dev/null; then
      echo "rollback para $r"; helm rollback loja "$r" -n ac14-helm; return
    fi
  done; echo "nenhuma revisão contém '$txt'"
}
volta_ate prod
```

## Diagnóstico controlado — explicação

O Helm procura a release só no namespace indicado (ou no do contexto).
