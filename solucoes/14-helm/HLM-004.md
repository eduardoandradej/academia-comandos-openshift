# Gabarito HLM-004 — Instalar uma release e ler o que ela é

> Consulte só depois de tentar. Enunciado: [trilhas/14-helm/exercicios/HLM-004.md](../../trilhas/14-helm/exercicios/HLM-004.md)

## Desafio sem pista — uma solução possível

```bash
oc get secret sh.helm.release.v1.loja.v1 -n ac14-helm -o jsonpath='{.data.release}' \
  | base64 -d | base64 -d | gunzip | jq '{name, version, status: .info.status, chart: .chart.metadata.name, chartVersion: .chart.metadata.version}'
```

O campo é base64 (do Secret) de um base64 (do Helm) de um JSON compactado com gzip.

## Diagnóstico controlado — explicação

O nome da release é único por namespace; o histórico é guardado por ele.
