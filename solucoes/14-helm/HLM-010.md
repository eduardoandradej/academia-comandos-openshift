# Gabarito HLM-010 — Upgrades seguros: --wait, --timeout e --atomic

> Consulte só depois de tentar. Enunciado: [trilhas/14-helm/exercicios/HLM-010.md](../../trilhas/14-helm/exercicios/HLM-010.md)

## Desafio sem pista — uma solução possível

```bash
entrega() {
  local v=$1 ns=ac14-helm antes
  antes=$(helm history loja -n "$ns" -o json 2>/dev/null | jq '[.[] | select(.status=="deployed")] | last.revision // empty')
  helm upgrade --install loja /tmp/ac14/ac14-loja -n "$ns" -f "$v" --atomic --timeout 2m || return 1
  if ! helm test loja -n "$ns" --timeout 60s; then
    echo "teste falhou"; [ -n "$antes" ] && helm rollback loja "$antes" -n "$ns"; return 1
  fi
  echo "entregue: revisão $(helm history loja -n "$ns" -o json | jq '.[-1].revision')"
}
entrega /tmp/ac14/ac14-loja/values-prod.yaml
```

## Diagnóstico controlado — explicação

`--wait` faz o Helm acompanhar a prontidão como `oc rollout status`; o prazo é `--timeout`.
