# Gabarito HLM-015 — Circuito de Helm e encerramento da trilha

> Consulte só depois de tentar. Enunciado: [trilhas/14-helm/exercicios/HLM-015.md](../../trilhas/14-helm/exercicios/HLM-015.md)

## Desafio sem pista — uma solução possível

```bash
oc whoami; helm env | grep KUBECONTEXT                                                   # 1
helm lint /tmp/ac14/ac14-loja                                                                            # 2
helm template loja /tmp/ac14/ac14-loja -f /tmp/ac14/ac14-loja/values-prod.yaml --show-only templates/deployment.yaml     # 3
helm install loja /tmp/ac14/ac14-loja -n ac14-helm; oc get secret -n ac14-helm -l owner=helm             # 4
helm get values loja -o yaml > v.yaml; helm upgrade loja /tmp/ac14/ac14-loja -f v.yaml --set pagina.conteudo=x   # 5
helm rollback loja <N>                                                                   # 6
# 7: with/required no modelo (HLM-007); 8: --set replicaCount=3 (HLM-008)
helm test loja                                                                           # 9
helm upgrade loja /tmp/ac14/ac14-loja --set image.tag=nao-existe --atomic --timeout 60s                  # 10
# 11: rótulo managed-by=Helm + anotações meta.helm.sh/* (HLM-011)
helm pull REPO/CHART --untar; helm template x DIR | grep kind:                           # 12
helm template loja /tmp/ac14/ac14-loja --skip-tests > gerado.yaml; oc kustomize .                        # 13
helm history loja; helm rollback loja <última deployed>                                  # 14
```

## Diagnóstico controlado — explicação

`--keep-history` mantém o histórico para auditoria; para limpar de vez, desinstale sem ele.
