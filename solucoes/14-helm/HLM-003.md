# Gabarito HLM-003 — helm template: renderizar como o Kustomize

> Consulte só depois de tentar. Enunciado: [trilhas/14-helm/exercicios/HLM-003.md](../../trilhas/14-helm/exercicios/HLM-003.md)

## Desafio sem pista — uma solução possível

```bash
r() { helm template loja /tmp/ac14/ac14-loja -n ac14-helm "$@" --show-only templates/deployment.yaml | python3 -c 'import sys,yaml,json;print(json.dumps(yaml.safe_load(sys.stdin)))'; }
jq -n --argjson a "$(r)" --argjson b "$(r -f /tmp/ac14/ac14-loja/values-prod.yaml)" '
  [$a,$b] | (.[0]|[paths(scalars)]) + (.[1]|[paths(scalars)]) | unique[] as $p
  | {campo: ($p|map(tostring)|join(".")), padrao: ($a|getpath($p)), prod: ($b|getpath($p))} | select(.padrao != .prod)'
```

## Diagnóstico controlado — explicação

O schema é verificado em `lint`, `template`, `install` e `upgrade`: valores inválidos nunca chegam ao cluster.
