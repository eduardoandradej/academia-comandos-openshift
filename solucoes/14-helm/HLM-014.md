## Desafio sem pista — uma solução possível

```bash
saude_release() {
  local r=$1 ns=${2:-ac14-helm} st rev pend drift teste
  st=$(helm status "$r" -n "$ns" -o json | jq -r .info.status); rev=$(helm status "$r" -n "$ns" -o json | jq -r .version)
  pend=$(helm history "$r" -n "$ns" -o json | jq -r '[.[] | select(.status|startswith("pending"))] | length')
  helm get manifest "$r" -n "$ns" | oc diff -n "$ns" -f - >/dev/null 2>&1 && drift=não || drift=sim
  helm test "$r" -n "$ns" >/dev/null 2>&1 && teste=passa || teste=falha
  echo "$r: status=$st revisão=$rev pendentes=$pend deriva=$drift teste=$teste"
}
saude_release loja
```

## Diagnóstico controlado — explicação

O Helm usa o status da última revisão como trava; uma revisão `pending-*` órfã bloqueia novas operações.
