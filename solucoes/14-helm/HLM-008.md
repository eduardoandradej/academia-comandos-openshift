# Gabarito HLM-008 — Validação de valores com values.schema.json

> Consulte só depois de tentar. Enunciado: [trilhas/14-helm/exercicios/HLM-008.md](../../trilhas/14-helm/exercicios/HLM-008.md)

## Desafio sem pista — uma solução possível

```bash
jq '.properties.env.propertyNames = {"not": {"enum": ["PATH"]}}' /tmp/ac14/ac14-loja/values.schema.json > /tmp/ac14/s.json && mv /tmp/ac14/s.json /tmp/ac14/ac14-loja/values.schema.json
helm template loja /tmp/ac14/ac14-loja --set env.PATH=/x 2>&1 | tail -1        # recusado
helm template loja /tmp/ac14/ac14-loja --set env.MODO=x >/dev/null && echo "MODO aceito"
```

## Diagnóstico controlado — explicação

`--set` converte números automaticamente; `--set-string` força texto — e o schema percebe a diferença.
