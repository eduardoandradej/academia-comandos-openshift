# Gabarito KUS-004 — Rótulos comuns e o cuidado com seletores

> Consulte só depois de tentar. Enunciado: [trilhas/13-kustomize/exercicios/KUS-004.md](../../trilhas/13-kustomize/exercicios/KUS-004.md)

## Desafio sem pista — uma solução possível

```bash
cd /tmp/ac13/kustomize/base
python3 - <<'EOF'
p = 'kustomization.yaml'; s = open(p).read()
s = s.replace("      academy.openshift.dev/managed-by: academia\n", "      academy.openshift.dev/managed-by: academia\n      equipe: plataforma\n", 1)
open(p, 'w').write(s)
EOF
oc kustomize . | grep -c 'equipe: plataforma'
oc kustomize . | awk '/^kind: Deployment/,/^---/' | sed -n '/selector:/,/template:/p' | grep -c equipe || echo "seletor intacto"
cd - >/dev/null
```

## Diagnóstico controlado — explicação

`commonLabels` foi criado quando aplicações eram criadas uma vez; para objetos vivos, alterar seletores é proibido.
