# Gabarito KUS-001 — Ler uma base Kustomize e renderizá-la

> Consulte só depois de tentar. Enunciado: [trilhas/13-kustomize/exercicios/KUS-001.md](../../trilhas/13-kustomize/exercicios/KUS-001.md)

## Desafio sem pista — uma solução possível

```bash
oc kustomize /tmp/ac13/kustomize/base > /tmp/ac13/base.out
nome=$(awk '/^kind: ConfigMap/{f=1} f && /^  name:/{print $2; exit}' /tmp/ac13/base.out); echo "gerado: $nome"
grep -n 'ac13-pagina' /tmp/ac13/base.out | grep -v "$nome" || echo "nenhuma referência ao nome sem hash"
```

## Diagnóstico controlado — explicação

Os caminhos em `resources` são relativos ao diretório da `kustomization.yaml`, não ao diretório atual.
