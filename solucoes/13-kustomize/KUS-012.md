# Gabarito KUS-012 — Template guardado no projeto e oc new-app --template

> Consulte só depois de tentar. Enunciado: [trilhas/13-kustomize/exercicios/KUS-012.md](../../trilhas/13-kustomize/exercicios/KUS-012.md)

## Desafio sem pista — uma solução possível

```bash
oc apply -f manifests/templates/ac13-template.yaml -n ac13-dev
oc process ac13-dev//ac13-web -p NOME=ac13-tpl-x | oc apply -n ac13-kustomize -f -
oc get deployment ac13-tpl-x -n ac13-kustomize -o name
```

`projeto//nome` busca o template em outro projeto (é preciso ter leitura nele); o destino é o `-n` do `oc apply`.

## Diagnóstico controlado — explicação

Sem namespace explícito, `oc process` procura o template no projeto atual e no `openshift`.
