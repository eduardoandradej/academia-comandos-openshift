# Gabarito KUS-007 — Patches: estratégico e JSON 6902

## Desafio sem pista — uma solução possível

```bash
cat >> /tmp/ac13/kustomize/overlays/prod/kustomization.yaml <<'EOF'
  - target:
      kind: Deployment
    patch: |-
      - op: add
        path: /spec/template/metadata/annotations
        value:
          academy.openshift.dev/revisado: "sim"
EOF
oc kustomize /tmp/ac13/kustomize/overlays/prod | grep -B2 -A1 'revisado'
```

Sem `name` no `target`, o patch vale para todos os objetos do tipo. Cuidado: `add` em `/annotations` **substitui** o
mapa se ele já existir; para acrescentar uma chave, use o caminho `/spec/template/metadata/annotations/academy.openshift.dev~1revisado`
(o `/` da chave vira `~1`), garantindo antes que o mapa exista.

## Diagnóstico controlado — explicação

O patch precisa encontrar exatamente o objeto descrito; um nome errado vira erro de renderização, não um patch ignorado.
