## Desafio sem pista — uma solução possível

```bash
valida_k() {
  local o=$1 out
  out=$(oc kustomize "$o" 2>&1) || { echo "renderização: $(head -1 <<<"$out")"; return 1; }
  printf '%s\n' "$out" | oc apply --dry-run=server -f - >/dev/null 2>/tmp/ac13/valida.err \
    || { echo "admissão: $(head -1 /tmp/ac13/valida.err)"; return 1; }
  echo "ok: $o"
}
valida_k /tmp/ac13/kustomize/overlays/dev
valida_k /tmp/ac13/kustomize/overlays/prod
```

## Diagnóstico controlado — explicação

O template não conhece tipos; só o servidor sabe que `replicas` precisa ser número.
