## Desafio sem pista — uma solução possível

```bash
oc kustomize base | awk '/^kind: ConfigMap/{f=1} f&&/name:/{print;exit}'                     # 1
oc apply -k base -n ac13-kustomize; oc diff -k base -n ac13-kustomize; oc delete -k base -n ac13-kustomize   # 2
# 3: secretGenerator + envFrom.secretRef (KUS-003)
# 4: labels: [{pairs: {...}, includeSelectors: false, includeTemplates: true}] (KUS-004)
oc apply -k overlays/dev; oc apply -k overlays/prod                                          # 5
# 6: images: [{name: registry.access.redhat.com/ubi9/httpd-24, digest: sha256:...}] (KUS-006)
# 7: patches: [{path: patch.yaml}, {target: {kind: Service, name: ac13-loja}, patch: "- op: add ..."}] (KUS-007)
# 8: overlay homolog (KUS-008)
# 9: KUS-009 desafio
oc process -f manifests/templates/ac13-template.yaml --parameters                            # 10
oc process -f ... -p NOME=a | oc apply -f -; oc process -f ... --param-file=b.env | oc apply -f -   # 11
oc apply -f manifests/templates/ac13-template.yaml; oc new-app --template=ac13-web -p NOME=c  # 12
# 13: KUS-013; 14: tabela do KUS-014; 15: limpeza
```

## Diagnóstico controlado — explicação

Projetos criados pelo próprio usuário podem ser removidos por ele; nenhum outro projeto é tocado.
