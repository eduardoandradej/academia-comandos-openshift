# Gabarito KUS-008 — Criar um overlay novo do zero

> Consulte só depois de tentar. Enunciado: [trilhas/13-kustomize/exercicios/KUS-008.md](../../trilhas/13-kustomize/exercicios/KUS-008.md)

## Desafio sem pista — uma solução possível

```bash
cat > /tmp/ac13/kustomize/overlays/homolog/kustomization.yaml <<'EOF'
apiVersion: kustomize.config.k8s.io/v1beta1
kind: Kustomization
resources:
  - ../../base
namespace: ac13-homolog
labels:
  - pairs:
      ambiente: homolog
    includeSelectors: false
    includeTemplates: true
replicas:
  - name: ac13-loja
    count: 1
configMapGenerator:
  - name: ac13-pagina
    behavior: replace
    literals:
      - index.html=loja da academia (homolog)
EOF
oc kustomize /tmp/ac13/kustomize/overlays/homolog | oc apply --dry-run=server -f -
```

## Diagnóstico controlado — explicação

O Kustomize só reescreve referências que conhece; Routes são um tipo do OpenShift fora da lista padrão.
