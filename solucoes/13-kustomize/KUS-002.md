# Gabarito KUS-002 — Aplicar, comparar e remover com -k

> Consulte só depois de tentar. Enunciado: [trilhas/13-kustomize/exercicios/KUS-002.md](../../trilhas/13-kustomize/exercicios/KUS-002.md)

## Desafio sem pista — uma solução possível

```bash
oc apply -k /tmp/ac13/kustomize/base -n ac13-kustomize
oc get deployment ac13-loja -n ac13-kustomize -o jsonpath='{.spec.template.spec.volumes[0].configMap.name}{"\n"}'
oc rollout history deployment/ac13-loja -n ac13-kustomize | tail -2
```

O conteúdo novo gera outro hash → outro **nome** de ConfigMap → o template do Deployment muda (volume aponta para o
nome novo) → nova revisão. É o mesmo truque manual do CFG-004/DCL-013, feito pelo gerador.

## Diagnóstico controlado — explicação

`-k` sempre espera um diretório com `kustomization.yaml` (ou `.yml`/`Kustomization`).
