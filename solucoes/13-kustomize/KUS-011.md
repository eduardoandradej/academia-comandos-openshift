# Gabarito KUS-011 — oc process: parâmetros, arquivos de parâmetros e valores gerados

> Consulte só depois de tentar. Enunciado: [trilhas/13-kustomize/exercicios/KUS-011.md](../../trilhas/13-kustomize/exercicios/KUS-011.md)

## Desafio sem pista — uma solução possível

```bash
S=$(oc get secret ac13-tpl-a-credencial -n ac13-kustomize -o jsonpath='{.data.senha}' | base64 -d)
oc process -f manifests/templates/ac13-template.yaml -p NOME=ac13-tpl-a -p MENSAGEM='instancia A' -p SENHA="$S" \
  | oc apply -n ac13-kustomize -f -; unset S
```

Passar o valor atual do parâmetro gerado torna o resultado determinístico. (O valor é de treino; com segredos reais,
mantenha o Secret fora do template.)

## Diagnóstico controlado — explicação

`oc process` valida os parâmetros contra a lista do template antes de renderizar.
