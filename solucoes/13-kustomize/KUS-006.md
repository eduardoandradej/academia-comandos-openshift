## Desafio sem pista — uma solução possível

```bash
promove_digest() {
  local tag=${1:-latest} d f=/tmp/ac13/kustomize/overlays/prod/kustomization.yaml
  d=$(oc image info "registry.access.redhat.com/ubi9/httpd-24:$tag" --filter-by-os=linux/amd64 -o json | jq -r .digest) || return 1
  sed -i -E "s|^    (newTag|digest): .*|    digest: $d|" "$f"
  oc diff -k "$(dirname "$f")" && { echo "nada muda"; return 0; }
  read -r -p "aplicar em ac13-prod? (s/N) " r; [ "$r" = s ] && oc apply -k "$(dirname "$f")"
}
promove_digest latest
```

## Diagnóstico controlado — explicação

O transformador compara o nome da imagem sem tag; qualquer diferença no prefixo faz ele ignorar o contêiner.
