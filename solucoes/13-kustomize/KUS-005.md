# Gabarito KUS-005 — Overlays: dev e prod a partir da mesma base

> Consulte só depois de tentar. Enunciado: [trilhas/13-kustomize/exercicios/KUS-005.md](../../trilhas/13-kustomize/exercicios/KUS-005.md)

## Desafio sem pista — uma solução possível

```bash
dep() { oc kustomize "/tmp/ac13/kustomize/overlays/$1" | python3 -c '
import sys, yaml, json
print(json.dumps([d for d in yaml.safe_load_all(sys.stdin) if d and d["kind"]=="Deployment"][0]))'; }
jq -n --argjson a "$(dep dev)" --argjson b "$(dep prod)" '
  [$a, $b] | (.[0] | [paths(scalars)]) + (.[1] | [paths(scalars)]) | unique[] as $p
  | {campo: ($p | map(tostring) | join(".")), dev: ($a | getpath($p)), prod: ($b | getpath($p))}
  | select(.dev != .prod)'
```

Requer o módulo `yaml` do Python (`python3-pyyaml`, padrão no RHEL). Aparecem: namespace, rótulo `ambiente`, réplicas,
nome do ConfigMap (hash), `env`, recursos e estratégia.

## Diagnóstico controlado — explicação

O overlay grava `metadata.namespace` nos objetos; um `-n` diferente é recusado pelo cliente para evitar aplicar no lugar errado.
