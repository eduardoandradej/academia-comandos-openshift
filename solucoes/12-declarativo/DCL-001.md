# Gabarito DCL-001 — Gerar manifestos sem escrever YAML do zero

> Consulte só depois de tentar. Enunciado: [trilhas/12-declarativo/exercicios/DCL-001.md](../../trilhas/12-declarativo/exercicios/DCL-001.md)

## Desafio sem pista — uma solução possível

```bash
oc create deployment ac12-web --image=registry.access.redhat.com/ubi9/httpd-24:latest --port=8080 --dry-run=client -o yaml \
  | oc label --local -f - academy.openshift.dev/managed-by=academia -o yaml \
  | oc set resources --local -f - --requests=cpu=25m,memory=48Mi --limits=cpu=100m,memory=128Mi -o yaml \
  | oc set probe --local -f - --readiness --open-tcp=8080 -o yaml \
  | grep -v -E '^\s*(creationTimestamp: null|status: \{\})$' > /tmp/ac12/deploy.yaml
oc apply --dry-run=client -f /tmp/ac12/deploy.yaml -n ac12-declarativo
```

Os comandos `oc label/set ... --local -f - -o yaml` editam o objeto **no pipe**, sem tocar o cluster (DCL-010).

## Diagnóstico controlado — explicação

Alguns geradores (`expose`) leem objetos do cluster para preencher campos; por isso falham mesmo em dry-run.
