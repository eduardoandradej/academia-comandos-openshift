# Gabarito DCL-005 — Merge de três vias: o que o apply preserva e o que apaga

> Consulte só depois de tentar. Enunciado: [trilhas/12-declarativo/exercicios/DCL-005.md](../../trilhas/12-declarativo/exercicios/DCL-005.md)

## Desafio sem pista — uma solução possível

```bash
sed -i '/^  replicas: 1$/d' /tmp/ac12/app.yaml
oc scale deployment/ac12-web --replicas=2 -n ac12-declarativo
oc diff -f /tmp/ac12/app.yaml -n ac12-declarativo | grep -E '^[-+]\s+replicas' || echo "diff não mexe em replicas"
oc apply -f /tmp/ac12/app.yaml -n ac12-declarativo
oc get deployment ac12-web -n ac12-declarativo -o jsonpath='{.spec.replicas}{"\n"}'     # 2
```

Atenção: no **primeiro** `apply` sem `replicas`, o campo estava no last-applied — pela regra 1 ele seria "removido",
o que para `replicas` significa voltar ao **default (1)**. Se a escala atual importa, remova antes a chave do
last-applied: `oc apply edit-last-applied` ou `oc apply set-last-applied -f` com o arquivo novo, e só então aplique.

## Diagnóstico controlado — explicação

`replicas` declarado no arquivo vence qualquer mudança feita fora dele, a cada `apply`.
