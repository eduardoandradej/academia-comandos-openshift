# Gabarito DCL-004 — oc diff: ver a mudança antes de fazê-la

> Consulte só depois de tentar. Enunciado: [trilhas/12-declarativo/exercicios/DCL-004.md](../../trilhas/12-declarativo/exercicios/DCL-004.md)

## Desafio sem pista — uma solução possível

```bash
aplica_com_portao() {
  local f=$1 ns=${2:-ac12-declarativo} rc
  oc diff -f "$f" -n "$ns"; rc=$?
  case $rc in
    0) echo "nada a aplicar";;
    1) read -r -p "aplicar? (s/N) " r; [ "$r" = s ] && oc apply -f "$f" -n "$ns";;
    *) echo "erro no diff (rc=$rc): não aplico"; return "$rc";;
  esac
}
aplica_com_portao /tmp/ac12/app.yaml
```

## Diagnóstico controlado — explicação

O diff compara o resultado do dry-run de servidor, que inclui defaults e mutações da versão atual.
