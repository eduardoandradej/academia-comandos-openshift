# Gabarito DCL-015 — Circuito declarativo e encerramento da trilha

> Consulte só depois de tentar. Enunciado: [trilhas/12-declarativo/exercicios/DCL-015.md](../../trilhas/12-declarativo/exercicios/DCL-015.md)

## Desafio sem pista — uma solução possível

```bash
oc create deployment x --image=registry.access.redhat.com/ubi9/httpd-24:latest --dry-run=client -o yaml | grep -v -E 'creationTimestamp|status: \{\}'   # 1
sed 's/replicas/replicaz/' app.yaml | oc apply --dry-run=server --validate=strict -f -                       # 2
oc apply -f app.yaml; oc apply -f app.yaml                                                                  # 3
oc diff -f app.yaml; echo $?                                                                                # 4
# 5: removido do arquivo some; declarado vence; não declarado fica (DCL-005)
sed -i '/^  replicas:/d' app.yaml                                                                           # 6
oc apply --server-side --field-manager=a -f cm.yaml; oc apply --server-side --field-manager=b -f cm2.yaml   # 7
oc label deploy ac12-web x=1; oc replace -f app.yaml                                                       # 8
oc patch deploy ac12-web --type=strategic -p '...'; --type=merge; --type=json                               # 9
oc patch deploy ac12-web --type=json -p '[{"op":"test",...},{"op":"replace",...}]'                      # 10
oc label --local -f app.yaml ambiente=prod -o yaml                                                          # 11
oc get deploy ac12-web -o json | jq 'del(.status, .metadata.uid, .metadata.resourceVersion, ...)'          # 12
oc apply -f dir/ && oc wait --for=condition=Available deploy/ac12-web                                       # 13
oc apply -f dir/ --prune -l app=ac12-web --prune-allowlist=... --dry-run=server                             # 14
# 15: tabela do DCL-014
```

## Diagnóstico controlado — explicação

Projetos auxiliares criados durante a trilha não têm o rótulo do projeto principal e precisam de remoção explícita.
