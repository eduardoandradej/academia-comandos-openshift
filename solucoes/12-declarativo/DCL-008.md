# Gabarito DCL-008 — Três tipos de patch: strategic, merge e json

> Consulte só depois de tentar. Enunciado: [trilhas/12-declarativo/exercicios/DCL-008.md](../../trilhas/12-declarativo/exercicios/DCL-008.md)

## Desafio sem pista — uma solução possível

```bash
i=$(oc get deployment ac12-web -n ac12-declarativo -o json | jq '.spec.template.spec.containers[0].env | map(.name) | index("MODO")')
oc patch deployment ac12-web -n ac12-declarativo --type=json -p "[
  {\"op\":\"test\",\"path\":\"/spec/template/spec/containers/0/env/$i/value\",\"value\":\"treino\"},
  {\"op\":\"replace\",\"path\":\"/spec/template/spec/containers/0/env/$i/value\",\"value\":\"homologacao\"}]"
oc patch deployment ac12-web -n ac12-declarativo --type=json -p "[
  {\"op\":\"test\",\"path\":\"/spec/template/spec/containers/0/env/$i/value\",\"value\":\"treino\"}]"; echo "rc=$?"   # agora falha
```

Se o `test` falha, nenhuma operação do patch é aplicada: é atômico.

## Diagnóstico controlado — explicação

JSON Merge Patch não sabe mesclar listas: o que você envia **é** a lista nova.
