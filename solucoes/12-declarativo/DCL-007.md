# Gabarito DCL-007 — replace e replace --force: substituir inteiro

> Consulte só depois de tentar. Enunciado: [trilhas/12-declarativo/exercicios/DCL-007.md](../../trilhas/12-declarativo/exercicios/DCL-007.md)

## Desafio sem pista — uma solução possível

```bash
# 1) só o documento do Deployment, com nome e seletor novos
python3 - <<'EOF' > /tmp/ac12/v2.yaml
docs = open('/tmp/ac12/app.yaml').read().split('\n---\n')
d = [x for x in docs if 'kind: Deployment' in x][0]
d = d.replace('name: ac12-web\n  labels', 'name: ac12-web-v2\n  labels', 1)
d = d.replace('    matchLabels:\n      app: ac12-web\n', '    matchLabels:\n      app: ac12-web\n      ver: "2"\n')
d = d.replace('      labels:\n        app: ac12-web\n', '      labels:\n        app: ac12-web\n        ver: "2"\n')
print(d)
EOF
oc apply -f /tmp/ac12/v2.yaml -n ac12-declarativo
oc rollout status deployment/ac12-web-v2 -n ac12-declarativo
# 2) o Service seleciona app=ac12-web: atende os dois enquanto convivem
oc get endpointslices -n ac12-declarativo -l kubernetes.io/service-name=ac12-web -o jsonpath='{range .items[*].endpoints[*]}{.targetRef.name}{"\n"}{end}'
# 3) só então remova o antigo
oc delete deployment ac12-web -n ac12-declarativo
```

O seletor é imutável: `replace --force` apagaria e recriaria o Deployment (todos os pods saem de uma vez). Criar o
novo ao lado e remover o antigo depois evita a janela sem pods. Para voltar ao estado da trilha, apague o
`ac12-web-v2` e reaplique `/tmp/ac12/app.yaml` (limpeza).

## Diagnóstico controlado — explicação

`resourceVersion` no arquivo transforma o `replace` em "só se ninguém mudou desde então".
