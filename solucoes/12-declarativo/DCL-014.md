## Desafio sem pista — uma solução possível

```bash
explica_erro() {
  local m; m=$(cat)
  case "$m" in
    *"unknown field"*|*"strict decoding"*) echo "campo inexistente: confira com oc explain";;
    *AlreadyExists*|*"already exists"*) echo "objeto já existe: use oc apply";;
    *"has been modified"*) echo "resourceVersion antigo: remova-o do arquivo ou pegue a versão atual";;
    *immutable*) echo "campo imutável: volte o valor, ou crie um objeto novo ao lado";;
    *conflict*) echo "SSA: campo de outro gerenciador; combine ou use --force-conflicts conscientemente";;
    *) echo "não classificado: $m";;
  esac
}
oc create -f /tmp/ac12/app.yaml -n ac12-declarativo 2>&1 | head -1 | explica_erro
```

## Diagnóstico controlado — explicação

Campos imutáveis protegem a identidade do objeto (o seletor diz quais pods o Deployment possui).
