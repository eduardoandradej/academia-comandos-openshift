# Gabarito DCL-012 — Prune: apagar o que saiu do manifesto (com rede de proteção)

> Consulte só depois de tentar. Enunciado: [trilhas/12-declarativo/exercicios/DCL-012.md](../../trilhas/12-declarativo/exercicios/DCL-012.md)

## Desafio sem pista — uma solução possível

```bash
sincroniza_dir() {
  local d=$1 app=$2 ns=${3:-ac12-declarativo} lista n
  local al=(--prune-allowlist=core/v1/ConfigMap --prune-allowlist=core/v1/Service --prune-allowlist=apps/v1/Deployment --prune-allowlist=route.openshift.io/v1/Route)
  lista=$(oc apply -f "$d" -n "$ns" --prune -l "app=$app" "${al[@]}" --dry-run=server | grep pruned)
  n=$(printf '%s' "$lista" | grep -c pruned)
  if [ "$n" -gt 2 ]; then echo "prune removeria $n objetos — abortado:"; echo "$lista"; return 1; fi
  oc apply -f "$d" -n "$ns" --prune -l "app=$app" "${al[@]}"
}
sincroniza_dir /tmp/ac12/dir ac12-web
```

## Diagnóstico controlado — explicação

O prune decide pelo seletor e pela anotação last-applied: qualquer objeto aplicado com o mesmo rótulo é candidato.
