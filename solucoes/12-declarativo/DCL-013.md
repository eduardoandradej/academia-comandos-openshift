## Desafio sem pista — uma solução possível

```bash
H=$(python3 -c "import hashlib,re;s=open('/tmp/ac12/app.yaml').read();m=re.search(r'index.html: \|\n((?:    .*\n)+)',s);print(hashlib.sha256(m.group(1).encode()).hexdigest()[:12])")
python3 - "$H" <<'EOF'
import sys, re
p = '/tmp/ac12/app.yaml'; s = open(p).read(); h = sys.argv[1]
s = re.sub(r'\n        academy.openshift.dev/config-hash: "?\w+"?', '', s)
s = s.replace("    metadata:\n      labels:\n        app: ac12-web\n",
              "    metadata:\n      annotations:\n        academy.openshift.dev/config-hash: \"%s\"\n      labels:\n        app: ac12-web\n" % h, 1)
open(p, 'w').write(s)
EOF
oc diff -f /tmp/ac12/app.yaml -n ac12-declarativo | grep config-hash; oc apply -f /tmp/ac12/app.yaml -n ac12-declarativo
```

Cada mudança no conteúdo gera outro hash, que muda o template e dispara rollout. É o que o `configMapGenerator` do
Kustomize faz automaticamente (Trilha 13). Se o arquivo já tiver `annotations` no template, ajuste o script.

`orphan` remove o dono e mantém os dependentes; eles continuam rodando sem controlador.
