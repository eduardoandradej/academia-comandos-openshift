# Gabarito DCL-009 — Editar arquivos sem cluster: --local e patch local

> Consulte só depois de tentar. Enunciado: [trilhas/12-declarativo/exercicios/DCL-009.md](../../trilhas/12-declarativo/exercicios/DCL-009.md)

## Desafio sem pista — uma solução possível

```bash
gera_ambiente() {
  local amb=$1 rep=$2 img=$3
  python3 - "$rep" "$img" <<'EOF' | oc label --local -f - "ambiente=$amb" -o yaml
import sys, json, subprocess
rep, img = int(sys.argv[1]), sys.argv[2]
docs = json.loads(subprocess.check_output(["oc", "create", "--dry-run=client", "-f", "/tmp/ac12/app.yaml", "-o", "json"]))
items = docs["items"] if docs.get("kind") == "List" else [docs]
for o in items:
    if o["kind"] == "Deployment":
        o["spec"]["replicas"] = rep
        o["spec"]["template"]["spec"]["containers"][0]["image"] = img
print(json.dumps({"apiVersion": "v1", "kind": "List", "items": items}))
EOF
}
gera_ambiente prod 2 registry.access.redhat.com/ubi8/httpd-24:latest | oc apply --dry-run=client -f - -o name
```

Funciona, mas repare quanto código foi preciso: é exatamente o problema que Kustomize resolve (Trilha 13).

## Diagnóstico controlado — explicação

Ferramentas `--local` processam cada documento do arquivo; mudanças em campos específicos de um tipo precisam de filtro.
