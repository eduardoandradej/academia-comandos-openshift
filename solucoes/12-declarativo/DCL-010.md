# Gabarito DCL-010 — Exportar um objeto vivo para um manifesto limpo

> Consulte só depois de tentar. Enunciado: [trilhas/12-declarativo/exercicios/DCL-010.md](../../trilhas/12-declarativo/exercicios/DCL-010.md)

## Desafio sem pista — uma solução possível

```bash
exporta() {
  oc get "$1" -n "${2:-ac12-declarativo}" -o json | jq '
    del(.status, .metadata.uid, .metadata.resourceVersion, .metadata.generation, .metadata.creationTimestamp,
        .metadata.managedFields, .metadata.namespace, .metadata.selfLink)
    | .metadata.annotations |= ((. // {}) | with_entries(select(.key | test("kubectl.kubernetes.io|deployment.kubernetes.io|openshift.io/generated-by") | not)))
    | if (.metadata.annotations | length) == 0 then del(.metadata.annotations) else . end
    | if .kind=="Service" then del(.spec.clusterIP, .spec.clusterIPs) else . end' \
  | oc apply --dry-run=client -f - -o yaml
}
exporta deployment/ac12-web
```

## Diagnóstico controlado — explicação

Um manifesto com `namespace` fixo só pode ser aplicado naquele namespace.
