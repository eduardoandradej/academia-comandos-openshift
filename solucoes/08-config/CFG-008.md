# Gabarito CFG-008 — Pull secret e service account

> Consulte só depois de tentar. Enunciado: [trilhas/08-config/exercicios/CFG-008.md](../../trilhas/08-config/exercicios/CFG-008.md)

## Desafio sem pista — uma solução possível

```bash
oc create sa ac08-robo -n ac08-config
oc secrets link ac08-robo ac08-pull --for=pull -n ac08-config
oc create deployment ac08-robo --image=registry.access.redhat.com/ubi9/httpd-24:latest -n ac08-config
oc set serviceaccount deployment/ac08-robo ac08-robo -n ac08-config
oc rollout status deployment/ac08-robo -n ac08-config
oc get pod -n ac08-config -l app=ac08-robo -o jsonpath='{.items[0].spec.imagePullSecrets}{"\n"}'
```

O controlador de admissão copia os `imagePullSecrets` da service account para o pod no momento da criação.

## Diagnóstico controlado — explicação

`no such host` é falha de DNS: o pull nem chegou a tentar autenticar.
