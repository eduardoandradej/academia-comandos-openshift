# Gabarito CFG-005 — Secrets: criar e ler sem expor

> Consulte só depois de tentar. Enunciado: [trilhas/08-config/exercicios/CFG-005.md](../../trilhas/08-config/exercicios/CFG-005.md)

## Desafio sem pista — uma solução possível

```bash
a=$(oc get secret ac08-banco -n ac08-config -o jsonpath='{.data.senha}' | base64 -d | sha256sum | cut -d' ' -f1)
b=$(printf '%s' 'senha-de-treino' | sha256sum | cut -d' ' -f1)
[ "$a" = "$b" ] && echo "senha confere" || echo "senha diferente"
```

O valor decodificado só passa pelo pipe até o `sha256sum`; nada é exibido. Note o `printf '%s'` (sem quebra de linha) — veja TS-027.

## Diagnóstico controlado — explicação

base64 é codificação reversível, usada para guardar bytes arbitrários em JSON/YAML. A proteção real de um Secret é o
RBAC (quem pode lê-lo) e, no cluster, a criptografia em repouso do etcd (configuração do admin).
