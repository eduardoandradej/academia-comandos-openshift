# Gabarito CFG-003 — Montar ConfigMap como arquivos

> Consulte só depois de tentar. Enunciado: [trilhas/08-config/exercicios/CFG-003.md](../../trilhas/08-config/exercicios/CFG-003.md)

## Desafio sem pista — uma solução possível

```bash
oc patch deployment ac08-app -n ac08-config --type=json -p '[
 {"op":"add","path":"/spec/template/spec/volumes/-","value":{"name":"modo","configMap":{"name":"ac08-literal","items":[{"key":"MODO","path":"atual"}],"defaultMode":292}}},
 {"op":"add","path":"/spec/template/spec/containers/0/volumeMounts/-","value":{"name":"modo","mountPath":"/etc/modo","readOnly":true}}]'
oc rollout status deployment/ac08-app -n ac08-config
oc exec deploy/ac08-app -n ac08-config -- sh -c 'cat /etc/modo/atual; echo; ls -lL /etc/modo/atual'
```

`defaultMode` é decimal no JSON: `292` = `0444` em octal. `ls -lL` segue o link para mostrar as permissões do arquivo real.

## Diagnóstico controlado — explicação

Um volume montado em um diretório esconde tudo o que a imagem tinha lá. Para acrescentar um único arquivo, use `subPath`.
