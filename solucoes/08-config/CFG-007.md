# Gabarito CFG-007 — Secrets tipados: TLS

> Consulte só depois de tentar. Enunciado: [trilhas/08-config/exercicios/CFG-007.md](../../trilhas/08-config/exercicios/CFG-007.md)

## Desafio sem pista — uma solução possível

```bash
for s in $(oc get secrets -n ac08-config -o json | jq -r '.items[] | select(.type=="kubernetes.io/tls") | .metadata.name'); do
  printf '%s: ' "$s"
  oc get secret "$s" -n ac08-config -o jsonpath='{.data.tls\.crt}' | base64 -d | openssl x509 -noout -subject -enddate | tr '\n' ' '; echo
done
```

## Diagnóstico controlado — explicação

Os módulos diferentes provam que certificado e chave não são do mesmo par; o `oc` recusa antes de enviar à API.
