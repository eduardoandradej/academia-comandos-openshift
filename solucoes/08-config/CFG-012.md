# Gabarito CFG-012 — Extrair e atualizar: oc extract e oc set data

> Consulte só depois de tentar. Enunciado: [trilhas/08-config/exercicios/CFG-012.md](../../trilhas/08-config/exercicios/CFG-012.md)

## Desafio sem pista — uma solução possível

```bash
for cm in $(oc get configmaps -n ac08-config -l academy.openshift.dev/managed-by=academia -o name | cut -d/ -f2); do
  mkdir -p "/tmp/ac08/backup/$cm"; oc extract "configmap/$cm" --to="/tmp/ac08/backup/$cm" -n ac08-config --confirm >/dev/null
done
oc delete configmap ac08-env -n ac08-config
oc create configmap ac08-env --from-file=/tmp/ac08/backup/ac08-env/ -n ac08-config
oc label configmap ac08-env academy.openshift.dev/managed-by=academia -n ac08-config
oc get configmap ac08-env -n ac08-config -o jsonpath='{.data}{"\n"}'
```

A restauração por diretório recria uma chave por arquivo — o mesmo resultado do `--from-env-file` original.

## Diagnóstico controlado — explicação

`oc extract` não sobrescreve arquivos existentes sem `--confirm`, para evitar perda de edições locais.
