# Gabarito CFG-010 — Um arquivo de configuração real: conf.d do httpd com subPath

> Consulte só depois de tentar. Enunciado: [trilhas/08-config/exercicios/CFG-010.md](../../trilhas/08-config/exercicios/CFG-010.md)

## Desafio sem pista — uma solução possível

```bash
oc create configmap ac08-httpd --from-literal=academia.conf='Header always set X-Academia "revisao"' --dry-run=client -o yaml \
  | oc apply -n ac08-config -f -
H=$(oc get configmap ac08-httpd -n ac08-config -o json | jq -cS .data | sha256sum | cut -c1-12)
oc patch deployment ac08-web -n ac08-config --type=merge -p "{\"spec\":{\"template\":{\"metadata\":{\"annotations\":{\"academy.openshift.dev/config-hash\":\"$H\"}}}}}"
oc rollout status deployment/ac08-web -n ac08-config
oc port-forward deploy/ac08-web 18088:8080 -n ac08-config >/dev/null 2>&1 & PF=$!; sleep 3
curl -sSI http://127.0.0.1:18088/ | grep -i x-academia; kill $PF
```

## Diagnóstico controlado — explicação

Com `subPath`, o kubelet copia o arquivo uma vez, sem o mecanismo de links `..data` que permite a atualização.
