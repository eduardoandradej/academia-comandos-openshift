# Gabarito CFG-006 — Consumir Secrets: variáveis e arquivos

> Consulte só depois de tentar. Enunciado: [trilhas/08-config/exercicios/CFG-006.md](../../trilhas/08-config/exercicios/CFG-006.md)

## Desafio sem pista — uma solução possível

```bash
oc patch deployment ac08-app -n ac08-config --type=json -p '[
 {"op":"add","path":"/spec/template/spec/volumes/-","value":{"name":"db","secret":{"secretName":"ac08-banco","items":[{"key":"senha","path":"senha"}],"defaultMode":256}}},
 {"op":"add","path":"/spec/template/spec/containers/0/volumeMounts/-","value":{"name":"db","mountPath":"/run/db","readOnly":true}}]'
oc rollout status deployment/ac08-app -n ac08-config
oc exec deploy/ac08-app -n ac08-config -- sh -c 'ls -lL /run/db/senha; wc -c < /run/db/senha'
```

`256` decimal = `0400`. O arquivo pertence ao grupo do pod; com o UID arbitrário do OpenShift, a leitura continua possível.

## Diagnóstico controlado — explicação

O `describe` mostra de onde a variável vem. Os valores só são materializados dentro do contêiner.
