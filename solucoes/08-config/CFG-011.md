# Gabarito CFG-011 — Volume projetado: ConfigMap, Secret e Downward API no mesmo diretório

> Consulte só depois de tentar. Enunciado: [trilhas/08-config/exercicios/CFG-011.md](../../trilhas/08-config/exercicios/CFG-011.md)

## Desafio sem pista — uma solução possível

```bash
V=$(oc get deployment ac08-app -n ac08-config -o json | jq '[.spec.template.spec.volumes[].name] | index("tudo")')
oc patch deployment ac08-app -n ac08-config --type=json -p "[{\"op\":\"add\",\"path\":\"/spec/template/spec/volumes/$V/projected/sources/2/downwardAPI/items/-\",
  \"value\":{\"path\":\"limite-memoria\",\"resourceFieldRef\":{\"containerName\":\"httpd-24\",\"resource\":\"limits.memory\",\"divisor\":\"1Mi\"}}}]"
oc rollout status deployment/ac08-app -n ac08-config
oc exec deploy/ac08-app -n ac08-config -- cat /etc/tudo/limite-memoria
```

Sem `limits` declarados, o valor reflete o padrão do LimitRange (se houver) ou a memória alocável do nó.

## Diagnóstico controlado — explicação

Um volume projetado só monta se todas as fontes existirem (a menos que marcadas como `optional: true`).
