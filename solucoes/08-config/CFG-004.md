# Gabarito CFG-004 — Atualizar configuração: arquivos se atualizam, variáveis não

> Consulte só depois de tentar. Enunciado: [trilhas/08-config/exercicios/CFG-004.md](../../trilhas/08-config/exercicios/CFG-004.md)

## Desafio sem pista — uma solução possível

```bash
oc create configmap ac08-literal --from-literal=MODO=v3 --from-literal=NIVEL_LOG=debug --dry-run=client -o yaml \
  | oc apply -n ac08-config -f -
H=$(oc get configmap ac08-literal -n ac08-config -o json | jq -cS .data | sha256sum | cut -c1-12)
oc patch deployment ac08-app -n ac08-config --type=merge \
  -p "{\"spec\":{\"template\":{\"metadata\":{\"annotations\":{\"academy.openshift.dev/config-hash\":\"$H\"}}}}}"
oc rollout status deployment/ac08-app -n ac08-config && oc exec deploy/ac08-app -n ac08-config -- printenv MODO   # v3
```

Mudou o conteúdo → muda o hash → muda o template → nova revisão. É o padrão usado por ferramentas como Helm e Kustomize
(Trilhas 13 e 14), que geram nomes ou anotações a partir do conteúdo.

## Diagnóstico controlado — explicação

Variáveis são copiadas para o processo na criação do contêiner; nenhum mecanismo as altera depois.
