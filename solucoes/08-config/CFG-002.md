# Gabarito CFG-002 — Injetar ConfigMap como variáveis de ambiente

> Consulte só depois de tentar. Enunciado: [trilhas/08-config/exercicios/CFG-002.md](../../trilhas/08-config/exercicios/CFG-002.md)

## Desafio sem pista — uma solução possível

```bash
oc patch deployment ac08-app -n ac08-config --type=json -p '[{"op":"add","path":"/spec/template/spec/containers/0/env/-",
  "value":{"name":"LOG_LEVEL","valueFrom":{"configMapKeyRef":{"name":"ac08-env","key":"NIVEL_LOG"}}}}]'
oc rollout status deployment/ac08-app -n ac08-config
oc exec deploy/ac08-app -n ac08-config -- printenv LOG_LEVEL      # info
```

Repetição 4: uma variável definida em `env` prevalece sobre a mesma vinda de `envFrom`.

## Diagnóstico controlado — explicação

Nomes de variáveis precisam seguir o padrão `[A-Za-z_][A-Za-z0-9_]*`; `app.conf` tem ponto e é descartada com aviso.
