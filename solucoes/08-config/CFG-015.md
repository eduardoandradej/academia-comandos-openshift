# Gabarito CFG-015 — Circuito de configuração e encerramento da trilha

> Consulte só depois de tentar. Enunciado: [trilhas/08-config/exercicios/CFG-015.md](../../trilhas/08-config/exercicios/CFG-015.md)

## Desafio sem pista — uma solução possível

```bash
oc create configmap c1 --from-literal=A=1 --from-literal=B=2 -n ac08-config                                  # 1
oc create configmap c2 --from-file=conf.txt=/tmp/ac08/app.conf -n ac08-config                                # 2
oc create configmap c3 --from-env-file=/tmp/ac08/app.env -n ac08-config                                      # 3
oc set env deployment/ac08-app --from=configmap/c3 --prefix=C3_ -n ac08-config                               # 4
oc patch deployment ac08-app -n ac08-config --type=json -p '[{"op":"add","path":"/spec/template/spec/containers/0/env/-","value":{"name":"SO_A","valueFrom":{"configMapKeyRef":{"name":"c1","key":"A"}}}}]'   # 5
oc set volume deployment/ac08-app --add --name=c2 --type=configmap --configmap-name=c2 --mount-path=/etc/c2 -n ac08-config   # 6
# 7: subPath via patch (CFG-010)
oc set data configmap/c1 A=9 -n ac08-config; oc exec deploy/ac08-app -n ac08-config -- printenv SO_A; \
  oc rollout restart deployment/ac08-app -n ac08-config                                                       # 8
read -rs S; oc create secret generic s9 --from-literal=v="$S" -n ac08-config; unset S                        # 9
oc describe secret s9 -n ac08-config                                                                         # 10
# 11: volume secret com defaultMode 256 (CFG-006)
oc create secret tls s12 --cert=/tmp/ac08/tls.crt --key=/tmp/ac08/tls.key -n ac08-config                     # 12 (gere o par antes)
oc create secret docker-registry s13 --docker-server=registry.exemplo.invalid --docker-username=t --docker-password=ficticia -n ac08-config; \
  oc secrets link default s13 --for=pull -n ac08-config                                                      # 13
oc create configmap c14-v1 --from-literal=V=1 --dry-run=client -o json | jq '.immutable=true' | oc apply -n ac08-config -f -   # 14
oc create configmap c3 --from-env-file=/tmp/ac08/app.env --dry-run=client -o yaml | oc diff -n ac08-config -f -   # 15
```

## Diagnóstico controlado — explicação

Chaves privadas de treino são descartáveis, mas o hábito de apagá-las é o mesmo que protege as reais.
