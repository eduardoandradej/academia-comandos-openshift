# Gabarito CFG-009 — ConfigMaps e Secrets imutáveis

> Consulte só depois de tentar. Enunciado: [trilhas/08-config/exercicios/CFG-009.md](../../trilhas/08-config/exercicios/CFG-009.md)

## Desafio sem pista — uma solução possível

```bash
oc set env deployment/ac08-app --from=configmap/ac08-fixo-v1 -n ac08-config && oc rollout status deployment/ac08-app -n ac08-config
oc get deployment ac08-app -n ac08-config -o json \
  | jq '(.spec.template.spec.containers[0].envFrom[] | select(.configMapRef.name=="ac08-fixo-v1") | .configMapRef.name) = "ac08-fixo-v2"' \
  | oc apply -n ac08-config -f -
oc rollout status deployment/ac08-app -n ac08-config
oc exec deploy/ac08-app -n ac08-config -- printenv VERSAO      # 2
oc delete configmap ac08-fixo-v1 -n ac08-config
```

A troca da referência é uma única mudança no template; o `jq` edita só o `envFrom` certo.

## Diagnóstico controlado — explicação

A API recusa qualquer escrita em `data` de um objeto imutável; mudar `immutable` de `true` para `false` também é proibido.
