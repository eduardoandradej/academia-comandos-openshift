# Gabarito CFG-001 — Criar ConfigMaps: literal, arquivo e arquivo de variáveis

> Consulte só depois de tentar. Enunciado: [trilhas/08-config/exercicios/CFG-001.md](../../trilhas/08-config/exercicios/CFG-001.md)

## Desafio sem pista — uma solução possível

```bash
{ oc create configmap ac08-tudo --from-literal=VERSAO=1 --from-file=httpd.conf=/tmp/ac08/app.conf --dry-run=client -o json
  oc create configmap ac08-tudo --from-env-file=/tmp/ac08/app.env --dry-run=client -o json; } \
  | jq -s '.[0] * .[1] | .metadata.labels={"academy.openshift.dev/managed-by":"academia"}' \
  | oc apply -n ac08-config -f -
oc get configmap ac08-tudo -n ac08-config -o json | jq -r '.data | keys[]'
```

O `oc` não aceita `--from-env-file` junto com as outras origens; gerar os dois objetos e mesclá-los com `jq` resolve em uma aplicação.

## Diagnóstico controlado — explicação

A mensagem é do próprio cliente, antes de contatar a API: combinação proibida pela ferramenta.
