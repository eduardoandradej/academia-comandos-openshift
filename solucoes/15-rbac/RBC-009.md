## Desafio sem pista — uma solução possível

```bash
cuidado() {
  local c="$*"
  case "$c" in
    *add-cluster-role-to-*|*"create clusterrolebinding"*|*add-scc-to-*|*" -n openshift-"*|*"--namespace=openshift-"*|*" -n kube-"*) echo "VERMELHO: $c";;
    *add-role-to-*|*" create "*|*" apply "*|*" delete "*|*" patch "*|*" label "*) echo "AMARELO: $c";;
    *) echo "VERDE: $c";;
  esac
}
cuidado oc adm policy add-cluster-role-to-user view developer
cuidado oc policy add-role-to-user view -z x -n ac15-rbac
cuidado oc get pods -n ac15-rbac
```

## Diagnóstico controlado — explicação

Um único binding de cluster para um grupo virtual alcança todos os usuários autenticados.
