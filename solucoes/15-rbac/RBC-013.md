# Gabarito RBC-013 — Identidades e o provedor OAuth (leitura) e o roteiro HTPasswd

> Consulte só depois de tentar. Enunciado: [trilhas/15-rbac/exercicios/RBC-013.md](../../trilhas/15-rbac/exercicios/RBC-013.md)

## Desafio sem pista — uma solução possível

```bash
ac-admin
grupos=$(oc get groups -o json)
oc get users -o json | jq -r --argjson g "$grupos" '.items[] | .metadata.name as $u
  | "\(.identities | join(",")) → \($u) → \([$g.items[] | select(.users // [] | index($u)) | .metadata.name] | join(",") | if .=="" then "-" else . end)"'
ac-dev
```

## Diagnóstico controlado — explicação

O OAuth lê o Secret do HTPasswd inteiro; um arquivo inválido derruba a autenticação de todos os usuários desse provedor.
