> Consulte só depois de tentar. Enunciado: [trilhas/15-rbac/exercicios/RBC-001.md](../../trilhas/15-rbac/exercicios/RBC-001.md)

## Desafio sem pista — uma solução possível

```bash
for r in $(oc api-resources --namespaced=false --verbs=list -o name); do
  oc auth can-i list "$r" -q 2>/dev/null && echo "$r"
done
```

Aparecem, tipicamente, `projects` (os seus), `selfsubject*reviews`, `storageclasses` e outros de leitura pública.

## Diagnóstico controlado — explicação

`oc auth whoami` usa `SelfSubjectReview` (Kubernetes 1.28+); o endpoint `users/~` é a forma tradicional do OpenShift.
