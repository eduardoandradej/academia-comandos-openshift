## Desafio sem pista — uma solução possível

```bash
ac-admin
oc adm create-bootstrap-project-template -o json | jq --slurpfile b <(python3 -c '
import yaml,json,sys; print(json.dumps(list(yaml.safe_load_all(open("manifests/baseline-seguro/quota-limitrange.yaml")))))') '
  .metadata.name = "ac-project-request" | .objects += [ $b[0][] | .metadata.namespace = "${PROJECT_NAME}" ]' > /tmp/ac15-template.json
jq -r '.objects[].kind' /tmp/ac15-template.json
ac-dev
```

Para ativar (VERMELHO, manual): `oc create -f` do template em `openshift-config` e
`oc patch project.config.openshift.io cluster --type=merge -p '{"spec":{"projectRequestTemplate":{"name":"ac-project-request"}}}'`.
Isso afeta **todos** os projetos novos do cluster. Apague `/tmp/ac15-template.json` ao terminar.
