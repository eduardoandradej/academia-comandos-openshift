# Gabarito RBC-007 — Grupos: conceder a uma equipe, não a pessoas

> Consulte só depois de tentar. Enunciado: [trilhas/15-rbac/exercicios/RBC-007.md](../../trilhas/15-rbac/exercicios/RBC-007.md)

## Desafio sem pista — uma solução possível

```bash
ac-admin
oc adm groups new ac15-auditores && oc label group ac15-auditores academy.openshift.dev/managed-by=academia academy.openshift.dev/trilha=15
for p in ac15-rbac ac15-alheio; do oc policy add-role-to-group view ac15-auditores -n "$p"; done
for p in ac15-rbac ac15-alheio; do
  printf '%s list pods=%s create deployments=%s\n' "$p" \
    "$(oc auth can-i list pods -n $p --as=qualquer --as-group=ac15-auditores --as-group=system:authenticated)" \
    "$(oc auth can-i create deployments -n $p --as=qualquer --as-group=ac15-auditores --as-group=system:authenticated)"
done
ac-dev
```

`--as=qualquer` não precisa existir: a impersonação testa a autorização para o nome e os grupos informados.

## Diagnóstico controlado — explicação

Bindings guardam o **nome** do grupo; um erro de digitação aponta para um grupo vazio, sem aviso.
