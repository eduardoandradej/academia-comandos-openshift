# Gabarito RBC-004 — RoleBindings por dentro: sujeitos, roleRef e auditoria

> Consulte só depois de tentar. Enunciado: [trilhas/15-rbac/exercicios/RBC-004.md](../../trilhas/15-rbac/exercicios/RBC-004.md)

## Desafio sem pista — uma solução possível

```bash
oc create rolebinding ac15-robo-edit --clusterrole=edit --serviceaccount=ac15-rbac:ac15-robo -n ac15-rbac
oc auth can-i create deployments -n ac15-rbac --as=system:serviceaccount:ac15-rbac:ac15-robo   # yes
oc delete rolebinding ac15-robo-view -n ac15-rbac
```

Criar o novo antes de apagar o antigo evita a janela sem permissão (`edit` inclui tudo de `view`).

## Diagnóstico controlado — explicação

O `roleRef` é a identidade do binding; mudá-lo exigiria reavaliar quem o criou. Por isso a API proíbe.
