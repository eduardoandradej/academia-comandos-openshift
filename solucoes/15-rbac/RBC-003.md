# Gabarito RBC-003 — Os papéis padrão do projeto: view, edit e admin

> Consulte só depois de tentar. Enunciado: [trilhas/15-rbac/exercicios/RBC-003.md](../../trilhas/15-rbac/exercicios/RBC-003.md)

## Desafio sem pista — uma solução possível

```bash
S=system:serviceaccount:ac15-rbac:ac15-leitor
oc policy add-role-to-user view -z ac15-leitor -n ac15-rbac
for a in "get secrets" "get configmaps" "get pods/log" "create pods/exec"; do printf 'view %-18s %s\n' "$a" "$(oc auth can-i $a -n ac15-rbac --as=$S)"; done
oc policy add-role-to-user edit -z ac15-leitor -n ac15-rbac
printf 'edit %-18s %s\n' "create pods/exec" "$(oc auth can-i create pods/exec -n ac15-rbac --as=$S)"
oc policy remove-role-from-user edit -z ac15-leitor -n ac15-rbac
```

## Diagnóstico controlado — explicação

Os papéis padrão são cumulativos e separam operar a aplicação (`edit`) de administrar o acesso a ela (`admin`).
