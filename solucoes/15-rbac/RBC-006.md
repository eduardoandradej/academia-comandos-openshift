# Gabarito RBC-006 — ClusterRole usada dentro de um projeto

> Consulte só depois de tentar. Enunciado: [trilhas/15-rbac/exercicios/RBC-006.md](../../trilhas/15-rbac/exercicios/RBC-006.md)

## Desafio sem pista — uma solução possível

```bash
ac-admin
oc get clusterrolebindings -o json | jq -r '.items[] | select(.roleRef.name=="cluster-admin")
  | .metadata.name as $b | .subjects[]? | "\(.kind)\t\(.name)\t(\($b))"'
ac-dev
```

Esperado: `system:masters` (grupo do certificado do instalador), o `admin` do HomeLab e contas de componentes.

## Diagnóstico controlado — explicação

Só papéis de cluster criam objetos de cluster; o developer administra apenas seus projetos.
