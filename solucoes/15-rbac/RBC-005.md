# Gabarito RBC-005 — Role própria com o mínimo necessário

> Consulte só depois de tentar. Enunciado: [trilhas/15-rbac/exercicios/RBC-005.md](../../trilhas/15-rbac/exercicios/RBC-005.md)

## Desafio sem pista — uma solução possível

```bash
oc create deployment ac15-alvo --image=registry.access.redhat.com/ubi9/httpd-24:latest -n ac15-rbac
oc create role ac15-escalador -n ac15-rbac --verb=get,list --resource=deployments
oc patch role ac15-escalador -n ac15-rbac --type=json -p '[{"op":"add","path":"/rules/-","value":{"apiGroups":["apps"],"resources":["deployments/scale"],"verbs":["get","update","patch"]}}]'
oc create rolebinding ac15-robo-escala --role=ac15-escalador --serviceaccount=ac15-rbac:ac15-robo -n ac15-rbac
S=system:serviceaccount:ac15-rbac:ac15-robo
oc scale deployment/ac15-alvo --replicas=2 -n ac15-rbac --as=$S && echo "escalou"
oc set image deployment/ac15-alvo httpd-24=registry.access.redhat.com/ubi9/httpd-24:latest -n ac15-rbac --as=$S 2>&1 | head -1   # Forbidden
oc scale deployment/ac15-alvo --replicas=1 -n ac15-rbac
```

## Diagnóstico controlado — explicação

`resourceNames` filtra por nome; operações de coleção (`list`, `watch` sem `fieldSelector` de nome, `create`) não têm nome a comparar.
