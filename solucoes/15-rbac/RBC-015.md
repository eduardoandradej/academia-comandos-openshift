# Gabarito RBC-015 — Circuito de RBAC e encerramento da trilha

> Consulte só depois de tentar. Enunciado: [trilhas/15-rbac/exercicios/RBC-015.md](../../trilhas/15-rbac/exercicios/RBC-015.md)

## Desafio sem pista — uma solução possível

```bash
oc auth whoami                                                                       # 1
oc auth can-i get pods/log -n ac15-rbac --as=system:serviceaccount:ac15-rbac:ac15-leitor                         # 2
# 3: tabela do RBC-003
oc create rolebinding novo --clusterrole=edit --serviceaccount=ac15-rbac:ac15-robo; oc delete rolebinding velho   # 4
oc create role r --verb=get --resource=configmaps --resource-name=ac15-publico       # 5
oc create rolebinding b --clusterrole=ac15-leitor-configmaps --serviceaccount=ac15-rbac:ac15-robo   # 6
oc adm groups add-users ac15-equipe developer; oc adm groups remove-users ac15-equipe developer      # 7 (admin)
T=$(oc create token ac15-leitor --duration=10m); oc --token="$T" whoami; unset T       # 8
oc adm policy add-cluster-role-to-user view developer --dry-run=client -o yaml       # 9 (admin)
# 10: matriz do RBC-010
oc get clusterrolebinding self-provisioners -o jsonpath='{.subjects}'               # 11 (admin)
oc get pod <pod> -o jsonpath='{.metadata.annotations.openshift\.io/scc}'            # 12
oc get identities; oc get users; oc get groups                                       # 13 (admin)
# 14: roteiro do RBC-014; 15: limpeza acima
```

## Diagnóstico controlado — explicação

Objetos de cluster sobrevivem aos projetos: a limpeza deles é sempre explícita e por rótulo.
