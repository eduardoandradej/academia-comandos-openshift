# Gabarito RBC-014 — Roteiro de diagnóstico de Forbidden

> Consulte só depois de tentar. Enunciado: [trilhas/15-rbac/exercicios/RBC-014.md](../../trilhas/15-rbac/exercicios/RBC-014.md)

## Desafio sem pista — uma solução possível

```bash
explica_forbidden() {
  sed -nE 's/.*(User|ServiceAccount) "([^"]+)" cannot ([a-z]+) resource "([^"]+)" in API group "([^"]*)"( in the namespace "([^"]+)")?( at the cluster scope)?.*/sujeito=\2\nverbo=\3\nrecurso=\4\ngrupo=\5 (vazio = core)\nescopo=\7\8/p' \
  | sed 's/^escopo=$/escopo=cluster/; s/^escopo= at the cluster scope$/escopo=cluster/'
}
oc get nodes --as=system:serviceaccount:ac15-rbac:ac15-robo 2>&1 | explica_forbidden
```

## Diagnóstico controlado — explicação

Recursos fora do grupo core aparecem com o grupo na mensagem; a regra precisa citar o mesmo grupo.
