# Gabarito DES-010 — Missão 10: estado persistente (REQUER PREPARAÇÃO)

> Consulte só depois de tentar. Enunciado: [trilhas/20-desafios/exercicios/DES-010.md](../../trilhas/20-desafios/exercicios/DES-010.md)

## Desafio sem pista — uma solução possível

```bash
N=ac20-estado
sed -e "s/AC09_SC/$SC/" -e 's/ac09-sts/ac20-banco/g' manifests/apps-exemplo/statefulset-mini.yaml | oc apply -n $N -f -
oc patch statefulset ac20-banco -n $N --type=merge -p '{"spec":{"persistentVolumeClaimRetentionPolicy":{"whenScaled":"Retain","whenDeleted":"Retain"}}}'
oc rollout status statefulset/ac20-banco -n $N
oc exec ac20-banco-0 -n $N -- sh -c 'echo prova > /dados/prova.txt'
oc delete pod ac20-banco-0 -n $N && oc wait --for=condition=Ready pod/ac20-banco-0 -n $N --timeout=120s
oc scale statefulset/ac20-banco --replicas=1 -n $N; oc scale statefulset/ac20-banco --replicas=2 -n $N
oc rollout status statefulset/ac20-banco -n $N && oc exec ac20-banco-0 -n $N -- cat /dados/prova.txt
```

## Diagnóstico controlado — explicação

Cada réplica espera o seu PVC ligar; uma barreira de storage trava a réplica correspondente.
