# Gabarito DES-005 — Missão 5: promoção de versões com ImageStream

> Consulte só depois de tentar. Enunciado: [trilhas/20-desafios/exercicios/DES-005.md](../../trilhas/20-desafios/exercicios/DES-005.md)

## Desafio sem pista — uma solução possível

```bash
N=ac20-loja
oc create imagestream loja -n $N && oc label is loja academy.openshift.dev/managed-by=academia -n $N
oc import-image loja:v1 --from=registry.access.redhat.com/ubi9/httpd-24:latest --confirm -n $N
oc import-image loja:v2 --from=registry.access.redhat.com/ubi8/httpd-24:latest --confirm -n $N
oc tag loja:v1 loja:prod -n $N
C=$(oc get deploy loja -n $N -o jsonpath='{.spec.template.spec.containers[0].name}')
oc set triggers deployment/loja --from-image=loja:prod --containers="$C" -n $N
oc tag loja:v2 loja:prod -n $N && oc rollout status deployment/loja -n $N        # promoção
oc tag loja:v1 loja:prod -n $N && oc rollout status deployment/loja -n $N        # volta
```

## Diagnóstico controlado — explicação

O gatilho grava o digest no template; é ele (não você) quem muda o Deployment.
