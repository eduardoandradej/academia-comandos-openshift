# Gabarito DES-009 — Missão 9: rotina de manutenção com CronJob

> Consulte só depois de tentar. Enunciado: [trilhas/20-desafios/exercicios/DES-009.md](../../trilhas/20-desafios/exercicios/DES-009.md)

## Desafio sem pista — uma solução possível

```bash
N=ac20-loja
oc create cronjob loja-relatorio --image=registry.access.redhat.com/ubi9/httpd-24:latest --schedule='17 3 * * *' -n $N --dry-run=client -o json -- \
  /bin/bash -c 'test -n "$ALVO" || { echo "ALVO não definido" >&2; exit 2; }; date; exec 3<>/dev/tcp/$ALVO/8080 && printf "GET / HTTP/1.0\r\n\r\n" >&3 && tail -1 <&3' \
  | jq '.spec.suspend=true | .spec.successfulJobsHistoryLimit=2 | .spec.failedJobsHistoryLimit=2
        | .spec.jobTemplate.spec.backoffLimit=1 | .spec.jobTemplate.spec.activeDeadlineSeconds=60
        | .spec.jobTemplate.spec.template.metadata.labels={"app":"loja-relatorio","academy.openshift.dev/managed-by":"academia"}
        | .spec.jobTemplate.spec.template.spec.containers[0].env=[{"name":"ALVO","value":"loja"}]
        | .spec.jobTemplate.spec.template.spec.containers[0].resources={"requests":{"cpu":"10m","memory":"16Mi"},"limits":{"cpu":"50m","memory":"64Mi"}}
        | .metadata.labels={"academy.openshift.dev/managed-by":"academia"}' | oc apply -n $N -f -
cat <<'EOF' | oc apply -n $N -f -
apiVersion: networking.k8s.io/v1
kind: NetworkPolicy
metadata: {name: loja-relatorio-saida, labels: {academy.openshift.dev/managed-by: academia}}
spec:
  podSelector: {matchLabels: {app: loja-relatorio}}
  policyTypes: [Egress]
  egress:
    - to: [{podSelector: {matchLabels: {app: loja}}}]
      ports: [{protocol: TCP, port: 8080}]
EOF
```

A política só seleciona os pods do Job (`app=loja-relatorio`); a loja continua sem saída.

## Diagnóstico controlado — explicação

Com saída negada no projeto, qualquer pod novo — inclusive de Jobs — herda o bloqueio.
