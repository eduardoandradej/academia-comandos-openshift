# Gabarito DES-003 — Missão 3: a loja isolada

> Consulte só depois de tentar. Enunciado: [trilhas/20-desafios/exercicios/DES-003.md](../../trilhas/20-desafios/exercicios/DES-003.md)

## Desafio sem pista — uma solução possível

```bash
N=ac20-loja
oc apply -f manifests/networkpolicies/00-negar-entrada.yaml -f manifests/networkpolicies/10-permitir-mesmo-projeto.yaml -n $N
oc apply -f manifests/networkpolicies/30-permitir-router.yaml -n $N      # seleciona app=loja: serve sem ajuste
oc apply -f manifests/networkpolicies/40-negar-saida.yaml -f manifests/networkpolicies/50-permitir-dns.yaml -n $N
```

O `oc create deployment loja` rotula os pods com `app=loja`, o mesmo seletor da política do router da Trilha 16 — por
isso ela serve sem ajuste. Confira sempre antes de reaproveitar (DIA-008).

## Diagnóstico controlado — explicação

O router é um cliente de outro namespace; sem política para ele, toda Route do projeto cai.
