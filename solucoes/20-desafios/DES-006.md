# Gabarito DES-006 — Missão 6: a loja em dois ambientes com Kustomize

> Consulte só depois de tentar. Enunciado: [trilhas/20-desafios/exercicios/DES-006.md](../../trilhas/20-desafios/exercicios/DES-006.md)

## Desafio sem pista — uma solução possível

Use `manifests/kustomize/` (Trilha 13) como modelo: a base com `configMapGenerator` (`files: [index.html]`) e
`labels` com `includeSelectors: false`; overlays com `namespace`, `replicas`, `images` (`name` sem tag, `digest`)
e `configMapGenerator` com `behavior: replace`. Comparação final:

```bash
diff <(oc kustomize /tmp/ac20/k/overlays/dev) <(oc kustomize /tmp/ac20/k/overlays/prod)
oc apply -k /tmp/ac20/k/overlays/dev && oc apply -k /tmp/ac20/k/overlays/prod
```

## Diagnóstico controlado — explicação

O overlay grava o namespace nos objetos; por isso o `-n` é dispensável (e perigoso se diferente).
