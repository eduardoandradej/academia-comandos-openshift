# Gabarito DES-011 — Missão 11: diagnóstico cego de uma loja com sete defeitos

> Consulte só depois de tentar. Enunciado: [trilhas/20-desafios/exercicios/DES-011.md](../../trilhas/20-desafios/exercicios/DES-011.md)

## Desafio sem pista — uma solução possível

| # | Andar | Defeito | Correção |
|---|---|---|---|
| 1 | 5 | Secret `ac20-api` não existe (`CreateContainerConfigError`) | `read -rs T; oc create secret generic ac20-api --from-literal=token="$T" -n ac20-cego; unset T` |
| 2 | 6 | `limits.memory: 20Mi` (OOMKilled) | `oc set resources deployment/ac20-loja --requests=memory=48Mi --limits=memory=128Mi -n ac20-cego` |
| 3 | 6 | ConfigMap com `indice.html` (sem `index.html`): `/` responde 403 e a readiness falha | `oc patch cm ac20-pagina -n ac20-cego --type=json -p '[{"op":"move","from":"/data/indice.html","path":"/data/index.html"}]'` |
| 4 | 7 | Service seleciona `app=ac20-shop` | `oc set selector service ac20-loja app=ac20-loja -n ac20-cego` |
| 5 | 7 | `targetPort: 8443` (TLS do httpd) | `oc patch svc ac20-loja -n ac20-cego --type=json -p '[{"op":"replace","path":"/spec/ports/0/targetPort","value":8080}]'` |
| 6 | 7 | Route aponta para `ac20-lojas` | `oc patch route ac20-loja -n ac20-cego --type=merge -p '{"spec":{"to":{"name":"ac20-loja"}}}'` |
| 7 | 7 | NetworkPolicy só libera o próprio projeto (router bloqueado) | `sed 's/app: loja/app: ac20-loja/' manifests/networkpolicies/30-permitir-router.yaml \| oc apply -n ac20-cego -f -` |

Depois do item 3, faça `oc rollout restart` se os pods não perceberem o arquivo novo a tempo (a montagem se
atualiza em até ~1 min). A readiness `httpGet /` passa a responder 200 com a página real.

## Diagnóstico controlado — explicação

Cada correção muda o sintoma: siga o novo sintoma até a Route responder.
