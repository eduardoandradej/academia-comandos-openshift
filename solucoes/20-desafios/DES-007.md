# Gabarito DES-007 — Missão 7: empacotar a loja como chart Helm

> Consulte só depois de tentar. Enunciado: [trilhas/20-desafios/exercicios/DES-007.md](../../trilhas/20-desafios/exercicios/DES-007.md)

## Desafio sem pista — uma solução possível

```bash
cp -r manifests/helm/ac14-loja /tmp/ac20/chart-loja
sed -i 's/^name: ac14-loja/name: chart-loja/' /tmp/ac20/chart-loja/Chart.yaml
grep -rl 'ac14-loja\.' /tmp/ac20/chart-loja/templates | xargs sed -i 's/ac14-loja\./chart-loja./g'
helm lint /tmp/ac20/chart-loja
helm install loja /tmp/ac20/chart-loja -n ac20-helm --atomic --timeout 2m
helm upgrade loja /tmp/ac20/chart-loja -n ac20-helm --set pagina.conteudo='loja v2' --atomic --timeout 2m
helm test loja -n ac20-helm
helm rollback loja 1 -n ac20-helm && helm test loja -n ac20-helm
```

Os helpers do chart da Trilha 14 usam o prefixo `ac14-loja.`; ao renomear o chart, renomeie também os `define`/`include` (o `sed` acima).

## Diagnóstico controlado — explicação

A trava do Helm é o status da última revisão; destrave com rollback, depois de garantir que ninguém está operando.
