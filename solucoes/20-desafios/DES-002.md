# Gabarito DES-002 — Missão 2: a loja segura

> Consulte só depois de tentar. Enunciado: [trilhas/20-desafios/exercicios/DES-002.md](../../trilhas/20-desafios/exercicios/DES-002.md)

## Desafio sem pista — uma solução possível

```bash
N=ac20-loja
oc create sa loja -n $N && oc label sa loja academy.openshift.dev/managed-by=academia -n $N
read -rs -p 'token fictício: ' T; echo; oc create secret generic loja-api --from-literal=token="$T" -n $N; unset T
oc label secret loja-api academy.openshift.dev/managed-by=academia -n $N
oc set serviceaccount deployment/loja loja -n $N
oc patch deployment loja -n $N --type=json -p '[
 {"op":"add","path":"/spec/template/spec/automountServiceAccountToken","value":false},
 {"op":"add","path":"/spec/template/spec/volumes/-","value":{"name":"api","secret":{"secretName":"loja-api","defaultMode":256}}},
 {"op":"add","path":"/spec/template/spec/containers/0/volumeMounts/-","value":{"name":"api","mountPath":"/etc/loja","readOnly":true}}]'
oc rollout status deployment/loja -n $N
```

Ao terminar, atualize `/tmp/ac20/loja.yaml` (DCL-010) para que o arquivo continue sendo a fonte da verdade.

## Diagnóstico controlado — explicação

Volumes de Secret são resolvidos pelo kubelet; um nome errado deixa o pod em `ContainerCreating`.
