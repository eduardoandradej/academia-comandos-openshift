# Gabarito DES-001 — Missão 1: a loja completa, do zero, em 20 minutos

> Consulte só depois de tentar. Enunciado: [trilhas/20-desafios/exercicios/DES-001.md](../../trilhas/20-desafios/exercicios/DES-001.md)

## Desafio sem pista — uma solução possível

```bash
cd /tmp/ac20
L=academy.openshift.dev/managed-by=academia
{
  oc create configmap loja-pagina --from-literal=index.html='loja da academia (missão 1)' --dry-run=client -o yaml
  echo '---'
  oc create deployment loja --image=registry.access.redhat.com/ubi9/httpd-24:latest --replicas=2 --port=8080 --dry-run=client -o yaml \
    | oc set volume --local -f - --add --name=pagina --type=configmap --configmap-name=loja-pagina --mount-path=/var/www/html -o yaml \
    | oc set resources --local -f - --requests=cpu=25m,memory=48Mi --limits=cpu=100m,memory=128Mi -o yaml \
    | oc set probe --local -f - --readiness --open-tcp=8080 -o yaml \
    | oc set probe --local -f - --liveness --open-tcp=8080 --period-seconds=10 -o yaml
  echo '---'
  oc create service clusterip loja --tcp=8080:8080 --dry-run=client -o yaml
  echo '---'
  cat <<'EOF'
apiVersion: route.openshift.io/v1
kind: Route
metadata:
  name: loja
spec:
  to: {kind: Service, name: loja}
  port: {targetPort: 8080-8080}
  tls: {termination: edge, insecureEdgeTerminationPolicy: Redirect}
EOF
} | oc label --local -f - $L -o yaml | grep -v -E 'creationTimestamp: null|status: \{\}' > loja.yaml
oc apply -f loja.yaml -n ac20-loja && oc rollout status deployment/loja -n ac20-loja
```

`oc create service clusterip loja --tcp=8080:8080` nomeia a porta `8080-8080`; por isso a Route usa esse nome.
O seletor gerado (`app=loja`) casa com os rótulos do `oc create deployment`.
