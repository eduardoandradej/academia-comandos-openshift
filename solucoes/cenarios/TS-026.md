# Gabarito TS-026 — Alterei o ConfigMap e nada mudou

> Cenário: [cenarios/troubleshooting/TS-026.md](../../cenarios/troubleshooting/TS-026.md)

## Causa

Hipóteses 1 e 2: variáveis são lidas só na criação do contêiner; montagens com `subPath` não recebem atualizações.

## Passos que confirmam

O primeiro comando confirma que o ConfigMap mudou (descarta 3). O `ac08-app` recebe `MODO` por `envFrom`; o `ac08-web`
monta `academia.conf` com `subPath`. Nos dois casos, a correção é recriar os pods:

```bash
oc rollout restart deployment/ac08-app deployment/ac08-web -n ac08-config
oc rollout status deployment/ac08-app -n ac08-config && oc rollout status deployment/ac08-web -n ac08-config
```

Para não depender de lembrar: anotação com o hash do conteúdo no template (CFG-004).

## Lição para a ficha de revisão

Mudar o ConfigMap não reinicia nada: saiba como cada consumidor lê a configuração.
