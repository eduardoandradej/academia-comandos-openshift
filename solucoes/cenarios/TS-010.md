# Gabarito TS-010 — Service sem endpoints: o seletor que não casa

> Cenário: [cenarios/troubleshooting/TS-010.md](../../cenarios/troubleshooting/TS-010.md)

## Causa

Hipótese 1: `oc create service clusterip obs-errado` gera o seletor `app=obs-errado`; nenhum pod tem esse rótulo.

## Passos que confirmam

`oc get pods -l app=obs-errado` não retorna nada; os pods têm `app=obs-web`. Correção:

```bash
oc set selector svc/obs-errado app=obs-web -n ac03-projetos
oc describe svc obs-errado -n ac03-projetos | grep Endpoints      # dois IP:8080
```

Com `targetPort` errado, os endpoints **apareceriam** (o seletor casa), mas as conexões falhariam; pods não prontos
apareceriam como endpoints não prontos na EndpointSlice.

## Lição para a ficha de revisão

`Endpoints: <none>` quase sempre é seletor ou readiness; teste o seletor do Service com `oc get pods -l`.
