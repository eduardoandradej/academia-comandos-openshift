# Gabarito TS-049 — Isolei o projeto e a Route caiu: 503 com pods saudáveis

> Cenário: [cenarios/troubleshooting/TS-049.md](../../cenarios/troubleshooting/TS-049.md)

## Causa

Hipótese 1: endpoints prontos e Route admitida (descartam 2 e 3); nenhuma política libera o router.

## Passos que confirmam

```bash
oc apply -f manifests/networkpolicies/30-permitir-router.yaml -n ac16-rede
curl -sS -m 5 "http://$(oc get route web-azul -n ac16-rede -o jsonpath='{.spec.host}')/"     # azul
```

A política seleciona o namespace do router pelo rótulo `policy-group.network.openshift.io/ingress: ""` e limita à
porta 8080. Abrir `namespaceSelector: {}` também "resolveria", mas liberaria o projeto para o cluster inteiro.

## Lição para a ficha de revisão

Ao isolar um projeto, liste os clientes legítimos de outros namespaces: o router é o primeiro deles.
