# Gabarito TS-019 — Service com endpoints, mas conexão recusada

> Cenário: [cenarios/troubleshooting/TS-019.md](../../cenarios/troubleshooting/TS-019.md)

## Causa

Hipótese 1: `targetPort: 8081`; o httpd escuta em 8080 (e 8443).

## Passos que confirmam

A EndpointSlice registra a porta 8081 com o pod pronto (o controlador não verifica se algo escuta ali). Sem
NetworkPolicy no projeto (descarta 3) e com `ready=true` (descarta 2). Correção:

```bash
oc patch svc loja-errada -n ac06-servicos --type=json -p '[{"op":"replace","path":"/spec/ports/0/targetPort","value":8080}]'
http() { oc exec ac06-cliente -n ac06-servicos -- bash -c "exec 3<>/dev/tcp/$1/${2:-8080} && printf 'GET / HTTP/1.0\r\n\r\n' >&3 && cat <&3" | tail -1; }
http loja-errada     # azul
```

## Lição para a ficha de revisão

Endpoints prontos + conexão recusada = porta: compare `targetPort` com o `containerPort`.
