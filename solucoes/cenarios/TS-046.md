# Gabarito TS-046 — Lê os pods, mas não os logs

> Cenário: [cenarios/troubleshooting/TS-046.md](../../cenarios/troubleshooting/TS-046.md)

## Causa

Hipótese 1: a regra cobre `pods`, não `pods/log`.

## Passos que confirmam

A mensagem cita `pods/log` (descarta 2, que seria `NotFound`) e o `get pods` funciona no mesmo projeto (descarta 3).
Correção mínima:

```bash
oc patch role ac15-so-pods -n ac15-rbac --type=json -p '[{"op":"add","path":"/rules/-","value":{"apiGroups":[""],"resources":["pods/log"],"verbs":["get"]}}]'
oc auth can-i get pods/log -n ac15-rbac --as=$S       # yes
```

O mesmo vale para `pods/exec`, `pods/portforward`, `deployments/scale`, `services/proxy`.

## Lição para a ficha de revisão

Subrecursos são recursos: conceda-os um a um.
