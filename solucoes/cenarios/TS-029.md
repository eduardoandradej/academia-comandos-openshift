# Gabarito TS-029 — Os dados sumiram depois do deploy

> Cenário: [cenarios/troubleshooting/TS-029.md](../../cenarios/troubleshooting/TS-029.md)

## Causa

Hipótese 1: `emptyDir` + nova revisão = pod novo = volume novo e vazio.

## Passos que confirmam

O `jq` mostra `"emptyDir": {}`; o histórico mostra uma revisão nova no horário do sumiço, e o pod mudou de nome.
Qualquer mudança no template (`set env`, `set image`, `rollout restart`) recria os pods. Correção: dados que
precisam ficar vão para um PVC (STO-008, REQUER PREPARAÇÃO) — ou para fora do cluster (objeto/banco de dados).

## Lição para a ficha de revisão

`emptyDir` é do pod, não do Deployment.
