# Gabarito TS-043 — another operation is in progress: a release travada

> Cenário: [cenarios/troubleshooting/TS-043.md](../../cenarios/troubleshooting/TS-043.md)

## Causa

Hipótese 1: revisão órfã em `pending-upgrade`; nenhum processo ativo (descarta 2).

## Passos que confirmam

O Helm usa o status da última revisão como trava. Sem processo ativo, faça rollback para a última `deployed`:

```bash
N=$(helm history loja -n ac14-helm -o json | jq '[.[] | select(.status=="deployed")] | last.revision')
helm rollback loja "$N" -n ac14-helm
helm history loja -n ac14-helm | tail -2      # pending-upgrade fica como "superseded"/"failed"; a nova revisão é deployed
```

Evite apagar à mão o Secret `pending` (funciona, mas perde a trilha de auditoria). Em pipelines, `--atomic` reduz o problema.

## Lição para a ficha de revisão

Interrupções deixam a release presa em `pending-*`: destrave com rollback, depois de garantir que ninguém está operando.
