# Gabarito TS-057 — O operador não atualiza: InstallPlan esperando aprovação

> Cenário: [cenarios/troubleshooting/TS-057.md](../../cenarios/troubleshooting/TS-057.md)

## Causa

Hipótese 1: `currentCSV` mais novo que `installedCSV` e um InstallPlan não aprovado.

## Passos que confirmam

Com aprovação manual, o OLM prepara a atualização e **espera**. Aprovar é uma mudança de cluster (novos pods, às vezes
CRDs novos):

```bash
# planejado, com janela (não executar pela Academia):
# oc patch installplan <nome> -n <ns> --type=merge -p '{"spec":{"approved":true}}'
```

Antes: leia o que muda (`oc get installplan <nome> -n <ns> -o yaml`, seção `status.plan`) e confira recursos do nó.
Aprovação manual é a escolha recomendada no SNO justamente por dar esse momento de decisão.

## Lição para a ficha de revisão

Aprovação manual no OLM é um portão intencional: o operador não atualiza até alguém decidir.
