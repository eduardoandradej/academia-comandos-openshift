# Gabarito TS-032 — Mudei a tag e a aplicação continua na versão antiga

> Cenário: [cenarios/troubleshooting/TS-032.md](../../cenarios/troubleshooting/TS-032.md)

## Causa

Hipóteses 1 e 3: o gatilho foi pausado; o template guarda o digest antigo gravado pelo próprio gatilho.

## Passos que confirmam

A anotação mostra `"paused":true`. Quando ativo, o gatilho grava a referência **por digest** no template — por isso
um `rollout restart` recria pods com o mesmo digest antigo. Reative o gatilho:

```bash
C=$(oc get deploy ac10-app -n ac10-imagens -o jsonpath='{.spec.template.spec.containers[0].name}')
oc set triggers deployment/ac10-app --auto --from-image=ac10-web:prod --containers="$C" -n ac10-imagens
oc rollout status deployment/ac10-app -n ac10-imagens
```

Ao reativar, o controlador compara e aplica o digest atual da `prod`, gerando a revisão nova.

## Lição para a ficha de revisão

Com gatilho de imagem, quem atualiza o template é o gatilho: pausado, nada muda — nem com restart.
