# Gabarito TS-007 — the server doesn't have a resource type

> Cenário: [cenarios/troubleshooting/TS-007.md](../../cenarios/troubleshooting/TS-007.md)

## Causa

Primeira linha: digitação (1). Segunda: depende do cluster (2) — o tipo pode ter sido substituído por `ImageDigestMirrorSet`/`ImageTagMirrorSet` em versões recentes; o `api-resources` responde.

## Passos que confirmam

`oc api-resources` lista `deployments` (`deploy`). Para o segundo, se não houver `imagecontentsourcepolicies` na lista
mas houver `imagedigestmirrorsets`, o tipo antigo não é servido. Falta de permissão daria `Forbidden`, não este erro.

## Lição para a ficha de revisão

Antes de concluir "o cluster está quebrado", pergunte ao próprio cluster com `oc api-resources`.
