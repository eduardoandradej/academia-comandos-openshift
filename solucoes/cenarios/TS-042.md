# Gabarito TS-042 — Template que renderiza, mas o servidor recusa

> Cenário: [cenarios/troubleshooting/TS-042.md](../../cenarios/troubleshooting/TS-042.md)

## Causa

Hipótese 1: substituição como texto em um campo numérico.

## Passos que confirmam

O `jq` mostra `"1"` (com aspas). `${X}` sempre produz texto; `${{X}}` insere o valor como JSON (`1`). O parâmetro tem
valor padrão (descarta 2) e o valor `1` é válido (descarta 3). Correção:

```bash
sed -i 's/replicas: \${REPLICAS}/replicas: ${{REPLICAS}}/' /tmp/ac13/tpl-errado.yaml
oc process -f /tmp/ac13/tpl-errado.yaml -p NOME=ac13-ts042 | oc apply --dry-run=server -n ac13-kustomize -f -
```

O mesmo vale para booleanos e para listas/objetos passados como parâmetro.

## Lição para a ficha de revisão

Templates não conhecem tipos: números e booleanos usam `${{X}}`.
