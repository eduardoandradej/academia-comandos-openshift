# Gabarito TS-033 — InvalidImageName: o pod que nem tenta baixar

> Cenário: [cenarios/troubleshooting/TS-033.md](../../cenarios/troubleshooting/TS-033.md)

## Causa

Hipótese 1: a referência viola a gramática de nomes de imagem (o `od -c` descarta caracteres invisíveis).

## Passos que confirmam

O kubelet valida a referência antes de qualquer pull: repositórios só aceitam minúsculas (`ubi9/httpd-24`). O host
do registry não diferencia maiúsculas no DNS, mas a referência inteira é recusada por causa do caminho. Tag inexistente (3) daria `manifest unknown`,
que exige pull. Correção:

```bash
oc delete pod ac10-planilha -n ac10-imagens
oc run ac10-planilha --image=registry.access.redhat.com/ubi9/httpd-24:latest -n ac10-imagens \
  --labels=academy.openshift.dev/managed-by=academia
```

## Lição para a ficha de revisão

InvalidImageName é erro de digitação/gramática, não de rede: corrija o texto antes de investigar o registry.
