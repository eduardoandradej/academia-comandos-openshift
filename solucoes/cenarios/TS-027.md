# Gabarito TS-027 — Senha certa, autenticação errada: o Secret com bytes a mais

> Cenário: [cenarios/troubleshooting/TS-027.md](../../cenarios/troubleshooting/TS-027.md)

## Causa

Hipótese 1: o `echo` acrescentou `\n`; o Secret tem 16 bytes em vez de 15.

## Passos que confirmam

O `describe` mostra `senha: 16 bytes`; `printf '%s'` do valor dá 15. O `od -c` termina em `\n`. Correção:

```bash
oc create secret generic ac08-credencial --from-literal=senha=senha-de-treino -n ac08-config \
  --dry-run=client -o yaml | oc apply -f -
oc describe secret ac08-credencial -n ac08-config | grep senha       # 15 bytes
```

Base64 duplo (hipótese 2) aparece como um tamanho bem maior (~20 bytes) e um valor decodificado que ainda parece
base64. Regra prática: em `data` vai o base64 do valor exato; em `stringData` ou `--from-literal`, o valor puro.

## Lição para a ficha de revisão

Confira o tamanho em bytes do Secret: é o jeito mais rápido de achar `\n` e base64 duplo sem expor o valor.
