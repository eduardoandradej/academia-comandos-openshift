# Gabarito TS-040 — apply -k recusado: o namespace que não bate

> Cenário: [cenarios/troubleshooting/TS-040.md](../../cenarios/troubleshooting/TS-040.md)

## Causa

Hipótese 1: os objetos renderizados já trazem `metadata.namespace: ac13-dev`.

## Passos que confirmam

O overlay grava o namespace em cada objeto; `-n` diferente é recusado pelo cliente para evitar aplicar no lugar
errado. Se o projeto não existisse (hipótese 2), o erro seria `namespaces "ac13-dev" not found` no servidor.

```bash
oc apply -k manifests/kustomize/overlays/dev            # sem -n
oc get deployment ac13-loja -n ac13-dev
```

Regra: base sem `namespace` → use `-n`; overlay com `namespace` → não use `-n` (ou use o mesmo).

## Lição para a ficha de revisão

Quem define o namespace de um overlay é o próprio overlay.
