# Gabarito TS-050 — Depois da política de saída, nenhum nome resolve

> Cenário: [cenarios/troubleshooting/TS-050.md](../../cenarios/troubleshooting/TS-050.md)

## Causa

Hipótese 1: a negação de saída cobre também o tráfego para o `openshift-dns`.

## Passos que confirmam

O Service existe (descarta 3) e outro projeto resolve nomes normalmente (descarta 2). Libere o DNS:

```bash
oc apply -f manifests/networkpolicies/50-permitir-dns.yaml -n ac16-rede
oc exec ac16-local -n ac16-rede -- getent hosts web-azul
```

Atenção à porta: os pods de DNS escutam na **5353**; uma liberação na 53 continua sem efeito.

## Lição para a ficha de revisão

Toda negação de saída começa com a liberação do DNS.
