# Gabarito TS-003 — Forbidden ao rotular o próprio projeto

> Cenário: [cenarios/troubleshooting/TS-003.md](../../cenarios/troubleshooting/TS-003.md)

## Causa

Hipótese 1. O autoprovisionamento concede `admin` **dentro** do namespace; o Namespace em si é recurso de cluster.

## Passos que confirmam

`requester` = developer (descarta 2); `can-i patch namespaces/...` = `no` e `can-i create configmaps` = `yes`. O perfil
`admin` (cluster-admin) consegue rotular — é o que o ORI-012 faz.

## Lição para a ficha de revisão

Escopo importa: permissões de namespace não alcançam objetos de cluster, nem o próprio Namespace.
