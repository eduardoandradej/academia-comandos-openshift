# Gabarito TS-058 — Tudo verde, mas a resposta está errada: o Service que pega duas versões

> Cenário: [cenarios/troubleshooting/TS-058.md](../../cenarios/troubleshooting/TS-058.md)

## Causa

Hipótese 1: `app=loja` seleciona `web-azul` e `web-verde`; o Service balanceia entre os dois.

## Passos que confirmam

Os endpoints listam pods das duas versões; cada um responde a sua página (descarta 3), e o teste não tem cache
(descarta 2). Correção — o seletor precisa dizer **qual** versão:

```bash
oc set selector service loja app=loja,cor=verde -n ac19-casos
```

É exatamente a troca azul/verde da Trilha 06, só que acidental. Monitoramento verde não garante resposta certa.

## Lição para a ficha de revisão

Saudável não é correto: confira o que o seletor realmente seleciona.
