# Gabarito TS-021 — Service sem tráfego: o pod roda, mas nunca fica pronto

> Cenário: [cenarios/troubleshooting/TS-021.md](../../cenarios/troubleshooting/TS-021.md)

## Causa

Hipótese 1: `Readiness probe failed: HTTP probe failed with statuscode: 404` (caminho `/saude-que-nao-existe`).

## Passos que confirmam

A EndpointSlice tem o endereço do pod com `ready=false` (o seletor casa: descarta 2); `restartCount` 0 (readiness não
reinicia contêiner: descarta 3). Correção possível — trocar a probe por TCP:

```bash
oc patch deployment web-lento -n ac06-servicos --type=json -p '[{"op":"replace","path":"/spec/template/spec/containers/0/readinessProbe","value":{"tcpSocket":{"port":8080},"periodSeconds":5}}]'
oc rollout status deployment/web-lento -n ac06-servicos
```

## Lição para a ficha de revisão

Pod `Running` não é pod pronto: sem readiness ok, o Service não envia tráfego.
