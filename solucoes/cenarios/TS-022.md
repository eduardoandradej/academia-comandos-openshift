# Gabarito TS-022 — Application is not available: o 503 do router

> Cenário: [cenarios/troubleshooting/TS-022.md](../../cenarios/troubleshooting/TS-022.md)

## Causa

Hipótese 1: o Deployment foi escalado para 0; o Service existe, mas não tem endpoints.

## Passos que confirmam

A Route está admitida (descarta 3) e aponta para `web-verde`, que existe (descarta 2). A EndpointSlice está vazia e o
Deployment tem 0 réplicas. Ao escalar para 1, o endpoint volta e o router passa a responder 200.

## Lição para a ficha de revisão

503 do router = Route sem destino utilizável. Siga a cadeia: Route → Service → endpoints → pods.
