# Gabarito TS-005 — Unauthorized depois do almoço

> Cenário: [cenarios/troubleshooting/TS-005.md](../../cenarios/troubleshooting/TS-005.md)

## Causa

Hipótese 1: sem token válido, a API responde 401 (Unauthorized), antes de qualquer avaliação de RBAC.

## Passos que confirmam

Após o `oc logout`, `oc whoami -t` não retorna token; um novo `oc login -u developer` resolve. Se o login falhar com
401, aí sim investigue a hipótese 2 (perfil admin: `oc get identities`).

## Lição para a ficha de revisão

401 = quem é você? 403 = eu sei quem você é, e a resposta é não.
