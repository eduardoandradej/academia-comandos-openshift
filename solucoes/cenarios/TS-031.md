# Gabarito TS-031 — ImagePullBackOff com nome curto: o ImageStream que o pod não encontra

> Cenário: [cenarios/troubleshooting/TS-031.md](../../cenarios/troubleshooting/TS-031.md)

## Causa

Hipótese 1: sem image-lookup, `ac10-web:v1` foi tratado como nome curto de registry.

## Passos que confirmam

A istag existe (descarta 2) e o evento mostra o runtime procurando `ac10-web` nos registries de busca do nó (por
exemplo, `docker.io/library/ac10-web:v1`) ou recusando nome curto — o registry de origem nem foi consultado
(descarta 3). Correção:

```bash
oc set image-lookup ac10-web -n ac10-imagens
oc rollout restart deployment/ac10-curto -n ac10-imagens     # pods novos passam pela resolução
oc get pod -n ac10-imagens -l app=ac10-curto -o jsonpath='{.items[0].spec.containers[0].image}{"\n"}'
```

Alternativa sem lookup: gatilho de imagem (`oc set triggers --from-image`), que grava a referência completa no template.

## Lição para a ficha de revisão

Nome curto de ImageStream só funciona com image-lookup (ou gatilho); senão, vira nome de registry.
