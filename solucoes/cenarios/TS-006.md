# Gabarito TS-006 — No resources found: o namespace errado

> Cenário: [cenarios/troubleshooting/TS-006.md](../../cenarios/troubleshooting/TS-006.md)

## Causa

Hipótese 1: o contexto passou a usar `default`.

## Passos que confirmam

`oc project -q` responde `default`; com `-n ac01-cli`, os pods aparecem.

## Lição para a ficha de revisão

`No resources found` não é erro: é uma resposta vazia para o namespace consultado. Leia qual namespace a mensagem cita.
