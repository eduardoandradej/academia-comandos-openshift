# Gabarito TS-061 — HTTPS responde, HTTP diz "Application is not available"

> Cenário: [cenarios/troubleshooting/TS-061.md](../../cenarios/troubleshooting/TS-061.md)

## Causa

Hipótese 1: sem `insecureEdgeTerminationPolicy`, o router não publica a Route na porta 80 e responde a página padrão (503).

## Passos que confirmam

O `curl -v` conecta no router (o DNS está certo) e recebe 503: o router não tem a Route para HTTP. As
NetworkPolicies do projeto não enxergam a porta 80 — ela termina no router, não no pod (descarta 3).

```bash
oc patch route ac20-ts061 -n ac20-cenarios --type=merge -p '{"spec":{"tls":{"insecureEdgeTerminationPolicy":"Redirect"}}}'
curl -s -o /dev/null -w 'http %{http_code} -> %{redirect_url}\n' "http://$H/"      # 302 para https
```

Prefira `Redirect` (HTTP vira HTTPS); `Allow` serve as duas versões e mantém o tráfego em texto claro.

## Lição para a ficha de revisão

HTTP falha e HTTPS funciona: confira `spec.tls.insecureEdgeTerminationPolicy`.
