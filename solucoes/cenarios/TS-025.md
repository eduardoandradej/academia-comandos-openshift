# Gabarito TS-025 — CreateContainerConfigError: a configuração que não existe

> Cenário: [cenarios/troubleshooting/TS-025.md](../../cenarios/troubleshooting/TS-025.md)

## Causa

Hipóteses 1 e 2 juntas: o ConfigMap `ac08-config-que-nao-existe` e o Secret `ac08-secret-que-nao-existe` não existem.

## Passos que confirmam

O evento mostra só a primeira referência que falhou (`configmap "ac08-config-que-nao-existe" not found`); o `jq` no
`env` revela que também falta o Secret. A imagem nunca chegou a ser executada (descarta 3). Correções válidas:

```bash
oc create configmap ac08-config-que-nao-existe --from-literal=MODO=treino -n ac08-config
read -rs -p 'token fictício: ' T; echo
oc create secret generic ac08-secret-que-nao-existe --from-literal=token="$T" -n ac08-config; unset T
oc get pods -n ac08-config -l app=ac08-sem-config          # Running sem precisar reiniciar
```

Alternativa quando a configuração é de fato opcional: `optional: true` no `configMapKeyRef`/`secretKeyRef`.

## Lição para a ficha de revisão

CreateContainerConfigError é falha de referência, não de imagem: leia o `env`/`volumes` inteiro, não só o primeiro evento.
