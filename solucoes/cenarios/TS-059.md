# Gabarito TS-059 — Funciona pelo IP do pod, falha pelo Service: a porta nomeada

> Cenário: [cenarios/troubleshooting/TS-059.md](../../cenarios/troubleshooting/TS-059.md)

## Causa

Hipótese 1: porta nomeada inexistente no contêiner; o EndpointSlice fica sem porta resolvida.

## Passos que confirmam

O acesso direto ao IP usa a 8080 real (descarta 2 e 3); o Service tenta resolver `web` nos pods e não encontra.
Correção:

```bash
oc patch service ac19-ts059 -n ac19-casos --type=json -p '[{"op":"replace","path":"/spec/ports/0/targetPort","value":"http"}]'
```

Nomes de porta são ótimos (resistem a mudança de número), desde que os dois lados usem o mesmo nome.

## Lição para a ficha de revisão

Com `targetPort` por nome, o nome precisa existir no contêiner — confira os dois lados.
