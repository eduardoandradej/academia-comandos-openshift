# Gabarito TS-047 — cannot change roleRef: trocar o papel de um binding

> Cenário: [cenarios/troubleshooting/TS-047.md](../../cenarios/troubleshooting/TS-047.md)

## Causa

Hipótese 1: a API proíbe mudar `roleRef`.

## Passos que confirmam

Você pode alterar RoleBindings (descarta 2) e `edit` existe (descarta 3). Crie o novo binding antes de apagar o antigo:

```bash
oc create rolebinding ac15-robo-acesso-edit --clusterrole=edit --serviceaccount=ac15-rbac:ac15-robo -n ac15-rbac
oc auth can-i create deployments -n ac15-rbac --as=system:serviceaccount:ac15-rbac:ac15-robo    # yes
oc delete rolebinding ac15-robo-acesso -n ac15-rbac
```

`subjects` podem mudar livremente; só `roleRef` é imutável.

## Lição para a ficha de revisão

Para trocar o papel, troque o binding: crie o novo e só então apague o antigo.
