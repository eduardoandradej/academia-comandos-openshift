# Gabarito TS-012 — oc label recusou: --overwrite e valores inválidos

> Cenário: [cenarios/troubleshooting/TS-012.md](../../cenarios/troubleshooting/TS-012.md)

## Causa

1: falta `--overwrite`; 2: chave com `ã`; 3: valor com espaço.

## Passos que confirmam

```bash
oc label cm/ac03-x ambiente=prod --overwrite -n ac03-projetos
oc label cm/ac03-x versao=1 -n ac03-projetos
oc label cm/ac03-x nota=dois-termos -n ac03-projetos          # ou use uma anotação para texto livre
```

## Lição para a ficha de revisão

Rótulos são identificadores curtos e restritos; texto livre vai em anotação.
