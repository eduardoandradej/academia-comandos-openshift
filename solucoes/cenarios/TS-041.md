# Gabarito TS-041 — Patch que não encontra o alvo

> Cenário: [cenarios/troubleshooting/TS-041.md](../../cenarios/troubleshooting/TS-041.md)

## Causa

Hipótese 1: o alvo `ac13-loja` não existe mais na base.

## Passos que confirmam

A base agora gera `Deployment/loja`; o `patch-recursos.yaml` e o `replicas:` do overlay ainda dizem `ac13-loja`.
O arquivo existe (descarta 2) e o `apiVersion` está certo (descarta 3). Correção: atualizar **todas** as referências
(patch, `replicas`, `target.name`) — ou, melhor, não renomear objetos da base sem revisar os overlays. Lembre também
que o Service seleciona `app: ac13-loja`: renomear o Deployment não muda rótulos.

```bash
grep -rl 'ac13-loja' /tmp/ac13/ts041/overlays | xargs sed -i 's/name: ac13-loja$/name: loja/'
oc kustomize /tmp/ac13/ts041/overlays/prod >/dev/null && echo "renderiza"
```

## Lição para a ficha de revisão

Overlays dependem dos nomes da base: renomear na base exige revisar todos os patches.
