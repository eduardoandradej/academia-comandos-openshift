# Gabarito TS-008 — JSONPath que não imprime nada

> Cenário: [cenarios/troubleshooting/TS-008.md](../../cenarios/troubleshooting/TS-008.md)

## Causa

Um problema por linha: (1) na primeira, (2) `podIP` na segunda, (3) `Running` na terceira.

## Passos que confirmam

```bash
oc get pods -n ac02-consultas -o jsonpath='{.items[*].metadata.name}{"\n"}'
oc get pods -n ac02-consultas -o jsonpath='{.items[*].status.podIP}{"\n"}'
oc get pods -n ac02-consultas -o jsonpath='{.items[?(@.status.phase=="Running")].metadata.name}{"\n"}'
```

## Lição para a ficha de revisão

JSONPath não reclama de caminho inexistente. Na dúvida, descubra a estrutura com `-o json | jq 'keys'`.
