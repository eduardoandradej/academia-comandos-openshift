# Gabarito TS-045 — --reuse-values: o padrão novo do chart que não chegou

> Cenário: [cenarios/troubleshooting/TS-045.md](../../cenarios/troubleshooting/TS-045.md)

## Causa

Hipótese 1: `--reuse-values` congela os valores calculados, ignorando defaults novos.

## Passos que confirmam

A coluna CHART mostra `ac14-loja-0.2.0` (descarta 3); o ConfigMap tem o texto antigo porque o **valor** é o antigo
(descarta 2). Correção: passar só os valores do usuário e deixar os padrões novos valerem.

```bash
helm get values loja -n ac14-helm -o yaml > /tmp/ac14/usuario.yaml       # só o que foi passado (replicaCount)
helm upgrade loja /tmp/ac14/ac14-loja -n ac14-helm -f /tmp/ac14/usuario.yaml
helm get values loja -n ac14-helm --all | grep -A1 '^pagina:'               # chart 0.2.0
```

Versões recentes do Helm têm `--reset-then-reuse-values`, que faz exatamente isso.

## Lição para a ficha de revisão

`--reuse-values` congela o passado; em upgrades de versão do chart, reaplique só os seus valores.
