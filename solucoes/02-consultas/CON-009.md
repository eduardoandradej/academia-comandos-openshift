# Gabarito CON-009 — custom-columns: tabelas sob medida

> Consulte só depois de tentar. Enunciado: [trilhas/02-consultas/exercicios/CON-009.md](../../trilhas/02-consultas/exercicios/CON-009.md)

## Desafio sem pista — uma solução possível

```bash
oc get events -n ac02-consultas --sort-by=.metadata.creationTimestamp \
  -o custom-columns=QUANDO:.metadata.creationTimestamp,TIPO:.type,OBJETO:.involvedObject.kind,NOME:.involvedObject.name,MOTIVO:.reason
```

`kind/nome` em uma única coluna não é possível com custom-columns (não há concatenação); por isso, duas colunas. Com
jsonpath: `'{range .items[*]}{.involvedObject.kind}/{.involvedObject.name}{"\n"}{end}'`.

## Diagnóstico controlado — explicação

custom-columns aceita apenas um caminho por coluna. Laços e formatação são recursos do `-o jsonpath`.
