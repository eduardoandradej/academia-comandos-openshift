# Gabarito CON-012 — Ordenar e ler eventos

> Consulte só depois de tentar. Enunciado: [trilhas/02-consultas/exercicios/CON-012.md](../../trilhas/02-consultas/exercicios/CON-012.md)

## Desafio sem pista — uma solução possível

```bash
LIMITE=$(date -u -d '-10 min' +%Y-%m-%dT%H:%M:%SZ)
oc get events -n ac02-consultas -o json | jq -r --arg t "$LIMITE" '.items
  | map(select(.metadata.creationTimestamp >= $t)) | sort_by(.metadata.creationTimestamp)[]
  | "\(.metadata.creationTimestamp) \(.involvedObject.kind)/\(.involvedObject.name) \(.message)"'
```

Datas ISO 8601 em UTC podem ser comparadas como texto.

## Diagnóstico controlado — explicação

Eventos têm vida curta, configurada no kube-apiserver. Ausência de eventos antigos é o comportamento esperado.
