# Gabarito CON-006 — Seletores de campo

> Consulte só depois de tentar. Enunciado: [trilhas/02-consultas/exercicios/CON-006.md](../../trilhas/02-consultas/exercicios/CON-006.md)

## Desafio sem pista — uma solução possível

```bash
oc get events -n ac02-consultas --field-selector involvedObject.kind=Pod \
  --sort-by=.metadata.creationTimestamp -o custom-columns=QUANDO:.metadata.creationTimestamp,MOTIVO:.reason,MSG:.message
```

## Diagnóstico controlado — explicação

A API só aceita campos que o tipo registra como selecionáveis. "Pronto" é uma condição dentro de uma lista
(`status.conditions`), não um campo simples — use jsonpath (CON-008) ou `jq` (CON-011).
