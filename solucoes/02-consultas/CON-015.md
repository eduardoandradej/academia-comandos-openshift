# Gabarito CON-015 — Leitura bruta da API, circuito e encerramento

> Consulte só depois de tentar. Enunciado: [trilhas/02-consultas/exercicios/CON-015.md](../../trilhas/02-consultas/exercicios/CON-015.md)

## Desafio sem pista — uma solução possível

```bash
oc api-resources --api-group=apps                                                    # 1
oc explain deployment.spec.replicas                                                  # 2
oc get pods -n ac02-consultas -o wide                                                # 3
oc get pods -n ac02-consultas -o name | cut -d/ -f2                                  # 4
oc get pods -n ac02-consultas -l tier=web -L app                                     # 5
oc get events -n ac02-consultas --field-selector type=Warning                        # 6
oc get deploy obs-web -n ac02-consultas -o jsonpath='{.spec.template.spec.containers[0].image}{"\n"}'   # 7
oc get pods -n ac02-consultas -o custom-columns=NOME:.metadata.name,FASE:.status.phase,REINICIOS:.status.containerStatuses[0].restartCount   # 8
oc get pods -n ac02-consultas -o go-template='{{range .items}}{{if ne .status.phase "Running"}}! {{end}}{{.metadata.name}}{{"\n"}}{{end}}'      # 9
oc get configmap obs-config -n ac02-consultas -o json | jq '.data | length'          # 10
oc get events -n ac02-consultas --sort-by=.metadata.creationTimestamp                # 11
oc describe svc obs-web -n ac02-consultas | grep Endpoints                           # 12
oc get nodes -o jsonpath='{range .items[*]}{.metadata.name}={.status.conditions[?(@.type=="Ready")].status}{"\n"}{end}'   # 13
oc get co -o json | jq -r '.items[] | select(any(.status.conditions[]; .type=="Degraded" and .status=="True")) | .metadata.name'   # 14
oc get --raw "/api/v1/namespaces/ac02-consultas/pods?labelSelector=app%3Dobs-web" | jq -r '.items[].metadata.name'               # 15
```

## Diagnóstico controlado — explicação

Na URL, o recurso é sempre o **plural** em minúsculas (`deployments`). A listagem de `/apis/apps/v1` mostra os nomes válidos.
