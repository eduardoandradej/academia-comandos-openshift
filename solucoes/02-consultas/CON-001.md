# Gabarito CON-001 — api-resources: o inventário de tipos

> Consulte só depois de tentar. Enunciado: [trilhas/02-consultas/exercicios/CON-001.md](../../trilhas/02-consultas/exercicios/CON-001.md)

## Desafio sem pista — uma solução possível

```bash
oc api-resources --namespaced=false --no-headers | awk '$3 ~ /openshift\.io\// || $2 ~ /openshift\.io\// {print $1, $NF}' | sort
```

Como a coluna `SHORTNAMES` pode estar vazia, o número de colunas varia; por isso o `awk` testa a 2ª e a 3ª colunas e
usa `$NF` (última) para o KIND. Alternativa robusta: `oc api-resources --namespaced=false -o name | grep 'openshift\.io$' | sort`.

Repetições: 1 `pvc`, `hpa` · 2 `project.openshift.io`, `config.openshift.io`.

## Diagnóstico controlado — explicação

`grep -i deploy` mostra `deployments` (`deploy`); o erro era de digitação (a). Se a busca não encontrar nada, o tipo
não existe neste cluster (b) — por exemplo, um CRD de operador não instalado.
