# Gabarito CON-007 — YAML e JSON: spec, status e metadata

> Consulte só depois de tentar. Enunciado: [trilhas/02-consultas/exercicios/CON-007.md](../../trilhas/02-consultas/exercicios/CON-007.md)

## Desafio sem pista — uma solução possível

```bash
POD=$(oc get pods -n ac02-consultas -l app=obs-web -o name | head -1 | cut -d/ -f2)
RS=$(oc get pod "$POD" -n ac02-consultas -o jsonpath='{.metadata.ownerReferences[0].name}')
DEP=$(oc get rs "$RS" -n ac02-consultas -o jsonpath='{.metadata.ownerReferences[0].name}')
echo "Pod $POD -> ReplicaSet $RS -> Deployment $DEP"
```

Repetição 5: o restart mudaria a anotação `kubectl.kubernetes.io/restartedAt` do template, criaria um novo ReplicaSet e
aumentaria `resourceVersion` e `metadata.generation`.

## Diagnóstico controlado — explicação

`ownerReferences` é uma lista (plural). Com o nome no singular, o `jq` recebe `null` e falha ao iterar (b).
