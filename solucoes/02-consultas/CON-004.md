# Gabarito CON-004 — oc get: formatos básicos e vários tipos

> Consulte só depois de tentar. Enunciado: [trilhas/02-consultas/exercicios/CON-004.md](../../trilhas/02-consultas/exercicios/CON-004.md)

## Desafio sem pista — uma solução possível

```bash
oc get pods -n ac02-consultas -l app=obs-web -o name | cut -d/ -f2
```

Alternativa: `oc get pods -n ac02-consultas --no-headers | awk '{print $1}'`.

## Diagnóstico controlado — explicação

"at the cluster scope" é a pista: a permissão de developer vale por namespace. `can-i` responde `no` para
`--all-namespaces` e `yes` para `-n ac02-consultas`.
