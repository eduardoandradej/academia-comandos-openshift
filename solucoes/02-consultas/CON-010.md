# Gabarito CON-010 — go-template: laços e condições

> Consulte só depois de tentar. Enunciado: [trilhas/02-consultas/exercicios/CON-010.md](../../trilhas/02-consultas/exercicios/CON-010.md)

## Desafio sem pista — uma solução possível

```bash
oc get pods -n ac02-consultas -o json | jq -r '.items[]
  | "\(.metadata.name): \(.spec.containers | length) contêiner(es), reinícios totais=\([.status.containerStatuses[]?.restartCount] | add // 0)"'
```

Escolha justificada: go-template não tem soma nativa; `jq` tem `add`. A contagem de contêineres sozinha cabe em
go-template: `{{range .items}}{{.metadata.name}}: {{len .spec.containers}}{{"\n"}}{{end}}`.

## Diagnóstico controlado — explicação

No go-template, `.a.b` navega por chaves; a chave `academy.openshift.dev/trilha` contém pontos, então é preciso `index`.
