# Gabarito CON-013 — describe ou get -o yaml?

> Consulte só depois de tentar. Enunciado: [trilhas/02-consultas/exercicios/CON-013.md](../../trilhas/02-consultas/exercicios/CON-013.md)

## Desafio sem pista — uma solução possível

```bash
oc get svc obs-web -n ac02-consultas -o json \
  | jq 'del(.status, .metadata.uid, .metadata.resourceVersion, .metadata.creationTimestamp,
            .metadata.managedFields, .metadata.annotations, .spec.clusterIP, .spec.clusterIPs)' \
  | oc apply --dry-run=server -n ac02-consultas -f -
```

Para salvar: troque o último comando por `> /tmp/ac-svc.yaml` (JSON é YAML válido) e depois valide com `-f /tmp/ac-svc.yaml`.

Perguntas: 1 describe (eventos e `Last State`) · 2 get -o yaml · 3 describe svc · 4 get -o yaml · 5 describe (ou jsonpath) ·
6 get -o yaml + limpeza · 7 describe (seção Environment) · 8 describe (Events).

## Diagnóstico controlado — explicação

`resourceVersion` implementa concorrência otimista: o servidor só aceita a gravação se a versão bater com a atual.
Manifestos para reaplicar não devem levar esse campo.
