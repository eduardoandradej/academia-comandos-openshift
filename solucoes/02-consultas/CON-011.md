# Gabarito CON-011 — jq: filtrar, transformar e contar

> Consulte só depois de tentar. Enunciado: [trilhas/02-consultas/exercicios/CON-011.md](../../trilhas/02-consultas/exercicios/CON-011.md)

## Desafio sem pista — uma solução possível

```bash
oc get deploy obs-web -n ac02-consultas -o json | jq -c '{
  nome: .metadata.name, desejado: .spec.replicas, pronto: .status.readyReplicas,
  imagem: .spec.template.spec.containers[0].image, rotulos: .metadata.labels }'
```

Repetição 2: `jq '.items | map({key: .metadata.name, value: .status.containerStatuses[0].restartCount}) | from_entries'`.
Repetição 4: `oc get events -n ac02-consultas -o json | jq '[.items[] | select(.type=="Warning")] | group_by(.reason) | map({(.[0].reason): length}) | add'`.

## Diagnóstico controlado — explicação

`.items` é uma lista; `.metadata` só existe nos elementos. `.items[]` itera e o resto do filtro passa a valer para cada pod.
