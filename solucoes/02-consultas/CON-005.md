# Gabarito CON-005 — Seletores de rótulo

> Consulte só depois de tentar. Enunciado: [trilhas/02-consultas/exercicios/CON-005.md](../../trilhas/02-consultas/exercicios/CON-005.md)

## Desafio sem pista — uma solução possível

```bash
oc get deploy,svc,configmap -n ac02-consultas -l academy.openshift.dev/trilha=02 -L app,tier,academy.openshift.dev/trilha
```

Previsões: 1 nenhum pod · 2 os dois pods · 3 nenhum · 4 Deployment, Service e ConfigMap · 5 os dois pods; o rótulo
`pod-template-hash` é acrescentado pelo controlador do Deployment para ligar pods ao ReplicaSet.

## Diagnóstico controlado — explicação

Com nome, o `oc` busca aquele objeto; com seletor, busca por rótulo. As duas coisas juntas são ambíguas e o cliente recusa antes de contatar a API.
