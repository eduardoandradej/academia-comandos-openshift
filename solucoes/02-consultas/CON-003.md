> Consulte só depois de tentar. Enunciado: [trilhas/02-consultas/exercicios/CON-003.md](../../trilhas/02-consultas/exercicios/CON-003.md)

## Desafio sem pista — uma solução possível

```bash
oc new-project ac02-consultas --skip-config-write
oc apply -f manifests/apps-exemplo/observacao-httpd.yaml -n ac02-consultas \
  && oc wait --for=condition=Available deployment/obs-web -n ac02-consultas --timeout=180s
echo "rc=$?"
```

`oc wait` retorna diferente de zero quando expira, e o `&&` impede a espera se o apply falhar.

## Diagnóstico controlado — explicação

A mensagem do evento diferencia as hipóteses: `dial tcp ... i/o timeout` ou `no such host` → (a); `manifest unknown`
ou `not found` → (b); erros 5xx → (c).
