# Gabarito POD-013 — oc debug: uma cópia do pod para investigar

> Consulte só depois de tentar. Enunciado: [trilhas/04-pods/exercicios/POD-013.md](../../trilhas/04-pods/exercicios/POD-013.md)

## Desafio sem pista — uma solução possível

```bash
oc get pod ac04-crash -n ac04-pods -o jsonpath='{.spec.containers[0].command}{"\n"}'     # leitura do spec
S=$(oc get pod ac04-crash -n ac04-pods -o jsonpath='{.spec.containers[0].command[2]}')
oc debug pod/ac04-crash -n ac04-pods -- sh -c "( $S ); echo rc=\$?"
oc logs ac04-crash -n ac04-pods --previous                                              # mesma mensagem, na instância anterior
```

A cópia executa o mesmo script e mostra `ERRO: variavel CONFIG_URL ausente` e `rc=1`, sem tocar no original.

## Diagnóstico controlado — explicação

`oc debug` remove o pod ao fim da sessão; se o terminal fechar de forma abrupta, a limpeza pode não acontecer (b).
