# Gabarito POD-015 — Circuito de pods e encerramento da trilha

> Consulte só depois de tentar. Enunciado: [trilhas/04-pods/exercicios/POD-015.md](../../trilhas/04-pods/exercicios/POD-015.md)

## Desafio sem pista — uma solução possível

```bash
oc run x --image=registry.access.redhat.com/ubi9/httpd-24:latest --dry-run=client -o yaml                       # 1
oc run ac04-web --image=registry.access.redhat.com/ubi9/httpd-24:latest \
  --labels=app=ac04-web,academy.openshift.dev/managed-by=academia --port=8080 -n ac04-pods                      # 2
oc wait --for=condition=Ready pod/ac04-web -n ac04-pods --timeout=120s                                          # 3
oc get pod ac04-web -n ac04-pods -o jsonpath='{.status.phase} {.status.podIP} {.spec.nodeName}{"\n"}'          # 4
oc logs ac04-web -n ac04-pods --tail=5 --timestamps                                                             # 5
oc exec ac04-web -n ac04-pods -- id -u                                                                          # 6
oc exec ac04-web -n ac04-pods -- sh -c 'tr "\0" " " </proc/1/cmdline; echo'                                    # 7
oc rsh ac04-web -n ac04-pods                                                                                    # 8 (exit)
echo t > /tmp/ac04-t && oc cp /tmp/ac04-t ac04-web:/tmp/t -n ac04-pods && oc exec ac04-web -n ac04-pods -- cat /tmp/t   # 9
oc port-forward pod/ac04-web 18080:8080 -n ac04-pods & sleep 3; curl -sS -o /dev/null -w '%{http_code}\n' http://127.0.0.1:18080/; kill %1   # 10
oc logs ac04-duplo -n ac04-pods -c relogio --tail=3                                                             # 11
oc run ac04-e --image=registry.access.redhat.com/ubi9/httpd-24:latest --restart=Never -n ac04-pods \
  --labels=academy.openshift.dev/managed-by=academia --command -- sh -c 'exit 2'; sleep 10
oc get pod ac04-e -n ac04-pods -o jsonpath='{.status.containerStatuses[0].state.terminated.exitCode}{"\n"}'    # 12
oc logs ac04-crash -n ac04-pods --previous                                                                      # 13
oc get pod ac04-web -n ac04-pods -o jsonpath='{.status.qosClass}{"\n"}'                                        # 14
oc get pod ac04-web -n ac04-pods -o jsonpath='{.status.containerStatuses[0].imageID}{"\n"}'                    # 15
```

## Diagnóstico controlado — explicação

`oc debug` cria a cópia sem rótulos; o `safe-cleanup` não a vê, mas apagar o projeto remove tudo o que está dentro dele.
