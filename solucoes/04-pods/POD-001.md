# Gabarito POD-001 — Anatomia de um Pod sem criar nada

> Consulte só depois de tentar. Enunciado: [trilhas/04-pods/exercicios/POD-001.md](../../trilhas/04-pods/exercicios/POD-001.md)

## Desafio sem pista — uma solução possível

```bash
oc run ac04-teste --image=registry.access.redhat.com/ubi9/httpd-24:latest \
  --labels=academy.openshift.dev/managed-by=academia --env=NIVEL=1 --port=8080 \
  --restart=Never --command --dry-run=client -o yaml -- sleep 30 > /tmp/ac04-pod.yaml
oc apply --dry-run=server -f /tmp/ac04-pod.yaml -n ac04-pods
```

Repetições 1 e 2: com `--command`, o que vem depois de `--` vai para `command`; sem ele, vai para `args` (e o
`ENTRYPOINT` da imagem continua valendo).

## Diagnóstico controlado — explicação

O `oc` herda o `kubectl run`, que deixou de aceitar `--requests`/`--limits`. O `--help` mostra `--overrides` como alternativa.
