# Gabarito POD-006 — exec: comandos pontuais dentro do contêiner

> Consulte só depois de tentar. Enunciado: [trilhas/04-pods/exercicios/POD-006.md](../../trilhas/04-pods/exercicios/POD-006.md)

## Desafio sem pista — uma solução possível

```bash
oc exec ac04-web -n ac04-pods -c ac04-web -- sh -c \
  'for p in /proc/[0-9]*; do printf "%s " "${p#/proc/}"; tr "\0" " " <"$p/cmdline"; echo; done'
```

Em um Pod criado por `oc run`, o contêiner tem o mesmo nome do Pod (`ac04-web`); `-c` é opcional aqui.

## Diagnóstico controlado — explicação

`exit code 127` é o código padrão de "comando não encontrado". A imagem UBI do httpd é enxuta; o kernel expõe os
processos em `/proc`, que funciona sem utilitários extras.
