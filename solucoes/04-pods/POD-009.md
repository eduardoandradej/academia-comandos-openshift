# Gabarito POD-009 — port-forward: acessar um pod ou Service pela ocp-admin

> Consulte só depois de tentar. Enunciado: [trilhas/04-pods/exercicios/POD-009.md](../../trilhas/04-pods/exercicios/POD-009.md)

## Desafio sem pista — uma solução possível

```bash
oc port-forward pod/ac04-web 18080:8080 -n ac04-pods > /tmp/ac04-pf.log 2>&1 &
PF=$!
trap 'kill $PF 2>/dev/null' EXIT
for i in $(seq 20); do grep -q 'Forwarding from' /tmp/ac04-pf.log && break; sleep 0.5; done
curl -sS -o /dev/null -w 'HTTP %{http_code}\n' http://127.0.0.1:18080/
kill $PF; trap - EXIT; rm -f /tmp/ac04-pf.log
```

## Diagnóstico controlado — explicação

Cada `oc port-forward` mantém a porta local enquanto o processo vive. `jobs`/`pgrep` mostram o processo esquecido.
