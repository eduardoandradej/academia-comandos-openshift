# Gabarito POD-008 — Copiar arquivos: oc cp nos dois sentidos

> Consulte só depois de tentar. Enunciado: [trilhas/04-pods/exercicios/POD-008.md](../../trilhas/04-pods/exercicios/POD-008.md)

## Desafio sem pista — uma solução possível

```bash
mkdir -p /tmp/ac04-evidencias
oc cp ac04-duplo:/etc/httpd/conf/httpd.conf /tmp/ac04-evidencias/httpd.conf -c web -n ac04-pods
oc exec ac04-duplo -n ac04-pods -c web -- env > /tmp/ac04-evidencias/env.txt
ls -l /tmp/ac04-evidencias
```

Para a saída de um comando, o redirecionamento local de `oc exec` é mais simples que `oc cp`.

## Diagnóstico controlado — explicação

O contêiner roda com um UID arbitrário da faixa do projeto, sem permissão em diretórios do sistema. `/tmp` é gravável.
