# Gabarito POD-002 — Criar um Pod e acompanhar seu ciclo de vida

> Consulte só depois de tentar. Enunciado: [trilhas/04-pods/exercicios/POD-002.md](../../trilhas/04-pods/exercicios/POD-002.md)

## Desafio sem pista — uma solução possível

```bash
oc get events -n ac04-pods --field-selector involvedObject.name=ac04-web \
  --sort-by=.metadata.creationTimestamp -o custom-columns=QUANDO:.metadata.creationTimestamp,MOTIVO:.reason,MSG:.message
oc get pod ac04-web -n ac04-pods -o jsonpath='{range .status.conditions[*]}{.type} {.lastTransitionTime}{"\n"}{end}'
```

Sequência típica de eventos: `Scheduled` → `AddedInterface` (rede do OpenShift) → `Pulling`/`Pulled` (ou `Pulled ...
already present on machine`) → `Created` → `Started`. A condição `Ready` registra o instante em que o pod passou a pronto.

## Diagnóstico controlado — explicação

Se houver `deletionTimestamp`, a exclusão anterior ainda está em curso (b). Com `--wait=true`, o `oc delete` só volta quando o objeto sumiu.
