# Gabarito POD-014 — Do pod ao contêiner: IDs, imagem e nó

> Consulte só depois de tentar. Enunciado: [trilhas/04-pods/exercicios/POD-014.md](../../trilhas/04-pods/exercicios/POD-014.md)

## Desafio sem pista — uma solução possível

```bash
D=$(oc get pod ac04-web -n ac04-pods -o jsonpath='{.status.containerStatuses[0].imageID}')
oc run ac04-digest --image="$D" --labels=academy.openshift.dev/managed-by=academia -n ac04-pods
oc wait --for=condition=Ready pod/ac04-digest -n ac04-pods --timeout=120s
[ "$(oc get pod ac04-digest -n ac04-pods -o jsonpath='{.status.containerStatuses[0].imageID}')" = "$D" ] && echo "mesma imagem"
```

## Diagnóstico controlado — explicação

A tag é um ponteiro móvel; o digest identifica o conteúdo. `imageID` diferente comprova imagens diferentes atrás da mesma tag.
