# Gabarito POD-005 — Vários contêineres e init containers

> Consulte só depois de tentar. Enunciado: [trilhas/04-pods/exercicios/POD-005.md](../../trilhas/04-pods/exercicios/POD-005.md)

## Desafio sem pista — uma solução possível

```bash
oc exec ac04-duplo -n ac04-pods -c relogio -- /bin/sh -c 'curl -sS -o /dev/null -w "%{http_code}\n" http://localhost:8080/ \
  || (exec 3<>/dev/tcp/127.0.0.1/8080 && echo "porta 8080 aberta via localhost")'
```

Qualquer código HTTP (inclusive 403, a página padrão do httpd) ou a abertura do socket prova a rede compartilhada: o
sidecar não roda httpd, mas alcança a porta 8080 em `localhost`.

## Diagnóstico controlado — explicação

O cliente escolhe o primeiro contêiner como padrão (e avisa com `Defaulted container ...`), a menos que a anotação
`kubectl.kubernetes.io/default-container` indique outro. Em ambos os casos, `-c` torna o comando explícito.
