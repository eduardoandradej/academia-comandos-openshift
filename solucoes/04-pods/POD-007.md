# Gabarito POD-007 — Shell interativo: exec -it e rsh

> Consulte só depois de tentar. Enunciado: [trilhas/04-pods/exercicios/POD-007.md](../../trilhas/04-pods/exercicios/POD-007.md)

## Desafio sem pista — uma solução possível

```bash
oc exec ac04-duplo -n ac04-pods -c web -- sh -c 'ls /etc/httpd/conf.d/*.conf | wc -l'
oc rsh -c web ac04-duplo -n ac04-pods
#   ls /etc/httpd/conf.d/*.conf | wc -l
#   exit
```

Repetição 2: o kubelet injeta variáveis `*_SERVICE_HOST`/`*_PORT` dos Services do namespace e `KUBERNETES_*` da API.

## Diagnóstico controlado — explicação

`-t` pede um pseudo-terminal; se o processo local não tem um, o cliente avisa e segue sem ele. Em automação, use só `oc exec` (sem `-it`).
