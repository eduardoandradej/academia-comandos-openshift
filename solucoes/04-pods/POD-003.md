# Gabarito POD-003 — Pods que terminam: restartPolicy e códigos de saída

> Consulte só depois de tentar. Enunciado: [trilhas/04-pods/exercicios/POD-003.md](../../trilhas/04-pods/exercicios/POD-003.md)

## Desafio sem pista — uma solução possível

```bash
oc get pods -n ac04-pods -l academy.openshift.dev/managed-by=academia -o json | jq -r '.items[]
  | .metadata.name + " | " + .spec.restartPolicy + " | "
    + ((.status.containerStatuses[0].state // {}) | keys[0] // "-") + " | "
    + ((.status.containerStatuses[0].state.terminated.exitCode
        // .status.containerStatuses[0].lastState.terminated.exitCode // "-") | tostring)'
```

Tabela: `Never`+0 = Completed, 0 reinícios · `Never`+1 = Error, 0 · `OnFailure`+0 = Completed, 0 · `OnFailure`+1 =
CrashLoopBackOff, crescendo · `Always`+0 e `Always`+1 = CrashLoopBackOff, crescendo.

## Diagnóstico controlado — explicação

`restartPolicy: Always` não olha o código de saída: o kubelet reinicia sempre. `exitCode=0` em `lastState` confirma
que o contêiner terminou bem e foi reiniciado mesmo assim.
