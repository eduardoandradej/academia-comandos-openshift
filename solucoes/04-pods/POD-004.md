# Gabarito POD-004 — Logs: atuais, contínuos, recentes e com horário

> Consulte só depois de tentar. Enunciado: [trilhas/04-pods/exercicios/POD-004.md](../../trilhas/04-pods/exercicios/POD-004.md)

## Desafio sem pista — uma solução possível

```bash
oc logs ac04-log -n ac04-pods --since=60s | grep -c aviso
oc logs ac04-log -n ac04-pods --since=60s --timestamps | grep aviso | tail -1
```

## Diagnóstico controlado — explicação

O Kubernetes só coleta stdout/stderr. Se a aplicação escreve em arquivo, o caminho é `oc exec ... -- tail` (POD-006)
ou ajustar a aplicação para escrever no stdout.
