# Gabarito STO-012 — Expandir um PVC

> Consulte só depois de tentar. Enunciado: [trilhas/09-storage/exercicios/STO-012.md](../../trilhas/09-storage/exercicios/STO-012.md)

## Desafio sem pista — uma solução possível

```bash
oc get resourcequota -n ac09-storage -o json | jq -r '.items[] | "\(.metadata.name): usado=\(.status.used["requests.storage"]) limite=\(.status.hard["requests.storage"])"'
# aumento = 1536Mi - tamanho atual; só prossiga se usado + aumento <= limite
oc patch pvc ac09-dados -n ac09-storage --type=merge -p '{"spec":{"resources":{"requests":{"storage":"1536Mi"}}}}'
```

## Diagnóstico controlado — explicação

A API protege contra perda de dados: um sistema de arquivos não encolhe com segurança.
