# Gabarito STO-003 — emptyDir em Deployment: o que sobrevive a quê

> Consulte só depois de tentar. Enunciado: [trilhas/09-storage/exercicios/STO-003.md](../../trilhas/09-storage/exercicios/STO-003.md)

## Desafio sem pista — uma solução possível

```bash
oc patch deployment ac09-app -n ac09-storage --type=json -p '[
 {"op":"add","path":"/spec/template/spec/volumes/-","value":{"name":"trabalho","emptyDir":{"sizeLimit":"32Mi"}}},
 {"op":"add","path":"/spec/template/spec/containers/0/volumeMounts/-","value":{"name":"trabalho","mountPath":"/trabalho"}}]'
oc rollout status deployment/ac09-app -n ac09-storage
oc get pod -n ac09-storage -l app=ac09-app -o jsonpath='{.items[0].spec.volumes[?(@.name=="trabalho")]}{"\n"}'
```

`oc set volume` não tem flag para `sizeLimit`; o patch JSON acrescenta volume e montagem na mesma revisão.

## Diagnóstico controlado — explicação

Cada pod novo recebe um `emptyDir` novo e vazio; o antigo é apagado com o pod antigo.
