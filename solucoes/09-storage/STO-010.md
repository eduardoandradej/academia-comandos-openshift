# Gabarito STO-010 — Ligação PV × PVC: claimRef, tamanho e seletores

> Consulte só depois de tentar. Enunciado: [trilhas/09-storage/exercicios/STO-010.md](../../trilhas/09-storage/exercicios/STO-010.md)

## Desafio sem pista — uma solução possível

```bash
oc get pvc -n ac09-storage -o json | jq -r '.items[] | select(.status.phase=="Pending")
  | "\(.metadata.name)\tclasse=\(.spec.storageClassName)\tmodos=\(.spec.accessModes|join(","))\tpedido=\(.spec.resources.requests.storage)\tseletor=\(.spec.selector // {} | tostring)"'
KUBECONFIG="$HOME/.kube/ac-admin.kubeconfig" oc get pv -o json | jq -r '.items[] | select(.status.phase=="Available")
  | "\(.metadata.name)\tclasse=\(.spec.storageClassName)\tmodos=\(.spec.accessModes|join(","))\ttam=\(.spec.capacity.storage)\trotulos=\(.metadata.labels|tostring)"'
```

Compare linha a linha: o primeiro critério que não bate é a causa.

## Diagnóstico controlado — explicação

O controlador de ligação só une PV e PVC que atendem a todos os critérios ao mesmo tempo.
