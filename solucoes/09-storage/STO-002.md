# Gabarito STO-002 — emptyDir compartilhado entre contêineres

> Consulte só depois de tentar. Enunciado: [trilhas/09-storage/exercicios/STO-002.md](../../trilhas/09-storage/exercicios/STO-002.md)

## Desafio sem pista — uma solução possível

```bash
oc exec ac09-compartilhado -c gerador -n ac09-storage -- stat -c '%i %n' /saida
oc exec ac09-compartilhado -c web -n ac09-storage -- stat -c '%i %n' /var/www/html
```

Mesmo inode = mesmo diretório no nó, montado em dois caminhos.

## Diagnóstico controlado — explicação

O `emptyDir` começa vazio; até a primeira escrita, o httpd não tem índice e responde 403 (como a página padrão da UBI).
