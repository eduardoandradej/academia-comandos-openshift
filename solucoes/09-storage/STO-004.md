# Gabarito STO-004 — emptyDir em memória: rápido e contado como RAM

> Consulte só depois de tentar. Enunciado: [trilhas/09-storage/exercicios/STO-004.md](../../trilhas/09-storage/exercicios/STO-004.md)

## Desafio sem pista — uma solução possível

```bash
lim=$(oc exec deploy/ac09-app -n ac09-storage -- cat /sys/fs/cgroup/memory.max)
cur=$(oc exec deploy/ac09-app -n ac09-storage -- cat /sys/fs/cgroup/memory.current)
echo "folga: $(( (lim - cur) / 1048576 )) MiB (e nunca acima do sizeLimit de 16 MiB)"
```

O menor entre a folga de memória e o `sizeLimit` é o teto; deixe margem, porque o httpd também cresce.

## Diagnóstico controlado — explicação

`sizeLimit` é vigiado pelo kubelet (despejo do pod); `limits.memory` pelo kernel (OOMKill do contêiner). Em tmpfs, os dois contam.
