# Gabarito STO-013 — StatefulSet: um PVC por réplica

> Consulte só depois de tentar. Enunciado: [trilhas/09-storage/exercicios/STO-013.md](../../trilhas/09-storage/exercicios/STO-013.md)

## Desafio sem pista — uma solução possível

```bash
oc scale statefulset/ac09-sts --replicas=2 -n ac09-storage && oc rollout status statefulset/ac09-sts -n ac09-storage
oc patch statefulset ac09-sts -n ac09-storage --type=merge \
  -p '{"spec":{"persistentVolumeClaimRetentionPolicy":{"whenScaled":"Delete","whenDeleted":"Retain"}}}'
oc scale statefulset/ac09-sts --replicas=1 -n ac09-storage
sleep 10; oc get pvc -n ac09-storage | grep dados-ac09-sts        # só o -0
```

Risco: reduzir réplicas passa a destruir dados; um `scale` errado vira perda definitiva (com `Delete` na classe/PV).

## Diagnóstico controlado — explicação

O StatefulSet cria pods em ordem e cada um espera seu PVC ligar; qualquer bloqueio no PVC trava a réplica.
