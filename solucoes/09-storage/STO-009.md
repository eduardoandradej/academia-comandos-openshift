# Gabarito STO-009 — PVC e montagem em um comando: oc set volume --claim-size

> Consulte só depois de tentar. Enunciado: [trilhas/09-storage/exercicios/STO-009.md](../../trilhas/09-storage/exercicios/STO-009.md)

## Desafio sem pista — uma solução possível

```bash
usados=$(oc get pods -n ac09-storage -o json | jq -c '[.items[].spec.volumes[]?.persistentVolumeClaim.claimName | select(.)] | unique')
oc get pvc -n ac09-storage -o json | jq -r --argjson u "$usados" '.items[] | select(.status.phase=="Bound") | .metadata.name | select(. as $n | $u | index($n) | not)'
```

## Diagnóstico controlado — explicação

O PVC é um objeto independente; o Deployment só o referencia.
