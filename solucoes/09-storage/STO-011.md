# Gabarito STO-011 — Modos de acesso no SNO: RWO, RWX e ReadWriteOncePod

> Consulte só depois de tentar. Enunciado: [trilhas/09-storage/exercicios/STO-011.md](../../trilhas/09-storage/exercicios/STO-011.md)

## Desafio sem pista — uma solução possível

```bash
for p in $(oc get pods -n ac09-storage -l app=ac09-app -o name); do
  oc exec -n ac09-storage "$p" -- sh -c 'for i in $(seq 200); do echo "$(hostname) $i" >> /dados/disputa.txt; done' &
done; wait
oc exec deploy/ac09-app -n ac09-storage -- sh -c 'wc -l < /dados/disputa.txt; sort /dados/disputa.txt | uniq -d | head -3'
```

O volume aceita as duas escritas; a ordem e a integridade das linhas dependem da aplicação (travas, arquivos
separados por réplica ou um StatefulSet com um PVC por pod — STO-013).

## Diagnóstico controlado — explicação

RWO restringe por **nó**; quem coordena acesso concorrente é a aplicação.
