## Desafio sem pista — uma solução possível

```bash
ac-admin
oc get pv -l academy.openshift.dev/managed-by=academia -o custom-columns=PV:.metadata.name,STATUS:.status.phase
# no kvm-server (host, com autorização): apague só o conteúdo dos diretórios de treino
#   sudo find /mnt/hd1tb/ac09-nfs/pv01 /mnt/hd1tb/ac09-nfs/pv02 /mnt/hd1tb/ac09-nfs/pv03 -mindepth 1 -delete
for pv in $(oc get pv -l academy.openshift.dev/managed-by=academia -o json | jq -r '.items[] | select(.status.phase=="Released") | .metadata.name'); do
  oc patch pv "$pv" --type=json -p '[{"op":"remove","path":"/spec/claimRef"}]'
done
oc get pv -l academy.openshift.dev/managed-by=academia     # Available
ac-dev
```

Remover o `claimRef` sem limpar os dados entregaria os arquivos antigos ao próximo PVC: limpe antes.

## Diagnóstico controlado — explicação

`Retain` protege os dados por padrão: o PV não é reutilizado automaticamente enquanto aponta para o PVC antigo.
