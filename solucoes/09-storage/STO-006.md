# Gabarito STO-006 — Storage do cluster visto pelo admin (somente leitura)

> Consulte só depois de tentar. Enunciado: [trilhas/09-storage/exercicios/STO-006.md](../../trilhas/09-storage/exercicios/STO-006.md)

## Desafio sem pista — uma solução possível

```bash
oc get pv -o json | jq -r '.items[] | [.metadata.name, .spec.capacity.storage, .spec.persistentVolumeReclaimPolicy,
  .status.phase, (if .spec.claimRef then "\(.spec.claimRef.namespace)/\(.spec.claimRef.name)" else "livre" end)] | @tsv'
```

## Diagnóstico controlado — explicação

PVs pertencem ao cluster, não a um projeto; só papéis de cluster (como o do admin) os listam.
