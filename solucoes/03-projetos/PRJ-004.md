# Gabarito PRJ-004 — Rótulos em lote por seletor

> Consulte só depois de tentar. Enunciado: [trilhas/03-projetos/exercicios/PRJ-004.md](../../trilhas/03-projetos/exercicios/PRJ-004.md)

## Desafio sem pista — uma solução possível

```bash
oc get configmap -n ac03-projetos -l camada=web --sort-by=.metadata.creationTimestamp -o name | tail -2 \
  | xargs -r -I{} oc label {} prioridade=alta -n ac03-projetos
oc get configmap -n ac03-projetos -l camada=web -L prioridade --sort-by=.metadata.creationTimestamp
```

Repetição 2: `oc label configmap -l 'camada in (web,db),!exposto' revisar=sim -n ac03-projetos`.

## Diagnóstico controlado — explicação

`oc label -l` só age sobre o que o seletor encontra; vazio no `get` com o mesmo seletor confirma (a); `oc project -q` diferente confirma (b).
