# Gabarito PRJ-001 — Project e Namespace: o mesmo objeto, duas visões

> Consulte só depois de tentar. Enunciado: [trilhas/03-projetos/exercicios/PRJ-001.md](../../trilhas/03-projetos/exercicios/PRJ-001.md)

## Desafio sem pista — uma solução possível

```bash
oc get namespaces -o json | jq -r '.items[]
  | select(.metadata.name | test("^(openshift|kube)|^default$") | not)
  | [.metadata.name,
     (.metadata.annotations["openshift.io/requester"] // "-"),
     .metadata.creationTimestamp,
     (.metadata.annotations["openshift.io/display-name"] // "-")] | @tsv' | column -t
```

## Diagnóstico controlado — explicação

A API de projetos filtra a lista pelo que o usuário pode acessar; a de namespaces exige `list namespaces` no escopo de
cluster. As duas respostas de `can-i` confirmam a hipótese (a).
