# Gabarito PRJ-011 — uid, resourceVersion, generation e observedGeneration

> Consulte só depois de tentar. Enunciado: [trilhas/03-projetos/exercicios/PRJ-011.md](../../trilhas/03-projetos/exercicios/PRJ-011.md)

## Desafio sem pista — uma solução possível

```bash
processado() {
  local alvo="$1" ns="$2" i
  for i in $(seq 30); do
    if oc get "$alvo" -n "$ns" -o json | jq -e '.metadata.generation == .status.observedGeneration' >/dev/null; then
      echo processado; return 0; fi
    sleep 2
  done
  echo "não processado em 60 s" >&2; return 1
}
oc scale deployment obs-web --replicas=1 -n ac03-projetos && processado deployment/obs-web ac03-projetos
```

Previsões: 1 rv · 2 nada · 3 rv+gen (e depois obs) · 4 tudo (uid novo) · 5 o Deployment pode ter só `status` alterado (rv), sem gen.

## Diagnóstico controlado — explicação

`observedGeneration` menor que `generation` no instante da leitura mostra que o controlador ainda não processou a mudança.
