# Gabarito PRJ-002 — Criar projetos e namespaces com metadados completos

> Consulte só depois de tentar. Enunciado: [trilhas/03-projetos/exercicios/PRJ-002.md](../../trilhas/03-projetos/exercicios/PRJ-002.md)

## Desafio sem pista — uma solução possível

```bash
ac-admin
oc policy add-role-to-user view developer -n ac03-extra
KUBECONFIG="$HOME/.kube/ac-developer.kubeconfig" oc get project ac03-extra -o name    # agora visível
oc policy remove-role-from-user view developer -n ac03-extra
KUBECONFIG="$HOME/.kube/ac-developer.kubeconfig" oc get project ac03-extra 2>&1 | head -1   # Forbidden/NotFound
ac-dev
```

Conceder papel em projeto é AMARELO aqui porque o escopo é o namespace de laboratório e a reversão é imediata.

## Diagnóstico controlado — explicação

`status.phase=Active` com `AlreadyExists` confirma (a). `Terminating` indicaria (b): espere a exclusão terminar antes de recriar.
