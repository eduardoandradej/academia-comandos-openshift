# Gabarito PRJ-007 — Metadados que o OpenShift coloca nos namespaces

> Consulte só depois de tentar. Enunciado: [trilhas/03-projetos/exercicios/PRJ-007.md](../../trilhas/03-projetos/exercicios/PRJ-007.md)

## Desafio sem pista — uma solução possível

```bash
oc get namespaces -o json | jq -r '.items[]
  | select(.metadata.name | test("^ac([0-9]{2})?-"))
  | [.metadata.name,
     (.metadata.annotations["openshift.io/sa.scc.uid-range"] // "-" | split("/")[0]),
     (.metadata.labels["pod-security.kubernetes.io/warn"] // "-")] | @tsv'
```

## Diagnóstico controlado — explicação

A anotação `openshift.io/scc` do pod mostra `restricted-v2`, e o UID atribuído é o primeiro da faixa do projeto. A imagem
apenas sugere um UID; a SCC decide.
