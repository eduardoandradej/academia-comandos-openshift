# Gabarito PRJ-013 — Inventário de uma aplicação por rótulo

> Consulte só depois de tentar. Enunciado: [trilhas/03-projetos/exercicios/PRJ-013.md](../../trilhas/03-projetos/exercicios/PRJ-013.md)

## Desafio sem pista — uma solução possível

```bash
cat > /tmp/inventario.sh <<'EOF'
#!/usr/bin/env bash
set -euo pipefail
ns="$1"; sel="$2"; negados=0
while read -r t; do
  if out=$(oc get "$t" -n "$ns" -l "$sel" -o name 2>/tmp/inv.err); then
    n=$(grep -c . <<<"$out" || true); [ "$n" -gt 0 ] && echo "$t: $n"
  elif grep -q Forbidden /tmp/inv.err; then negados=$((negados+1)); fi
done < <(oc api-resources --namespaced=true --verbs=list -o name)
echo "tipos negados: $negados"; rm -f /tmp/inv.err
EOF
chmod +x /tmp/inventario.sh && /tmp/inventario.sh ac03-projetos app=obs-web
```

Repetição 5: uma requisição por tipo (dezenas de chamadas à API).

## Diagnóstico controlado — explicação

`oc auth can-i list <tipo>` responde `no` para os tipos citados: a permissão de `admin` do projeto não inclui todos os
tipos (alguns exigem papéis específicos).
