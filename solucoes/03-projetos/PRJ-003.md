# Gabarito PRJ-003 — Rótulos: adicionar, sobrescrever, listar e remover

> Consulte só depois de tentar. Enunciado: [trilhas/03-projetos/exercicios/PRJ-003.md](../../trilhas/03-projetos/exercicios/PRJ-003.md)

## Desafio sem pista — uma solução possível

```bash
oc label configmap/ac03-rotulos ambiente=treino camada=dados academy.openshift.dev/trilha=03 --overwrite -n ac03-projetos
for k in $(oc get configmap ac03-rotulos -n ac03-projetos -o json | jq -r '.metadata.labels | keys[]'); do
  case "$k" in academy.openshift.dev/managed-by|ambiente|camada|academy.openshift.dev/trilha) ;; *) oc label configmap/ac03-rotulos "$k-" -n ac03-projetos ;; esac
done
oc get configmap ac03-rotulos -n ac03-projetos -o json | jq -S '.metadata.labels'
```

Repetições 2 e 3: a API recusa (`a valid label must be an empty string or consist of alphanumeric characters, '-', '_' or '.'...`).

## Diagnóstico controlado — explicação

Sem `--overwrite`, o `oc label` nunca troca um valor existente — uma proteção para comandos aplicados em lote.
