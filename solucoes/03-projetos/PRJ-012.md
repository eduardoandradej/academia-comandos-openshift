# Gabarito PRJ-012 — Rótulos imperativos versus manifesto declarativo

> Consulte só depois de tentar. Enunciado: [trilhas/03-projetos/exercicios/PRJ-012.md](../../trilhas/03-projetos/exercicios/PRJ-012.md)

## Desafio sem pista — uma solução possível

| Operação | Efeito | Prova |
|---|---|---|
| `oc label ... extra=imperativo` + `apply` | `extra` permanece | `--show-labels` |
| `oc label ... versao=v9 --overwrite` + `apply` | `versao` volta a `v1` | `jsonpath .metadata.labels.versao` |
| retirar `camada` do arquivo + `apply` | `camada` é removido | `--show-labels` |
| `oc replace -f` | o objeto fica exatamente como o arquivo: `extra` some | `--show-labels` |

## Diagnóstico controlado — explicação

O merge de três vias só remove o que **estava** no último declarado e **saiu** do arquivo. Campos criados por outros
caminhos não são de responsabilidade do `apply` client-side.
