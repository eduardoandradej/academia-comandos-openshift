# Gabarito PRJ-010 — Finalizers e exclusão em duas fases (somente leitura)

> Consulte só depois de tentar. Enunciado: [trilhas/03-projetos/exercicios/PRJ-010.md](../../trilhas/03-projetos/exercicios/PRJ-010.md)

## Desafio sem pista — uma solução possível

```bash
oc new-project ac03-finalizador --skip-config-write
oc delete project ac03-finalizador --wait=false
date -u +%FT%TZ; oc get project ac03-finalizador -o jsonpath='fase={.status.phase} deletionTimestamp={.metadata.deletionTimestamp}{"\n"}'
until ! oc get project ac03-finalizador >/dev/null 2>&1; do sleep 2; done; date -u +%FT%TZ; echo "removido"
```

O laço `until` só lê; ele termina quando o `get` passa a falhar com `NotFound`.

## Diagnóstico controlado — explicação

As condições do namespace dizem o que falta: `NamespaceContentRemaining` lista tipos e quantidades ainda presentes;
`NamespaceFinalizersRemaining` lista finalizers pendentes; `NamespaceDeletionDiscoveryFailure` indica uma API
agregada indisponível (hipótese c), comum quando a pilha de métricas está com problema.
