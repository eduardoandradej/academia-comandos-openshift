# Gabarito PRJ-006 — Rótulos recomendados app.kubernetes.io/*

> Consulte só depois de tentar. Enunciado: [trilhas/03-projetos/exercicios/PRJ-006.md](../../trilhas/03-projetos/exercicios/PRJ-006.md)

## Desafio sem pista — uma solução possível

```bash
oc get svc -n ac03-projetos -l app.kubernetes.io/name=loja -o json | jq -r '.items
  | sort_by(.metadata.labels["app.kubernetes.io/instance"], .metadata.labels["app.kubernetes.io/component"])[]
  | [.metadata.labels["app.kubernetes.io/instance"], .metadata.labels["app.kubernetes.io/component"], .metadata.name] | @tsv' | column -t
```

## Diagnóstico controlado — explicação

Sem pods com `app=loja-api`, a EndpointSlice do Service não tem endpoints. Isso volta a aparecer, como falha, no TS-010.
