# Gabarito PRJ-015 — Circuito de metadados e encerramento da trilha

> Consulte só depois de tentar. Enunciado: [trilhas/03-projetos/exercicios/PRJ-015.md](../../trilhas/03-projetos/exercicios/PRJ-015.md)

## Desafio sem pista — uma solução possível

```bash
oc get projects -o custom-columns=NOME:.metadata.name,EXIBICAO:.metadata.annotations.openshift\.io/display-name   # 1
oc get project ac03-projetos -o jsonpath='{.metadata.annotations.openshift\.io/requester}{"\n"}'                  # 2
oc create configmap ac03-c --from-literal=x=1 --dry-run=client -o yaml \
  | oc label --local -f - academy.openshift.dev/managed-by=academia -o yaml | oc apply -n ac03-projetos -f -       # 3
oc label cm/ac03-c t=1 -n ac03-projetos; oc label cm/ac03-c t=2 --overwrite -n ac03-projetos                     # 4
oc label cm/ac03-c t- -n ac03-projetos                                                                           # 5
oc label cm -l academy.openshift.dev/managed-by=academia revisado=sim -n ac03-projetos --dry-run=server \
  && oc label cm -l academy.openshift.dev/managed-by=academia revisado=sim -n ac03-projetos                       # 6
oc annotate cm/ac03-c nota="$(printf 'a\nb')" -n ac03-projetos                                                   # 7
oc get cm -n ac03-projetos -o json | jq -r '.items[] | select(.metadata.annotations.nota) | .metadata.name'       # 8
oc get svc obs-web -n ac03-projetos -o jsonpath='{.spec.selector}{"\n"}'; oc describe svc obs-web -n ac03-projetos | grep Endpoints   # 9
P=$(oc get pods -n ac03-projetos -l app=obs-web -o name | head -1); RS=$(oc get "$P" -n ac03-projetos -o jsonpath='{.metadata.ownerReferences[0].name}'); \
  echo "$P -> $RS -> $(oc get rs "$RS" -n ac03-projetos -o jsonpath='{.metadata.ownerReferences[0].name}')"     # 10
oc get deploy obs-web -n ac03-projetos -o jsonpath='{.metadata.generation} {.status.observedGeneration}{"\n"}'   # 11
oc get project ac03-projetos -o jsonpath='{.spec.finalizers}{"\n"}'                                             # 12
oc get ns ac03-projetos -o jsonpath='{.metadata.annotations.openshift\.io/sa\.scc\.uid-range}{"\n"}'            # 13 (admin)
oc get ns -l academy.openshift.dev/managed-by=academia -L academy.openshift.dev/trilha                          # 14 (admin)
echo "projects=$(oc get projects --no-headers | wc -l) namespaces=$(oc get ns --no-headers | wc -l)"            # 15 (admin)
```

## Diagnóstico controlado — explicação

Projetos só aparecem para quem tem papel neles. `ac03-extra` foi criado por `admin` com `oc create namespace`; o
developer só o via durante o desafio do PRJ-002.
