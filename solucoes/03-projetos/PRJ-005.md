# Gabarito PRJ-005 — Anotações: metadados que não selecionam

> Consulte só depois de tentar. Enunciado: [trilhas/03-projetos/exercicios/PRJ-005.md](../../trilhas/03-projetos/exercicios/PRJ-005.md)

## Desafio sem pista — uma solução possível

```bash
oc get configmap -n ac03-projetos -o json | jq -r '.items[]
  | select(.metadata.annotations["academy.openshift.dev/autor"] != null)
  | "\(.metadata.name)\t\(.metadata.annotations["academy.openshift.dev/autor"])"'
```

## Diagnóstico controlado — explicação

A API só aceita seletores sobre rótulos (e sobre alguns campos). Filtrar por anotação é sempre no cliente (jq, jsonpath com filtro).
