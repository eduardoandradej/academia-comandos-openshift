# Gabarito CLI-007 — Projetos: criar, listar e alternar

> Consulte só depois de tentar. Enunciado: [trilhas/01-cli/exercicios/CLI-007.md](../../trilhas/01-cli/exercicios/CLI-007.md)

## Desafio sem pista — uma solução possível

```bash
acp() {
  [[ "${1:-}" =~ ^ac[0-9]{2}-[a-z0-9-]+$ ]] || { echo "recusado: $1 não é projeto de laboratório" >&2; return 1; }
  oc project "$1"
}
acp ac01-cli          # alterna
acp openshift-console # recusado
```

## Diagnóstico controlado — explicação

`developer` não tem papel em `default`; o `oc project` falha antes de alterar o kubeconfig. `can-i` responde `no` (hipótese a).
