## Desafio sem pista — uma solução possível

```bash
oc version --client                                   # 1
oc version -o json | jq -r .serverVersion.gitVersion  # 2
oc whoami                                             # 3
oc whoami --show-server                               # 4
oc whoami --show-context                              # 5
oc whoami --show-console                              # 6
oc auth whoami                                        # 7
oc whoami -t | wc -c                                  # 8
oc config get-contexts                                # 9
oc config view --minify -o jsonpath='{.clusters[0].cluster.server}{"\n"}'   # 10
oc project -q                                         # 11
oc projects -q | grep '^ac01-'                        # 12
oc config set-context --current --namespace=ac01-cli  # 13
oc status -n ac01-cli                                 # 14
oc get svc -n ac01-cli -v=6 2>&1 | grep GET           # 15
oc get --raw /api/v1/namespaces/ac01-cli/services | jq -r '.items[].metadata.name'   # 16
kubectl get pods -n ac01-cli                          # 17
oc auth can-i list nodes; KUBECONFIG=~/.kube/ac-admin.kubeconfig oc auth can-i list nodes   # 18
curl -ksS https://api.ocp.example.lab:6443/readyz; echo   # 19
oc plugin list                                        # 20
```

## Diagnóstico controlado — explicação

O script só apaga um projeto se ele tiver o rótulo da Academia **ou** se a identidade atual for o `requester`. Projetos
criados como `developer` neste trilha cumprem a segunda condição.
