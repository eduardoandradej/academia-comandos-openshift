## Desafio sem pista — uma solução possível

Pela saída: `deployment/obs-web deploys ... 2 pods` (ou contagem equivalente), `svc/obs-web - <ClusterIP>:8080` e
ausência de linha `http://...` (sem Route). Confirmações:

```bash
oc get deployment obs-web -n ac01-cli -o jsonpath='{.spec.replicas}{"\n"}'
oc get svc obs-web -n ac01-cli -o jsonpath='{.spec.ports[0].port}{"\n"}'
oc get routes -n ac01-cli
```

## Diagnóstico controlado — explicação

Os eventos do pod dizem a causa: `Failed to pull image` (a), `exceeded quota` aparece nos eventos do ReplicaSet (b),
`FailedScheduling ... Insufficient memory` (c).
