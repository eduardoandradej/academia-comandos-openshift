# Gabarito CLI-001 — Versões do cliente e do servidor

> Consulte só depois de tentar. Enunciado: [trilhas/01-cli/exercicios/CLI-001.md](../../trilhas/01-cli/exercicios/CLI-001.md)

## Desafio sem pista — uma solução possível

```bash
printf 'cliente=%s servidor_k8s=%s\n' \
  "$(oc version --client -o json | jq -r '.releaseClientVersion // .clientVersion.gitVersion')" \
  "$(oc version -o json | jq -r .serverVersion.gitVersion)"
```

A versão do OpenShift do servidor vem do `ClusterVersion`, que `developer` não pode ler; a versão do Kubernetes vem
de `/version`, liberado para todos os autenticados.

## Diagnóstico controlado — explicação

`oc version --client` funciona mesmo sem kubeconfig — então o cliente está íntegro e o erro é de configuração ou rede.
