# Gabarito CLI-012 — Plugins do oc

> Consulte só depois de tentar. Enunciado: [trilhas/01-cli/exercicios/CLI-012.md](../../trilhas/01-cli/exercicios/CLI-012.md)

## Desafio sem pista — uma solução possível

```bash
cat > ~/.local/bin/oc-ac-quem <<'EOF'
#!/usr/bin/env bash
printf '%s@%s (%s)\n' "$(oc whoami)" "$(oc whoami --show-server)" "$(oc whoami --show-context)"
EOF
chmod +x ~/.local/bin/oc-ac-quem
oc ac-quem
```

## Diagnóstico controlado — explicação

`command -v oc-ac-ola` vazio com o arquivo existente indica `PATH` (a); `ls -l` sem `x` indica (b). No RHEL 9,
`~/.local/bin` costuma entrar no `PATH` pelo `~/.bashrc` padrão, mas só se o diretório existir no login.
