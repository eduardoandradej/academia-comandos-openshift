# Gabarito CLI-011 — Verbosidade e timeout: ver o que a CLI faz

> Consulte só depois de tentar. Enunciado: [trilhas/01-cli/exercicios/CLI-011.md](../../trilhas/01-cli/exercicios/CLI-011.md)

## Desafio sem pista — uma solução possível

```bash
oc get configmap obs-config -n ac01-cli -v=6 2>&1 | grep -o 'GET https[^ ]*'
oc get --raw /api/v1/namespaces/ac01-cli/configmaps/obs-config | jq -r .data.MODO
```

ConfigMap é do grupo core (`/api/v1`); Deployments ficam em `/apis/apps/v1`; Routes em `/apis/route.openshift.io/v1`.

## Diagnóstico controlado — explicação

Se com `--request-timeout=10s` funciona e `time oc get --raw /readyz` é rápido, era só o timeout curto (a). Lentidão
consistente com nó perto do limite de memória aponta para (b).
