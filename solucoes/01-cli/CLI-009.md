# Gabarito CLI-009 — Vários kubeconfigs, contextos e --context

> Consulte só depois de tentar. Enunciado: [trilhas/01-cli/exercicios/CLI-009.md](../../trilhas/01-cli/exercicios/CLI-009.md)

## Desafio sem pista — uma solução possível

```bash
for c in dev adm; do printf '%s: ' "$c"; oc --context="$c" auth can-i create resourcequotas -n ac01-cli; done
```

Esperado: `dev: no` e `adm: yes`.

## Diagnóstico controlado — explicação

Contextos só existem nos arquivos presentes na lista atual. Se o terminal tem `KUBECONFIG` apenas com o arquivo do
developer, `adm` não existe ali (hipótese a).

## Erros comuns

- Incluir o kubeconfig do instalador na lista "por conveniência": qualquer `oc login` ou `rename-context` pode acabar gravado nele.
