# Gabarito CLI-008 — Namespace padrão, -n e precedência

> Consulte só depois de tentar. Enunciado: [trilhas/01-cli/exercicios/CLI-008.md](../../trilhas/01-cli/exercicios/CLI-008.md)

## Desafio sem pista — uma solução possível

```bash
ctx() { printf 'contexto=%s namespace_padrao=%s\n' "$(oc config current-context)" \
  "$(oc config view --minify -o jsonpath='{.contexts[0].context.namespace}')"; }
ctx
oc config set-context --current --namespace=ac01-cli-b >/dev/null; ctx   # nome igual, namespace muda
oc project ac01-cli >/dev/null; ctx                                       # nome muda para ac01-cli/...
```

Previsões das repetições: 1 `ac01-cli` · 2 `ac01-cli-inexistente` (lista vazia ou Forbidden) · 3 `default`
(Forbidden para developer) · 4 `ac01-cli` (-n vence) · 5 Forbidden (nodes é de cluster, e developer não lista nós).

## Diagnóstico controlado — explicação

Se o jsonpath do namespace vier vazio, o contexto não tem namespace e os comandos caem em `default` (hipótese a).
