# Gabarito CLI-002 — A ajuda como mapa: help, --help e options

> Consulte só depois de tentar. Enunciado: [trilhas/01-cli/exercicios/CLI-002.md](../../trilhas/01-cli/exercicios/CLI-002.md)

## Desafio sem pista — uma solução possível

```bash
oc get pods --sort-by=.metadata.creationTimestamp --ignore-not-found
```

Respostas das repetições: 1 `--previous` (`-p`) · 2 `--wait=false` · 3 `oc config get-contexts` ·
4 `--skip-config-write` · 5 `--request-timeout`.

## Diagnóstico controlado — explicação

A flag correta é `--sort-by`; o `grep -i sort` encontra a linha. Flags desconhecidas falham antes de qualquer contato com a API.
