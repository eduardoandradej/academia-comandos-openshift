# Gabarito CLI-004 — Login e logout com kubeconfig dedicado

> Consulte só depois de tentar. Enunciado: [trilhas/01-cli/exercicios/CLI-004.md](../../trilhas/01-cli/exercicios/CLI-004.md)

## Desafio sem pista — uma solução possível

```bash
export KUBECONFIG=/tmp/ac-temp.kubeconfig
oc login https://api.ocp.example.lab:6443 -u developer   # aceite o modo inseguro OU use --certificate-authority
oc whoami
oc logout
unset KUBECONFIG; rm -f /tmp/ac-temp.kubeconfig
```

Os perfis em `~/.kube` não foram tocados porque o `KUBECONFIG` apontava para o arquivo temporário durante todo o ciclo.

## Diagnóstico controlado — explicação

401 no login vem do servidor OAuth: as credenciais não conferem para o provedor. Se `oc get identities` mostrar
`homelab-users:developer`, o usuário existe e já entrou antes — o mais provável é a senha (hipótese a).
