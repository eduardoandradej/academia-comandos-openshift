# Gabarito CLI-005 — whoami a fundo, sem revelar segredos

> Consulte só depois de tentar. Enunciado: [trilhas/01-cli/exercicios/CLI-005.md](../../trilhas/01-cli/exercicios/CLI-005.md)

## Desafio sem pista — uma solução possível

```bash
printf 'usuario=%s grupos=%s console=%s\n' "$(oc whoami)" \
  "$(oc auth whoami -o json | jq -r '.status.userInfo.groups | join(",")')" \
  "$(oc whoami --show-console)"
```

## Diagnóstico controlado — explicação

O kubeconfig do instalador usa `client-certificate-data`/`client-key-data`: não existe token a mostrar (hipótese a).
`oc config view --minify` confirma pelo nome dos campos, com os valores ocultos.

## Erros comuns

- Colar a saída de `oc whoami -t` em chat, issue ou commit: qualquer pessoa com o token age como você até ele expirar. Se acontecer, faça `oc logout` imediatamente (revoga o token).
