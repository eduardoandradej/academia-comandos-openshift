# Gabarito ADM-012 — Logs do nó sem entrar no nó

> Consulte só depois de tentar. Enunciado: [trilhas/17-admin/exercicios/ADM-012.md](../../trilhas/17-admin/exercicios/ADM-012.md)

## Desafio sem pista — uma solução possível

```bash
N=$(oc get nodes -o jsonpath='{.items[0].metadata.name}')
oc get events -n ac17-cotas --field-selector reason=Pulled -o json | jq -r '.items[-1] | "\(.lastTimestamp)\t\(.message)"'
oc adm node-logs "$N" --unit=crio --since=-60m | grep -i 'pulled image' | tail -2
```

O journal usa a hora local do nó; os eventos, UTC: compare com cuidado de fuso.

## Diagnóstico controlado — explicação

`nodes/log` é um subrecurso de cluster; só papéis de admin o leem.
