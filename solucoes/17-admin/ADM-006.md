# Gabarito ADM-006 — Quota e LimitRange juntos: a ordem da admissão

> Consulte só depois de tentar. Enunciado: [trilhas/17-admin/exercicios/ADM-006.md](../../trilhas/17-admin/exercicios/ADM-006.md)

## Desafio sem pista — uma solução possível

```bash
oc get resourcequota -n ac17-cotas -o json | jq -r --argjson d '{"requests.cpu":25,"requests.memory":32,"limits.cpu":100,"limits.memory":128,"pods":1}' '
  def v: if test("m$") then (.[:-1]|tonumber) elif test("Mi$") then (.[:-2]|tonumber) elif test("Gi$") then (.[:-2]|tonumber*1024)
         elif test("^[0-9.]+$") then (tonumber) else 0 end;
  .items[] | select((.spec.scopes // []) | length == 0) | .metadata.name as $q | .status as $s
  | .spec.hard | keys[] | select($d[.]) as $k
  | (($s.hard[$k]|v) * (if ($k|test("cpu")) and ($s.hard[$k]|test("m$")|not) then 1000 else 1 end)) as $h
  | (($s.used[$k]|v) * (if ($k|test("cpu")) and ($s.used[$k]|test("m$")|not) then 1000 else 1 end)) as $u
  | "\($q) \($k): restam \($h - $u), o pod pede \($d[$k]) → \(if ($h-$u) < $d[$k] then "RECUSA" else "ok" end)"'
```

A linha com RECUSA indica o limite que vai barrar; os padrões vêm do LimitRange.

## Diagnóstico controlado — explicação

A quota só aceita pods com valores declarados para os recursos que ela controla; o LimitRange é quem os declara por você.
