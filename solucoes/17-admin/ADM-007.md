# Gabarito ADM-007 — ClusterResourceQuota: uma cota para vários projetos

> Consulte só depois de tentar. Enunciado: [trilhas/17-admin/exercicios/ADM-007.md](../../trilhas/17-admin/exercicios/ADM-007.md)

## Desafio sem pista — uma solução possível

```bash
cat <<'EOF' | oc apply --dry-run=server -f -
apiVersion: quota.openshift.io/v1
kind: ClusterResourceQuota
metadata:
  name: ac17-por-dono
spec:
  selector:
    annotations:
      openshift.io/requester: developer
  quota:
    hard:
      pods: "10"
EOF
```

Aplicada de verdade, ela limitaria **todos** os projetos do developer — inclusive os de outras trilhas.

## Diagnóstico controlado — explicação

A CRQ soma o uso dos projetos selecionados; um projeto vazio pode já não ter folga.
