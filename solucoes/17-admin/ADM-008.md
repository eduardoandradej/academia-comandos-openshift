# Gabarito ADM-008 — Onde os pods podem rodar: node selector, taints e o agendador (leitura)

> Consulte só depois de tentar. Enunciado: [trilhas/17-admin/exercicios/ADM-008.md](../../trilhas/17-admin/exercicios/ADM-008.md)

## Desafio sem pista — uma solução possível

```bash
oc run ac17-seletor --image=registry.access.redhat.com/ubi9/httpd-24:latest -n ac17-cotas --overrides='{"spec":{"nodeSelector":{"disco":"inexistente"}}}' --dry-run=server -o name
```

A admissão aceita (o pod é válido); só o agendador descobre que nenhum nó serve, e o pod fica `Pending` com
`FailedScheduling`. Uma recusa de admissão (quota, LimitRange, SCC) impede o pod de existir.

## Diagnóstico controlado — explicação

O seletor do namespace é somado ao do pod pela admissão; um rótulo inexistente torna o pod inagendável.
