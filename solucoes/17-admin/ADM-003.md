# Gabarito ADM-003 — ResourceQuota completa: computação, objetos e escopos

> Consulte só depois de tentar. Enunciado: [trilhas/17-admin/exercicios/ADM-003.md](../../trilhas/17-admin/exercicios/ADM-003.md)

## Desafio sem pista — uma solução possível

```bash
oc get resourcequota -n ac17-cotas -o json | jq -r '.items[] | .status as $s | .spec.hard | keys[] as $k
  | "\($k)\t\($s.used[$k] // "0")/\($s.hard[$k])"' | sort | column -t
```

Para porcentagens com unidades (m, Mi), converta como no ADM-002; contagens podem ser divididas diretamente.

## Diagnóstico controlado — explicação

O status da quota é recalculado de forma assíncrona; a admissão, porém, já usa a quota assim que ela existe.
