## Desafio sem pista — uma solução possível

```bash
N=$(oc get nodes -o jsonpath='{.items[0].metadata.name}')
oc get pods -A --field-selector=spec.nodeName="$N",status.phase=Running -o json | jq -r '
  def m: if . == null then 0 elif test("m$") then (.[:-1]|tonumber) else (tonumber*1000) end;
  [.items[].spec.containers[].resources.requests.cpu | m] | add | "requests.cpu somados: \(.)m"'
oc describe node "$N" | sed -n '/Allocated resources:/,/Events:/p' | grep -m1 cpu
```

A diferença pequena vem de init containers e overhead de pod, que o `describe` considera.
