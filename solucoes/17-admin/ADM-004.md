# Gabarito ADM-004 — Quota em ação: recusas e a exigência de requests

> Consulte só depois de tentar. Enunciado: [trilhas/17-admin/exercicios/ADM-004.md](../../trilhas/17-admin/exercicios/ADM-004.md)

## Desafio sem pista — uma solução possível

```bash
oc get resourcequota -n ac17-cotas -o json | jq -r '
  def cpu: if test("m$") then (.[:-1]|tonumber) else (tonumber*1000) end;
  def mem: if test("Mi$") then (.[:-2]|tonumber) elif test("Gi$") then (.[:-2]|tonumber*1024) else (tonumber/1048576) end;
  [.items[] | .status as $s | (
     (if $s.hard["requests.cpu"] then ((($s.hard["requests.cpu"]|cpu) - ($s.used["requests.cpu"]|cpu)) / 50 | floor) else empty end),
     (if $s.hard["requests.memory"] then ((($s.hard["requests.memory"]|mem) - ($s.used["requests.memory"]|mem)) / 64 | floor) else empty end),
     (if $s.hard.pods and ((.spec.scopes // []) | length == 0) then (($s.hard.pods|tonumber) - ($s.used.pods|tonumber)) else empty end))]
  | "cabem \(min) pods"'
```

O menor dos limites decide. Lembre-se de que os limits (`limits.cpu/memory`) também contam, se o pod os declarar.

## Diagnóstico controlado — explicação

A quota de computação exige que cada pod informe os recursos que ela limita; sem isso, não há como somá-los.
