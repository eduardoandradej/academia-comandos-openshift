# Gabarito ADM-009 — PriorityClass: prioridade baixa para o treino

> Consulte só depois de tentar. Enunciado: [trilhas/17-admin/exercicios/ADM-009.md](../../trilhas/17-admin/exercicios/ADM-009.md)

## Desafio sem pista — uma solução possível

```bash
oc get pods -A -o json | jq -r '[.items[] | {c: (.spec.priorityClassName // "(nenhuma)"), p: (.spec.priority // 0)}]
  | group_by(.c) | map("\(.[0].p)\t\(.[0].c)\t\(length) pods") | .[]' | sort -rn | column -t
oc get pods -A -o json | jq '[.items[] | select((.spec.priority // 0) > -10)] | length'
```

## Diagnóstico controlado — explicação

`priorityClassName` precisa existir na admissão; a prioridade numérica é copiada para o pod naquele momento.
