# Gabarito ADM-002 — Quem reserva e quem consome: ranking por projeto

## Desafio sem pista — uma solução possível

```bash
oc adm top pods -A --no-headers 2>/dev/null | awk '$1 ~ /^ac/ {gsub("m","",$3); u[$1]+=$3} END {for (n in u) print n, u[n]}' > /tmp/ac17-uso.txt
oc get pods -A -o json | jq -r '.items[] | select(.metadata.namespace|startswith("ac")) | select(.status.phase=="Running")
  | .metadata.namespace as $n | .spec.containers[].resources.requests.cpu // "0" | "\($n) \(if test("m$") then .[:-1] else (tonumber*1000|tostring) end)"' \
  | awk '{r[$1]+=$2} END {for (n in r) print n, r[n]}' > /tmp/ac17-req.txt
join <(sort /tmp/ac17-uso.txt) <(sort /tmp/ac17-req.txt) | awk '{p = ($3>0) ? 100*$2/$3 : 0; printf "%s uso=%sm req=%sm %.0f%%%s\n", $1, $2, $3, p, (p<20?" superdimensionado":"")}'
rm -f /tmp/ac17-uso.txt /tmp/ac17-req.txt
```

## Diagnóstico controlado — explicação

Requests vêm da API (sempre disponíveis); uso vem da Metrics API (pode faltar).
