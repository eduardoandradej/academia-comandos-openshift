## Desafio sem pista — uma solução possível

```bash
por_que_nao_sobe() {
  local d=$1 ns=${2:-ac17-cotas} m
  m=$(oc get events -n "$ns" --field-selector type=Warning -o json | jq -r --arg d "$d" '[.items[] | select(.involvedObject.name|startswith($d))] | last | .message // ""')
  case "$m" in
    *"exceeded quota"*|*"must specify"*) echo "quota: $m";;
    *"per Container"*|*minimum*|*ratio*) echo "LimitRange: $m";;
    *PriorityClass*) echo "prioridade: $m";;
    *Insufficient*|*"node affinity"*|*"node selector"*|*"didn't match"*) echo "agendamento: $m";;
    *Evict*|*"low on resource"*) echo "despejo: $m";;
    "") echo "sem avisos: confira oc rollout status e os pods";;
    *) echo "outro: $m";;
  esac
}
por_que_nao_sobe ac17-grande
```

## Diagnóstico controlado — explicação

Recusas de admissão aparecem no controlador que tentou criar o pod (ReplicaSet), não em um pod.
