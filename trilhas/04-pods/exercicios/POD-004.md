## Objetivo e indicador de sucesso

Ler logs de um Pod com todas as variações úteis: `-f`, `--tail`, `--since`, `--timestamps`, por rótulo e por Deployment.

**Indicador de sucesso:** você mostra só as últimas 5 linhas dos últimos 2 minutos, com horário, sem consulta.

## Conceito

`oc logs` mostra o que o contêiner escreve em **stdout/stderr**. O kubelet guarda esses logs no nó enquanto o
contêiner existir (e a instância anterior, para `--previous`). Arquivos de log gravados dentro do contêiner **não**
aparecem no `oc logs`.

| Opção | Efeito |
|---|---|
| `-f` | segue em tempo real |
| `--tail=N` | só as últimas N linhas |
| `--since=2m` / `--since-time=...` | só o período |
| `--timestamps` | prefixa cada linha com o horário |
| `-l chave=valor` | pods por rótulo |
| `deployment/NOME` | um pod do Deployment |
| `--previous` (`-p`) | a instância anterior do contêiner (após reinício) |

## Comandos guiados

```bash
oc run ac04-log --image=registry.access.redhat.com/ubi9/httpd-24:latest \
  --labels=app=ac04-log,academy.openshift.dev/managed-by=academia -n ac04-pods \
  --command -- /bin/sh -c 'i=0; while true; do i=$((i+1)); echo "linha $i"; [ $((i % 5)) -eq 0 ] && echo "aviso $i" >&2; sleep 2; done'
oc wait --for=condition=Ready pod/ac04-log -n ac04-pods --timeout=120s
oc logs ac04-log -n ac04-pods
oc logs ac04-log -n ac04-pods --tail=5
oc logs ac04-log -n ac04-pods --since=30s
oc logs ac04-log -n ac04-pods --timestamps --tail=3
oc logs -f ac04-log -n ac04-pods                     # Ctrl+C para sair
oc logs -l app=ac04-log -n ac04-pods --tail=2
oc logs ac04-log -n ac04-pods | grep -c aviso        # stderr também vem
oc logs pod/ac04-web -n ac04-pods --tail=5           # logs do httpd
```

## Repetições

1. Últimas 5 linhas dos últimos 2 minutos, com horário.
2. `oc logs -f ac04-log -n ac04-pods --tail=0` — só o que chegar a partir de agora.
3. `oc logs ac04-log -n ac04-pods | tail -1` × `--tail=1`: qual é mais eficiente e por quê?
4. Logs do alvo da Trilha 02, se existir: `oc logs deployment/obs-web -n ac02-consultas --tail=3`.
5. `oc logs ac04-log -n ac04-pods --limit-bytes=100`.

## Desafio sem pista

Conte quantas linhas de `aviso` o Pod escreveu nos últimos 60 segundos e mostre a última delas com o horário.

## Diagnóstico controlado

- **Sintoma:** `oc logs` não mostra nada, mas a aplicação "está registrando".
- **Hipóteses:** (a) a aplicação grava em arquivo, não em stdout; (b) contêiner errado (em pods com vários contêineres); (c) logs ainda vazios.
- **Investigação:** `oc exec <pod> -- ls -l /var/log` (ou o diretório da app); `oc get pod <pod> -o jsonpath='{.spec.containers[*].name}'`.
- **Reversão:** nada a reverter.

## Validação

```bash
oc logs ac04-log -n ac04-pods --tail=1 | grep -q '^linha' && echo OK
```

## Limpeza segura

```bash
oc delete pod ac04-log -n ac04-pods
```
