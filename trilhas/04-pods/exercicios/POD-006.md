## Conceito

`oc exec <pod> [-c contêiner] -- <comando> [args]` roda um **novo processo** no contêiner, com o mesmo usuário e o
mesmo sistema de arquivos. O `--` separa as opções do `oc` do comando remoto. Só existe o que a **imagem** tem: imagens
mínimas podem não ter `ps`, `curl` ou nem mesmo shell.

Alterações feitas por `exec` (arquivos criados, processos iniciados) **somem** quando o contêiner é recriado — não
são forma de configurar nada.

## Comandos guiados

```bash
oc exec ac04-web -n ac04-pods -- id                       # UID atribuído pela SCC (faixa do projeto)
oc exec ac04-web -n ac04-pods -- hostname                 # nome do pod
oc exec ac04-web -n ac04-pods -- cat /etc/os-release
oc exec ac04-web -n ac04-pods -- env | sort | head -20
oc exec ac04-web -n ac04-pods -- sh -c 'tr "\0" " " </proc/1/cmdline; echo'   # comando do processo 1
oc exec ac04-web -n ac04-pods -- ls -la /tmp
oc exec ac04-web -n ac04-pods -- cat /etc/resolv.conf    # DNS do cluster dentro do pod
oc exec ac04-duplo -n ac04-pods -c relogio -- date -u
oc exec deploy/obs-web -n ac02-consultas -- id 2>/dev/null || echo "(alvo da Trilha 02 não existe; tudo bem)"
```

## Repetições

1. `oc exec ac04-web -n ac04-pods -- sh -c 'echo $HOME; pwd'` — por que precisa de `sh -c`?
2. `oc exec ac04-web -n ac04-pods -- which ps curl tar bash` — o que a imagem tem?
3. `oc exec ac04-web -n ac04-pods -- df -h /tmp`.
4. `oc exec ac04-web -n ac04-pods -- sh -c 'echo teste > /tmp/x && cat /tmp/x'`; depois apague e recrie o Pod e procure `/tmp/x`.
5. Compare `oc exec ac04-web -- id` com a anotação `openshift.io/sa.scc.uid-range` do namespace (PRJ-007).

## Desafio sem pista

Sem `ps` na imagem, liste todos os processos do contêiner `web` (PID e comando) lendo `/proc`.

## Diagnóstico controlado

- **Sintoma:** `exec: "ps": executable file not found in $PATH` (ou `command terminated with exit code 127`).
- **Hipóteses:** a imagem não tem o utilitário.
- **Investigação:** `oc exec ac04-web -n ac04-pods -- sh -c 'command -v ps || echo ausente'`.
- **Reversão:** nada a reverter. Use `/proc` ou `oc debug` (POD-013) com outra imagem.

## Validação

```bash
oc exec ac04-web -n ac04-pods -- id -u | grep -Eq '^[0-9]+$' && echo OK
```
