## Objetivo e indicador de sucesso

Abrir e encerrar shells interativos com `oc exec -it` e `oc rsh`, em contêineres diferentes, sem deixar sessões presas.

## Conceito

| Comando | Diferença |
|---|---|
| `oc exec -it <pod> -- /bin/bash` | `-i` mantém a entrada aberta, `-t` aloca um terminal; você escolhe o shell |
| `oc rsh <pod>` | atalho do OpenShift: abre `/bin/sh` com terminal; aceita `-c` e um comando no fim |
| `oc rsh <pod> <comando>` | executa um comando único com terminal |

Saia com `exit` ou Ctrl+D. Sem `-t`, editores e programas de tela cheia não funcionam; sem `-i`, você não consegue digitar.

## Comandos guiados

```bash
oc exec -it ac04-web -n ac04-pods -- /bin/bash
#   dentro: id; hostname; ls /var/www; exit
oc rsh ac04-web -n ac04-pods
#   dentro: echo $SHELL; cat /etc/hostname; exit
oc rsh -c relogio ac04-duplo -n ac04-pods
#   dentro: date; exit
oc rsh ac04-web -n ac04-pods ls -l /etc/httpd/conf.d   # comando único
```

## Repetições

1. Entre e saia 5× de cada forma, sem olhar.
2. Dentro do shell, rode `env | grep -i kubernetes` — de onde vêm essas variáveis?
3. `oc exec -i ac04-web -n ac04-pods -- sh -c 'cat > /tmp/entrada' < /etc/hostname` (só `-i`): o que foi gravado?
4. `oc rsh --help | sed -n '/Examples:/,/Options:/p'`.
5. Abra um shell e, em outro terminal, apague o pod (só na repetição final): o que acontece com a sessão?

## Desafio sem pista

Sem abrir um shell interativo, conte quantos arquivos `.conf` há em `/etc/httpd/conf.d` do contêiner `web` do `ac04-duplo`.
Depois, faça o mesmo de dentro de um shell aberto com `rsh`.

## Diagnóstico controlado

- **Sintoma:** `Unable to use a TTY - input is not a terminal or the right kind of file` (por exemplo, dentro de um script).
- **Hipóteses:** `-t` pedido sem terminal local.
- **Investigação:** rode `oc exec -it ...` dentro de `bash -c '... </dev/null'` e compare com o terminal interativo.
- **Reversão:** nada a reverter; em scripts, use `oc exec` sem `-t`.

## Validação

```bash
oc rsh ac04-web -n ac04-pods true && echo "rsh OK"
```

## Limpeza segura

Saia de todos os shells (`exit`). Nada a apagar.
