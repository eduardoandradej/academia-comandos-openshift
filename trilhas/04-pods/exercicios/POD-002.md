## Conceito

| Fase (`status.phase`) | Significado |
|---|---|
| `Pending` | aceito pela API; aguardando agendamento ou download de imagem |
| `Running` | ao menos um contêiner rodando |
| `Succeeded` | todos terminaram com código 0 e não serão reiniciados |
| `Failed` | todos terminaram e ao menos um falhou |
| `Unknown` | o nó não informa o estado |

`STATUS` na saída de `oc get pods` é um resumo mais detalhado (`ContainerCreating`, `ErrImagePull`,
`CrashLoopBackOff`...) calculado a partir dos estados dos contêineres.

## Comandos guiados

```bash
oc run ac04-web --image=registry.access.redhat.com/ubi9/httpd-24:latest \
  --labels=app=ac04-web,academy.openshift.dev/managed-by=academia --port=8080 -n ac04-pods
oc get pods -n ac04-pods -w                       # Ctrl+C quando ficar Running 1/1
oc get pod ac04-web -n ac04-pods -o wide
oc get pod ac04-web -n ac04-pods -o jsonpath='{.status.phase}{"\n"}'
oc get pod ac04-web -n ac04-pods -o jsonpath='{range .status.conditions[*]}{.type}={.status} {.lastTransitionTime}{"\n"}{end}'
oc describe pod ac04-web -n ac04-pods | sed -n '/Events:/,$p'
oc get pod ac04-web -n ac04-pods -o jsonpath='{.metadata.annotations.openshift\.io/scc}{"\n"}'   # SCC aplicada
```

## Repetições

1. Apague e recrie 5×, cronometrando quanto tempo leva até `Running` (a imagem já está em cache depois da 1ª vez).
2. `oc get pod ac04-web -n ac04-pods -o jsonpath='{.status.containerStatuses[0].state}' | jq .`.
3. `oc get pod ac04-web -n ac04-pods -o jsonpath='{.status.podIP} {.spec.nodeName}{"\n"}'`.
4. `oc get pod ac04-web -n ac04-pods -o jsonpath='{.status.qosClass}{"\n"}'` (anote; volta no POD-012).
5. Compare `oc get pod ac04-web -o yaml` com o YAML gerado no POD-001: o que o cluster acrescentou?

## Desafio sem pista

Recrie o Pod e, só com comandos de leitura, reconstrua a linha do tempo dele: horário de agendamento, de download (ou
de uso da imagem em cache), de criação e de início do contêiner, e o momento em que ficou `Ready`.

## Diagnóstico controlado

- **Sintoma:** `Error from server (AlreadyExists): pods "ac04-web" already exists`.
- **Hipóteses:** (a) o Pod da repetição anterior ainda existe; (b) ainda está terminando.
- **Investigação:** `oc get pod ac04-web -n ac04-pods -o jsonpath='{.metadata.deletionTimestamp}{"\n"}'`.
- **Reversão:** `oc delete pod ac04-web -n ac04-pods --wait=true` e recrie.

## Validação

```bash
oc wait --for=condition=Ready pod/ac04-web -n ac04-pods --timeout=120s
```

## Limpeza segura

O Pod `ac04-web` é usado nos POD-004 a POD-010. Para apagar agora: `oc delete pod ac04-web -n ac04-pods`.
