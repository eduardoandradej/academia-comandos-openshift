# POD-008 — Copiar arquivos: oc cp nos dois sentidos

- **ID:** POD-008

## Objetivo e indicador de sucesso

Copiar arquivos e diretórios entre a `ocp-admin` e um contêiner, nos dois sentidos, inclusive em contêiner específico.

**Indicador de sucesso:** um diretório vai para o contêiner e volta idêntico (mesmo `sha256sum`).

## Conceito

Sintaxe: `oc cp <origem> <destino> [-c contêiner] [-n ns]`, onde o lado remoto é `<pod>:<caminho>`
(ou `<ns>/<pod>:<caminho>`). Por baixo, o `oc cp` usa **`tar` dentro do contêiner** — sem `tar` na imagem, ele falha.

Use para coletar evidências (um arquivo de configuração, um dump pequeno) ou levar um script de diagnóstico. Não use
como forma de implantar: o arquivo some quando o contêiner é recriado. Arquivos grandes também consomem espaço do nó.

## Comandos guiados

```bash
mkdir -p /tmp/ac04-cp && echo "ola do ocp-admin" > /tmp/ac04-cp/nota.txt
oc cp /tmp/ac04-cp/nota.txt ac04-web:/tmp/nota.txt -n ac04-pods            # local → pod
oc exec ac04-web -n ac04-pods -- cat /tmp/nota.txt
oc cp ac04-web:/etc/httpd/conf/httpd.conf /tmp/ac04-cp/httpd.conf -n ac04-pods   # pod → local
grep -E '^Listen' /tmp/ac04-cp/httpd.conf
oc cp /tmp/ac04-cp ac04-duplo:/tmp/copia -c relogio -n ac04-pods            # diretório, contêiner específico
oc exec ac04-duplo -n ac04-pods -c relogio -- ls -l /tmp/copia
```

## Repetições

1. Copie de volta o diretório `/tmp/copia` para `/tmp/ac04-volta` e compare com `diff -r`.
2. `sha256sum` do arquivo nos dois lados.
3. Use a forma `ac04-pods/ac04-web:/tmp/nota.txt` (namespace no caminho).
4. Tente copiar para `/etc` do contêiner e leia o erro.
5. `oc cp --help | sed -n '/Examples:/,/Options:/p'`.

## Desafio sem pista

Colete para a `ocp-admin` o arquivo de configuração principal do httpd **e** a saída de `env` do contêiner `web` do
`ac04-duplo`, em um diretório `/tmp/ac04-evidencias`, sem abrir shell interativo.

## Diagnóstico controlado

- **Sintoma:** `tar: /etc/teste: Cannot open: Permission denied` (ou erro equivalente) ao copiar para `/etc`.
- **Hipóteses:** o processo roda com UID sem permissão de escrita naquele diretório.
- **Investigação:** `oc exec ac04-web -n ac04-pods -- sh -c 'id; ls -ld /etc /tmp'`.
- **Reversão:** nada foi gravado. Use um diretório gravável (`/tmp`).

## Validação

```bash
oc exec ac04-web -n ac04-pods -- sha256sum /tmp/nota.txt | cut -d' ' -f1 | grep -q "$(sha256sum /tmp/ac04-cp/nota.txt | cut -d' ' -f1)" && echo "cópia íntegra"
```

## Limpeza segura

```bash
rm -rf /tmp/ac04-cp /tmp/ac04-volta /tmp/ac04-evidencias
oc exec ac04-web -n ac04-pods -- rm -f /tmp/nota.txt
oc exec ac04-duplo -n ac04-pods -c relogio -- rm -rf /tmp/copia
```
