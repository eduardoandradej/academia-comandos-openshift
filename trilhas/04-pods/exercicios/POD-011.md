## Objetivo e indicador de sucesso

Controlar o que o contêiner executa (`command`/`args`) e com quais variáveis (`env`), e conferir o resultado por dentro.

**Indicador de sucesso:** três pods com combinações diferentes de `command`, `args` e `env`, e você prevê a saída de cada um antes de olhar o log.

## Conceito

| Imagem | Pod | Resultado |
|---|---|---|
| `ENTRYPOINT` + `CMD` | nada | roda `ENTRYPOINT CMD` |
| | só `args` | roda `ENTRYPOINT args` |
| | `command` | roda `command` (ignora `ENTRYPOINT` e `CMD`) |
| | `command` + `args` | roda `command args` |

Variáveis: `env` (pares) e `envFrom` (de ConfigMap/Secret, Trilha 08). Referências `$(VAR)` em `command`/`args` são
expandidas pelo Kubernetes; `$VAR` só é expandido se houver um shell.

## Comandos guiados

```bash
L=academy.openshift.dev/managed-by=academia; IMG=registry.access.redhat.com/ubi9/httpd-24:latest
oc run ac04-cmd --image=$IMG --labels=$L --restart=Never -n ac04-pods --env=SAUDACAO=ola \
  --command -- /bin/sh -c 'echo "$SAUDACAO de $(hostname)"'
oc run ac04-k8s --image=$IMG --labels=$L --restart=Never -n ac04-pods --env=NOME=academia \
  --command -- echo 'expandido pelo kubernetes: $(NOME)'
oc run ac04-sem --image=$IMG --labels=$L --restart=Never -n ac04-pods --env=NOME=academia \
  --command -- echo 'sem shell: $NOME'
sleep 15
for p in ac04-cmd ac04-k8s ac04-sem; do printf '%s: ' "$p"; oc logs "$p" -n ac04-pods; done
oc get pod ac04-k8s -n ac04-pods -o jsonpath='{.spec.containers[0].command}{"\n"}{.spec.containers[0].env}{"\n"}'
oc exec ac04-web -n ac04-pods -- sh -c 'echo $HOME $HTTPD_MAIN_CONF_PATH'    # variáveis vindas da imagem
```

## Repetições

1. Preveja e execute: `--command -- printenv SAUDACAO` com `--env=SAUDACAO=oi`.
2. Preveja: sem `--command`, `-- -v` (vai para `args` do httpd?) — gere com `--dry-run=client -o yaml` e confira.
3. Duas variáveis com `--env` repetido.
4. `oc set env pod/ac04-web --list -n ac04-pods`.
5. Leia `ENTRYPOINT`/`CMD` da imagem: `oc image info registry.access.redhat.com/ubi9/httpd-24:latest -o json | jq '.config.config | {Entrypoint, Cmd}'` (se o acesso ao registry permitir).

## Desafio sem pista

Crie um Pod que imprima `pod=<nome do pod> ns=<namespace>` usando o Downward API em variáveis de ambiente (`fieldRef`),
sem shell e sem digitar o nome do namespace no comando.

## Diagnóstico controlado

- **Sintoma:** o log mostra literalmente `$NOME` em vez do valor.
- **Hipóteses:** `$VAR` sem shell não é expandido; só `$(VAR)` é expandido pelo Kubernetes.
- **Investigação:** compare os logs de `ac04-k8s` e `ac04-sem`.
- **Reversão:** apague os pods de teste.
