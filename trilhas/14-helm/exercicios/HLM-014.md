## Conceito

| Mensagem (trecho) | Causa | Correção |
|---|---|---|
| `parse error` / `YAML parse error` | modelo ou indentação | `helm lint`, `helm template --debug` |
| `values don't meet the specifications of the schema` | valor inválido | ajustar o valor |
| `cannot re-use a name that is still in use` | release existe | `upgrade` |
| `invalid ownership metadata` | objeto fora do Helm | renomear/adotar (TS-044) |
| `another operation (install/upgrade/rollback) is in progress` | release em `pending-*` | rollback para a última `deployed` (TS-043) |
| `context deadline exceeded` | pods não ficaram prontos | eventos, `helm rollback` |
| valor novo do chart ignorado | `--reuse-values` | passar valores explicitamente (TS-045) |

## Diagnóstico controlado

- **Sintoma:** `Error: UPGRADE FAILED: another operation (install/upgrade/rollback) is in progress`.
- **Hipóteses:** um `helm upgrade` anterior foi interrompido e a revisão ficou `pending-upgrade`.
- **Investigação:** `helm history loja -n ac14-helm` (última linha).
- **Reversão:** `helm rollback loja <última deployed> -n ac14-helm`. Veja TS-043.

## Validação
