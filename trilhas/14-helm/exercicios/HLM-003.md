# HLM-003 — helm template: renderizar como o Kustomize

## Objetivo e indicador de sucesso

Renderizar o chart com valores diferentes (`--set`, `-f`), filtrar um modelo (`--show-only`) e validar o resultado no servidor sem instalar.

**Indicador de sucesso:** a renderização com `values-prod.yaml` mostra 2 réplicas e `AMBIENTE=prod`, e passa no `--dry-run=server`.

```bash
test -d /tmp/ac14/ac14-loja || { mkdir -p /tmp/ac14; cp -r manifests/helm/ac14-loja /tmp/ac14/; }
```

## Conceito

> **Cópia de trabalho.** Edite `/tmp/ac14/ac14-loja`, nunca `manifests/helm/ac14-loja` do repositório.
> Para recomeçar: `rm -rf /tmp/ac14/ac14-loja && cp -r manifests/helm/ac14-loja /tmp/ac14/`.

`helm template` produz YAML puro, como `oc kustomize`: nada é instalado e não há release. É o melhor jeito de revisar
um chart — inclusive de terceiros — antes de usá-lo. `--show-only templates/x.yaml` mostra só um arquivo.

## Comandos guiados

```bash
oc new-project ac14-helm --display-name='Academia 14 - Helm' 2>/dev/null || oc project ac14-helm
helm template loja /tmp/ac14/ac14-loja -n ac14-helm | head -40
helm template loja /tmp/ac14/ac14-loja -n ac14-helm -f /tmp/ac14/ac14-loja/values-prod.yaml --show-only templates/deployment.yaml | grep -E 'replicas|AMBIENTE|value:'
helm template loja /tmp/ac14/ac14-loja -n ac14-helm --set replicaCount=2 --set route.enabled=false | grep -c '^kind: Route'
helm template loja /tmp/ac14/ac14-loja -n ac14-helm -f /tmp/ac14/ac14-loja/values-prod.yaml | oc apply --dry-run=server -n ac14-helm -f -
```

## Repetições

1. Compare `helm template` com e sem `-f values-prod.yaml` usando `diff`.
2. `--set pagina.conteudo='outra pagina'` e veja o `checksum/pagina` mudar.
3. `--set image.digest=sha256:...` (digest real do IMG-001) e veja a imagem renderizada.
4. `--set replicaCount=5`: o que acontece? (schema)
5. Renderize com outro nome de release (`helm template vitrine ...`).

## Desafio sem pista

Mostre, com um comando, a diferença entre a renderização padrão e a de produção apenas para o Deployment, campo a campo.

## Diagnóstico controlado

- **Sintoma:** `Error: values don't meet the specifications of the schema(s) ... replicaCount: Must be less than or equal to 2`.
- **Hipóteses:** valor fora do `values.schema.json` (limite da Academia).
- **Investigação:** `cat values.schema.json | jq .properties.replicaCount`.
- **Reversão:** nada foi renderizado; use 1 ou 2.

## Validação

```bash
helm template loja /tmp/ac14/ac14-loja -f /tmp/ac14/ac14-loja/values-prod.yaml --show-only templates/deployment.yaml | grep -q 'replicas: 2' && echo OK
```
