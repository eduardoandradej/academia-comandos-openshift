## Conceito

> Para recomeçar: `rm -rf /tmp/ac14/ac14-loja && cp -r manifests/helm/ac14-loja /tmp/ac14/`.

| Construção | Uso |
|---|---|
| `{{- if .Values.x }} ... {{- end }}` | bloco opcional |
| `{{- with .Values.x }} {{ . }} {{- end }}` | bloco opcional que muda o contexto para `x` |
| `{{- range $k, $v := .Values.mapa }}` | repetir por item |
| `{{ .Values.x \| default "padrão" }}` | valor padrão |
| `{{ required "mensagem" .Values.x }}` | falha se faltar |
| `{{ toYaml .Values.obj \| nindent 8 }}` | inserir um bloco YAML indentado |
| `{{ .Values.x \| quote }}` | aspas seguras |

`{{-` e `-}}` removem espaços/linhas em branco ao redor.

## Comandos guiados

```bash
python3 - <<'EOF'
p = '/tmp/ac14/ac14-loja/templates/deployment.yaml'; s = open(p).read()
s = s.replace('''      annotations:
        checksum/pagina:''', '''      annotations:
        {{- with .Values.podAnnotations }}
        {{- toYaml . | nindent 8 }}
        {{- end }}
        checksum/pagina:''', 1)
s = s.replace('''  labels:
    {{- include "ac14-loja.labels" . | nindent 4 }}
spec:''', '''  labels:
    {{- include "ac14-loja.labels" . | nindent 4 }}
    equipe: {{ required "defina o valor 'equipe' (ex.: --set equipe=plataforma)" .Values.equipe | quote }}
  annotations:
    academy.openshift.dev/ambiente: {{ .Values.ambiente | default "lab" | quote }}
spec:''', 1)
open(p, 'w').write(s)
EOF
helm template loja /tmp/ac14/ac14-loja --show-only templates/deployment.yaml 2>&1 | tail -2           # falha: required
helm template loja /tmp/ac14/ac14-loja --set equipe=plataforma --show-only templates/deployment.yaml | sed -n '1,15p'
helm template loja /tmp/ac14/ac14-loja --set equipe=plataforma --set podAnnotations.revisado=sim --show-only templates/deployment.yaml | grep -A3 'annotations:'
```

## Repetições

1. Torne o rótulo `equipe` opcional com `default "sem-equipe"` em vez de `required`.
2. Acrescente `podAnnotations: {}` ao `values.yaml` e documente-o com um comentário.
3. Use `range` para gerar uma porta extra por item de uma lista `portasExtras`.
4. O que acontece com `toYaml` sem `nindent`?
5. Rode `helm lint` depois de cada mudança.

## Desafio sem pista

Acrescente um ConfigMap **opcional** `templates/extra.yaml` que só é criado se `extra.habilitado=true`, com as chaves
vindas do mapa `extra.dados`, e prove os dois casos.

## Diagnóstico controlado

- **Sintoma:** `Error: YAML parse error on ac14-loja/templates/deployment.yaml: error converting YAML to JSON: yaml: line 14: did not find expected key`.
- **Hipóteses:** indentação errada do bloco inserido (`nindent` com número errado, ou falta de `-` no `{{-`).
- **Investigação:** `helm template ... --debug` mostra o YAML gerado até o erro.
- **Reversão:** ajuste a indentação; nada foi instalado.

## Validação
