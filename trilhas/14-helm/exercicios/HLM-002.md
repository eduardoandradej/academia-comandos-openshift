## Objetivo e indicador de sucesso

Ler um chart local (`Chart.yaml`, `values.yaml`, `templates/`, `_helpers.tpl`, schema, testes) e validá-lo com `helm lint`.

**Indicador de sucesso:** `helm lint` sem erros e você explica de onde vem cada rótulo dos objetos gerados.

## Conceito

> **Cópia de trabalho.** Edite `/tmp/ac14/ac14-loja`, nunca `manifests/helm/ac14-loja` do repositório.
> Para recomeçar: `rm -rf /tmp/ac14/ac14-loja && cp -r manifests/helm/ac14-loja /tmp/ac14/`.

| Arquivo | Papel |
|---|---|
| `Chart.yaml` | metadados; `version` (do chart) × `appVersion` (da aplicação) |
| `values.yaml` | valores padrão, sobrescritos na instalação |
| `values.schema.json` | validação dos valores (tipos, limites) |
| `templates/*.yaml` | modelos Go: `{{ .Values.x }}`, `{{ include "..." . }}` |
| `templates/_helpers.tpl` | definições reutilizáveis (nome, rótulos, imagem) |
| `templates/NOTES.txt` | mensagem exibida após instalar |
| `templates/tests/` | pods executados por `helm test` |

## Comandos guiados

```bash
find /tmp/ac14/ac14-loja -type f | sort
helm show chart /tmp/ac14/ac14-loja
helm show values /tmp/ac14/ac14-loja
cat /tmp/ac14/ac14-loja/templates/_helpers.tpl
helm lint /tmp/ac14/ac14-loja
helm lint /tmp/ac14/ac14-loja -f /tmp/ac14/ac14-loja/values-prod.yaml
```

## Repetições

1. Qual a diferença entre `version` e `appVersion`? Quando cada uma muda?
2. Que rótulos o helper `ac14-loja.labels` acrescenta? E o `selectorLabels`?
3. Por que os seletores usam só `name` e `instance`?
4. O que o `checksum/pagina` no Deployment faz? (dica: KUS-002, CFG-004)
5. `helm show readme /tmp/ac14/ac14-loja`.

## Desafio sem pista

Sem renderizar, preveja os nomes de todos os objetos que `helm install loja` criaria, e depois confira com `helm template`.

## Diagnóstico controlado

- **Sintoma:** `[ERROR] templates/: parse error at (ac14-loja/templates/deployment.yaml:12): function "inclde" not defined`.
- **Hipóteses:** erro de digitação em função do modelo.
- **Investigação:** a linha citada pelo `helm lint`.
- **Reversão:** corrija o modelo na cópia; nada foi instalado.

## Validação
