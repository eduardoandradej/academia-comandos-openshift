## Objetivo e indicador de sucesso

Adicionar um repositório público, procurar e baixar um chart, e auditá-lo (valores, modelos, imagens, RBAC) **sem instalar**.

**Indicador de sucesso:** um relatório de uma linha por tipo de objeto que o chart criaria, incluindo se ele pede permissões de cluster.

## Conceito

| Comando | Efeito |
|---|---|
| `helm repo add NOME URL` / `helm repo update` | registra e atualiza o índice (local) |
| `helm search repo TERMO` | procura nos índices locais |
| `helm show values/chart/readme REPO/CHART` | lê sem baixar o pacote inteiro |
| `helm pull REPO/CHART --untar -d DIR` | baixa para inspeção |
| `helm template ... \| grep kind` | o que seria criado |

Regra da Academia: chart de terceiros só é instalado depois de auditado e se não exigir `ClusterRole`, CRDs, SCC
especial ou recursos acima da quota.

## Comandos guiados

```bash
helm repo add openshift-helm-charts https://charts.openshift.io/ 2>/dev/null; helm repo update
helm repo list
helm search repo openshift-helm-charts | head -15
CH=$(helm search repo openshift-helm-charts -o json | jq -r '.[0].name'); echo "$CH"
helm show chart "$CH"
helm show values "$CH" | head -40
mkdir -p /tmp/ac14/terceiros && helm pull "$CH" --untar -d /tmp/ac14/terceiros
helm template auditoria /tmp/ac14/terceiros/* -n ac14-helm | grep -E '^kind:' | sort | uniq -c
helm template auditoria /tmp/ac14/terceiros/* -n ac14-helm | grep -E '^\s+image:' | sort -u
```

## Repetições

1. O chart cria `ClusterRole`, `ClusterRoleBinding` ou `CustomResourceDefinition`?
2. Que imagens ele usa? São de registries confiáveis? Têm digest?
3. Pede `privileged`, `hostPath` ou `runAsUser: 0`?
4. Quanto de CPU/memória pede no padrão? Cabe na quota?
5. Remova o repositório (`helm repo remove`).

## Desafio sem pista

Escreva `audita_chart <dir>` que imprime: tipos de objeto, objetos de escopo de cluster, imagens sem digest e soma dos
`requests.cpu` — e conclui "instalável na Academia: sim/não".

## Diagnóstico controlado

- **Sintoma:** `Error: looks like "https://charts.openshift.io/" is not a valid chart repository or cannot be reached`.
- **Hipóteses:** sem saída para a internet a partir da `ocp-admin`; DNS; proxy.
- **Investigação:** `curl -sSI https://charts.openshift.io/index.yaml | head -1`.
- **Reversão:** sem rede, use só o chart local da Academia.

## Validação

```bash
helm repo list 2>/dev/null | grep -c openshift-helm-charts
```

## Limpeza segura

```bash
rm -rf /tmp/ac14/terceiros
helm repo remove openshift-helm-charts 2>/dev/null || true
```
