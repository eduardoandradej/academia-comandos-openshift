# DCL-001 — Gerar manifestos sem escrever YAML do zero

## Objetivo e indicador de sucesso

Gerar manifestos de Deployment, Service, ConfigMap e Route com `--dry-run=client -o yaml`, juntá-los em um arquivo
multidocumento e remover o que não deve ir para um manifesto.

**Indicador de sucesso:** `/tmp/ac12/gerado.yaml` com 4 documentos, sem `status` nem `creationTimestamp`, aceito por `oc apply --dry-run=client`.

## Conceito

`--dry-run=client -o yaml` faz o comando imperativo **imprimir** o objeto em vez de criá-lo. É o jeito mais rápido
de obter um esqueleto correto. Depois:

- remova `status: {}` e `creationTimestamp: null` (ruído);
- acrescente rótulos, recursos, probes e securityContext;
- junte objetos com `---` em um arquivo (ordem: dependências primeiro).

`oc create route` e `oc expose` exigem o Service no servidor; para gerar a Route offline, escreva-a (DCL-013) ou use
`oc create route edge ... --service=X --dry-run=client -o yaml`.

## Comandos guiados

```bash
oc new-project ac12-declarativo --display-name='Academia 12 - Declarativo'
mkdir -p /tmp/ac12 && cd /tmp/ac12
oc create configmap ac12-pagina --from-literal=index.html='versao 1' --dry-run=client -o yaml > cm.yaml
oc create deployment ac12-web --image=registry.access.redhat.com/ubi9/httpd-24:latest --port=8080 --dry-run=client -o yaml > deploy.yaml
oc create service clusterip ac12-web --tcp=8080:8080 --dry-run=client -o yaml > svc.yaml
oc create route edge ac12-web --service=ac12-web --dry-run=client -o yaml > route.yaml
for f in cm deploy svc route; do grep -v -E '^\s*(creationTimestamp: null|status: \{\})$' "$f.yaml"; echo '---'; done | sed '$d' > gerado.yaml
grep -c '^kind:' gerado.yaml
oc apply --dry-run=client -f gerado.yaml -n ac12-declarativo
cd - >/dev/null
```

## Repetições

1. Gere um Job e um CronJob da mesma forma (Trilha 05).
2. Gere um Secret genérico com valor fictício e repare em `data` (base64).
3. O que o `oc create service clusterip` pôs no seletor? Combina com os rótulos do Deployment?
4. Compare o `deploy.yaml` com `manifests/apps-exemplo/declarativo-app.yaml`: o que falta no gerado?
5. Gere tudo de novo, de memória, em menos de 3 minutos.

## Desafio sem pista

Produza, só com comandos (sem editor), um `deploy.yaml` já com o rótulo da Academia, `requests/limits` e readiness TCP,
pronto para aplicar.

## Diagnóstico controlado

- **Sintoma:** `error: failed to create route: services "ac12-web" not found` ao usar `oc expose` com `--dry-run=client`.
- **Hipóteses:** `oc expose` consulta o Service no servidor, mesmo em dry-run.
- **Investigação:** `oc get svc ac12-web -n ac12-declarativo`.
- **Reversão:** gere a Route com `oc create route ... --service=` ou escreva o YAML.
