## Conceito

| `--type` | Formato | Listas |
|---|---|---|
| `strategic` (padrão) | YAML/JSON parcial | mescla por **chave** (`containers` por `name`, `env` por `name`) |
| `merge` (JSON Merge Patch) | JSON parcial | **substitui** a lista inteira |
| `json` (JSON Patch) | lista de operações `add/remove/replace/test` | por **índice** |

Recursos personalizados (CRDs) não aceitam `strategic`: use `merge` ou `json`.
Prévia segura: `--dry-run=server -o yaml` mostra o resultado sem gravar.

## Comandos guiados

```bash
oc patch deployment ac12-web -n ac12-declarativo --type=strategic \
  -p '{"spec":{"template":{"spec":{"containers":[{"name":"web","env":[{"name":"NIVEL","value":"1"}]}]}}}}'
oc get deployment ac12-web -n ac12-declarativo -o jsonpath='{.spec.template.spec.containers[0].env}{"\n"}'   # MODO e NIVEL
oc patch deployment ac12-web -n ac12-declarativo --type=merge --dry-run=server -o json \
  -p '{"spec":{"template":{"spec":{"containers":[{"name":"web","env":[{"name":"NIVEL","value":"2"}]}]}}}}' \
  | jq '.spec.template.spec.containers[0] | {image, env, ports}'          # a lista foi substituída: sem image!
oc patch deployment ac12-web -n ac12-declarativo --type=json \
  -p '[{"op":"replace","path":"/spec/template/spec/containers/0/env/1/value","value":"3"}]'
oc get deployment ac12-web -n ac12-declarativo -o jsonpath='{.spec.template.spec.containers[0].env}{"\n"}'
```

## Repetições

1. Por que o patch `merge` em dry-run falharia ao gravar (ou criaria um contêiner sem imagem)?
2. Use `--type=merge` para algo **sem lista** (`spec.replicas`, anotações).
3. Remova `NIVEL` com JSON Patch (`op: remove` no índice certo).
4. Use `test` para só alterar se o valor atual for `3`.
5. Remova uma chave de mapa com merge patch (`{"metadata":{"labels":{"x":null}}}`).

## Desafio sem pista

Escreva um JSON Patch que **só** troca `MODO` para `homologacao` se o valor atual for `treino`, encontrando o índice
de `MODO` dinamicamente (sem supor que é 0).

## Diagnóstico controlado

- **Sintoma:** `The Deployment "ac12-web" is invalid: spec.template.spec.containers[0].image: Required value`.
- **Hipóteses:** merge patch substituiu a lista de contêineres por uma parcial.
- **Investigação:** prévia com `--dry-run=server -o yaml`.
- **Reversão:** nada foi gravado (a validação recusou); use `strategic` ou `json` para listas.

## Validação

```bash
oc get deployment ac12-web -n ac12-declarativo -o jsonpath='{.spec.template.spec.containers[0].env[?(@.name=="NIVEL")].value}{"\n"}'   # 3
```
