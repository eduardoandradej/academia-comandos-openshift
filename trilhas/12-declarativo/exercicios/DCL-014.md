## Conceito

| Mensagem | Causa | Correção |
|---|---|---|
| `unknown field` / `strict decoding error` | erro de digitação ou campo de outra versão | `oc explain` |
| `AlreadyExists` | `create` de algo que existe | `apply` |
| `the object has been modified` | `resourceVersion` antigo no arquivo | tirar `resourceVersion` |
| `field is immutable` | mudou seletor, `clusterIP`, `volumeName`... | criar ao lado / recriar conscientemente |
| `Apply failed with N conflict(s)` | SSA: campo de outro gerenciador | combinar ou `--force-conflicts` |

## Comandos guiados

```bash
f=/tmp/ac12/app.yaml; ns=ac12-declarativo
sed 's/containerPort:/containerPortt:/' $f | oc apply --dry-run=server -f - -n $ns 2>&1 | grep -m1 -i unknown
oc create -f $f -n $ns 2>&1 | grep -m1 AlreadyExists
oc get configmap ac12-pagina -n $ns -o yaml > /tmp/ac12/rv.yaml; oc label configmap ac12-pagina tmp=1 -n $ns
oc replace -f /tmp/ac12/rv.yaml -n $ns 2>&1 | grep -m1 modified; oc label configmap ac12-pagina tmp- -n $ns
python3 -c "import sys;s=open('$f').read();print(s.replace('      app: ac12-web\n  template','      app: ac12-web\n      ver: \"2\"\n  template',1).replace('        app: ac12-web\n        academy','        app: ac12-web\n        ver: \"2\"\n        academy',1))" \
  | oc apply -f - -n $ns 2>&1 | grep -m1 -i immutable
oc apply --server-side --field-manager=outro -f $f -n $ns 2>&1 | grep -m1 -i conflict || echo "(sem conflito: veja a repetição 4)"
```

## Repetições

1. Para cada mensagem, escreva a correção mínima e aplique.
2. Por que o `immutable` só aparece no servidor?
3. Mude o `clusterIP` do Service no arquivo e leia a recusa.
4. Faça o conflito de SSA aparecer: aplique primeiro com `--server-side --field-manager=dono` e depois com `outro`, mudando um valor.
5. Escreva a tabela de memória.

## Diagnóstico controlado

- **Sintoma:** `spec.selector: Invalid value: ... field is immutable`.
- **Hipóteses:** o seletor de um Deployment não muda depois de criado.
- **Investigação:** compare `spec.selector` do arquivo e do vivo.
- **Reversão:** volte o seletor no arquivo, ou crie um Deployment novo ao lado (DCL-007). Veja TS-037.
