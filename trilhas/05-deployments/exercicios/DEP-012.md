## Conceito

Um **DaemonSet** roda um pod em cada nó que atende ao seu seletor/tolerâncias — típico de agentes (DNS, rede, coleta de
logs). Não há `replicas`: o número de pods é o número de nós elegíveis. No SNO, portanto, um.

O OpenShift usa DaemonSets em `openshift-dns`, `openshift-multus`, `openshift-machine-config-operator` e outros —
**somente leitura** nesta Academia.

## Comandos guiados

```bash
oc apply -f manifests/apps-exemplo/daemonset-mini.yaml -n ac05-deploy
oc rollout status daemonset/ac05-ds -n ac05-deploy
oc get daemonset ac05-ds -n ac05-deploy
oc get pods -n ac05-deploy -l app=ac05-ds -o wide
oc logs -l app=ac05-ds -n ac05-deploy --tail=1
oc scale daemonset/ac05-ds --replicas=2 -n ac05-deploy; echo "rc=$?"   # recusado: DaemonSet não escala
ac-admin
oc get daemonsets -A | head -15                                         # leitura
oc get daemonset dns-default -n openshift-dns -o jsonpath='{.status.desiredNumberScheduled} {.status.numberReady}{"\n"}'
ac-dev
```

## Repetições

1. `oc describe daemonset ac05-ds -n ac05-deploy` — `Desired`, `Current`, `Ready`.
2. Coloque um `nodeSelector` inexistente com `oc patch` e veja `DESIRED` ir para 0; remova-o.
3. `oc rollout history daemonset/ac05-ds -n ac05-deploy` — DaemonSets também têm revisões.
4. (admin) Liste as tolerâncias de um DaemonSet da plataforma (leitura).
5. Compare um DaemonSet com um Deployment de 1 réplica: o que muda quando o nó é substituído?

## Desafio sem pista

Faça o DaemonSet parar de rodar pods **sem apagá-lo** e depois volte ao normal, provando os dois estados.

## Diagnóstico controlado

- **Sintoma:** `error: no scaler has been implemented for {apps DaemonSet}` (texto aproximado).
- **Hipóteses:** DaemonSets não têm réplicas.
- **Investigação:** `oc explain daemonset.spec | grep -i replica || echo "sem campo replicas"`.
- **Reversão:** nada foi alterado.

## Validação

```bash
oc get daemonset ac05-ds -n ac05-deploy -o jsonpath='{.status.numberReady}{"\n"}'   # 1
```
