## Objetivo e indicador de sucesso

Escalar `ac05-web` entre 0 e 2 réplicas (teto do HomeLab), usar a pré-condição `--current-replicas` e observar a autocura.

**Indicador de sucesso:** você escala para 0 e volta para 2, e explica o que acontece com o ReplicaSet e com os pods.

## Conceito

`oc scale` altera `spec.replicas`. Escalar não cria revisão nova (não muda o template). Escalar para **0** mantém o
Deployment e o ReplicaSet, só sem pods — útil para "desligar" sem apagar.

`--current-replicas=N` só aplica a mudança se o valor atual for N (proteção contra corrida entre pessoas/scripts).

Teto da Academia: **2 réplicas** (o SNO compartilha recursos com o control plane).

## Comandos guiados

```bash
oc scale deployment/ac05-web --replicas=1 -n ac05-deploy
oc get deployment ac05-web -n ac05-deploy
oc scale deployment/ac05-web --replicas=0 -n ac05-deploy
oc get rs,pods -n ac05-deploy -l app=ac05-web           # RS com DESIRED 0
oc scale deployment/ac05-web --replicas=2 --current-replicas=0 -n ac05-deploy
oc scale deployment/ac05-web --replicas=1 --current-replicas=5 -n ac05-deploy; echo "rc=$?"   # recusado
oc rollout status deployment/ac05-web -n ac05-deploy
oc rollout history deployment/ac05-web -n ac05-deploy   # escalar não cria revisão
```

## Repetições

1. Escale 0 → 2 → 1 → 2 cronometrando cada `rollout status`.
2. Em um terminal, `oc get pods -n ac05-deploy -l app=ac05-web -w`; em outro, escale.
3. `oc patch deployment ac05-web -n ac05-deploy --type=merge -p '{"spec":{"replicas":1}}'` — mesmo efeito do `scale`.
4. Com baseline aplicada, tente `--replicas=8` e leia os eventos do ReplicaSet (`exceeded quota`). Volte para 2.
5. `oc get deployment ac05-web -n ac05-deploy -o jsonpath='{.spec.replicas} {.status.replicas} {.status.readyReplicas}{"\n"}'`.

## Desafio sem pista

Escreva um comando que escala `ac05-web` para 1 **somente** se ele estiver com 2 réplicas, e que imprima `já estava em 1`
quando a pré-condição falhar porque o valor já é 1.

## Diagnóstico controlado

- **Sintoma:** `error: Expected replicas to be 5, was 2`.
- **Hipóteses:** a pré-condição `--current-replicas` não confere.
- **Investigação:** `oc get deployment ac05-web -n ac05-deploy -o jsonpath='{.spec.replicas}{"\n"}'`.
- **Reversão:** nada foi alterado.

## Validação

```bash
oc get deployment ac05-web -n ac05-deploy -o jsonpath='{.spec.replicas}{"\n"}'   # 2
```

## Limpeza segura

Deixe `ac05-web` com 2 réplicas: `oc scale deployment/ac05-web --replicas=2 -n ac05-deploy`.
