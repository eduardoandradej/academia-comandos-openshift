## Conceito

`oc rollout undo deployment/x` volta ao template da revisão **anterior**; `--to-revision=N` escolhe a revisão. O undo
**não** apaga histórico: o template antigo é reaplicado e vira a revisão mais recente (o número antigo desaparece da lista,
porque aquele ReplicaSet passa a ser o atual).

`oc rollout history ... --revision=N` mostra o template completo da revisão N — confira antes de voltar.
`revisionHistoryLimit` (padrão 10) define quantos ReplicaSets antigos são guardados.

## Comandos guiados

```bash
oc rollout history deployment/ac05-web -n ac05-deploy
oc rollout history deployment/ac05-web -n ac05-deploy --revision=2        # template da revisão 2
oc rollout undo deployment/ac05-web -n ac05-deploy --dry-run=server -o yaml | grep -A2 'name: VERSAO'
oc rollout undo deployment/ac05-web -n ac05-deploy --to-revision=2
oc rollout status deployment/ac05-web -n ac05-deploy
oc rollout history deployment/ac05-web -n ac05-deploy                      # a "2" virou a mais recente
oc exec deploy/ac05-web -n ac05-deploy -- printenv VERSAO                  # v2
oc rollout undo deployment/ac05-web -n ac05-deploy                         # volta à anterior (a que estava antes do undo)
oc exec deploy/ac05-web -n ac05-deploy -- printenv VERSAO
```

## Repetições

1. Desenhe a lista de revisões antes e depois de cada undo.
2. Dois `oc rollout undo` seguidos: você "alterna" entre duas versões?
3. `oc get deployment ac05-web -n ac05-deploy -o jsonpath='{.spec.revisionHistoryLimit}{"\n"}'`.
4. `oc patch deployment ac05-web -n ac05-deploy --type=merge -p '{"spec":{"revisionHistoryLimit":2}}'` e veja ReplicaSets antigos sumirem; volte para 10.
5. Undo para uma revisão inexistente (`--to-revision=99`) e leia o erro.

## Desafio sem pista

Volte para a revisão cujo `CHANGE-CAUSE` contém `v3` **sem olhar o número dela** (encontre-o por comando) e prove que a
variável `VERSAO` ficou `v3`.

## Diagnóstico controlado

- **Sintoma:** `error: unable to find specified revision 1 in history`.
- **Hipóteses:** (a) a revisão já foi reaproveitada por um undo; (b) excedeu o `revisionHistoryLimit`.
- **Investigação:** `oc rollout history deployment/ac05-web -n ac05-deploy`; `oc get rs -n ac05-deploy -l app=ac05-web`.
- **Reversão:** nada foi alterado; escolha uma revisão listada.

## Validação

```bash
oc rollout status deployment/ac05-web -n ac05-deploy --timeout=60s
```

## Limpeza segura

Volte `revisionHistoryLimit` para 10 se o alterou. O Deployment segue para o DEP-005.
