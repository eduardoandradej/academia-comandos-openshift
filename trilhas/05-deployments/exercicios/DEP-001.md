**Indicador de sucesso:** você explica por que apagar um pod do Deployment não diminui o número de pods.

## Conceito

Um **Deployment** descreve o estado desejado de uma aplicação sem estado: imagem, réplicas, estratégia de atualização.
Ele não cria pods diretamente: cria um **ReplicaSet** por versão do template, e o ReplicaSet mantém o número de pods.

```text
Deployment ac05-web ──cria──▶ ReplicaSet ac05-web-<hash> ──mantém──▶ Pods ac05-web-<hash>-<sufixo>
```

`oc create deployment` gera o rótulo `app=<nome>` e usa-o no seletor. O nome do contêiner é derivado da imagem
(`httpd-24`).

## Comandos guiados

```bash
oc new-project ac05-deploy --display-name='Academia 05 - Deployments'
oc create deployment ac05-web --image=registry.access.redhat.com/ubi9/httpd-24:latest \
  --replicas=2 --port=8080 -n ac05-deploy --dry-run=client -o yaml     # ver antes
oc create deployment ac05-web --image=registry.access.redhat.com/ubi9/httpd-24:latest \
  --replicas=2 --port=8080 -n ac05-deploy
oc label deployment ac05-web academy.openshift.dev/managed-by=academia -n ac05-deploy
oc rollout status deployment/ac05-web -n ac05-deploy
oc get deploy,rs,pods -n ac05-deploy -l app=ac05-web
oc get deployment ac05-web -n ac05-deploy -o jsonpath='{.spec.selector}{"\n"}{.spec.template.spec.containers[0].name}{"\n"}'
POD=$(oc get pods -n ac05-deploy -l app=ac05-web -o name | head -1)
oc delete "$POD" -n ac05-deploy
oc get pods -n ac05-deploy -l app=ac05-web -w        # um novo pod aparece; Ctrl+C
```

## Repetições

1. Apague os dois pods ao mesmo tempo (`oc delete pods -l app=ac05-web`) e cronometre a volta.
2. `oc describe deployment ac05-web -n ac05-deploy` — encontre `Replicas`, `StrategyType`, `NewReplicaSet`.
3. Siga `ownerReferences` de um pod até o Deployment (Trilha 03).
4. `oc get rs -n ac05-deploy -l app=ac05-web -o jsonpath='{.items[0].metadata.labels.pod-template-hash}{"\n"}'`.
5. Apague e recrie o Deployment inteiro de memória (5×).

## Desafio sem pista

Crie um segundo Deployment `ac05-extra` com 1 réplica, já com o rótulo da Academia no **template dos pods** (não só no
Deployment), em um único pipeline idempotente. Prove que os pods têm o rótulo.

## Diagnóstico controlado

- **Sintoma:** `error: failed to create deployment: deployments.apps "ac05-web" already exists`.
- **Hipóteses:** `oc create` não é idempotente.
- **Investigação:** `oc get deployment ac05-web -n ac05-deploy -o jsonpath='{.metadata.creationTimestamp}{"\n"}'`.
- **Reversão:** nada a reverter; use `--dry-run=client -o yaml | oc apply -f -` para repetir sem erro.

## Validação

```bash
oc get deployment ac05-web -n ac05-deploy -o jsonpath='{.status.readyReplicas}/{.spec.replicas}{"\n"}'   # 2/2
```

## Limpeza segura

`ac05-web` é usado até o DEP-008. Apague só o extra: `oc delete deployment ac05-extra -n ac05-deploy --ignore-not-found`.
