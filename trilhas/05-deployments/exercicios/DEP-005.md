# DEP-005 — restart, pause e resume

## Identificação

- **ID:** DEP-005

## Objetivo e indicador de sucesso

Reiniciar pods sem mudar a configuração (`restart`) e agrupar várias mudanças em uma revisão só (`pause`/`resume`).

**Indicador de sucesso:** três mudanças feitas com o rollout pausado resultam em exatamente uma revisão nova.

## Conceito

| Comando | Efeito |
|---|---|
| `oc rollout restart` | recria todos os pods com o **mesmo** template (grava a anotação `kubectl.kubernetes.io/restartedAt` no template → revisão nova) |
| `oc rollout undo` | volta a um template **anterior** |
| `oc rollout pause` | mudanças no template ficam acumuladas, sem rollout |
| `oc rollout resume` | aplica tudo de uma vez, em uma revisão |

Enquanto pausado, `oc rollout status` fica aguardando e `oc rollout undo` é recusado.

## Comandos guiados

```bash
oc get pods -n ac05-deploy -l app=ac05-web -o name > /tmp/ac05-antes.txt
oc rollout restart deployment/ac05-web -n ac05-deploy
oc rollout status deployment/ac05-web -n ac05-deploy
oc get pods -n ac05-deploy -l app=ac05-web -o name | diff /tmp/ac05-antes.txt - || echo "pods novos"
oc get deployment ac05-web -n ac05-deploy -o jsonpath='{.spec.template.metadata.annotations}{"\n"}'

oc rollout pause deployment/ac05-web -n ac05-deploy
oc set env deployment/ac05-web VERSAO=v5 -n ac05-deploy
oc set env deployment/ac05-web COR=verde -n ac05-deploy
oc set resources deployment/ac05-web --requests=cpu=20m,memory=32Mi --limits=cpu=100m,memory=128Mi -n ac05-deploy
oc get rs -n ac05-deploy -l app=ac05-web                  # nenhum RS novo ainda
oc rollout resume deployment/ac05-web -n ac05-deploy
oc rollout status deployment/ac05-web -n ac05-deploy
oc rollout history deployment/ac05-web -n ac05-deploy | tail -2
```

## Repetições

1. Com o rollout pausado, tente `oc rollout undo` e leia a recusa.
2. `oc get deployment ac05-web -n ac05-deploy -o jsonpath='{.spec.paused}{"\n"}'` em cada estado.
3. Faça 3 `restart` seguidos: quantas revisões novas?
4. Compare `restart` com apagar todos os pods (`oc delete pods -l app=ac05-web`): o que muda no histórico?
5. Pause, mude, e faça `oc rollout status ... --timeout=10s`: o que ele diz?

## Desafio sem pista

Prepare a "versão 6" (três variáveis novas e limites de memória de 96 Mi) sem que nenhum pod seja recriado até você
decidir; então libere e prove que só houve uma revisão.

## Diagnóstico controlado

- **Sintoma:** `error: deployments.apps "ac05-web" can't undo paused deployment (run rollout resume first)`.
- **Hipóteses:** o Deployment está pausado.
- **Investigação:** `oc get deployment ac05-web -n ac05-deploy -o jsonpath='{.spec.paused}'`.
- **Reversão:** `oc rollout resume deployment/ac05-web -n ac05-deploy`.

## Validação

```bash
oc get deployment ac05-web -n ac05-deploy -o jsonpath='{.spec.paused}{"\n"}' | grep -qv true && echo "não pausado"
```

## Limpeza segura

```bash
oc rollout resume deployment/ac05-web -n ac05-deploy 2>/dev/null || true
rm -f /tmp/ac05-antes.txt
```
