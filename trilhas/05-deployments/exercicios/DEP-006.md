## Objetivo e indicador de sucesso

Alterar imagem (por digest), recursos e variáveis com `oc set`, sempre conferindo antes com `--dry-run=server` e depois com `rollout status`.

**Indicador de sucesso:** o Deployment roda a mesma imagem fixada por digest, com recursos definidos, e você mostra cada mudança no histórico.

## Conceito

| Comando | Altera |
|---|---|
| `oc set image deployment/x <contêiner>=<imagem>` | imagem de um contêiner (`*=` para todos) |
| `oc set resources deployment/x --requests=... --limits=...` | requests e limits |
| `oc set env deployment/x CHAVE=valor` / `CHAVE-` | adiciona / remove variável |
| `oc set env deployment/x --list` | lista variáveis |

Fixar a imagem pelo **digest** (`imagem@sha256:...`) garante que todas as réplicas e todas as revisões rodem exatamente
o mesmo conteúdo — e, aqui, permite praticar `set image` sem baixar nada novo.

## Comandos guiados

```bash
C=$(oc get deployment ac05-web -n ac05-deploy -o jsonpath='{.spec.template.spec.containers[0].name}')   # httpd-24
D=$(oc get pods -n ac05-deploy -l app=ac05-web -o jsonpath='{.items[0].status.containerStatuses[0].imageID}')
echo "contêiner=$C digest=$D"
oc set image deployment/ac05-web "$C=$D" -n ac05-deploy --dry-run=server -o jsonpath='{.spec.template.spec.containers[0].image}{"\n"}'
oc set image deployment/ac05-web "$C=$D" -n ac05-deploy
oc rollout status deployment/ac05-web -n ac05-deploy
oc set resources deployment/ac05-web -c "$C" --requests=cpu=25m,memory=48Mi --limits=cpu=150m,memory=128Mi -n ac05-deploy
oc set env deployment/ac05-web --list -n ac05-deploy
oc set env deployment/ac05-web COR- MODO- -n ac05-deploy
oc rollout history deployment/ac05-web -n ac05-deploy | tail -4
oc get deployment ac05-web -n ac05-deploy -o jsonpath='{.spec.template.spec.containers[0].image}{"\n"}{.spec.template.spec.containers[0].resources}{"\n"}'
```

## Repetições

1. Volte para a tag `:latest` com `oc set image` e depois de novo para o digest.
2. `oc set image deployment/ac05-web '*=<digest>'` (curinga).
3. `oc set resources deployment/ac05-web --limits=memory=1Gi -n ac05-deploy --dry-run=server` com baseline aplicada: leia a recusa.
4. `oc set env deployment/ac05-web --list -n ac05-deploy | grep -v '^#'`.
5. Faça uma mudança com `oc set` e desfaça com `oc rollout undo`.

## Desafio sem pista

Em uma única revisão, fixe a imagem pelo digest, defina requests de 30m/40Mi e remova todas as variáveis que você
criou nesta trilha (`VERSAO`, `COR`, `MODO`). Prove o estado final com um único jsonpath.

## Diagnóstico controlado

- **Sintoma:** `error: unable to find container named "httpd"`.
- **Hipóteses:** nome do contêiner diferente do usado no comando (`oc create deployment` usa o nome base da imagem: `httpd-24`).
- **Investigação:** `oc get deployment ac05-web -n ac05-deploy -o jsonpath='{.spec.template.spec.containers[*].name}'`.
- **Reversão:** nada foi alterado.

## Validação

```bash
oc get deployment ac05-web -n ac05-deploy -o jsonpath='{.spec.template.spec.containers[0].image}' | grep -q '@sha256:' && echo "fixado por digest"
```
