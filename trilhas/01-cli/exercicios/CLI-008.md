## Conceito

Todo comando de recurso com escopo de namespace atua em:

1. o namespace da flag `-n`/`--namespace`, se presente;
2. senão, o namespace do contexto atual (definido por `oc project` ou `oc config set-context --current --namespace=`);
3. senão, `default`.

`oc config set-context --current --namespace=X` muda o contexto **atual** sem criar um novo (diferente de
`oc project`). Recursos de cluster (`nodes`, `projects`, `clusterroles`) ignoram o namespace.

## Comandos guiados

```bash
oc project ac01-cli
oc get pods                                              # atua em ac01-cli
oc get pods -n ac00-orientacao 2>&1 | head -2            # -n vence o contexto (pode dar NotFound/Forbidden se não existir)
oc config set-context --current --namespace=ac01-cli     # muda o contexto atual, sem criar outro
oc config view --minify -o jsonpath='{.contexts[0].context.namespace}{"\n"}'
oc get configmaps --namespace=ac01-cli -o name           # forma longa da flag
oc get projects -n ac01-cli -o name | head -3            # recurso de cluster: -n não filtra
```

## Repetições

Para cada comando, **escreva a previsão** e só depois execute:

1. `oc get cm` (com contexto em `ac01-cli`)
2. `oc get cm -n ac01-cli-inexistente`
3. `oc config set-context --current --namespace=default && oc get cm` (como developer)
4. `oc get cm -n ac01-cli` (logo após o item 3)
5. `oc get nodes -n ac01-cli` (como developer)

Ao final, restaure: `oc config set-context --current --namespace=ac01-cli`.

## Desafio sem pista

Escreva um comando que mostre, em uma linha, `contexto=<c> namespace_padrao=<n>` e use-o para provar que `oc project`
e `oc config set-context --current --namespace=` têm efeitos diferentes sobre o **nome** do contexto.

## Diagnóstico controlado

- **Sintoma:** `No resources found in default namespace.` logo após criar algo em `ac01-cli`.
- **Hipóteses:** (a) contexto sem namespace (cai em `default`); (b) recurso criado em outro namespace.
- **Investigação:** `oc project -q`; `oc config view --minify -o jsonpath='{.contexts[0].context.namespace}'`.
- **Reversão:** `oc project ac01-cli`.

## Validação

```bash
[ "$(oc project -q)" = ac01-cli ] && echo "contexto restaurado"
```
