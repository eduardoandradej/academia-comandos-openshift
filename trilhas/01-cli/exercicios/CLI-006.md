## Conceito

`oc config view` mostra o kubeconfig efetivo (a fusão de todos os arquivos de `KUBECONFIG`), **ocultando** dados
sensíveis (`DATA+OMITTED`, `REDACTED`). `--minify` restringe ao contexto atual. `--raw` desliga a ocultação — é
VERMELHO e não é usado nesta Academia.

Estrutura:

```text
clusters[]   -> name, cluster.server, cluster.certificate-authority(-data)
users[]      -> name, user.token | client-certificate-data ...
contexts[]   -> name, context.cluster, context.user, context.namespace
current-context
```

## Comandos guiados

```bash
oc config view --minify                                   # só o contexto atual, com segredos ocultos
oc config get-contexts                                    # tabela de contextos
oc config get-clusters                                    # nomes dos clusters
oc config get-users                                       # nomes das entradas de usuário
oc config current-context
oc config view --minify -o jsonpath='{.clusters[0].cluster.server}{"\n"}'
oc config view --minify -o jsonpath='{.contexts[0].context.namespace}{"\n"}'
oc config view -o jsonpath='{range .contexts[*]}{.name}{" -> "}{.context.user}{"\n"}{end}'
```

## Repetições

1. `oc config view --minify -o yaml | grep -n -E 'token|data'` — confira que só aparecem marcadores ocultos.
2. `oc config view -o jsonpath='{.users[*].name}{"\n"}'`.
3. `oc config view --minify -o json | jq '.contexts[0]'`.
4. Compare `oc config current-context` com `oc whoami --show-context`.
5. Repita os itens no perfil `admin`.

## Desafio sem pista

Liste, em formato `contexto | servidor | usuário local | namespace`, todos os contextos do arquivo do perfil
`developer`, sem usar `--raw` e sem abrir o arquivo.

## Diagnóstico controlado

- **Sintoma:** `oc config view --minify` imprime `error: current-context must exist in order to minify`.
- **Como reproduzir sem risco:** `KUBECONFIG=/tmp/vazio.kubeconfig oc config view --minify` (arquivo inexistente).
- **Hipóteses:** (a) kubeconfig vazio/inexistente; (b) `current-context` aponta para contexto apagado.
- **Investigação:** `oc config current-context`; `oc config get-contexts`.
- **Reversão:** nada a reverter; o arquivo temporário nem é criado.

## Validação

```bash
oc config view --minify -o jsonpath='{.clusters[0].cluster.server}{"\n"}' | grep -q 'api.ocp.example.lab:6443' && echo OK
```
