## Pré-flight

```bash
rpm -q bash-completion || echo "bash-completion ausente: use a forma 'source <(...)' abaixo"
```

## Conceito

`oc completion bash` imprime um script de completion. Duas formas de carregá-lo:

- **Por sessão:** `source <(oc completion bash)` — vale até fechar o terminal.
- **Persistente:** salvar o script em `~/.local/share/bash-completion/completions/oc`; o pacote `bash-completion` o
  carrega sob demanda na próxima sessão.

O completion consulta a API para sugerir nomes (projetos, pods). Se a sessão estiver expirada, as sugestões de nomes
somem, mas as de subcomandos continuam.

## Comandos guiados

```bash
source <(oc completion bash)                     # ativa só nesta sessão
mkdir -p ~/.local/share/bash-completion/completions
oc completion bash > ~/.local/share/bash-completion/completions/oc
kubectl completion bash > ~/.local/share/bash-completion/completions/kubectl
ls -l ~/.local/share/bash-completion/completions/
# Abra um terminal novo e teste:
#   oc get dep<TAB>        -> deployments
#   oc get pods -n <TAB>   -> lista namespaces visíveis
#   oc config use-<TAB>    -> use-context
```

## Repetições

1. `oc rollout <TAB><TAB>` — quais subcomandos aparecem?
2. `oc adm <TAB><TAB>`.
3. `oc get --sort<TAB>`.
4. `oc explain deployment.spec.<TAB>` — completa campos?
5. Digite 20 comandos das trilhas 00–01 usando TAB sempre que possível.

## Desafio sem pista

Faça o completion funcionar em um terminal novo sem editar o `~/.bashrc` e prove que ele carregou sem pressionar TAB.

## Diagnóstico controlado

- **Sintoma:** em um terminal novo, TAB não completa nada.
- **Hipóteses:** (a) pacote `bash-completion` ausente; (b) arquivo no diretório errado; (c) shell não é bash.
- **Investigação:** `rpm -q bash-completion`; `echo "$0"`; `ls ~/.local/share/bash-completion/completions/`;
  `complete -p oc` (mostra a função registrada, se houver).
- **Reversão:** `rm -f ~/.local/share/bash-completion/completions/{oc,kubectl}`.

## Validação

```bash
bash -ic 'complete -p oc' 2>/dev/null || echo "carregamento é sob demanda: pressione TAB uma vez e repita"
```

## Limpeza segura

Mantenha o completion (é útil em todas as trilhas). Para desfazer: `rm -f ~/.local/share/bash-completion/completions/{oc,kubectl}`.
