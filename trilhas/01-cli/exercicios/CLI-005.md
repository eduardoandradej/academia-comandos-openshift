## Objetivo e indicador de sucesso

Usar todas as formas de `oc whoami` (e `oc auth whoami`) e provar a existência de um token sem exibi-lo.

**Indicador de sucesso:** você responde identidade, servidor, contexto, URL da Console e grupos — e nenhum token aparece na tela.

## Conceito

| Comando | Responde |
|---|---|
| `oc whoami` | nome do usuário segundo a API |
| `oc whoami --show-server` | URL da API do contexto |
| `oc whoami --show-context` | nome do contexto atual |
| `oc whoami --show-console` | URL da Console Web |
| `oc whoami -t` / `--show-token` | **o token** — nunca exibir em tela, log ou issue |
| `oc auth whoami` | usuário, UID e **grupos** (via SelfSubjectReview; clientes recentes) |

Os grupos explicam permissões herdadas: `system:authenticated` e `system:authenticated:oauth` dão, por exemplo, o
direito de autoprovisionar projetos.

## Comandos guiados

```bash
oc whoami
oc whoami --show-server
oc whoami --show-context
oc whoami --show-console
oc auth whoami                           # usuário e grupos
oc auth whoami -o json | jq -r '.status.userInfo.groups[]'
oc whoami -t | wc -c                     # tamanho do token: prova que existe sem mostrá-lo
oc whoami -t | cut -c1-7                 # prefixo apenas (tokens OAuth começam com sha256~)
```

## Repetições

1. Repita tudo no perfil `admin`: quais grupos mudam?
2. `ac-recovery; oc whoami -t; echo "rc=$?"` — o que acontece com certificado de cliente? (Volte com `ac-dev`.)
3. `oc auth whoami -o yaml`.
4. Una servidor e usuário em uma linha: `echo "$(oc whoami)@$(oc whoami --show-server)"`.
5. `oc whoami --show-console` e abra a URL no navegador do Windows (o `hosts` precisa ter a entrada).

## Desafio sem pista

Produza a linha `usuario=<u> grupos=<g1,g2,...> console=<url>` sem que nenhum token apareça na tela ou no histórico.

## Diagnóstico controlado

- **Sintoma:** no perfil de recuperação, `oc whoami -t` responde `error: no token is currently in use for this session`.
- **Hipóteses:** (a) autenticação por certificado de cliente, não por token; (b) sessão expirada.
- **Investigação:** `oc whoami` (funciona → não é expiração); `oc config view --minify | grep -E 'client-certificate|token'` (mostra `DATA+OMITTED`, sem revelar).
- **Reversão:** `ac-dev`.

## Validação

```bash
[ "$(oc whoami)" = developer ] && oc whoami -t | grep -q '^sha256~' && echo "sessão OAuth válida"
```
