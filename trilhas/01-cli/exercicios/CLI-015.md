## Conceito

O circuito remove as pistas: a lista abaixo diz **o que** obter, não **como**. Faça em voz baixa ou anotando, sem

## Comandos guiados

Circuito (escreva o comando de cada item):

1. Versão do cliente, sem contatar a API.
2. Versão do Kubernetes do servidor.
3. Identidade atual.
4. Servidor da API.
5. Contexto atual.
6. URL da Console.
7. Grupos da identidade.
8. Prova de que há token, sem exibi-lo.
9. Lista de contextos.
10. Servidor do contexto atual via `oc config` e jsonpath.

12. Lista dos seus projetos `ac01-*`.
13. Mudar o namespace padrão do contexto sem criar contexto novo.
14. Resumo do projeto `ac01-cli`.
15. URL da API usada por um `oc get` de Services.
16. Mesma consulta com `oc get --raw`.
17. A mesma lista de pods com `kubectl`.
18. Uma permissão negada para developer e concedida para admin, usando `--context` ou o perfil.
19. Saúde da API com `curl`.
20. Lista de plugins.

## Desafio sem pista

Faça o circuito completo sem consulta. Em seguida, encerre a trilha com a limpeza abaixo e prove que nada ficou.

## Diagnóstico controlado

- **Sintoma:** `safe-cleanup.sh --delete-project` recusa apagar `ac01-cli`.
- **Hipóteses:** (a) você não é o `requester` e o namespace não tem o rótulo da Academia; (b) nome digitado errado.
- **Investigação:** `oc get project ac01-cli -o jsonpath='{.metadata.annotations.openshift\.io/requester}{"\n"}'`.
- **Reversão:** se o projeto foi criado por outra identidade, apague-o com ela, ou peça ao `admin` para rotular o namespace e repita.
