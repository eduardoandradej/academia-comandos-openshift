# CLI-012 — Plugins do oc

## Objetivo e indicador de sucesso

Entender como o `oc` encontra plugins e criar um plugin local inofensivo.

**Indicador de sucesso:** `oc plugin list` mostra seu plugin e `oc ac-ola` o executa.

## Nível

**Nível:** Intermediário

## Duração e repetições

- **Duração sugerida:** 15 min
- **Repetições:** 5×

## Contexto

- **Terminal:** `student@ocp-admin`, na raiz do repositório clonado (`cd ~/academia-comandos-openshift`)
- **Perfil:** `developer`
- **Projeto:** nenhum
- **Impacto:** MUTAÇÃO LOCAL REVERSÍVEL (um script em `~/.local/bin`)

## Pré-flight

```bash
echo "$PATH" | tr ':' '\n' | grep -n "$HOME/.local/bin" || echo "~/.local/bin não está no PATH"
```

## Conceito

Qualquer executável no `PATH` com nome `oc-<nome>` vira o subcomando `oc <nome>`. Hífens no nome viram espaços ou
hífens no comando (`oc-ac-ola` → `oc ac-ola`). `oc plugin list` lista os encontrados e avisa sobre conflitos.

Plugins rodam com **as suas** permissões e com acesso ao seu kubeconfig. Nunca instale plugin de origem não revisada.

## Comandos guiados

```bash
mkdir -p ~/.local/bin
cat > ~/.local/bin/oc-ac-ola <<'EOF'
#!/usr/bin/env bash
# Plugin de exemplo da Academia: só leitura.
echo "Olá, $(oc whoami) — projeto atual: $(oc project -q 2>/dev/null || echo '-')"
EOF
chmod +x ~/.local/bin/oc-ac-ola
oc plugin list
oc ac-ola
```

## Repetições

1. Faça o plugin aceitar um argumento `-n <ns>` e mostrar `oc get pods -n <ns> -o name | wc -l`.
2. Crie `oc-ac-saude` que roda `oc get --raw /readyz`.
3. Rode `oc plugin list` e interprete avisos (se houver).
4. Remova o bit de execução (`chmod -x`) e veja o efeito em `oc plugin list`.
5. Apague e recrie os plugins de memória.

## Desafio sem pista

Crie o plugin `oc ac-quem` que imprime `usuario@servidor (contexto)` usando apenas `oc whoami` e suas flags.

## Diagnóstico controlado

- **Sintoma:** `error: unknown command "ac-ola" for "oc"`.
- **Hipóteses:** (a) `~/.local/bin` fora do `PATH`; (b) arquivo sem permissão de execução; (c) nome errado.
- **Investigação:** `command -v oc-ac-ola`; `ls -l ~/.local/bin/oc-ac-ola`; `oc plugin list`.
- **Reversão:** `rm -f ~/.local/bin/oc-ac-*`.

## Validação

```bash
oc plugin list 2>/dev/null | grep -q oc-ac-ola && oc ac-ola
```

## Limpeza segura

```bash
rm -f ~/.local/bin/oc-ac-ola ~/.local/bin/oc-ac-saude ~/.local/bin/oc-ac-quem
oc plugin list
```
