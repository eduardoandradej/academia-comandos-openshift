## Conceito

A ajuda do `oc` tem três níveis:

1. `oc help` (ou `oc` sozinho): lista os subcomandos agrupados por finalidade.
2. `oc <subcomando> --help` (ou `-h`): descrição, **exemplos**, flags do subcomando e sintaxe.
3. `oc options`: flags **globais**, válidas para todos os subcomandos (`-n`, `--context`, `--request-timeout`, `-v`...).

A seção `Examples:` é a mais útil para a memória muscular: leia, entenda e só então adapte. `oc explain` (Trilha 02)
documenta **recursos**; `--help` documenta **comandos**.

## Comandos guiados

```bash
oc help | less                                   # mapa geral (q para sair)
oc get --help | sed -n '/Examples:/,/Options:/p' # só os exemplos de oc get
oc get --help | grep -E -- '--sort-by|--ignore-not-found|--show-labels'
oc options | grep -E -- '--namespace|--context|--request-timeout|--loglevel|-v,'
oc adm --help | sed -n '/Commands:/,$p' | head -40    # subcomandos administrativos
oc create --help | grep -A40 'Available Commands'     # o que oc create sabe gerar
```

## Diagnóstico controlado

- **Sintoma:** `Error: unknown flag: --sortby`.
- **Hipóteses:** (a) nome de flag errado; (b) flag existe em outro subcomando; (c) versão do cliente.
- **Investigação:** `oc get --help | grep -i sort`; `oc options | grep -i sort`.
- **Reversão:** nada a reverter.
