## Conceito

`oc login` troca usuário e senha por um **token OAuth** e o grava no kubeconfig em uso, criando ou atualizando um
contexto `<projeto>/<servidor>/<usuário>`. `oc logout` **revoga** o token no servidor e o remove do arquivo — o
contexto continua lá, mas sem credencial válida.

Formas úteis:

| Forma | Quando |
|---|---|
| `oc login <url> -u <user>` | primeira vez no arquivo |
| `oc login -u <user>` | reautenticar no servidor do contexto atual |
| `oc login --server=<url> --username=<user>` | forma longa, para scripts legíveis |

Tokens expiram (por padrão, em 24 h). Ao expirar, os comandos respondem `Unauthorized`.

## Comandos guiados

```bash
ac-dev
oc logout                                       # revoga o token atual
oc whoami; echo "rc=$?"                         # erro esperado, rc != 0
oc login -u developer                           # senha no prompt
oc whoami && oc whoami --show-context
ac-admin
oc logout && oc login -u admin
oc whoami
stat -c '%y' "$HOME/openshift-lab/ocp422-sno/install/auth/kubeconfig"   # inalterado desde o ORI-004?
```

## Repetições

1. Ciclo completo de `developer` 5×, sem olhar após o segundo.
2. Ciclo completo de `admin` 5×.
3. `oc login --server=https://api.ocp.example.lab:6443 --username=developer` (forma longa).
4. `oc whoami -t | wc -c` após o login (há token) e após o logout (não há).
5. `oc config get-contexts` após cada login: quantos contextos existem no arquivo do perfil?

## Desafio sem pista

Em um terminal novo, sem usar as funções de `scripts/perfis.sh`, entre como `developer` gravando em um kubeconfig
temporário em `/tmp`, prove a identidade, encerre a sessão e apague o arquivo — sem afetar nenhum outro perfil.

## Diagnóstico controlado

- **Sintoma:** `Login failed (401 Unauthorized)` ao digitar a senha.
- **Hipóteses:** (a) senha errada; (b) usuário não existe no HTPasswd; (c) provedor errado selecionado.
- **Investigação:** no perfil admin, `oc get oauth cluster -o jsonpath='{.spec.identityProviders[*].name}{"\n"}'`
  e `oc get pods -n openshift-authentication`; `oc get identities | grep developer`.
- **Reversão:** nada a reverter. Não "redefina" a senha editando o Secret do HTPasswd neste exercício (VERMELHO).

## Validação

```bash
KUBECONFIG="$HOME/.kube/ac-developer.kubeconfig" oc whoami   # developer
KUBECONFIG="$HOME/.kube/ac-admin.kubeconfig" oc whoami       # admin
```
