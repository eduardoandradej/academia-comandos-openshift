## Conceito

`oc project <nome>` muda o projeto atual. Internamente, o `oc` cria (se preciso) um contexto chamado
`<projeto>/<servidor>/<usuário>` e passa a usá-lo. Por isso o kubeconfig acumula contextos com o tempo.

| Comando | Efeito |
|---|---|
| `oc project` | mostra projeto e servidor atuais |
| `oc project -q` | só o nome (bom para scripts) |
| `oc project <nome>` | alterna |
| `oc projects` | lista os projetos acessíveis, marcando o atual |
| `oc projects -q` | só os nomes |

## Comandos guiados

```bash
oc new-project ac01-cli --display-name='Academia 01 - CLI'
oc new-project ac01-cli-b --skip-config-write          # não muda o projeto atual
oc project -q                                          # ac01-cli
oc projects                                            # * marca o atual
oc projects -q | grep '^ac01-'
oc project ac01-cli-b
oc config get-contexts                                 # observe os nomes <projeto>/<servidor>/<usuário>
oc project ac01-cli
oc get project ac01-cli -o jsonpath='{.metadata.annotations.openshift\.io/display-name}{"\n"}'
```

## Repetições

1. Alterne 10× entre `ac01-cli` e `ac01-cli-b` com `oc project` e confira com `oc project -q`.
2. `oc project default; echo "rc=$?"` — como developer, o que acontece?
3. `oc get projects -o custom-columns=NOME:.metadata.name,EXIBICAO:.metadata.annotations.openshift\.io/display-name`.
4. `oc describe project ac01-cli`.
5. Apague `ac01-cli-b` e confirme `NotFound`; recrie-o e apague de novo.

## Desafio sem pista

Escreva uma função de shell `acp` que alterna para um projeto de laboratório recebido como argumento **somente** se
o nome seguir o padrão `acNN-*`, e recusa qualquer outro nome.

## Diagnóstico controlado

- **Sintoma:** `error: You are not a member of project "default".` (ou mensagem equivalente).
- **Hipóteses:** (a) falta de papel no projeto; (b) projeto inexistente.
- **Investigação:** `oc auth can-i get pods -n default`; `oc get project default`.
- **Reversão:** nada mudou; o projeto atual continua o anterior (`oc project -q`).

## Validação

```bash
oc get project ac01-cli -o name && oc project -q
oc get project ac01-cli-b 2>&1 | grep -q NotFound && echo "rascunho removido"
```

## Limpeza segura

```bash
oc delete project ac01-cli-b --ignore-not-found     # o rascunho
```

`ac01-cli` permanece até o CLI-015.
