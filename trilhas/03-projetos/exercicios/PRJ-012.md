## Conceito

`oc apply` (client-side) guarda o que você declarou na anotação `kubectl.kubernetes.io/last-applied-configuration` e,
na próxima aplicação, calcula três vias: o declarado antes, o declarado agora e o estado atual.

- Rótulo **adicionado por `oc label`** e ausente do manifesto: o `apply` **não** remove (não estava no declarado antes).
- Rótulo **presente no manifesto anterior** e retirado do arquivo: o `apply` **remove**.
- Rótulo do manifesto **sobrescrito** por `oc label`: o `apply` volta ao valor do arquivo.

Moral: misturar imperativo e declarativo no mesmo campo gera surpresa; escolha um dono para cada campo.

## Comandos guiados

```bash
cat > /tmp/ac03-decl.yaml <<'EOF'
apiVersion: v1
kind: ConfigMap
metadata:
  name: ac03-decl
  labels:
    academy.openshift.dev/managed-by: academia
    camada: web
    versao: v1
data:
  x: "1"
EOF
oc apply -f /tmp/ac03-decl.yaml -n ac03-projetos
oc label configmap ac03-decl extra=imperativo -n ac03-projetos              # imperativo
oc label configmap ac03-decl versao=v9 --overwrite -n ac03-projetos         # sobrescreve campo do manifesto
oc diff -f /tmp/ac03-decl.yaml -n ac03-projetos                             # o que o apply mudaria?
oc apply -f /tmp/ac03-decl.yaml -n ac03-projetos
oc get configmap ac03-decl -n ac03-projetos --show-labels                   # extra fica; versao volta a v1
sed -i '/camada: web/d' /tmp/ac03-decl.yaml                                 # retira um rótulo do arquivo
oc apply -f /tmp/ac03-decl.yaml -n ac03-projetos
oc get configmap ac03-decl -n ac03-projetos --show-labels                   # camada sumiu
oc get configmap ac03-decl -n ac03-projetos -o jsonpath='{.metadata.annotations.kubectl\.kubernetes\.io/last-applied-configuration}' | jq .metadata.labels
```

## Repetições

1. Repita a sequência com anotações em vez de rótulos.
2. Use `oc apply --server-side` em uma cópia (`ac03-decl-ss`) e compare: onde fica o registro de quem gerencia cada campo? (`--show-managed-fields`)
3. Faça `oc replace -f` com o arquivo: o rótulo `extra` sobrevive?
4. Faça `oc patch configmap ac03-decl --type=merge -p '{"metadata":{"labels":{"versao":"v2"}}}'` e depois `oc diff`.
5. Remova a anotação `last-applied-configuration` e reaplique: o que muda no cálculo?

## Desafio sem pista

Monte uma tabela com 4 linhas (adicionar imperativo / sobrescrever campo do manifesto / retirar do manifesto /
`replace`) e o efeito observado em cada uma, cada linha com o comando que prova o resultado.

## Diagnóstico controlado

- **Sintoma:** "apliquei o manifesto, mas um rótulo que não está no arquivo continua no objeto".
- **Hipóteses:** rótulo adicionado imperativamente nunca fez parte do declarado.
- **Investigação:** compare `--show-labels` com `last-applied-configuration`.
- **Reversão:** `oc label configmap ac03-decl extra- -n ac03-projetos`, ou use `oc replace`/server-side apply com cuidado.

## Validação

```bash
oc get configmap ac03-decl -n ac03-projetos -o jsonpath='{.metadata.labels.versao}{"\n"}'   # v1
```

rm -f /tmp/ac03-decl.yaml
