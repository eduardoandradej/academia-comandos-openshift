## Conceito

Um rótulo é um par `chave=valor` usado para **selecionar**. Regras de sintaxe:

- chave: prefixo opcional em formato DNS + `/` + nome (até 63 caracteres; letras, números, `-`, `_`, `.`);
- valor: até 63 caracteres, mesmo conjunto, começando e terminando com alfanumérico (pode ser vazio);
- prefixos `kubernetes.io/` e `k8s.io/` são reservados ao sistema.

| Operação | Sintaxe |
|---|---|
| adicionar | `oc label <tipo>/<nome> chave=valor` |
| sobrescrever | `oc label <tipo>/<nome> chave=novo --overwrite` |
| remover | `oc label <tipo>/<nome> chave-` |
| listar | `oc label <tipo>/<nome> --list` |
| simular | `--dry-run=server` |

## Comandos guiados

```bash
oc create configmap ac03-rotulos --from-literal=x=1 --dry-run=client -o yaml \
  | oc label --local -f - academy.openshift.dev/managed-by=academia -o yaml | oc apply -n ac03-projetos -f -
oc label configmap/ac03-rotulos ambiente=treino -n ac03-projetos
oc label configmap/ac03-rotulos --list -n ac03-projetos
oc label configmap/ac03-rotulos ambiente=revisao -n ac03-projetos; echo "rc=$?"     # falha: já existe
oc label configmap/ac03-rotulos ambiente=revisao --overwrite -n ac03-projetos
oc label configmap/ac03-rotulos camada=dados versao=v1 -n ac03-projetos              # dois de uma vez
oc get configmap ac03-rotulos -n ac03-projetos --show-labels
oc label configmap/ac03-rotulos versao- -n ac03-projetos                            # remove
oc label configmap/ac03-rotulos camada=cache --overwrite --dry-run=server -o yaml -n ac03-projetos | grep -A6 'labels:'
```

## Repetições

1. Adicione `dono=seu-nome` e remova-o (5×).
2. Tente `oc label configmap/ac03-rotulos 'versão=1'` (com acento) e leia o erro.
3. Tente um valor com espaço: `oc label configmap/ac03-rotulos nota='dois termos'`.
4. Adicione `academy.openshift.dev/trilha=03` e liste só os rótulos com esse prefixo.
5. Use `kubectl label` para a mesma sequência.

## Desafio sem pista

Deixe o ConfigMap com exatamente quatro rótulos — o da Academia, `ambiente=treino`, `camada=dados` e
`academy.openshift.dev/trilha=03` — sem apagá-lo, e prove o resultado com uma única consulta ordenada por chave.

## Diagnóstico controlado

- **Sintoma:** `error: 'ambiente' already has a value (treino), and --overwrite is false`.
- **Hipóteses:** proteção contra sobrescrita acidental.
- **Investigação:** `oc label configmap/ac03-rotulos --list -n ac03-projetos`.
- **Reversão:** nada foi alterado; repita com `--overwrite` se a intenção for trocar o valor.

## Validação

```bash
oc get configmap ac03-rotulos -n ac03-projetos -o json | jq -r '.metadata.labels | keys | length'   # 4 após o desafio
```

## Limpeza segura

```bash
oc delete configmap -l academy.openshift.dev/managed-by=academia -n ac03-projetos --dry-run=client
oc delete configmap ac03-rotulos -n ac03-projetos
```
