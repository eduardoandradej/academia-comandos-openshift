## Objetivo e indicador de sucesso

Usar `oc annotate` para registrar informação descritiva e entender por que anotações não servem para selecionar.

**Indicador de sucesso:** você grava, sobrescreve, lê e remove anotações, inclusive um valor com várias linhas.

## Conceito

| | Rótulo | Anotação |
|---|---|---|
| Serve para selecionar (`-l`) | sim | **não** |
| Tamanho do valor | até 63 caracteres | até 256 KiB no total do objeto |
| Uso típico | identidade, agrupamento | descrição, autoria, URLs, configuração lida por controladores |
| Exemplos do sistema | `app.kubernetes.io/name` | `openshift.io/display-name`, `kubectl.kubernetes.io/last-applied-configuration` |

A sintaxe de `oc annotate` espelha a de `oc label` (`--overwrite`, `chave-`, `--list`).

## Comandos guiados

```bash
oc create configmap ac03-notas --from-literal=x=1 --dry-run=client -o yaml \
  | oc label --local -f - academy.openshift.dev/managed-by=academia -o yaml | oc apply -n ac03-projetos -f -
oc annotate configmap/ac03-notas academy.openshift.dev/autor=estudante -n ac03-projetos
oc annotate configmap/ac03-notas academy.openshift.dev/descricao='ConfigMap de treino da trilha 03' -n ac03-projetos
oc annotate configmap/ac03-notas --list -n ac03-projetos
oc annotate configmap/ac03-notas academy.openshift.dev/autor=revisor --overwrite -n ac03-projetos
oc get configmap ac03-notas -n ac03-projetos -o jsonpath='{.metadata.annotations.academy\.openshift\.dev/descricao}{"\n"}'
oc annotate configmap/ac03-notas academy.openshift.dev/historico="$(printf 'linha 1\nlinha 2')" -n ac03-projetos
oc get configmap ac03-notas -n ac03-projetos -o json | jq -r '.metadata.annotations["academy.openshift.dev/historico"]'
oc annotate configmap/ac03-notas academy.openshift.dev/historico- -n ac03-projetos
oc get configmap -n ac03-projetos -l academy.openshift.dev/autor=revisor 2>&1 | head -1   # não seleciona por anotação
```

## Repetições

1. Leia as anotações de `oc get project ac03-projetos -o json | jq '.metadata.annotations'`.
2. Grave uma anotação com uma URL de documentação.
3. Tente `oc annotate configmap/ac03-notas 'descrição=x'` e leia o erro (a chave segue as mesmas regras dos rótulos).
4. Compare `--list` de rótulos e de anotações no mesmo objeto.
5. Faça `oc apply` de um ConfigMap e procure `kubectl.kubernetes.io/last-applied-configuration`.

## Desafio sem pista

Encontre todos os ConfigMaps do projeto que tenham a anotação `academy.openshift.dev/autor`, mostrando nome e valor —
sabendo que `-l` não funciona para anotações.

## Diagnóstico controlado

- **Sintoma:** `oc get configmap -l academy.openshift.dev/autor=revisor` responde `No resources found`, embora a anotação exista.
- **Hipóteses:** anotações não são indexadas para seleção.
- **Investigação:** `oc annotate configmap/ac03-notas --list -n ac03-projetos` × `oc label configmap/ac03-notas --list -n ac03-projetos`.
- **Reversão:** nada a reverter.

## Validação

```bash
oc get configmap ac03-notas -n ac03-projetos -o jsonpath='{.metadata.annotations.academy\.openshift\.dev/autor}{"\n"}'   # revisor
```

## Limpeza segura

```bash
oc delete configmap ac03-notas -n ac03-projetos
```
