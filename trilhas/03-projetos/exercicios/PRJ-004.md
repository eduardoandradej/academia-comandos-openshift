## Objetivo e indicador de sucesso

Aplicar e remover rótulos em vários objetos de uma vez usando `-l`, com simulação antes.

**Indicador de sucesso:** você rotula só os objetos certos entre 6 ConfigMaps e prova que os demais ficaram intactos.

## Conceito

`oc label <tipo> -l <seletor> chave=valor -n <ns>` aplica a todos os objetos que casam com o seletor. É poderoso e
perigoso na mesma medida: **sempre** liste antes (`oc get ... -l <seletor> -o name`) e simule (`--dry-run=server`).
A Academia evita `--all` mesmo dentro do namespace: prefira um seletor explícito.

## Comandos guiados

```bash
for n in a b c; do
  oc create configmap "ac03-web-$n" --from-literal=x=1 --dry-run=client -o yaml \
    | oc label --local -f - academy.openshift.dev/managed-by=academia camada=web -o yaml | oc apply -n ac03-projetos -f -
  oc create configmap "ac03-db-$n" --from-literal=x=1 --dry-run=client -o yaml \
    | oc label --local -f - academy.openshift.dev/managed-by=academia camada=db -o yaml | oc apply -n ac03-projetos -f -
done
oc get configmap -n ac03-projetos -l camada=web -o name                         # 1. listar o alvo
oc label configmap -l camada=web exposto=sim -n ac03-projetos --dry-run=server  # 2. simular
oc label configmap -l camada=web exposto=sim -n ac03-projetos                   # 3. aplicar
oc get configmap -n ac03-projetos -L camada,exposto                             # 4. conferir
oc label configmap -l exposto=sim exposto- -n ac03-projetos                     # remover em lote
```

## Repetições

1. Rotule `backup=diario` só nos `camada=db`.
2. Rotule `revisar=sim` em `camada in (web,db)` que **não** tenham `exposto`.
3. Troque `camada=db` por `camada=dados` em lote (`--overwrite`).
4. Remova `revisar` de todos que o tenham.
5. Conte, a cada passo, quantos objetos têm cada rótulo (`-L`).

## Desafio sem pista

Rotule `prioridade=alta` apenas nos dois ConfigMaps mais recentes do projeto que tenham `camada=web`, sem digitar os nomes.

## Diagnóstico controlado

- **Sintoma:** o comando em lote responde `No resources found` e nada é rotulado.
- **Hipóteses:** (a) seletor sem correspondência (valor ou chave errados); (b) namespace errado.
- **Investigação:** rode o mesmo seletor com `oc get ... -o name`; `oc project -q`.
- **Reversão:** nada a reverter.

## Validação

```bash
oc get configmap -n ac03-projetos -l 'camada=web,!exposto' -o name | wc -l    # 3 após remover exposto
```
