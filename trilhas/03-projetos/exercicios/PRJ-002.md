# PRJ-002 — Criar projetos e namespaces com metadados completos

## Identificação

- **ID:** PRJ-002
- **Trilha:** [03 — Projetos e metadados](../README.md)
- **Referência didática:** DO180 — projetos. DO280 — autosserviço de projetos.
- **Fichas de comando:** [`oc-new-project`](../../../catalogo/fichas/oc-new-project.md)
- **Status:** proposto — escrito e revisado estaticamente; ainda não executado contra o cluster pelo autor

## Objetivo e indicador de sucesso

Criar `ac03-projetos` como `developer` (com nome de exibição e descrição) e `ac03-extra` como `admin` via `oc create namespace`, já rotulado.

**Indicador de sucesso:** os dois existem, e você explica por que um tem `openshift.io/requester` e o outro não.

## Nível

**Nível:** Iniciante

## Duração e repetições

- **Duração sugerida:** 15 min
- **Repetições:** 5× (criar/apagar um rascunho)

## Contexto

- **Terminal:** `student@ocp-admin`, na raiz do repositório clonado (`cd ~/academia-comandos-openshift`)
- **Perfil:** `developer` e `admin`
- **Projeto:** `ac03-projetos` e `ac03-extra`
- **Impacto:** MUTAÇÃO LOCAL REVERSÍVEL

## Pré-flight

```bash
source scripts/perfis.sh && ac-dev   # perfil developer (ORI-004)
scripts/preflight.sh                 # sem FALHA
oc whoami                            # developer
```

## Conceito

| Caminho | Quem | O que acontece |
|---|---|---|
| `oc new-project` | developer | cria via ProjectRequest; o solicitante vira `admin` do projeto; grava `openshift.io/requester` |
| `oc create namespace` | admin | cria o Namespace puro; ninguém recebe papel automaticamente; sem `requester` |

Para que o `scripts/safe-cleanup.sh` aceite apagar um namespace criado com `create namespace`, ele precisa do rótulo
da Academia — por isso o `admin` o cria **já rotulado**, pelo padrão gerar → rotular → aplicar.

## Comandos guiados

```bash
oc new-project ac03-projetos \
  --display-name='Academia 03 - Projetos' \
  --description='Trilha 03: metadados, rótulos, anotações e donos'
oc get project ac03-projetos -o jsonpath='{.metadata.annotations}' | jq .
oc create namespace ac03-extra 2>&1 | head -1          # developer: Forbidden

ac-admin
oc create namespace ac03-extra --dry-run=client -o yaml \
  | oc label --local -f - academy.openshift.dev/managed-by=academia academy.openshift.dev/trilha=03 -o yaml \
  | oc apply -f -
oc get namespace ac03-extra --show-labels
oc get project ac03-extra -o jsonpath='{.metadata.annotations.openshift\.io/requester}{"\n"}'   # vazio
oc get rolebindings -n ac03-extra                      # nenhum binding de usuário
oc label namespace ac03-projetos academy.openshift.dev/managed-by=academia academy.openshift.dev/trilha=03
ac-dev
oc get project ac03-extra 2>&1 | head -1               # developer não vê: não tem papel lá
```

## Repetições

1. Crie e apague `ac03-rascunho` com `oc new-project --skip-config-write` (5×).
2. `oc describe project ac03-projetos`.
3. `oc get project ac03-projetos -o jsonpath='{.metadata.annotations.openshift\.io/description}{"\n"}'`.
4. (admin) `oc get namespace ac03-extra -o yaml | grep -A6 '^metadata:'`.
5. (admin) `oc get namespaces -l academy.openshift.dev/trilha=03`.

## Desafio sem pista

Como `admin`, dê ao `developer` acesso de leitura ao `ac03-extra` só pelo tempo de uma verificação: prove que ele passa a
ver o projeto e, depois de remover o acesso, que deixa de ver.

## Diagnóstico controlado

- **Sintoma:** `Error from server (AlreadyExists): namespaces "ac03-extra" already exists` ao repetir o `oc create namespace`.
- **Hipóteses:** (a) `create` não é idempotente; (b) namespace em `Terminating` de uma tentativa anterior.
- **Investigação:** `oc get namespace ac03-extra -o jsonpath='{.status.phase}{"\n"}'`.
- **Reversão:** nada a reverter; o pipeline com `oc apply` (guiados) é idempotente.

## Validação

```bash
oc get project ac03-projetos -o name
KUBECONFIG="$HOME/.kube/ac-admin.kubeconfig" oc get namespace ac03-extra -o jsonpath='{.metadata.labels.academy\.openshift\.dev/managed-by}{"\n"}'   # academia
```

## Limpeza segura

Os dois projetos ficam até o PRJ-015. Garanta que o rascunho sumiu: `oc get project ac03-rascunho` → `NotFound`.
Se fez o desafio, confirme que o binding temporário foi removido.
