# PRJ-013 — Inventário de uma aplicação por rótulo

## Objetivo e indicador de sucesso

Listar **todos** os tipos de objeto de um projeto que carregam um rótulo — indo além do `oc get all`.

**Indicador de sucesso:** um inventário que inclui ConfigMaps, EndpointSlices e ReplicaSets do alvo, que `oc get all` não mostra completamente.

## Conceito

`oc get all` é um **atalho** para uma lista fixa de tipos (pods, services, deployments, replicasets e alguns tipos do
OpenShift). Ele não inclui ConfigMaps, Secrets, EndpointSlices, RoleBindings, NetworkPolicies, PVCs...

Para um inventário real, percorra os tipos com escopo de namespace que aceitam `list`, consultando cada um com o
seletor. Tipos sem permissão para `developer` devolvem `Forbidden` — descarte esses erros conscientemente.

## Comandos guiados

```bash
oc get all -n ac03-projetos -l app=obs-web                       # o atalho
oc get configmap,endpointslices -n ac03-projetos -l app=obs-web  # o que ficou de fora (EndpointSlice usa outro rótulo)
oc get endpointslices -n ac03-projetos -l kubernetes.io/service-name=obs-web -o name
oc api-resources --namespaced=true --verbs=list -o name | wc -l  # quantos tipos existem
oc api-resources --namespaced=true --verbs=list -o name \
  | xargs -n1 -I{} sh -c 'oc get {} -n ac03-projetos -l academy.openshift.dev/managed-by=academia -o name 2>/dev/null' \
  | sort
```

## Repetições

1. Repita o inventário com o seletor `app=obs-web`.
2. Conte quantos tipos retornaram `Forbidden` para developer (redirecione o erro para um arquivo e conte).
3. Repita no perfil `admin` e compare.
4. Inventarie o que **não** tem o rótulo da Academia no projeto (`-l '!academy.openshift.dev/managed-by'`).
5. Meça com `time` quanto o inventário completo demora — por que ele é lento?

## Desafio sem pista

Escreva um script de leitura `inventario.sh <ns> <seletor>` que imprime `tipo: quantidade` para cada tipo com pelo menos
um objeto e, no fim, quantos tipos foram negados por permissão.

## Diagnóstico controlado

- **Sintoma:** o inventário imprime várias linhas `Error from server (Forbidden)`.
- **Hipóteses:** tipos que developer não pode listar no namespace (por exemplo, recursos administrativos).
- **Investigação:** `oc auth can-i list <tipo> -n ac03-projetos` para um dos tipos citados.
- **Reversão:** nada a reverter; trate o erro (descarte ou conte), não ignore às cegas.

## Validação

```bash
oc api-resources --namespaced=true --verbs=list -o name | xargs -n1 -I{} sh -c 'oc get {} -n ac03-projetos -l app=obs-web -o name 2>/dev/null' | grep -c .   # > 5
```
