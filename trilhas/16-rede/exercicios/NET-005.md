# NET-005 — Liberar um cliente de outro projeto (e o AND × OR)

## Identificação

- **ID:** NET-005
- **Trilha:** [16 — Rede e isolamento](../README.md)
- **Referência didática:** DO280 — NetworkPolicy (seletores).
- **Fichas de comando:** [`oc-networkpolicy`](../../../catalogo/fichas/oc-networkpolicy.md)
- **Status:** proposto — escrito e revisado estaticamente; ainda não executado contra o cluster pelo autor

## Objetivo e indicador de sucesso

Liberar a loja só para o `ac16-cliente` do `ac16-vizinho`, na porta 8080, e ver como uma vírgula de YAML transforma AND em OR.

**Indicador de sucesso:** `ac16-cliente` acessa; `ac16-intruso` (mesmo projeto vizinho) não — e, com a versão "OR", passa a acessar.

## Pré-flight

```bash
source scripts/perfis.sh && ac-dev   # perfil developer (ORI-004)
scripts/preflight.sh                 # sem FALHA
oc whoami                            # developer
```

```bash
oc get pods -n ac16-rede -l app=loja -o name       # web-azul e web-verde (NET-002)
oc get pod ac16-cliente -n ac16-vizinho -o name    # cliente do projeto vizinho (NET-002)
oc get pod ac16-local -n ac16-rede -o name         # cliente do próprio projeto (NET-002)
t() { oc exec "$1" -n "$2" -- timeout 3 bash -c "exec 3<>/dev/tcp/$3/${4:-8080} && printf 'GET / HTTP/1.0\r\n\r\n' >&3 && tail -1 <&3" 2>/dev/null || echo FALHOU; }
t ac16-local ac16-rede web-azul                    # função de teste: imprime a página ou FALHOU
```

REQUER PREPARAÇÃO: pull de `registry.access.redhat.com/ubi9/httpd-24` (normalmente já em cache).

## Conceito

> **Função de teste `t`** (definida no pré-flight): `t <pod> <projeto> <destino> [porta]` abre uma conexão HTTP de
> dentro do pod (sem `curl`, por `/dev/tcp`) e imprime a última linha da resposta — ou `FALHOU` em 3 s.
> Bloqueio por NetworkPolicy aparece como **timeout** (os pacotes são descartados), não como "connection refused".

```yaml
from:
  - namespaceSelector: {matchLabels: {kubernetes.io/metadata.name: ac16-vizinho}}
    podSelector: {matchLabels: {app: ac16-cliente}}       # MESMO item: projeto E pod (AND)
---
from:
  - namespaceSelector: {matchLabels: {kubernetes.io/metadata.name: ac16-vizinho}}
  - podSelector: {matchLabels: {app: ac16-cliente}}       # itens separados: projeto OU pod (OR)
```

No segundo caso, **qualquer** pod do `ac16-vizinho` entra, e o `podSelector` sozinho vale para o **próprio** projeto.

## Comandos guiados

```bash
oc apply -f manifests/networkpolicies/20-permitir-cliente-vizinho.yaml -n ac16-rede
t ac16-cliente ac16-vizinho web-azul.ac16-rede.svc         # azul
t ac16-intruso ac16-vizinho web-azul.ac16-rede.svc         # FALHOU
t ac16-cliente ac16-vizinho web-azul.ac16-rede.svc 8443    # FALHOU: só 8080 liberada
sed 's/^          podSelector:/        - podSelector:/' manifests/networkpolicies/20-permitir-cliente-vizinho.yaml | sed 's/name: ac16-cliente-vizinho/name: ac16-ou/' > /tmp/ac16-ou.yaml
diff manifests/networkpolicies/20-permitir-cliente-vizinho.yaml /tmp/ac16-ou.yaml
oc apply -f /tmp/ac16-ou.yaml -n ac16-rede
t ac16-intruso ac16-vizinho web-azul.ac16-rede.svc         # azul: o OR liberou o projeto inteiro
oc delete -f /tmp/ac16-ou.yaml -n ac16-rede; rm -f /tmp/ac16-ou.yaml
```

## Repetições

1. Leia o `oc describe` das duas versões: como cada uma aparece?
2. Libere também a 8443 só para o `ac16-cliente`.
3. Use um rótulo seu no namespace (`oc label namespace ac16-vizinho equipe=parceira`) — developer pode rotular o próprio projeto? (Forbidden: rótulos de namespace são do admin)
4. Por que `kubernetes.io/metadata.name` é o seletor mais seguro para um projeto específico?
5. Escreva as duas formas de memória.

## Desafio sem pista

Libere a loja para **qualquer** pod `app=ac16-cliente` de **qualquer** projeto (e nada mais), e prove com o `ac16-local` e o `ac16-cliente`.

## Diagnóstico controlado

- **Sintoma:** uma política "só para o cliente do projeto X" deixou entrar todo o projeto X.
- **Hipóteses:** `namespaceSelector` e `podSelector` em itens separados da lista `from` (OR).
- **Investigação:** `oc get networkpolicy <nome> -o yaml` — conte os `-` em `from`.
- **Reversão:** junte os dois seletores no mesmo item. Veja TS-051.

## Validação

```bash
oc get networkpolicy ac16-cliente-vizinho -n ac16-rede -o jsonpath='{.spec.ingress[0].from[0]}{"\n"}' | grep -q podSelector && echo "AND"
```
