## Objetivo e indicador de sucesso

Transformar a loja em um chart próprio com valores documentados, schema e teste, e entregá-la com `--atomic`.

**Indicador de sucesso:** `helm lint` limpo, `helm install --atomic` ok, `helm test` aprovado e um `helm rollback` funcionando.

**Requisitos** (projeto `ac20-helm`; REQUER PREPARAÇÃO: cliente `helm`, docs/11):

1. Chart `/tmp/ac20/chart-loja` (pode partir de `manifests/helm/ac14-loja`) com `pagina`, `replicaCount` e `image` em `values.yaml`.
2. Schema que limita `replicaCount` a 1–2.
3. Teste (`helm test`) que confere o conteúdo da página.
4. Instalação com `--atomic --timeout 2m`; um upgrade mudando a página; um rollback para a revisão 1.
5. Antes de tudo: `oc whoami` = `developer` (o Helm usa o mesmo KUBECONFIG).

## Repetições

1. Quantas revisões a release tem? Qual a descrição de cada uma?
2. O `helm test` falha se você mudar a página por fora com `oc patch`? Por quê? (HLM-009)
3. Compare o chart com os overlays da missão 6: o que cada um faz melhor?
4. Rode `helm template` e compare com `/tmp/ac20/loja.yaml`.
5. Refaça em D+30.

## Desafio sem pista

Escreva `entrega` (HLM-010) para este chart: upgrade `--atomic`, `helm test` e rollback automático se o teste falhar — e prove o caminho de falha com uma página que o teste não reconhece.

## Diagnóstico controlado

- **Sintoma:** `another operation (install/upgrade/rollback) is in progress`.
- **Hipóteses:** upgrade interrompido (TS-043).
- **Investigação:** `helm history`.
- **Reversão:** `helm rollback` para a última `deployed`.

## Validação

```bash
ok() { if eval "$2" >/dev/null 2>&1; then echo "OK   $1"; else echo "FALHA $1"; fi; }
ok "identidade developer" "[ \"\$(oc whoami)\" = developer ]"
ok "lint limpo"           "helm lint /tmp/ac20/chart-loja"
ok "schema barra 3"       "! helm template x /tmp/ac20/chart-loja --set replicaCount=3"
ok "release deployed"     "[ \"\$(helm status loja -n ac20-helm -o json | jq -r .info.status)\" = deployed ]"
ok "teste aprovado"       "helm test loja -n ac20-helm"
ok "houve rollback"       "helm history loja -n ac20-helm -o json | jq -e '[.[].description] | any(test(\"Rollback\"))'"
```
