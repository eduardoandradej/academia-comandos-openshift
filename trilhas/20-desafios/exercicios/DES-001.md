## Objetivo e indicador de sucesso

Publicar uma aplicação completa a partir de nada: página em ConfigMap, Deployment com probes e recursos, Service e
Route HTTPS — tudo rotulado e reproduzível a partir de um arquivo.

## Conceito

> **Missão.** Você recebe **requisitos**, não comandos. Escolha as ferramentas das trilhas anteriores, cumpra todos os
> requisitos dentro do tempo e confira com a **Validação** (autoavaliação: cada linha deve responder `OK`). O gabarito
> mostra **uma** solução; outras que passem na validação são igualmente válidas.

**Requisitos** (projeto `ac20-loja`):

1. ConfigMap `loja-pagina` com `index.html` contendo a palavra `loja`, montado em `/var/www/html`.
2. Deployment `loja` com a imagem `httpd-24`, **2 réplicas**, requests e limits declarados.
3. Readiness e liveness por TCP na 8080.
4. Service `loja` na porta 8080.
5. Route `loja` com TLS **edge** e redirecionamento de HTTP para HTTPS.
6. Todos os objetos com `academy.openshift.dev/managed-by=academia`.
7. Tudo descrito em **um** arquivo `/tmp/ac20/loja.yaml`, aplicado com `oc apply -f`.

## Desafio sem pista

Cumpra a missão gerando o YAML **só com comandos** (`--dry-run=client -o yaml`, `oc set ... --local`), sem escrever YAML à mão, exceto a Route.

## Diagnóstico controlado

- **Sintoma:** a Route edge responde 503.
- **Hipóteses:** pods não prontos (probe), Service sem endpoints (seletor), `targetPort` errado.
- **Investigação:** triagem do DIA-002.
- **Reversão:** corrija o andar indicado pela triagem.

## Validação

```bash
ok() { if eval "$2" >/dev/null 2>&1; then echo "OK   $1"; else echo "FALHA $1"; fi; }
N=ac20-loja
ok "2 réplicas prontas"      "[ \"\$(oc get deploy loja -n $N -o jsonpath='{.status.readyReplicas}')\" = 2 ]"
ok "requests e limits"       "oc get deploy loja -n $N -o jsonpath='{.spec.template.spec.containers[0].resources.limits.memory}' | grep -q ."
ok "readiness e liveness"    "oc get deploy loja -n $N -o jsonpath='{.spec.template.spec.containers[0].livenessProbe}{.spec.template.spec.containers[0].readinessProbe}' | grep -q tcpSocket"
ok "página do ConfigMap"     "oc get cm loja-pagina -n $N -o jsonpath='{.data.index\.html}' | grep -q loja"
ok "Route HTTPS edge"        "[ \"\$(oc get route loja -n $N -o jsonpath='{.spec.tls.termination}')\" = edge ]"
ok "HTTP redireciona"        "[ \"\$(oc get route loja -n $N -o jsonpath='{.spec.tls.insecureEdgeTerminationPolicy}')\" = Redirect ]"
ok "responde pela Route"     "curl -sSk -m 5 https://\$(oc get route loja -n $N -o jsonpath='{.spec.host}')/ | grep -q loja"
ok "rótulo da Academia"      "[ \$(oc get deploy,svc,route,cm -n $N -l academy.openshift.dev/managed-by=academia --no-headers | wc -l) -ge 4 ]"
```
