## Objetivo e indicador de sucesso

Garantir que a loja aguenta deploy, falha de pod e pico leve: rollout sem queda, PDB, desligamento gracioso e HPA até 2 réplicas.

**Indicador de sucesso:** validação `OK` e um `rollout restart` com zero falhas medido por um cliente dentro do projeto.

## Conceito

> **Missão.** Você recebe **requisitos**, não comandos. Escolha as ferramentas das trilhas anteriores, cumpra todos os
> requisitos dentro do tempo e confira com a **Validação** (autoavaliação: cada linha deve responder `OK`). O gabarito
> mostra **uma** solução; outras que passem na validação são igualmente válidas.

**Requisitos** (projeto `ac20-loja`):

1. Estratégia com `maxUnavailable: 0` e `maxSurge: 1`.
2. `preStop` curto e `terminationGracePeriodSeconds` coerente.
3. PDB que permita **uma** interrupção voluntária com 2 réplicas.
4. HPA de 1 a 2 réplicas por CPU (o manifesto da loja **não** pode mais declarar `replicas`, DCL-005).
5. Um `rollout restart` sem nenhuma requisição recusada (cliente no próprio projeto, RES-010).

## Comandos guiados

```bash
oc get deployment loja -n ac20-loja -o name
# ... cumpra os requisitos; para o teste de queda, use o cliente do RES-010 dentro do ac20-loja ...
```

## Repetições

1. Com o HPA, quantas réplicas ficam em repouso? O PDB ainda permite interrupção com 1 réplica?
2. Ajuste o PDB para não travar manutenção quando o HPA reduzir (RES-013).
3. Repita o teste de queda 3 vezes.
4. A validação das missões 1–3 continua `OK`?
5. Refaça em D+7.

## Desafio sem pista

Faça o PDB e o HPA conviverem: o PDB nunca deve zerar as interrupções permitidas, qualquer que seja o número de réplicas escolhido pelo HPA.

## Diagnóstico controlado

- **Sintoma:** HPA com `TARGETS <unknown>`.
- **Hipóteses:** sem `requests.cpu` ou sem Metrics API (TS-035).
- **Investigação:** `oc describe hpa`.
- **Reversão:** declare requests; aguarde as métricas.

## Validação

```bash
ok() { if eval "$2" >/dev/null 2>&1; then echo "OK   $1"; else echo "FALHA $1"; fi; }
N=ac20-loja
ok "maxUnavailable 0"       "[ \"\$(oc get deploy loja -n $N -o jsonpath='{.spec.strategy.rollingUpdate.maxUnavailable}')\" = 0 ]"
ok "preStop definido"       "oc get deploy loja -n $N -o jsonpath='{.spec.template.spec.containers[0].lifecycle.preStop}' | grep -q ."
ok "PDB existe"             "oc get pdb -n $N -o name | grep -q ."
ok "HPA 1-2"                "[ \"\$(oc get hpa -n $N -o jsonpath='{.items[0].spec.minReplicas}-{.items[0].spec.maxReplicas}')\" = 1-2 ]"
ok "manifesto sem replicas" "! grep -qE '^ *replicas:' /tmp/ac20/loja.yaml"
```
