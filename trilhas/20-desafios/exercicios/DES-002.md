## Conceito

> **Missão.** Você recebe **requisitos**, não comandos. Escolha as ferramentas das trilhas anteriores, cumpra todos os
> requisitos dentro do tempo e confira com a **Validação** (autoavaliação: cada linha deve responder `OK`). O gabarito
> mostra **uma** solução; outras que passem na validação são igualmente válidas.

**Requisitos** (projeto `ac20-loja`):

1. ServiceAccount `loja` usada pelo Deployment; `automountServiceAccountToken: false` (a loja não fala com a API).
2. Secret `loja-api` (valor **fictício**, digitado no prompt) montado em `/etc/loja/token` com modo `0400`.
3. Nenhum valor de Secret em variável de ambiente.
4. A SA `default` do projeto **não** pode ler Secrets (prove com `can-i`).
5. O pod roda com a SCC `restricted-v2`.

## Comandos guiados

```bash
oc get deployment loja -n ac20-loja -o name     # da missão 1
# ... cumpra os requisitos ...
```

## Repetições

1. Prove que o token não aparece em `oc exec ... env`.
2. Troque o valor do Secret e veja o arquivo atualizar (sem `rollout restart`).
3. Por que `automountServiceAccountToken: false` é uma boa prática aqui?
4. Rode a validação da missão 1 de novo.
5. Refaça em D+7.

## Desafio sem pista

Acrescente uma verificação automática que falhe se **qualquer** contêiner do projeto tiver `secretKeyRef` ou `envFrom.secretRef`.

## Diagnóstico controlado

- **Sintoma:** depois de montar o Secret, o pod fica `ContainerCreating`.
- **Hipóteses:** Secret com nome errado ou inexistente (`MountVolume.SetUp failed`).
- **Investigação:** eventos do pod.
- **Reversão:** crie o Secret ou corrija o nome.

## Validação

```bash
ok() { if eval "$2" >/dev/null 2>&1; then echo "OK   $1"; else echo "FALHA $1"; fi; }
N=ac20-loja; P=$(oc get pod -n $N -l app=loja -o jsonpath='{.items[0].metadata.name}')
ok "SA própria"            "[ \"\$(oc get deploy loja -n $N -o jsonpath='{.spec.template.spec.serviceAccountName}')\" = loja ]"
ok "sem token da API"      "[ \"\$(oc get deploy loja -n $N -o jsonpath='{.spec.template.spec.automountServiceAccountToken}')\" = false ]"
ok "token montado 0400"    "oc exec $P -n $N -- sh -c 'stat -Lc %a /etc/loja/token' | grep -q 400"
ok "nada de Secret em env" "! oc get deploy loja -n $N -o json | grep -qE 'secretKeyRef|secretRef'"
ok "default não lê Secret" "[ \"\$(oc auth can-i get secrets -n $N --as=system:serviceaccount:$N:default)\" = no ]"
ok "SCC restricted-v2"     "oc get pod $P -n $N -o jsonpath='{.metadata.annotations.openshift\.io/scc}' | grep -q restricted-v2"
```
