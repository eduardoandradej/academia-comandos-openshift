## Objetivo e indicador de sucesso

Isolar o projeto da loja: só o router e o próprio projeto entram; a loja só sai para o DNS.

**Indicador de sucesso:** validação toda `OK`, inclusive a Route (missão 1) e um pod de outro projeto bloqueado.

## Conceito

> **Missão.** Você recebe **requisitos**, não comandos. Escolha as ferramentas das trilhas anteriores, cumpra todos os
> requisitos dentro do tempo e confira com a **Validação** (autoavaliação: cada linha deve responder `OK`). O gabarito
> mostra **uma** solução; outras que passem na validação são igualmente válidas.

**Requisitos** (projeto `ac20-loja`; use um projeto `ac20-fora` com um pod cliente para o teste negativo):

1. Nenhuma entrada, exceto do próprio projeto e do router, e só na porta 8080.
2. A loja não abre conexões de saída, exceto DNS do cluster.
3. Pod em `ac20-fora` **não** alcança a loja; a Route continua respondendo.
4. Políticas rotuladas; nenhuma política fora do `ac20-loja`.

## Repetições

1. Que políticas da Trilha 16 você reaproveitou? Precisou ajustar seletores?
2. O teste negativo é timeout ou refused? Por quê?
3. A validação da missão 1 continua toda `OK`?
4. Por que a loja precisa de DNS se não abre conexões?
5. Refaça em D+7.

## Desafio sem pista

Escreva o "contrato de rede" da loja como um script que testa 4 caminhos (router ok, próprio projeto ok, `ac20-fora` bloqueado, saída para a internet bloqueada).

## Diagnóstico controlado

- **Sintoma:** a Route voltou a responder 503 depois das políticas.
- **Hipóteses:** router não liberado ou liberado só para `app=loja` com rótulo diferente.
- **Investigação:** NET-007; `podSelector` × rótulos.
- **Reversão:** ajuste a política do router.

## Validação

```bash
ok() { if eval "$2" >/dev/null 2>&1; then echo "OK   $1"; else echo "FALHA $1"; fi; }
N=ac20-loja
ok "Route responde"            "curl -sSk -m 5 https://\$(oc get route loja -n $N -o jsonpath='{.spec.host}')/ | grep -q loja"
ok "outro projeto bloqueado"   "! oc exec fora -n ac20-fora -- timeout 3 bash -c '</dev/tcp/loja.$N.svc/8080'"
ok "loja sem saída externa"    "! oc exec deploy/loja -n $N -- timeout 3 bash -c '</dev/tcp/registry.access.redhat.com/443'"
ok "loja resolve nomes"        "oc exec deploy/loja -n $N -- getent hosts loja"
ok "políticas rotuladas"       "[ \$(oc get networkpolicy -n $N -l academy.openshift.dev/managed-by=academia --no-headers | wc -l) -ge 3 ]"
```
