## Objetivo e indicador de sucesso

Transformar a loja em base + overlays `dev` e `prod`, em projetos próprios, sem duplicar YAML.

**Indicador de sucesso:** `oc apply -k` dos dois overlays cria ambientes que diferem **só** no que foi pedido.

**Requisitos** (projetos `ac20-dev` e `ac20-prod`):

1. `/tmp/ac20/k/base` com a loja (sem namespace, sem Route TLS específica de ambiente).
2. `dev`: 1 réplica, página "dev", rótulo `ambiente=dev`.
3. `prod`: 2 réplicas, página "prod", imagem por **digest**, rótulo `ambiente=prod`.
4. Rótulos sem tocar seletores; página via `configMapGenerator` (rollout automático ao mudar).
5. `diff` das renderizações mostra só réplicas, página/hash, imagem, namespace e rótulo.

## Repetições

1. Mude a página da `dev` e prove o rollout automático só lá.
2. O `diff` das renderizações tem alguma diferença inesperada?
3. Como o digest da `prod` foi escolhido? Está registrado no Git (no arquivo)?
4. Valide cada overlay com `--dry-run=server` antes de aplicar.
5. Refaça em D+7.

## Desafio sem pista

Acrescente um overlay `homolog` herdando de `prod` (não da base), mudando só a página e o namespace, e prove com o `diff`.

## Diagnóstico controlado

- **Sintoma:** `the namespace from the provided object ... does not match`.
- **Hipóteses:** `-n` diferente do `namespace` do overlay (TS-040).
- **Investigação:** `grep namespace overlays/*/kustomization.yaml`.
- **Reversão:** aplique sem `-n`.

## Validação

```bash
ok() { if eval "$2" >/dev/null 2>&1; then echo "OK   $1"; else echo "FALHA $1"; fi; }
K=/tmp/ac20/k/overlays
ok "dev renderiza"          "oc kustomize $K/dev"
ok "prod com digest"        "oc kustomize $K/prod | grep -q '@sha256:'"
ok "prod com 2 réplicas"    "oc kustomize $K/prod | grep -q 'replicas: 2'"
ok "seletores intactos"     "! oc kustomize $K/prod | sed -n '/selector:/,/template:/p' | grep -q ambiente"
ok "dev aplicado e pronto"  "[ \"\$(oc get deploy loja -n ac20-dev -o jsonpath='{.status.readyReplicas}')\" -ge 1 ]"
ok "prod aplicado e pronto" "[ \"\$(oc get deploy loja -n ac20-prod -o jsonpath='{.status.readyReplicas}')\" = 2 ]"
```
