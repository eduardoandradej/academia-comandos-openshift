## Conceito

> **Somente observação.** Nesta trilha nenhum comando altera operadores, `ClusterVersion`, `MachineConfig`, OLM ou
> o nó. Onde aparece uma mudança, ela vem com `--dry-run=server` (validada, não gravada) ou como plano escrito.
> No SNO, mexer nesses objetos pode reiniciar o único nó ou derrubar o cluster.

| Objeto | Onde | Significa |
|---|---|---|
| `CatalogSource` | `openshift-marketplace` | um catálogo (Red Hat, certificados, comunidade) |
| `PackageManifest` | (virtual) | um operador disponível em algum catálogo |
| canal | no pacote | trilha de atualização (`stable`, `stable-4.x`...) |

Catálogos baixam imagens e consomem recursos; em instalações enxutas, alguns podem estar desabilitados (`OperatorHub`).

## Comandos guiados

```bash
oc get catalogsources -n openshift-marketplace
oc get catalogsources -n openshift-marketplace -o json | jq -r '.items[] | "\(.metadata.name)\t\(.status.connectionState.lastObservedState // "?")"'
oc get operatorhub cluster -o jsonpath='{.spec}{"\n"}{.status.sources}{"\n"}'
oc get packagemanifests -n openshift-marketplace --no-headers | wc -l
oc get packagemanifests -n openshift-marketplace | grep -iE 'lvms|nfd|cert-manager' | head
P=$(oc get packagemanifests -n openshift-marketplace -o name | grep -m1 -E 'lvms-operator|cert-manager' | cut -d/ -f2)
oc get packagemanifest "$P" -n openshift-marketplace -o json | jq -r '.status.defaultChannel as $d | .status.channels[] | "\(.name)\(if .name==$d then " (padrão)" else "" end)\t\(.currentCSV)"'
```

## Repetições

1. Quantos pacotes cada catálogo oferece? (`.status.catalogSource` dos PackageManifests)
2. Algum catálogo não está `READY`?
3. O LVM Storage (opção B da Trilha 09) aparece? Em que canal?
4. Como developer, `oc get packagemanifests -n openshift-marketplace` funciona?
5. Leia a descrição curta de um pacote (`.status.channels[0].currentCSVDesc.description`).

## Desafio sem pista

Liste os 10 pacotes do catálogo `redhat-operators` com seu canal padrão e a versão do CSV atual nesse canal.

## Diagnóstico controlado

- **Sintoma:** `oc get packagemanifests` vazio.
- **Hipóteses:** catálogos desabilitados no `OperatorHub` ou pods de catálogo sem conseguir baixar imagens.
- **Investigação:** `oc get operatorhub cluster -o yaml`; `oc get pods -n openshift-marketplace`.
- **Reversão:** decisão de administração (nada a mudar pela Academia).
