## Objetivo e indicador de sucesso

Mostrar que, com LimitRange, pods sem resources passam pela quota (os padrões são preenchidos antes), e que a quota
conta os valores **preenchidos**.

**Indicador de sucesso:** o mesmo `oc run` sem resources é recusado sem LimitRange e aceito com ele, e a quota usada sobe pelos valores padrão.

## Conceito

Ordem simplificada da admissão de um pod:

1. **mutação**: LimitRange preenche requests/limits ausentes; SCC define UID e contexto;
2. **validação**: LimitRange confere min/max/razão; **quota** soma e confere; SCC valida.

Por isso a combinação "quota + LimitRange com padrões" é a baseline da Academia (e da sala de aula).

## Comandos guiados

```bash
oc delete limitrange ac17-limites -n ac17-cotas --ignore-not-found
ac-dev; oc run ac17-x --image=registry.access.redhat.com/ubi9/httpd-24:latest -n ac17-cotas 2>&1 | tail -1; ac-admin                  # must specify
oc apply -f manifests/admin/limitrange-completo.yaml -n ac17-cotas
oc get resourcequota ac17-computacao -n ac17-cotas -o jsonpath='{.status.used}{"\n"}'
ac-dev; oc run ac17-x --image=registry.access.redhat.com/ubi9/httpd-24:latest -n ac17-cotas; ac-admin                                # aceito
sleep 5; oc get resourcequota ac17-computacao -n ac17-cotas -o jsonpath='{.status.used}{"\n"}'   # +25m / +32Mi / +100m / +128Mi
```

## Repetições

1. Que valores a quota contou para o `ac17-x`? Batem com o `defaultRequest`/`default`?
2. Quantos pods sem resources cabem agora? (requests.cpu 300m ÷ 25m, limitado por `pods: 4`)
3. Crie pods até a recusa e leia qual limite bateu primeiro.
4. Compare com a baseline da Academia (`manifests/baseline-seguro/quota-limitrange.yaml`).
5. Explique a ordem da admissão de memória.

## Desafio sem pista

Descubra, só com leitura, qual limite vai recusar o próximo pod sem resources no `ac17-cotas` — antes de tentar criá-lo.

## Diagnóstico controlado

- **Sintoma:** o LimitRange existe, mas pods continuam recusados por `must specify`.
- **Hipóteses:** o LimitRange não tem `default`/`defaultRequest` para o recurso que a quota limita.
- **Investigação:** `oc describe limitrange` × `oc describe quota`.
- **Reversão:** acrescente o padrão que falta (admin).

## Validação

```bash
oc get pod ac17-x -n ac17-cotas -o jsonpath='{.spec.containers[0].resources.limits.cpu}{"\n"}'    # 100m
```

## Limpeza segura

```bash
oc delete pod ac17-x -n ac17-cotas --ignore-not-found
```
