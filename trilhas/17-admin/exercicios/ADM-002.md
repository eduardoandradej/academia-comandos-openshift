## Objetivo e indicador de sucesso

Montar o ranking de projetos por CPU/memória reservadas e usadas, e listar pods sem requests (`BestEffort`).

**Indicador de sucesso:** uma tabela "projeto → requests CPU, requests memória, uso" com os 10 maiores.

## Conceito

Os componentes do OpenShift reservam a maior parte do SNO; os projetos `ac*` ficam com o resto. Pods `BestEffort`
(sem requests nem limits) não reservam nada e são os primeiros despejados sob pressão.

## Comandos guiados

```bash
oc get pods -A -o json | jq -r '
  def cpu: if . == null then 0 elif test("m$") then (.[:-1]|tonumber) else (tonumber*1000) end;
  def mem: if . == null then 0 elif test("Mi$") then (.[:-2]|tonumber) elif test("Gi$") then (.[:-2]|tonumber*1024)
           elif test("Ki$") then (.[:-2]|tonumber/1024) else (tonumber/1048576) end;
  [.items[] | select(.status.phase=="Running") | {ns: .metadata.namespace, c: ([.spec.containers[].resources.requests.cpu | cpu] | add),
   m: ([.spec.containers[].resources.requests.memory | mem] | add)}]
  | group_by(.ns) | map({ns: .[0].ns, cpu: (map(.c)|add), mem: (map(.m)|add|floor)}) | sort_by(-.cpu) | .[:10][]
  | "\(.ns)\t\(.cpu)m\t\(.mem)Mi"' | column -t
oc adm top pods -A --sort-by=memory 2>/dev/null | head -10
oc get pods -A -o json | jq -r '.items[] | select(.status.qosClass=="BestEffort") | "\(.metadata.namespace)/\(.metadata.name)"' | head
```

## Repetições

1. Que fração do total reservado pertence a `openshift-*`?
2. Algum projeto `ac*` aparece no ranking? Com quanto?
3. Liste os pods `BestEffort` dos seus projetos.
4. Ordene por uso real (`oc adm top pods -A --sort-by=cpu`).
5. Compare reservado × usado para `openshift-monitoring`.

## Desafio sem pista

Para os projetos `ac*`, calcule a razão uso/reserva de CPU e aponte os superdimensionados (uso < 20% do request).

## Diagnóstico controlado

- **Sintoma:** `oc adm top pods -A` responde `metrics not available`.
- **Hipóteses:** Metrics API indisponível (RES-002).
- **Investigação:** `oc get apiservice v1beta1.metrics.k8s.io`.
- **Reversão:** use só os requests (que não dependem de métricas).

## Validação

oc get pods -A -o json | jq '[.items[] | select(.status.qosClass=="BestEffort")] | length'
