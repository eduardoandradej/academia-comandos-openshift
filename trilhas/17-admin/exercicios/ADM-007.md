# ADM-007 — ClusterResourceQuota: uma cota para vários projetos

## Identificação

- **ID:** ADM-007
- **Trilha:** [17 — Administração de recursos](../README.md)
- **Referência didática:** DO280 — cotas multiprojeto.
- **Fichas de comando:** [`oc-quota-limitrange`](../../../catalogo/fichas/oc-quota-limitrange.md)
- **Status:** proposto — escrito e revisado estaticamente; ainda não executado contra o cluster pelo autor

## Objetivo e indicador de sucesso

Criar uma ClusterResourceQuota que vale para todos os projetos com um rótulo, e ver o consumo de um projeto reduzir o que sobra para o outro.

**Indicador de sucesso:** dois projetos `ac17-equipe-a/b` dividem 3 pods; o terceiro pod de qualquer um deles é recusado.

## Nível

**Nível:** Avançado

## Duração e repetições

- **Duração sugerida:** 20 min
- **Repetições:** 3×

## Contexto

- **Terminal:** `student@ocp-admin`, na raiz do repositório clonado (`cd ~/academia-comandos-openshift`)
- **Perfil:** `admin` (e `developer` para ler a cota aplicada)
- **Projeto:** `ac17-equipe-a`, `ac17-equipe-b`
- **Impacto:** MUTAÇÃO DE CLUSTER (1 ClusterResourceQuota rotulada) · MUTAÇÃO LOCAL

## Pré-flight

```bash
source scripts/perfis.sh && ac-admin
oc whoami                            # admin
scripts/preflight.sh                 # sem FALHA; memória do nó abaixo de 85%
```

## Conceito

> **Perfil admin, escopo de treino.** Os exercícios usam o perfil `admin`, mas só criam objetos em projetos `ac17-*`
> ou objetos de cluster rotulados `academy.openshift.dev/trilha=17`. Nada em `openshift-*`, `kube-*`, nó ou rede.

A **ClusterResourceQuota** (OpenShift) seleciona projetos por rótulo (ou por anotação, como
`openshift.io/requester`) e soma o uso de **todos** eles. Cada projeto selecionado vê a cota como
`AppliedClusterResourceQuota` (`oc describe appliedclusterresourcequota -n <projeto>`), inclusive o developer.

## Comandos guiados

```bash
oc apply -f manifests/admin/clusterresourcequota-ac17.yaml
for p in ac17-equipe-a ac17-equipe-b; do
  oc new-project "$p" --skip-config-write >/dev/null 2>&1 || true
  oc label namespace "$p" academy.openshift.dev/equipe=ac17 academy.openshift.dev/managed-by=academia --overwrite
  oc apply -f manifests/admin/limitrange-completo.yaml -n "$p"
  oc policy add-role-to-user admin developer -n "$p"
done
sleep 5; oc describe clusterresourcequota ac17-equipe
ac-dev
oc run p1 --image=registry.access.redhat.com/ubi9/httpd-24:latest -n ac17-equipe-a; oc run p2 --image=registry.access.redhat.com/ubi9/httpd-24:latest -n ac17-equipe-a
oc run p3 --image=registry.access.redhat.com/ubi9/httpd-24:latest -n ac17-equipe-b
oc run p4 --image=registry.access.redhat.com/ubi9/httpd-24:latest -n ac17-equipe-b 2>&1 | tail -1                    # exceeded quota: ac17-equipe
oc describe appliedclusterresourcequota -n ac17-equipe-b
ac-admin
```

## Repetições

1. Como developer, `oc get clusterresourcequota` funciona? E `appliedclusterresourcequota`?
2. Retire o rótulo de um projeto: a cota deixa de valer para ele? O uso total cai?
3. Use o seletor por anotação `openshift.io/requester: developer` (todos os projetos que o developer criou) — só em dry-run.
4. A CRQ e as quotas do projeto valem ao mesmo tempo?
5. Compare com a quota por projeto (ADM-003).

## Desafio sem pista

Escreva (sem aplicar) a ClusterResourceQuota "todos os projetos que o developer criar podem ter no máximo 10 pods
somados", e valide com `--dry-run=server`.

## Diagnóstico controlado

- **Sintoma:** um projeto novo, vazio, recusa o primeiro pod com `exceeded quota: ac17-equipe`.
- **Hipóteses:** a cota é compartilhada e outro projeto da equipe já a consumiu.
- **Investigação:** `oc describe clusterresourcequota ac17-equipe` (uso por namespace).
- **Reversão:** libere pods no outro projeto ou ajuste a CRQ. Veja TS-053.

## Validação

```bash
oc get clusterresourcequota ac17-equipe -o jsonpath='{.status.total.used.pods}/{.status.total.hard.pods}{"\n"}'    # 3/3
```

## Limpeza segura

```bash
oc delete project ac17-equipe-a ac17-equipe-b --ignore-not-found
```

A ClusterResourceQuota `ac17-equipe` é removida no ADM-015.
