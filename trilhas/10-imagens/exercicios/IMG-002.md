# IMG-002 — Que imagem está rodando de verdade

## Identificação

- **ID:** IMG-002
- **Trilha:** [10 — Imagens e registries](../README.md)
- **Referência didática:** DO180 — imagens de contêiner (tags e digests).
- **Fichas de comando:** [`oc-image-imagestream`](../../../catalogo/fichas/oc-image-imagestream.md), [`oc-get`](../../../catalogo/fichas/oc-get.md)
- **Status:** proposto — escrito e revisado estaticamente; ainda não executado contra o cluster pelo autor

## Objetivo e indicador de sucesso

Comparar a imagem **pedida** (`spec`) com a **executada** (`status.containerStatuses[].imageID`) e descobrir quando elas divergem.

**Indicador de sucesso:** você mostra o digest em execução de um pod criado com `:latest` e compara com o digest atual da tag.

## Conceito

| Campo | O que mostra |
|---|---|
| `spec.containers[].image` | o que foi pedido (pode ser tag) |
| `status.containerStatuses[].image` | a imagem resolvida pelo runtime |
| `status.containerStatuses[].imageID` | **digest** do que está rodando |

Se a tag `latest` foi atualizada no registry depois que o pod nasceu, o pod continua no digest antigo até ser recriado.

## Comandos guiados

```bash
NSX=ac10-imagens; oc get project $NSX >/dev/null 2>&1 || oc new-project $NSX
oc run ac10-um --image=registry.access.redhat.com/ubi9/httpd-24:latest -n $NSX --labels=academy.openshift.dev/managed-by=academia
oc wait --for=condition=Ready pod/ac10-um -n $NSX --timeout=120s
oc get pod ac10-um -n $NSX -o jsonpath='pedido:  {.spec.containers[0].image}{"\n"}rodando: {.status.containerStatuses[0].imageID}{"\n"}'
oc image info registry.access.redhat.com/ubi9/httpd-24:latest -o json | jq -r .digest
oc get pods -n $NSX -o custom-columns=POD:.metadata.name,PEDIDO:.spec.containers[0].image,DIGEST:.status.containerStatuses[0].imageID
```

## Repetições

1. Rode a mesma coluna para todos os seus projetos `ac*` (um por vez).
2. O digest em execução bate com o digest atual da tag? Se não, por quê?
3. Crie um pod pelo digest (`imagem@sha256:...`) e compare as colunas.
4. Encontre a imagem dos init containers (`initContainerStatuses`).
5. (admin, leitura) Quais imagens diferentes rodam no projeto `openshift-console`? Só leitura.

## Desafio sem pista

Liste os pods de um projeto cujo digest em execução é **diferente** do digest atual da tag pedida no registry.

## Diagnóstico controlado

- **Sintoma:** dois pods do mesmo Deployment com `:latest` rodam digests diferentes.
- **Hipóteses:** a tag mudou no registry entre a criação de um pod e a do outro (`imagePullPolicy: Always`).
- **Investigação:** coluna `DIGEST` acima; idade dos pods.
- **Reversão:** fixe a imagem por digest (DEP-005) ou use ImageStream (IMG-005) para controlar quando a tag muda.

## Validação

```bash
oc get pod ac10-um -n ac10-imagens -o jsonpath='{.status.containerStatuses[0].imageID}{"\n"}' | grep -q '@sha256:' && echo OK
```

## Limpeza segura

```bash
oc delete pod ac10-um ac10-digest -n ac10-imagens --ignore-not-found
```
