# IMG-013 — oc new-app a partir de ImageStream

## Identificação

- **ID:** IMG-013
- **Trilha:** [10 — Imagens e registries](../README.md)
- **Referência didática:** DO180 — implantação de aplicações (new-app).
- **Fichas de comando:** [`oc-image-imagestream`](../../../catalogo/fichas/oc-image-imagestream.md)
- **Status:** proposto — escrito e revisado estaticamente; ainda não executado contra o cluster pelo autor

## Objetivo e indicador de sucesso

Criar uma aplicação com `oc new-app` a partir da `ac10-web:prod` e identificar o que o comando gerou (Deployment com
gatilho, Service, rótulos).

**Indicador de sucesso:** você lista todos os objetos gerados por `new-app` e mostra que o Deployment já nasceu com gatilho de imagem.

## Nível

**Nível:** Intermediário

- **Duração sugerida:** 15 min
- **Repetições:** 3×

## Conceito

`oc new-app --image-stream=ac10-web:prod --name=X` cria um Deployment que usa a istag e **já** configura o gatilho de
imagem, além de um Service para as portas expostas pela imagem. `--dry-run -o yaml` mostra tudo antes de criar.

## Comandos guiados

```bash
oc new-app --image-stream=ac10-web:prod --name=ac10-novo -l academy.openshift.dev/managed-by=academia -n ac10-imagens --dry-run -o yaml | grep -E '^(kind|  name)|kind: ' | head
oc new-app --image-stream=ac10-web:prod --name=ac10-novo -l academy.openshift.dev/managed-by=academia -n ac10-imagens
oc get all -n ac10-imagens -l app=ac10-novo
oc set triggers deployment/ac10-novo -n ac10-imagens
oc get svc ac10-novo -n ac10-imagens -o jsonpath='{.spec.ports}{"\n"}'
oc rollout status deployment/ac10-novo -n ac10-imagens
```

## Repetições

1. Compare o Deployment do `new-app` com o do `oc create deployment` (IMG-007): diferenças?
2. Que rótulos e anotações o `new-app` acrescentou?
3. Gere com `--dry-run -o yaml > /tmp/ac10-novo.yaml` e revise antes de criar.
4. Apague tudo pelo rótulo `app=ac10-novo`.
5. Use `oc new-app --image=registry.access.redhat.com/ubi9/httpd-24:latest` (sem ImageStream): o que muda?

## Desafio sem pista

Com `oc new-app` usando `--image`, o comando cria um ImageStream? Descubra (dry-run) e explique quando cria e quando não cria.

## Diagnóstico controlado

- **Sintoma:** `error: unable to locate any images in image streams with name "ac10-wb"`.
- **Hipóteses:** nome do ImageStream errado ou em outro projeto.
- **Investigação:** `oc get is -n ac10-imagens`.
- **Reversão:** nada foi criado; corrija o nome.

## Validação

```bash
oc set triggers deployment/ac10-novo -n ac10-imagens | grep -q 'ac10-web:prod' && echo "gatilho automático"
```

## Limpeza segura

```bash
oc delete all -l app=ac10-novo -n ac10-imagens
```
