# IMG-001 — Anatomia de uma referência de imagem

## Identificação

- **ID:** IMG-001

- **Fichas de comando:** [`oc-image-imagestream`](../../../catalogo/fichas/oc-image-imagestream.md)

## Objetivo e indicador de sucesso

Decompor qualquer referência de imagem em registry, repositório, tag e digest, e consultar seus metadados sem baixá-la.

**Indicador de sucesso:** para três referências, você diz o registry, o repositório, a tag e o digest correspondente.

## Conceito

```text
registry.access.redhat.com / ubi9/httpd-24 : latest @ sha256:3f1c...
└──────── registry ──────┘   └ repositório ┘  └ tag ┘  └─ digest ─┘
```

| Parte | Significado | Muda? |
|---|---|---|
| registry | servidor | — |
| repositório | "nome" da imagem (pode ter vários níveis) | — |
| tag | rótulo legível (`latest`, `1-345`) | **sim**: pode passar a apontar para outra imagem |
| digest | hash do manifesto | **nunca**: identifica o conteúdo |

Sem registry, o CRI-O tenta os `unqualified-search-registries` do nó — evite nomes curtos (TS-031).
`oc image info` lê o manifesto e a configuração direto do registry, sem baixar camadas.

## Comandos guiados

```bash
oc image info registry.access.redhat.com/ubi9/httpd-24:latest
oc image info registry.access.redhat.com/ubi9/httpd-24:latest -o json | jq -r '.digest, .config.config.User, (.config.config.ExposedPorts | keys | join(","))'
oc image info registry.access.redhat.com/ubi9/ubi-minimal:latest --filter-by-os=linux/amd64 | head -12
oc image info registry.access.redhat.com/ubi9/httpd-24:latest --show-multiarch 2>/dev/null | grep -E 'OS|Arch|Digest' | head
D=$(oc image info registry.access.redhat.com/ubi9/httpd-24:latest -o json | jq -r .digest); echo "registry.access.redhat.com/ubi9/httpd-24@$D"
oc image info "registry.access.redhat.com/ubi9/httpd-24@$D" | head -5
```

## Repetições

1. Decomponha `quay.io/redhattraining/hello-world-nginx:v1.0` e `nginx` (o que falta neste?).
2. Compare o tamanho total da imagem (`Size`) de `httpd-24` e `ubi-minimal`.
3. Quantas camadas cada uma tem? (`-o json | jq '.layers | length'`)
4. Repita a consulta por digest: o resultado mudou?
5. Leia o campo `Created` e explique por que `latest` "envelhece" sem mudar de nome.

## Desafio sem pista

Mostre, com um único comando, a lista de variáveis de ambiente e o comando de entrada (`Entrypoint`/`Cmd`) declarados
na imagem `httpd-24`.

## Diagnóstico controlado

- **Sintoma:** `error: unable to read image ...: manifest unknown`.
- **Hipóteses:** (a) tag inexistente; (b) repositório errado; (c) registry exige login.
- **Investigação:** troque a tag por `latest`; confira o nome do repositório no catálogo do registry; leia a mensagem (`unauthorized` = credencial).
- **Reversão:** nada a reverter (consulta).

## Validação

```bash
oc image info registry.access.redhat.com/ubi9/httpd-24:latest -o json | jq -r .digest | grep -q '^sha256:' && echo OK
```
