## Conceito

| Campo da imagem | Por que importa no OpenShift |
|---|---|
| `User` | a SCC `restricted-v2` ignora e usa um UID arbitrário; imagens que exigem root (`User: 0` e escrita em `/`) falham |
| `ExposedPorts` | porta típica do Service; portas < 1024 exigem privilégio |
| `Volumes` | caminhos que viram `emptyDir` anônimo se nada for montado |
| `WorkingDir`, `Entrypoint`, `Cmd` | o que roda e de onde |
| `Labels` | origem, versão, mantenedor (`io.openshift.*`, `com.redhat.*`) |

## Comandos guiados

```bash
for img in registry.access.redhat.com/ubi9/httpd-24:latest registry.access.redhat.com/ubi9/ubi-minimal:latest docker.io/library/nginx:latest; do
  echo "== $img"
  oc image info "$img" --filter-by-os=linux/amd64 -o json 2>/dev/null \
    | jq -c '.config.config | {User, ExposedPorts, Volumes, WorkingDir, Entrypoint, Cmd}'
done
oc image info registry.access.redhat.com/ubi9/httpd-24:latest -o json | jq -r '.config.config.Labels | to_entries[] | select(.key|test("^(name|version|release|io.openshift.expose-services)$")) | "\(.key)=\(.value)"'
```

## Repetições

1. Por que `nginx` (Docker Hub) escuta na 80 e o que isso causa com a SCC `restricted-v2`?
2. Encontre o rótulo `io.openshift.expose-services` da `httpd-24`: que portas ele anuncia?
3. A `ubi-minimal` declara `Cmd`? O que o pod faria sem `command`?
4. Compare `User` da `httpd-24` (1001) com o UID que o pod recebe (`oc exec ... id`).
5. Faça o mesmo para uma imagem que você usa no trabalho.

## Desafio sem pista

Monte uma "ficha de compatibilidade" de uma linha para cada imagem: `porta<1024?`, `user root?`, `volumes declarados`.

## Diagnóstico controlado

- **Sintoma:** imagem do Docker Hub em `CrashLoopBackOff` com `bind() to 0.0.0.0:80 failed (13: Permission denied)`.
- **Hipóteses:** porta privilegiada sem capability `NET_BIND_SERVICE`, UID não root.
- **Investigação:** `ExposedPorts` e `User` da imagem; `oc logs --previous`.
- **Reversão:** use uma imagem preparada para UID arbitrário (ex.: `nginxinc/nginx-unprivileged`, porta 8080) — não peça `anyuid`.

## Validação

```bash
oc image info registry.access.redhat.com/ubi9/httpd-24:latest -o json | jq -e '.config.config.ExposedPorts | has("8080/tcp")' >/dev/null && echo "8080 exposta"
```
