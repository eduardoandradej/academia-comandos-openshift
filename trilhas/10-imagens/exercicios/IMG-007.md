# IMG-007 — Usar ImageStream em Deployment: image-lookup

## Identificação

- **ID:** IMG-007
- **Trilha:** [10 — Imagens e registries](../README.md)
- **Referência didática:** DO180 — ImageStreams em workloads.
- **Fichas de comando:** [`oc-image-imagestream`](../../../catalogo/fichas/oc-image-imagestream.md)
- **Status:** proposto — escrito e revisado estaticamente; ainda não executado contra o cluster pelo autor

## Objetivo e indicador de sucesso

Fazer um Deployment usar `image: ac10-web:prod` (nome curto do ImageStream) com `oc set image-lookup` e ver a resolução.

**Indicador de sucesso:** o pod roda com o digest da `ac10-web:prod`, embora o Deployment diga só `ac10-web:prod`.

## Conceito

Por padrão, `image: ac10-web:prod` em um Deployment seria tratado como nome curto de registry (falha, TS-031).
`oc set image-lookup ac10-web` liga `spec.lookupPolicy.local: true`: a admissão troca o nome curto pela referência
completa registrada na istag (digest) ao criar o pod.

## Comandos guiados

```bash
oc set image-lookup ac10-web -n ac10-imagens
oc set image-lookup -n ac10-imagens                         # lista o estado de todos os ImageStreams
oc create deployment ac10-app --image=ac10-web:prod -n ac10-imagens
oc label deployment ac10-app academy.openshift.dev/managed-by=academia -n ac10-imagens
oc rollout status deployment/ac10-app -n ac10-imagens
oc get deployment ac10-app -n ac10-imagens -o jsonpath='{.spec.template.spec.containers[0].image}{"\n"}'   # ac10-web:prod
oc get pod -n ac10-imagens -l app=ac10-app -o jsonpath='{.items[0].spec.containers[0].image}{"\n"}'        # referência completa
```

## Repetições

1. Desligue o lookup (`oc set image-lookup ac10-web --enabled=false`) e recrie o pod: o que acontece? (TS-031)
2. Religue e confira.
3. Crie um pod solto com `--image=ac10-web:v1`: o lookup vale para pods também?
4. Mude `prod` para outro digest: o pod atual muda? E um pod novo?
5. `oc get is ac10-web -o jsonpath='{.spec.lookupPolicy}'`.

## Desafio sem pista

Explique (e demonstre) por que mudar a tag `prod` **não** atualiza o Deployment existente, mesmo com image-lookup — e
o que é necessário para atualizar.

## Diagnóstico controlado

- **Sintoma:** pod em `ErrImagePull` com `image: ac10-web:prod` e mensagem sobre nome curto / `docker.io/library/ac10-web`.
- **Hipóteses:** `lookupPolicy.local` desligado; nome do ImageStream errado; ImageStream em outro projeto.
- **Investigação:** `oc set image-lookup -n ac10-imagens`; `oc get istag -n ac10-imagens`.
- **Reversão:** `oc set image-lookup ac10-web -n ac10-imagens`; apague o pod para recriá-lo. Veja TS-031.

## Validação

```bash
oc get pod -n ac10-imagens -l app=ac10-app -o jsonpath='{.items[0].spec.containers[0].image}{"\n"}' | grep -q '@sha256:' && echo "resolvido por digest"
```
