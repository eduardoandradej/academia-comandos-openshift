## Conceito

`oc tag <externa> ac10-web:auto --scheduled` faz o cluster reconsultar a origem periodicamente (intervalo do cluster,
tipicamente ~15 min). Se o digest mudou, a istag muda — e um gatilho de imagem faria **deploy automático de algo que
ninguém testou**. Use com cuidado; prefira promoção explícita (IMG-008).

| `referencePolicy` | Pods baixam de | Requisito |
|---|---|---|
| `Source` (padrão) | registry original, por digest | nenhum |
| `Local` | registry interno (pull-through) | registry interno ativo — **REQUER PREPARAÇÃO** (IMG-010) |

## Comandos guiados

```bash
oc tag registry.access.redhat.com/ubi9/ubi-minimal:latest ac10-web:auto --scheduled -n ac10-imagens
oc get is ac10-web -n ac10-imagens -o json | jq '.spec.tags[] | select(.name=="auto") | {importPolicy, referencePolicy}'
oc describe is ac10-web -n ac10-imagens | grep -A3 '^auto'
oc tag registry.access.redhat.com/ubi9/ubi-minimal:latest ac10-web:auto -n ac10-imagens     # sem --scheduled: desliga
oc get is ac10-web -n ac10-imagens -o json | jq '.spec.tags[] | select(.name=="auto") | .importPolicy'
oc tag -d ac10-web:auto -n ac10-imagens
```

## Repetições

1. (admin, leitura) `oc get image.config.openshift.io cluster -o jsonpath='{.spec.imageStreamImportMode}{"\n"}'` e a configuração de importação agendada.
2. Por que importação agendada + gatilho + `latest` é uma combinação arriscada?
3. Crie uma tag com `--reference-policy=local` e leia o status (o que falta?).
4. `oc import-image --help | grep -E 'scheduled|reference-policy|import-mode'`.
5. Explique quando a importação agendada é útil (ex.: imagem base com correções de segurança + pipeline de teste).

## Desafio sem pista

Liste todas as tags dos ImageStreams do projeto com importação agendada ligada (para auditoria).

## Diagnóstico controlado

- **Sintoma:** pods de um Deployment com gatilho mudaram de versão de madrugada, sem ninguém fazer deploy.
- **Hipóteses:** tag com `--scheduled` + gatilho de imagem.
- **Investigação:** `importPolicy` das tags; `oc rollout history`; eventos do ImageStream.
- **Reversão:** desligue o agendamento (`oc tag` sem `--scheduled`) e use promoção explícita.

## Validação

```bash
oc get is ac10-web -n ac10-imagens -o json | jq -e '[.spec.tags[] | select(.importPolicy.scheduled==true)] | length == 0' >/dev/null && echo "sem agendamentos"
```

## Limpeza segura

```bash
oc tag -d ac10-web:auto ac10-web:local -n ac10-imagens 2>/dev/null || true
```
