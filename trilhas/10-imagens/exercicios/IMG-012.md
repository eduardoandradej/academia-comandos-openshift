# IMG-012 — Extrair um arquivo de uma imagem sem rodá-la

## Identificação

- **ID:** IMG-012
- **Trilha:** [10 — Imagens e registries](../README.md)
- **Referência didática:** DO180 — imagens de contêiner (inspeção).
- **Fichas de comando:** [`oc-image-imagestream`](../../../catalogo/fichas/oc-image-imagestream.md)
- **Status:** proposto — escrito e revisado estaticamente; ainda não executado contra o cluster pelo autor

## Objetivo e indicador de sucesso

Copiar um arquivo de configuração de dentro de uma imagem para a `ocp-admin` com `oc image extract`, sem criar pods.

**Indicador de sucesso:** `/tmp/ac10/httpd.conf` existe e você encontra nele a diretiva `Listen`.

## Nível

**Nível:** Intermediário

- **Duração sugerida:** 10 min

## Pré-flight

```bash
source scripts/perfis.sh && ac-dev

```

```bash
df -h /tmp     # a extração percorre as camadas da imagem (~100-150 MB transferidos)
```

## Conceito

`oc image extract <imagem> --path <caminho-na-imagem>:<diretório-local>` lê as camadas e grava só os arquivos
pedidos. Útil para ler configuração padrão (e decidir o que sobrepor com ConfigMap, Trilha 08) sem executar nada.

## Comandos guiados

```bash
mkdir -p /tmp/ac10
oc image extract registry.access.redhat.com/ubi9/httpd-24:latest --path /etc/httpd/conf/httpd.conf:/tmp/ac10 --filter-by-os=linux/amd64 --confirm
ls -l /tmp/ac10
grep -nE '^(Listen|DocumentRoot|User|Group|IncludeOptional)' /tmp/ac10/httpd.conf
```

## Repetições

1. Extraia o diretório `/etc/httpd/conf.d/` inteiro e liste os arquivos.
2. Confirme o `DocumentRoot` que você usou nas trilhas 06 e 08.
3. Extraia `/etc/os-release` da `ubi-minimal`.
4. Compare o tempo da extração da `ubi-minimal` com o da `httpd-24`.
5. `oc image extract --help | grep -E -- '--path|--only-files|--confirm'`.

## Desafio sem pista

Descubra, só por extração, quais módulos do httpd são carregados por padrão na imagem (arquivos `conf.modules.d`).

## Diagnóstico controlado

- **Sintoma:** `error: directory /tmp/ac10 is not empty, pass --confirm to overwrite`.
- **Hipóteses:** proteção contra sobrescrita.
- **Investigação:** `ls /tmp/ac10`.
- **Reversão:** use outro diretório ou `--confirm`.

## Validação

```bash
grep -q '^Listen' /tmp/ac10/httpd.conf && echo OK
```

## Limpeza segura

```bash
rm -rf /tmp/ac10
```
