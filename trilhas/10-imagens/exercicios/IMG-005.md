## Conceito

Um **ImageStream** é um catálogo de tags dentro do projeto. Cada tag (`ImageStreamTag`, `istag`) aponta para uma
imagem por **digest**, com histórico. Vantagens: o projeto decide quando a tag muda (reimportação), Deployments podem
reagir à mudança (IMG-008) e o nome curto `ac10-web:v1` fica estável.

Sem registry interno (HomeLab), use a política de referência padrão `Source`: os pods continuam baixando do registry
original, pelo digest registrado. A política `Local` (cópia via registry interno) **REQUER PREPARAÇÃO** (IMG-010).

## Comandos guiados

```bash
oc create imagestream ac10-web -n ac10-imagens
oc label imagestream ac10-web academy.openshift.dev/managed-by=academia -n ac10-imagens
oc import-image ac10-web:v1 --from=registry.access.redhat.com/ubi9/httpd-24:latest --confirm -n ac10-imagens
oc get imagestream ac10-web -n ac10-imagens
oc get istag -n ac10-imagens
oc describe imagestream ac10-web -n ac10-imagens | sed -n '1,25p'
oc get istag ac10-web:v1 -n ac10-imagens -o jsonpath='{.image.dockerImageReference}{"\n"}'
oc get imagestream ac10-web -n ac10-imagens -o jsonpath='{.spec.tags[0].referencePolicy.type}{"\n"}'   # Source
```

## Repetições

1. Importe também `ac10-web:minimal` a partir de `ubi-minimal:latest`.
2. Rode `oc import-image ac10-web:v1 -n ac10-imagens` de novo: o histórico ganhou item? (só se o digest mudou)
3. `oc get istag ac10-web:v1 -o yaml | grep -A3 dockerImageMetadata` (metadados copiados).
4. `oc explain imagestream.spec.tags`.
5. Por que `status.dockerImageRepository` está vazio no HomeLab?

## Desafio sem pista

Prove que o digest guardado em `ac10-web:v1` é o mesmo que `oc image info` mostra para a origem, sem copiar valores à mão.

## Diagnóstico controlado

- **Sintoma:** `oc import-image` responde `error: tag v1 failed: ... manifest unknown` (ou `Import failed`).
- **Hipóteses:** referência de origem errada (tag/repo) ou registry inacessível a partir do cluster.
- **Investigação:** `oc describe is ac10-web` (condição `ImportSuccess`); `oc image info <origem>` na `ocp-admin`.
- **Reversão:** `oc tag -d ac10-web:v1 -n ac10-imagens` e importe de novo com a referência correta.

## Validação

```bash
oc get istag ac10-web:v1 -n ac10-imagens -o jsonpath='{.image.metadata.name}{"\n"}' | grep -q '^sha256:' && echo OK
```
