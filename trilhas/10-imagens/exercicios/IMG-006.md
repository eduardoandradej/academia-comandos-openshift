## Objetivo e indicador de sucesso

Usar `oc tag` para promover imagens entre tags (`v1` → `prod`), criar alias que seguem outra tag e remover tags.

**Indicador de sucesso:** `prod` aponta para o digest de `v1`; `atual` é um alias que acompanha `v1`; `minimal` foi apagada.

## Conceito

| Comando | Efeito |
|---|---|
| `oc tag ac10-web:v1 ac10-web:prod` | `prod` passa a apontar para a **imagem atual** de `v1` (cópia do digest) |
| `oc tag --alias ac10-web:v1 ac10-web:atual` | `atual` **segue** `v1`: muda quando `v1` mudar |
| `oc tag <externa> ac10-web:x` | tag aponta para uma imagem externa (como `import-image`) |
| `oc tag -d ac10-web:x` | apaga a tag |

Promover por `oc tag` é o fluxo "testei a v1, agora é a prod" sem rebuild nem novo pull.

## Comandos guiados

```bash
oc tag ac10-web:v1 ac10-web:prod -n ac10-imagens
oc tag --alias ac10-web:v1 ac10-web:atual -n ac10-imagens
oc tag registry.access.redhat.com/ubi9/ubi-minimal:latest ac10-web:minimal -n ac10-imagens
oc get istag -n ac10-imagens -o custom-columns=TAG:.metadata.name,DIGEST:.image.metadata.name
oc get imagestream ac10-web -n ac10-imagens -o json | jq -r '.spec.tags[] | "\(.name) <- \(.from.kind) \(.from.name)"'
oc tag -d ac10-web:minimal -n ac10-imagens
oc get istag -n ac10-imagens
```

## Repetições

1. Aponte `v1` para `ubi-minimal`: o que acontece com `prod` e com `atual`?
2. Volte `v1` para a `httpd-24`.
3. Crie a tag `rollback` a partir do histórico (`oc tag ac10-web@sha256:... ac10-web:rollback`).
4. Liste o histórico de `v1` (`oc get is ac10-web -o jsonpath='{.status.tags[?(@.tag=="v1")].items[*].image}'`).
5. Apague e recrie as tags de memória.

## Desafio sem pista

Faça a tag `prod` voltar para o digest **anterior** de `v1` (pelo histórico do ImageStream), sem digitar o digest à mão.

## Diagnóstico controlado

- **Sintoma:** depois de mudar `v1`, a `prod` "não acompanhou".
- **Hipóteses:** `oc tag` sem `--alias` copia a referência no momento; não segue.
- **Investigação:** `.spec.tags[]` — `from.kind` `ImageStreamImage` (cópia) × `ImageStreamTag` (alias).
- **Reversão:** é o comportamento desejado para promoção; use `--alias` só quando quiser acompanhar.

## Validação

```bash
[ "$(oc get istag ac10-web:prod -n ac10-imagens -o jsonpath='{.image.metadata.name}')" = \
  "$(oc get istag ac10-web:v1 -n ac10-imagens -o jsonpath='{.image.metadata.name}')" ] && echo "prod = v1"
```

## Limpeza segura

```bash
oc tag -d ac10-web:rollback ac10-web:minimal -n ac10-imagens 2>/dev/null || true
```
