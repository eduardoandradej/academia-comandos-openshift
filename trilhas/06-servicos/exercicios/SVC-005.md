## Conceito

Todo Service ganha o registro `<svc>.<ns>.svc.cluster.local`. O `resolv.conf` dos pods tem uma lista `search`:

```text
search ac06-servicos.svc.cluster.local svc.cluster.local cluster.local
```

Por isso `web-azul` (curto) resolve **no mesmo namespace**, e `web-azul.ac06-servicos` resolve de qualquer lugar. O
Service `kubernetes` em `default` aponta para a API e existe em todo cluster. No OpenShift, o DNS é servido pelo
operador de DNS (`openshift-dns`) — só leitura.

## Comandos guiados

```bash
oc exec ac06-cliente -n ac06-servicos -- cat /etc/resolv.conf
oc exec ac06-cliente -n ac06-servicos -- getent hosts web-azul
oc exec ac06-cliente -n ac06-servicos -- getent hosts web-azul.ac06-servicos.svc.cluster.local
oc exec ac06-cliente -n ac06-servicos -- getent hosts kubernetes.default.svc.cluster.local      # a API
oc exec ac06-cliente -n ac06-servicos -- getent hosts dns-default.openshift-dns.svc.cluster.local   # o próprio DNS
oc exec ac06-cliente -n ac06-servicos -- getent hosts nao-existe || echo "não resolve (código $?)"
oc get svc web-azul -n ac06-servicos -o jsonpath='{.spec.clusterIP}{"\n"}'                     # mesmo IP do getent
```

## Repetições

1. Leia o `nameserver` do `resolv.conf` e compare com `oc get svc -n openshift-dns` (perfil admin, leitura).
2. Explique o `options ndots:5` do `resolv.conf`.
3. Resolva `web-verde`, `web-verde.ac06-servicos` e o FQDN.
4. `oc exec ac06-cliente -n ac06-servicos -- getent ahosts web-azul` (todas as respostas).
5. Resolva um nome externo (`registry.access.redhat.com`): o DNS do cluster encaminha para o DNS do HomeLab.

## Desafio sem pista

Crie o projeto rascunho `ac06-outro` com um pod cliente e prove, de lá, que `web-azul` **não** resolve, mas
`web-azul.ac06-servicos` resolve e responde `azul`. Apague o rascunho ao final.

## Diagnóstico controlado

- **Sintoma:** do `ac06-outro`, `getent hosts web-azul` não retorna nada.
- **Hipóteses:** a lista `search` só inclui o namespace do próprio pod.
- **Investigação:** `cat /etc/resolv.conf` no pod do `ac06-outro`.
- **Reversão:** use o nome com namespace.

## Validação

```bash
oc exec ac06-cliente -n ac06-servicos -- getent hosts web-azul.ac06-servicos.svc.cluster.local | grep -q "$(oc get svc web-azul -n ac06-servicos -o jsonpath='{.spec.clusterIP}')" && echo "DNS ok"
```
