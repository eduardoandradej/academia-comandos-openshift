# SVC-008 — Headless Service: DNS que devolve os pods

## Objetivo e indicador de sucesso

Criar um Service headless (`clusterIP: None`) e comparar sua resposta DNS com a de um Service comum.

**Indicador de sucesso:** `getent ahosts` no headless devolve os IPs dos pods; no comum, o ClusterIP.

```bash
http() { oc exec ac06-cliente -n ac06-servicos -- bash -c "exec 3<>/dev/tcp/$1/${2:-8080} && printf 'GET / HTTP/1.0\r\n\r\n' >&3 && cat <&3" | tail -1; }
```

## Conceito

| | Service comum | Headless (`clusterIP: None`) |
|---|---|---|
| IP virtual | sim | não |
| Resposta DNS | o ClusterIP | os **IPs dos pods** prontos |
| Balanceamento | pela rede do cluster | pelo cliente (escolhe um IP) |
| Uso típico | aplicações sem estado | StatefulSets, bancos em cluster, descoberta de pares |

## Comandos guiados

```bash
cat <<'EOF' | oc apply -n ac06-servicos -f -
apiVersion: v1
kind: Service
metadata: {name: loja-headless, labels: {academy.openshift.dev/managed-by: academia}}
spec:
  clusterIP: None
  selector: {app: loja}
  ports: [{name: http, port: 8080, targetPort: http}]
EOF
oc get svc loja-headless -n ac06-servicos                              # CLUSTER-IP: None
oc exec ac06-cliente -n ac06-servicos -- getent ahosts loja-headless | awk '{print $1}' | sort -u
oc get pods -n ac06-servicos -l app=loja -o jsonpath='{range .items[*]}{.status.podIP}{"\n"}{end}'
oc exec ac06-cliente -n ac06-servicos -- getent ahosts loja | awk '{print $1}' | sort -u      # o ClusterIP
```

## Repetições

1. Escale `web-verde` para 2 e resolva o headless de novo.
2. Recrie um pod e veja o IP novo aparecer no DNS.
3. Tente mudar `clusterIP` de um Service existente para `None` e leia o erro (campo imutável).
4. `http loja-headless` várias vezes: o cliente sempre usa o primeiro IP?
5. `oc explain service.spec.clusterIP`.

## Desafio sem pista

Usando só o DNS do headless, faça uma requisição HTTP a **cada** pod da loja e mostre a cor de cada um.

## Diagnóstico controlado

- **Sintoma:** `The Service "loja" is invalid: spec.clusterIPs[0]: Invalid value: ["None"]: may not change once set`.
- **Hipóteses:** `clusterIP` é imutável.
- **Investigação:** `oc explain service.spec.clusterIP`.
- **Reversão:** nada foi alterado; crie um Service novo.

## Validação

```bash
oc get svc loja-headless -n ac06-servicos -o jsonpath='{.spec.clusterIP}{"\n"}'   # None
```
