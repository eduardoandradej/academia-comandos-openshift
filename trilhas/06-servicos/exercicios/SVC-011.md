## Objetivo e indicador de sucesso

Criar um Service `ExternalName` que é só um apelido DNS (CNAME) para outro nome, sem seletor nem ClusterIP.

**Indicador de sucesso:** `api-cluster` resolve para o mesmo IP de `kubernetes.default.svc.cluster.local`.


## Conceito

`type: ExternalName` com `externalName: <nome DNS>` faz o DNS do cluster responder um CNAME. Não há proxy, porta
nem endpoints: a aplicação conecta direto no destino. Útil para dar um nome interno estável a algo externo (um banco
gerenciado, por exemplo) e trocá-lo sem mudar a aplicação.

## Comandos guiados

```bash
oc create service externalname api-cluster --external-name=kubernetes.default.svc.cluster.local -n ac06-servicos
oc label svc api-cluster academy.openshift.dev/managed-by=academia -n ac06-servicos
oc get svc api-cluster -n ac06-servicos -o wide
oc exec ac06-cliente -n ac06-servicos -- getent hosts api-cluster
oc exec ac06-cliente -n ac06-servicos -- getent hosts kubernetes.default.svc.cluster.local
oc exec ac06-cliente -n ac06-servicos -- bash -c 'timeout 3 bash -c "</dev/tcp/api-cluster/443" && echo "API alcançável pelo apelido"'
oc get endpointslices -n ac06-servicos -l kubernetes.io/service-name=api-cluster      # nenhuma
```

## Repetições

1. Aponte o apelido para `web-verde.ac06-servicos.svc.cluster.local` e teste `http api-cluster` (porta 8080).
2. Aponte para um nome externo (`registry.access.redhat.com`) e resolva.
3. `oc explain service.spec.externalName`.
4. Por que ExternalName não tem `port` obrigatória?
5. Compare com um Service comum sem seletor (próximo item do desafio).

## Desafio sem pista

Crie um Service **sem seletor** (`loja-manual`) e uma EndpointSlice manual apontando para o IP do pod azul. Teste e
explique a diferença em relação ao ExternalName.

## Diagnóstico controlado

- **Sintoma:** HTTPS para um ExternalName falha com erro de certificado (nome não confere).
- **Hipóteses:** o cliente valida o nome que **ele** usou (`api-cluster`), não o destino do CNAME.
- **Investigação:** o certificado servido pelo destino lista quais nomes?
- **Reversão:** nada a reverter; ExternalName não reescreve o nome usado pelo cliente.
