## Objetivo e indicador de sucesso

```bash
http() { oc exec ac06-cliente -n ac06-servicos -- bash -c "exec 3<>/dev/tcp/$1/${2:-8080} && printf 'GET / HTTP/1.0\r\n\r\n' >&3 && cat <&3" | tail -1; }
```

## Conceito

Com o seletor `app=loja` (sem `cor`), o Service tem dois endpoints. Cada **nova conexão** é encaminhada a um deles,
escolhido pela implementação de rede (OVN-Kubernetes no OpenShift). A escolha é por conexão, não por requisição HTTP
dentro de uma conexão reaproveitada — e não é round-robin estrito.

## Comandos guiados

```bash
oc set selector svc/loja app=loja -n ac06-servicos
oc get endpointslices -n ac06-servicos -l kubernetes.io/service-name=loja -o jsonpath='{range .items[*].endpoints[*]}{.targetRef.name}{"\n"}{end}'
for i in $(seq 20); do http loja; done | sort | uniq -c
oc scale deployment/web-verde --replicas=2 -n ac06-servicos
oc wait --for=condition=Available deployment/web-verde -n ac06-servicos --timeout=120s
for i in $(seq 30); do http loja; done | sort | uniq -c      # proporção tende a 1:2
oc scale deployment/web-verde --replicas=1 -n ac06-servicos
```

## Repetições

1. Repita a contagem 5× e anote as proporções.
2. Escale `web-azul` para 0 durante a contagem: o que acontece?
3. Volte o seletor para só azul e conte de novo.
4. Use o ClusterIP em vez do nome: muda algo?
5. Explique por que uma conexão HTTP persistente (keep-alive) sempre veria a mesma cor.

## Desafio sem pista

Produza a tabela `cor | respostas | %` para 40 requisições ao Service `loja` com 1 azul e 1 verde.

## Diagnóstico controlado

- **Sintoma:** todas as 20 respostas foram da mesma cor.
- **Hipóteses:** (a) o seletor ainda inclui `cor`; (b) um dos pods não está pronto; (c) afinidade de sessão ativa (SVC-012).
- **Investigação:** seletor do Service; EndpointSlices; `oc get svc loja -o jsonpath='{.spec.sessionAffinity}'`.
- **Reversão:** ajuste o seletor ou a afinidade.

## Validação

```bash
for i in $(seq 20); do http loja; done | sort -u | wc -l    # 2
```

## Limpeza segura

Volte o seletor para azul: `oc set selector svc/loja app=loja,cor=azul -n ac06-servicos`.
