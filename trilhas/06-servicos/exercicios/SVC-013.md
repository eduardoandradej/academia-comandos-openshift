## Conceito

| Tipo | Como expõe | No HomeLab |
|---|---|---|
| `ClusterIP` | só dentro do cluster | usado em toda a Academia |
| `NodePort` | uma porta (30000–32767) em cada nó | proibido pela quota (`services.nodeports: 0`) |
| `LoadBalancer` | IP externo de um balanceador (nuvem ou MetalLB) | **NÃO DISPONÍVEL NO HOME LAB ATUAL**: não há provedor; e a quota proíbe |
| Route (OpenShift) | HTTP/HTTPS pelo Ingress (`*.apps`) | Trilha 07 |

## Comandos guiados

```bash
oc create service nodeport loja-np --tcp=8080:8080 -n ac06-servicos --dry-run=client -o yaml | grep -E 'type|nodePort'
oc create service nodeport loja-np --tcp=8080:8080 -n ac06-servicos 2>&1 | head -2      # recusa da quota
oc create service loadbalancer loja-lb --tcp=8080:8080 -n ac06-servicos 2>&1 | head -2   # recusa da quota
oc describe resourcequota ac-quota -n ac06-servicos 2>/dev/null | grep -E 'services'
oc explain service.spec.type
```

## Repetições

- **Sintoma:** `exceeded quota: ac-quota, requested: services.nodeports=1, used: services.nodeports=0, limited: services.nodeports=0`.
- **Hipóteses:** quota da Academia.
- **Investigação:** `oc describe quota ac-quota -n ac06-servicos`.
- **Reversão:** nada foi criado.
