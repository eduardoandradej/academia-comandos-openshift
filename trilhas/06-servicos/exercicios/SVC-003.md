## Conceito

O controlador de endpoints observa os pods que casam com o seletor e publica **EndpointSlices** (rótulo
`kubernetes.io/service-name=<svc>`), com IP, porta, pod de origem (`targetRef`) e condições (`ready`, `serving`,
`terminating`). O objeto antigo `Endpoints` ainda existe, mas está obsoleto — prefira EndpointSlices.

Só endpoints `ready` recebem tráfego normal. Pod sem readiness pronta = fora do balanceamento.

## Comandos guiados

```bash
oc get endpointslices -n ac06-servicos -l kubernetes.io/service-name=web-azul
oc get endpointslices -n ac06-servicos -l kubernetes.io/service-name=web-azul \
  -o jsonpath='{range .items[*].endpoints[*]}{.addresses[0]} {.targetRef.name} ready={.conditions.ready}{"\n"}{end}'
oc scale deployment/web-azul --replicas=2 -n ac06-servicos
oc get endpointslices -n ac06-servicos -l kubernetes.io/service-name=web-azul -w     # Ctrl+C ao ver 2
oc get pods -n ac06-servicos -l cor=azul -o wide
oc get endpoints web-azul -n ac06-servicos            # visão legada (pode emitir aviso de obsolescência)
oc scale deployment/web-azul --replicas=1 -n ac06-servicos
```

## Repetições

1. Escale para 0 e leia a EndpointSlice (vazia) e `oc describe svc`.
2. Durante um `rollout restart`, observe endpoints `terminating`.
3. `oc get endpointslices -n ac06-servicos -o custom-columns=NOME:.metadata.name,SVC:.metadata.labels.kubernetes\.io/service-name,ENDPOINTS:.endpoints[*].addresses[0]`.
4. Compare os IPs dos endpoints com `oc get pods -o wide`.
5. `oc explain endpointslice.endpoints.conditions`.

## Desafio sem pista

Escreva uma linha que, dado o nome de um Service, imprime `pronto` ou `sem backend pronto`, olhando só as EndpointSlices.

## Diagnóstico controlado

- **Sintoma:** `oc get endpoints` mostra um aviso `v1 Endpoints is deprecated`.
- **Hipóteses:** API legada; não é erro.
- **Investigação:** `oc api-resources | grep -i endpoint`.
- **Reversão:** nada a reverter; use EndpointSlices.

## Validação

```bash
oc get endpointslices -n ac06-servicos -l kubernetes.io/service-name=web-azul -o jsonpath='{.items[*].endpoints[*].conditions.ready}{"\n"}'   # true
```

## Limpeza segura

Garanta `web-azul` com 1 réplica: `oc scale deployment/web-azul --replicas=1 -n ac06-servicos`.
