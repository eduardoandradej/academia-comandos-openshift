## Objetivo e indicador de sucesso

Ativar `sessionAffinity: ClientIP` no Service `loja` e mostrar que o mesmo cliente passa a cair sempre no mesmo backend.

**Indicador de sucesso:** com afinidade, 20 requisições do cliente veem uma só cor; sem afinidade, as duas.


## Conceito

`sessionAffinity: ClientIP` faz conexões do mesmo IP de origem irem para o mesmo endpoint por um tempo
(`sessionAffinityConfig.clientIP.timeoutSeconds`, padrão 10800 s). Ajuda aplicações que guardam sessão em memória — mas
é um paliativo: aplicações sem estado (sessão fora do pod) escalam melhor.

## Comandos guiados

```bash
oc set selector svc/loja app=loja -n ac06-servicos
for i in $(seq 20); do http loja; done | sort | uniq -c          # duas cores
oc patch svc loja -n ac06-servicos --type=merge -p '{"spec":{"sessionAffinity":"ClientIP","sessionAffinityConfig":{"clientIP":{"timeoutSeconds":60}}}}'
for i in $(seq 20); do http loja; done | sort | uniq -c          # uma cor só
oc get svc loja -n ac06-servicos -o jsonpath='{.spec.sessionAffinity} {.spec.sessionAffinityConfig}{"\n"}'
oc patch svc loja -n ac06-servicos --type=merge -p '{"spec":{"sessionAffinity":"None","sessionAffinityConfig":null}}'
```

## Repetições

1. Com afinidade, teste de um segundo cliente (`oc debug pod/ac06-cliente -- ...`): ele cai na mesma cor?
2. Espere o `timeoutSeconds` (60 s) e teste de novo.
3. Com afinidade, escale para 0 o backend escolhido: o que acontece com o cliente?
4. `oc explain service.spec.sessionAffinityConfig`.
5. Volte para `None` e confira as duas cores.

## Desafio sem pista

Prove que dois clientes diferentes, com afinidade ativa, podem cair em cores diferentes — e que cada um continua na sua.

## Diagnóstico controlado

- **Sintoma:** depois de desligar a afinidade, um cliente ainda vê sempre a mesma cor por alguns segundos.
- **Hipóteses:** entradas de afinidade já estabelecidas ainda válidas.
- **Investigação:** repita após o tempo configurado.
- **Reversão:** nada a reverter.

## Validação

```bash
oc get svc loja -n ac06-servicos -o jsonpath='{.spec.sessionAffinity}{"\n"}'   # None
```
