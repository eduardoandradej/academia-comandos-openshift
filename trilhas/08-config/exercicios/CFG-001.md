## Conceito

Um **ConfigMap** guarda configuração **não sensível** como pares chave → valor, separada da imagem. As origens:

| Origem | Chave gerada | Valor |
|---|---|---|
| `--from-literal=CHAVE=valor` | `CHAVE` | `valor` |
| `--from-file=arquivo` | nome do arquivo | conteúdo inteiro |
| `--from-file=chave=arquivo` | `chave` | conteúdo inteiro |
| `--from-file=diretório/` | um item por arquivo | conteúdo de cada arquivo |
| `--from-env-file=arquivo` | cada linha `K=V` | `V` |

Limite prático: 1 MiB por objeto. Para segredos, use Secret (CFG-005).

## Comandos guiados

```bash
oc new-project ac08-config --display-name='Academia 08 - Configuração'
mkdir -p /tmp/ac08 && cd /tmp/ac08
printf 'Listen 8080\nServerName academia\n' > app.conf
printf 'MODO=treino\nNIVEL_LOG=info\n# comentário ignorado\nCOR=azul\n' > app.env
cd - >/dev/null
oc create configmap ac08-literal --from-literal=MODO=treino --from-literal=NIVEL_LOG=debug -n ac08-config
oc create configmap ac08-arquivo --from-file=/tmp/ac08/app.conf --from-file=principal.conf=/tmp/ac08/app.conf -n ac08-config
oc create configmap ac08-env --from-env-file=/tmp/ac08/app.env -n ac08-config
oc label configmap ac08-literal ac08-arquivo ac08-env academy.openshift.dev/managed-by=academia -n ac08-config
oc get configmaps -n ac08-config -l academy.openshift.dev/managed-by=academia
oc describe configmap ac08-arquivo -n ac08-config
oc get configmap ac08-env -n ac08-config -o jsonpath='{.data}{"\n"}'
oc get configmap ac08-arquivo -n ac08-config -o json | jq -r '.data | keys[]'
```

## Repetições

1. Gere cada ConfigMap com `--dry-run=client -o yaml` antes de criar e compare com o resultado.
2. Crie um ConfigMap a partir do **diretório** `/tmp/ac08/`.
3. O que acontece com a linha de comentário do `app.env`?
4. Tente criar de novo `ac08-literal` e leia o erro; repita de forma idempotente com `--dry-run=client -o yaml | oc apply -f -`.
5. `oc get configmap ac08-arquivo -n ac08-config -o jsonpath='{.data.principal\.conf}'` — por que o `\.`?

## Desafio sem pista

Crie o ConfigMap `ac08-tudo` com: uma chave literal `VERSAO=1`, o arquivo `app.conf` com a chave `httpd.conf` e todas as
variáveis de `app.env` — **em um único comando**, se o `oc` permitir; se não, explique por quê e faça em dois passos idempotentes.

## Diagnóstico controlado

- **Sintoma:** `error: from-env-file cannot be combined with from-file or from-literal`.
- **Hipóteses:** combinação de origens não suportada no mesmo comando.
- **Investigação:** `oc create configmap --help | grep -A3 from-env-file`.
- **Reversão:** nada foi criado; gere as partes separadamente e mescle (gabarito).

## Validação

```bash
oc get configmap ac08-env -n ac08-config -o jsonpath='{.data.COR}{"\n"}'   # azul
```
