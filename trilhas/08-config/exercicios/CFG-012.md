## Objetivo e indicador de sucesso

Exportar um ConfigMap para arquivos, editá-los e devolver as mudanças, usando `oc extract` e `oc set data`.

**Indicador de sucesso:** o ciclo extrair → editar → `oc set data --from-file` altera só a chave desejada.

## Conceito

> **Valores fictícios.** Todo Secret desta trilha usa valores inventados (`senha-de-treino`, `token-ficticio`).
> Mesmo assim, trate a saída de comandos que mostram dados de Secret como sensível: não cole em chats, issues ou commits.

- `oc extract configmap/<nome> --to=<dir>` grava cada chave como arquivo (`--keys` escolhe; `--confirm` sobrescreve).
- `oc set data configmap/<nome> CHAVE=valor` ou `--from-file=chave=arquivo` atualiza só as chaves informadas.
- Para Secrets, os mesmos comandos funcionam — e **gravam os valores em disco**: use só com dados fictícios e apague depois.

## Comandos guiados

```bash
mkdir -p /tmp/ac08/extraido
oc extract configmap/ac08-arquivo --to=/tmp/ac08/extraido -n ac08-config --confirm
ls -l /tmp/ac08/extraido
echo 'KeepAlive On' >> /tmp/ac08/extraido/app.conf
oc set data configmap/ac08-arquivo --from-file=app.conf=/tmp/ac08/extraido/app.conf -n ac08-config
oc get configmap ac08-arquivo -n ac08-config -o jsonpath='{.data.app\.conf}'
oc set data configmap/ac08-literal NIVEL_LOG=warn -n ac08-config
oc set data configmap/ac08-literal NIVEL_LOG- -n ac08-config          # remove a chave
oc get configmap ac08-literal -n ac08-config -o jsonpath='{.data}{"\n"}'
```

## Repetições

1. Extraia só a chave `principal.conf` (`--keys`).
2. Extraia para a saída padrão: `oc extract configmap/ac08-literal --to=- -n ac08-config`.
3. Repita o ciclo com o Secret fictício `ac08-banco` e apague os arquivos extraídos em seguida.
4. Compare `oc set data` com o padrão `create --dry-run | apply`: qual preserva chaves que você não mencionou?
5. `oc set data --help | sed -n '/Examples:/,/Options:/p'`.

## Desafio sem pista

Faça um "backup" de todos os ConfigMaps rotulados do projeto em `/tmp/ac08/backup/<nome>/`, apague um deles e restaure-o a partir dos arquivos.

## Diagnóstico controlado

- **Sintoma:** `error: /tmp/ac08/extraido/app.conf: file exists, pass --confirm to overwrite`.
- **Hipóteses:** proteção contra sobrescrita.
- **Investigação:** `ls /tmp/ac08/extraido`.
- **Reversão:** nada a reverter; use `--confirm` se a intenção for sobrescrever.

## Validação

```bash
oc get configmap ac08-arquivo -n ac08-config -o jsonpath='{.data.app\.conf}' | grep -q KeepAlive && echo OK
```

## Limpeza segura

```bash
rm -rf /tmp/ac08/extraido /tmp/ac08/backup /tmp/ac08/secret-extraido
```
