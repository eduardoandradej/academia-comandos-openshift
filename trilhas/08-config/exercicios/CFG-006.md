## Objetivo e indicador de sucesso

## Conceito

> **Valores fictícios.** Todo Secret desta trilha usa valores inventados (`senha-de-treino`, `token-ficticio`).
> Mesmo assim, trate a saída de comandos que mostram dados de Secret como sensível: não cole em chats, issues ou commits.

As formas são as mesmas do ConfigMap: `oc set env --from=secret/x [--prefix]`, `secretKeyRef` para chaves isoladas e
`oc set volume --type=secret --secret-name=x`. Diferenças de risco:

- variáveis aparecem para **qualquer** processo do contêiner e em `oc exec ... env`; podem vazar em logs de erro;
- arquivos permitem permissões restritas (`defaultMode`) e atualização automática.

Prefira arquivos para segredos sempre que a aplicação permitir.

## Comandos guiados

```bash
oc set env deployment/ac08-app --from=secret/ac08-banco --prefix=DB_ -n ac08-config
oc set volume deployment/ac08-app --add --name=segredos --type=secret --secret-name=ac08-api \
  --mount-path=/etc/segredos --read-only=true -n ac08-config
V=$(oc get deployment ac08-app -n ac08-config -o json | jq '[.spec.template.spec.volumes[].name] | index("segredos")')
oc patch deployment ac08-app -n ac08-config --type=json \
  -p "[{\"op\":\"add\",\"path\":\"/spec/template/spec/volumes/$V/secret/defaultMode\",\"value\":256}]"
oc rollout status deployment/ac08-app -n ac08-config
oc exec deploy/ac08-app -n ac08-config -- sh -c 'ls -lL /etc/segredos; printenv | grep -c "^DB_"'
oc exec deploy/ac08-app -n ac08-config -- sh -c 'wc -c < /etc/segredos/token'     # tamanho, não o valor
oc describe pod -n ac08-config -l app=ac08-app | sed -n '/Environment/,/Mounts/p'
```

## Repetições

1. Explique o que a variável `V` calcula e por que o índice fixo `0` seria um erro.
2. Use `secretKeyRef` para injetar só `senha` como `SENHA_BANCO`.
3. `oc set env deployment/ac08-app --list -n ac08-config` — os valores de Secret aparecem?
4. Mude o token (`oc set data secret/ac08-api token=outro-ficticio`) e observe o arquivo se atualizar.
5. Remova as variáveis `DB_*` e mantenha só o arquivo.

## Desafio sem pista

Monte o Secret `ac08-banco` de modo que **só** a chave `senha` vire o arquivo `/run/db/senha` com modo 0400, sem
variáveis de ambiente, e prove a permissão e o tamanho do arquivo.

## Diagnóstico controlado

- **Sintoma:** `oc describe pod` mostra `DB_SENHA: <set to the key 'senha' in secret 'ac08-banco'>`.
- **Hipóteses:** é o comportamento correto: o describe mostra a **referência**, não o valor.
- **Investigação:** `oc exec ... -- printenv DB_SENHA | wc -c` (tamanho) — o valor só existe dentro do contêiner.
- **Reversão:** nada a reverter.

## Validação

```bash
oc exec deploy/ac08-app -n ac08-config -- test -s /etc/segredos/token && echo "token montado"
```

## Limpeza segura

```bash
oc set env deployment/ac08-app DB_USUARIO- DB_SENHA- -n ac08-config 2>/dev/null || true
```
