# CFG-011 — Volume projetado: ConfigMap, Secret e Downward API no mesmo diretório

## Identificação

- **Referência didática:** DO180 — configuração de aplicações (volumes).

## Objetivo e indicador de sucesso

Combinar um ConfigMap, um Secret e informações do próprio pod (Downward API) em um único diretório com volume `projected`.

**Indicador de sucesso:** `/etc/tudo` contém `modo`, `token` e `nome-do-pod`.

## Conceito

Um volume `projected` junta várias fontes (`configMap`, `secret`, `downwardAPI`, `serviceAccountToken`) em um único
diretório. Útil quando a aplicação espera toda a configuração em um lugar só. O token de service account montado
automaticamente em todo pod (`/var/run/secrets/kubernetes.io/serviceaccount`) também é um volume projetado.

## Comandos guiados

```bash
oc patch deployment ac08-app -n ac08-config --type=json -p '[
 {"op":"add","path":"/spec/template/spec/volumes/-","value":{"name":"tudo","projected":{"sources":[
   {"configMap":{"name":"ac08-literal","items":[{"key":"MODO","path":"modo"}]}},
   {"secret":{"name":"ac08-api","items":[{"key":"token","path":"token"}]}},
   {"downwardAPI":{"items":[{"path":"nome-do-pod","fieldRef":{"fieldPath":"metadata.name"}},
                            {"path":"rotulos","fieldRef":{"fieldPath":"metadata.labels"}}]}}]}}},
 {"op":"add","path":"/spec/template/spec/containers/0/volumeMounts/-","value":{"name":"tudo","mountPath":"/etc/tudo","readOnly":true}}]'
oc rollout status deployment/ac08-app -n ac08-config
oc exec deploy/ac08-app -n ac08-config -- sh -c 'ls /etc/tudo; cat /etc/tudo/modo; echo; cat /etc/tudo/nome-do-pod; echo; cat /etc/tudo/rotulos'
oc exec deploy/ac08-app -n ac08-config -- ls /var/run/secrets/kubernetes.io/serviceaccount   # o volume projetado padrão
```

## Repetições

1. Acrescente `resourceFieldRef` com `limits.memory` ao Downward API.
2. Mude um rótulo do pod (`oc label pod`) e veja o arquivo `rotulos` atualizar.
3. Compare o volume `projected` com dois volumes separados.
4. Leia o `namespace` do pod pelo arquivo do token da SA.
5. `oc explain pod.spec.volumes.projected.sources`.

## Desafio sem pista

Faça o arquivo `/etc/tudo/limite-memoria` mostrar o limite de memória do contêiner em MiB.

## Diagnóstico controlado

- **Sintoma:** o pod fica em `ContainerCreating` com `MountVolume.SetUp failed ... secret "ac08-api" not found`.
- **Hipóteses:** uma das fontes do volume projetado não existe.
- **Investigação:** `oc describe pod ... | sed -n '/Events:/,$p'`.
- **Reversão:** crie a fonte ausente ou remova-a do volume.

## Validação

```bash
oc exec deploy/ac08-app -n ac08-config -- test -f /etc/tudo/nome-do-pod && echo OK
```
