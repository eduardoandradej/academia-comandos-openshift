## Conceito

`oc create secret tls <nome> --cert=<crt> --key=<key>` cria um Secret do tipo `kubernetes.io/tls` com as chaves
`tls.crt` e `tls.key`. O cliente valida que o certificado e a chave formam um par. Esse formato é o esperado por
Ingress, por operadores e pelos certificados de serviço do OpenShift (RTE-009).

## Comandos guiados

```bash
cd /tmp/ac08
openssl req -x509 -newkey rsa:2048 -nodes -days 7 -keyout tls.key -out tls.crt -subj "/CN=ac08.apps.ocp.example.lab" 2>/dev/null
cd - >/dev/null
oc create secret tls ac08-tls --cert=/tmp/ac08/tls.crt --key=/tmp/ac08/tls.key -n ac08-config
oc label secret ac08-tls academy.openshift.dev/managed-by=academia -n ac08-config
oc get secret ac08-tls -n ac08-config -o jsonpath='{.type}{"\n"}'
oc describe secret ac08-tls -n ac08-config
oc get secret ac08-tls -n ac08-config -o jsonpath='{.data.tls\.crt}' | base64 -d | openssl x509 -noout -subject -enddate   # só o certificado (público)
```

## Repetições

1. Gere outra chave (`openssl genrsa -out /tmp/ac08/outra.key 2048`) e tente criar o Secret com o certificado antigo e a chave nova.
2. Tente criar um Secret `kubernetes.io/tls` com `oc create secret generic --type=kubernetes.io/tls` sem a chave `tls.key`.
3. Leia a data de expiração do certificado guardado.
4. Use `oc create secret tls ... --dry-run=client -o yaml | grep -E '^(type|  tls)'` (sem imprimir os dados completos).
5. Explique por que ler `tls.crt` é aceitável e `tls.key` não.

## Desafio sem pista

Escreva um comando que liste todos os Secrets TLS do projeto com o CN e a data de expiração de cada certificado.

## Diagnóstico controlado

- **Sintoma:** `error: tls: private key does not match public key`.
- **Hipóteses:** certificado e chave de pares diferentes.
- **Investigação:** compare o módulo: `openssl x509 -noout -modulus -in tls.crt | sha256sum` × `openssl rsa -noout -modulus -in <key> | sha256sum`.
- **Reversão:** nada foi criado; use o par correto.

## Validação

```bash
oc get secret ac08-tls -n ac08-config -o json | jq -r '.data | keys | join(",")'    # tls.crt,tls.key
```
