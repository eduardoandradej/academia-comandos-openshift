## Conceito

O circuito diz **o que** obter, não **como**. Itens que exigiram consulta vão para a revisão D+1.

## Comandos guiados

Circuito sem pistas:

1. ConfigMap a partir de literais.
2. ConfigMap a partir de um arquivo, com nome de chave escolhido.
3. ConfigMap a partir de um arquivo de variáveis.
4. Injetar um ConfigMap inteiro como variáveis, com prefixo.
5. Injetar uma única chave com nome de variável próprio.
6. Montar um ConfigMap como diretório.
7. Acrescentar um único arquivo a um diretório existente.
8. Mostrar que variáveis não se atualizam e reiniciar o Deployment.
9. Secret genérico com o valor digitado no prompt.
10. Listar chaves e tamanhos de um Secret sem exibir valores.
11. Montar um Secret como arquivo com modo 0400.
12. Secret TLS a partir de certificado e chave de treino.
13. Pull secret ligado a uma service account.
14. ConfigMap imutável e a "atualização" por nome novo.
15. Ciclo gerar → diff → apply de um ConfigMap.

## Repetições

## Desafio sem pista

Faça o circuito completo sem consulta. Em seguida, encerre a trilha com a limpeza abaixo e prove que nada ficou — inclusive em `/tmp`.

## Diagnóstico controlado

- **Sintoma:** depois da limpeza, ainda há arquivos `*.key` em `/tmp`.
- **Hipóteses:** chaves de treino geradas em outros diretórios.
- **Investigação:** `find /tmp -maxdepth 3 -name '*.key' -user "$(whoami)" 2>/dev/null`.
- **Reversão:** apague-as; elas nunca devem ir para o repositório (o `.gitignore` bloqueia, mas a limpeza é sua).

## Validação

```bash
oc get project ac08-config 2>&1 | grep -q NotFound && echo "trilha 08 limpa"
[ ! -d /tmp/ac08 ] && echo "/tmp/ac08 removido"
```

## Limpeza segura

```bash
pkill -f 'oc port-forward .* -n ac08-config' || true
scripts/safe-cleanup.sh -n ac08-config                              # simula
scripts/safe-cleanup.sh -n ac08-config --execute --delete-project   # apaga rotulados e o projeto
oc get project ac08-config                                          # até NotFound

```
