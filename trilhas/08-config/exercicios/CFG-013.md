## Objetivo e indicador de sucesso

Manter ConfigMaps como arquivos e atualizá-los com o padrão gerar → `oc diff` → `oc apply`, sem `create` repetido.

**Indicador de sucesso:** uma mudança em `/tmp/ac08/app.env` chega ao cluster com `oc diff` mostrando só a linha alterada.

## Conceito

`oc create configmap ... --dry-run=client -o yaml | oc apply -f -` é o jeito idempotente de manter um ConfigMap a partir
de arquivos: cria se não existir, atualiza se existir. Com `oc diff` no meio, você vê exatamente o que muda antes de
aplicar. Kustomize (Trilha 13) automatiza esse padrão com `configMapGenerator`.

## Comandos guiados

```bash
gera() { oc create configmap ac08-env --from-env-file=/tmp/ac08/app.env --dry-run=client -o yaml \
  | oc label --local -f - academy.openshift.dev/managed-by=academia -o yaml; }
gera | oc diff -n ac08-config -f -; echo "rc=$?"               # 0 = nada a mudar
sed -i 's/^COR=.*/COR=verde/' /tmp/ac08/app.env
gera | oc diff -n ac08-config -f -; echo "rc=$?"               # 1 = mostra COR azul -> verde
gera | oc apply -n ac08-config -f -
oc get configmap ac08-env -n ac08-config -o jsonpath='{.data.COR}{"\n"}'
```

## Repetições

1. Acrescente uma variável nova ao arquivo e repita o ciclo.
2. Remova uma variável do arquivo: o `apply` remove a chave do cluster?
3. Faça o mesmo ciclo para o ConfigMap `ac08-arquivo` a partir de `/tmp/ac08/app.conf`.
4. Faça uma mudança imperativa (`oc set data`) e veja o `oc diff` acusar a diferença.
5. Escreva a função `gera` de memória.

## Desafio sem pista

Escreva uma função `sincroniza <nome> <arquivo-env>` que mostra o diff, pede confirmação (`s/N`) e só então aplica.

## Diagnóstico controlado

- **Sintoma:** o `oc diff` mostra mudanças em `metadata.labels` que você não fez.
- **Hipóteses:** o objeto no cluster tem rótulos que o gerado não tem (ou vice-versa).
- **Investigação:** compare `--show-labels` com a saída da função `gera`.
- **Reversão:** inclua os rótulos na geração (como a função faz com o da Academia).

## Validação

```bash
gera | oc diff -n ac08-config -f - >/dev/null && echo "cluster = arquivo"
```

## Limpeza segura

Nada além do ConfigMap atualizado.
