# CFG-010 — Um arquivo de configuração real: conf.d do httpd com subPath

## Identificação

- **ID:** CFG-010
- **Trilha:** [08 — ConfigMaps e Secrets](../README.md)
- **Referência didática:** DO180 — configuração de aplicações (arquivos de configuração).
- **Fichas de comando:** [`oc-configmap-secret`](../../../catalogo/fichas/oc-configmap-secret.md), [`oc-set-volume`](../../../catalogo/fichas/oc-set-volume.md)
- **Status:** proposto — escrito e revisado estaticamente; ainda não executado contra o cluster pelo autor

## Objetivo e indicador de sucesso

Acrescentar um arquivo ao diretório `/etc/httpd/conf.d` do httpd via ConfigMap com `subPath`, sem apagar os arquivos
da imagem, e ver o efeito em um cabeçalho HTTP.

**Indicador de sucesso:** a resposta do httpd traz o cabeçalho `X-Academia: treino`.

## Nível

**Nível:** Avançado

## Conceito

`subPath` monta **um item** do volume em um caminho de arquivo, sem esconder o resto do diretório. É o jeito de
acrescentar `conf.d/academia.conf` mantendo os `.conf` da imagem. Ressalva importante: arquivos montados com
`subPath` **não** recebem atualizações do ConfigMap — mude o ConfigMap e reinicie o Deployment.

## Comandos guiados

```bash
oc create configmap ac08-httpd --from-literal=academia.conf='Header always set X-Academia "treino"' -n ac08-config
oc label configmap ac08-httpd academy.openshift.dev/managed-by=academia -n ac08-config
oc create deployment ac08-web --image=registry.access.redhat.com/ubi9/httpd-24:latest -n ac08-config
oc label deployment ac08-web academy.openshift.dev/managed-by=academia -n ac08-config
oc patch deployment ac08-web -n ac08-config --type=json -p '[
 {"op":"add","path":"/spec/template/spec/volumes","value":[{"name":"conf","configMap":{"name":"ac08-httpd"}}]},
 {"op":"add","path":"/spec/template/spec/containers/0/volumeMounts","value":[{"name":"conf","mountPath":"/etc/httpd/conf.d/academia.conf","subPath":"academia.conf"}]}]'
oc rollout status deployment/ac08-web -n ac08-config
oc exec deploy/ac08-web -n ac08-config -- ls /etc/httpd/conf.d            # os arquivos da imagem continuam lá
oc port-forward deploy/ac08-web 18088:8080 -n ac08-config >/dev/null 2>&1 & PF=$!; sleep 3
curl -sSI http://127.0.0.1:18088/ | grep -i x-academia
kill $PF
```

## Repetições

1. Mude o valor do cabeçalho no ConfigMap e teste sem reiniciar: mudou? Reinicie e teste de novo.
2. Monte o ConfigMap **sem** `subPath` em `/etc/httpd/conf.d` em um Deployment de teste e veja o httpd falhar (TS/diagnóstico do CFG-003).
3. Confira a sintaxe da configuração com `oc exec deploy/ac08-web -- httpd -t`.
4. Acrescente um segundo cabeçalho no mesmo arquivo (valor multilinha com `--from-file`).
5. Leia o arquivo dentro do pod com `oc exec ... -- cat /etc/httpd/conf.d/academia.conf`.

## Desafio sem pista

Mude o cabeçalho para `X-Academia: revisao` de forma que os pods sejam recriados **automaticamente** por causa da
mudança (técnica do hash do CFG-004), e prove pelo `curl`.

## Diagnóstico controlado

- **Sintoma:** mudei o ConfigMap, mas o cabeçalho continua antigo mesmo depois de minutos.
- **Hipóteses:** montagem com `subPath` não se atualiza.
- **Investigação:** `oc get deployment ac08-web -o jsonpath='{.spec.template.spec.containers[0].volumeMounts}'`.
- **Reversão:** `oc rollout restart deployment/ac08-web -n ac08-config`. Veja TS-026.

## Validação

```bash
oc exec deploy/ac08-web -n ac08-config -- httpd -t 2>&1 | grep -q 'Syntax OK' && echo "configuração válida"
```

## Limpeza segura

```bash
pkill -f 'oc port-forward deploy/ac08-web' || true
```
