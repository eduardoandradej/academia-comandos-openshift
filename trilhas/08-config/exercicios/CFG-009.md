## Objetivo e indicador de sucesso

Marcar um ConfigMap como `immutable` e entender o que isso impede e o que permite.

**Indicador de sucesso:** você mostra a recusa ao editar o objeto imutável e faz a "atualização" pelo caminho certo (novo nome).

## Conceito

`immutable: true` impede qualquer alteração em `data`/`binaryData` — e não pode ser desfeito (só apagando e recriando).
Vantagens: protege contra mudanças acidentais e reduz a carga no API server (o kubelet deixa de observar o objeto).
Padrão de uso: versionar no nome (`config-v1`, `config-v2`) e trocar a referência no Deployment.

## Comandos guiados

```bash
oc create configmap ac08-fixo-v1 --from-literal=VERSAO=1 --dry-run=client -o json \
  | jq '.immutable=true | .metadata.labels={"academy.openshift.dev/managed-by":"academia"}' | oc apply -n ac08-config -f -
oc get configmap ac08-fixo-v1 -n ac08-config -o jsonpath='{.immutable}{"\n"}'
oc set data configmap/ac08-fixo-v1 VERSAO=2 -n ac08-config; echo "rc=$?"                  # recusado
oc patch configmap ac08-fixo-v1 -n ac08-config --type=merge -p '{"immutable":false}'; echo "rc=$?"   # recusado
oc label configmap ac08-fixo-v1 revisado=sim -n ac08-config                               # metadados podem mudar
oc create configmap ac08-fixo-v2 --from-literal=VERSAO=2 --dry-run=client -o json \
  | jq '.immutable=true | .metadata.labels={"academy.openshift.dev/managed-by":"academia"}' | oc apply -n ac08-config -f -
```

## Repetições

1. Injete `ac08-fixo-v1` no `ac08-app` (`--from`) e depois troque para o `v2`.
2. Faça o mesmo com um Secret imutável.
3. Apague o `v1` quando nenhum Deployment o usar mais.
4. `oc explain configmap.immutable`.
5. Liste os ConfigMaps imutáveis do projeto com `jq`.

## Desafio sem pista

Troque o `ac08-app` de `ac08-fixo-v1` para `ac08-fixo-v2` em uma única revisão, prove o valor novo e apague o `v1`.

## Diagnóstico controlado

- **Sintoma:** `field is immutable when immutable is set` (ou mensagem equivalente).
- **Hipóteses:** objeto marcado como imutável.
- **Investigação:** `oc get configmap <nome> -o jsonpath='{.immutable}'`.
- **Reversão:** crie uma versão nova com outro nome.

## Validação

```bash
oc get configmap ac08-fixo-v2 -n ac08-config -o jsonpath='{.immutable} {.data.VERSAO}{"\n"}'   # true 2
```

## Limpeza segura

```bash
oc delete configmap ac08-fixo-v1 ac08-fixo-v2 -n ac08-config --ignore-not-found
```
