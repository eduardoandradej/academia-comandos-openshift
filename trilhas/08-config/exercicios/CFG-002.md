# CFG-002 — Injetar ConfigMap como variáveis de ambiente

## Identificação

- **ID:** CFG-002
- **Trilha:** [08 — ConfigMaps e Secrets](../README.md)

- **Fichas de comando:** [`oc-configmap-secret`](../../../catalogo/fichas/oc-configmap-secret.md), [`oc-set`](../../../catalogo/fichas/oc-set.md)

## Objetivo e indicador de sucesso

Injetar um ConfigMap inteiro (com e sem prefixo) e uma chave isolada como variáveis de um Deployment, e conferir dentro do pod.

**Indicador de sucesso:** `oc exec` mostra `MODO`, `CFG_COR` e `NIVEL` com os valores certos.

## Conceito

| Forma | YAML gerado | Resultado |
|---|---|---|
| `oc set env deploy/x --from=configmap/cm` | `envFrom: [{configMapRef: {name: cm}}]` | uma variável por chave |
| `... --prefix=CFG_` | `envFrom` com `prefix` | `CFG_<chave>` |
| chave isolada (YAML ou `--keys`) | `env[].valueFrom.configMapKeyRef` | só aquela chave, com o nome que você escolher |

Chaves que não são nomes válidos de variável (por exemplo, `app.conf`) são **ignoradas** pelo `envFrom` (com evento de aviso).

## Comandos guiados

```bash
oc create deployment ac08-app --image=registry.access.redhat.com/ubi9/httpd-24:latest -n ac08-config
oc label deployment ac08-app academy.openshift.dev/managed-by=academia -n ac08-config
oc set env deployment/ac08-app --from=configmap/ac08-literal -n ac08-config
oc set env deployment/ac08-app --from=configmap/ac08-env --prefix=CFG_ -n ac08-config
oc set env deployment/ac08-app NIVEL=configmap:ac08-env:NIVEL_LOG -n ac08-config 2>/dev/null \
  || oc patch deployment ac08-app -n ac08-config --type=json -p '[{"op":"add","path":"/spec/template/spec/containers/0/env/-","value":{"name":"NIVEL","valueFrom":{"configMapKeyRef":{"name":"ac08-env","key":"NIVEL_LOG"}}}}]'
oc rollout status deployment/ac08-app -n ac08-config
oc exec deploy/ac08-app -n ac08-config -- env | grep -E '^(MODO|NIVEL_LOG|CFG_|NIVEL)=' | sort
oc get deployment ac08-app -n ac08-config -o jsonpath='{.spec.template.spec.containers[0].envFrom}{"\n"}{.spec.template.spec.containers[0].env}{"\n"}'
oc set env deployment/ac08-app --list -n ac08-config
```

## Repetições

1. `oc set env deployment/ac08-app --from=configmap/ac08-arquivo -n ac08-config` — o que acontece com a chave `app.conf`? (veja os eventos)
2. Use `--keys=COR` para injetar só uma chave do `ac08-env`.
3. Remova o `envFrom` do `ac08-literal` com `oc patch --type=json` (operação `remove` no índice certo de `envFrom`) e confira.
4. Quem vence se a mesma variável vier de `env` e de `envFrom`?
5. Repita a injeção em um Deployment novo, de memória.

## Desafio sem pista

Faça a variável `LOG_LEVEL` do contêiner receber o valor da chave `NIVEL_LOG` do `ac08-env`, **sem** injetar nenhuma outra
chave desse ConfigMap, e prove por `oc exec`.

## Diagnóstico controlado

- **Sintoma:** `Warning ... Keys [app.conf] from the EnvFrom configMap ac08-config/ac08-arquivo were skipped since they are considered invalid environment variable names.`
- **Hipóteses:** chave com ponto não é nome válido de variável.
- **Investigação:** `oc get events -n ac08-config --field-selector reason=InvalidEnvironmentVariableNames`.
- **Reversão:** monte esse ConfigMap como **arquivo** (CFG-003) em vez de variável.

## Validação

```bash
oc exec deploy/ac08-app -n ac08-config -- printenv CFG_COR    # azul
```
