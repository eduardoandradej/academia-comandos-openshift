## Conceito

O sorteio tira a pista do nome do arquivo: você recebe só o sintoma. Repita em dias diferentes (D+1, D+3, D+7);
anote o tempo e o andar em que cada defeito apareceu. Os casos 06 (rede) e 10 (renderização) ficam fora do sorteio
porque mudam de projeto ou não usam o cluster.

## Comandos guiados

```bash
sorteia() {
  local n; n=$(printf '%s\n' 01 02 03 04 05 07 08 09 | shuf -n1)
  oc apply -f "manifests/casos/caso-$n.yaml" -n ac19-casos >/dev/null && echo "$n" > /tmp/ac19-sorteado
  sed -n '1s/^# Caso [0-9]* (Trilha 19): /sintoma: /p' "manifests/casos/caso-$n.yaml"
  date +%s > /tmp/ac19-inicio
}
resolvi() { echo "caso $(cat /tmp/ac19-sorteado): $(( ($(date +%s) - $(cat /tmp/ac19-inicio)) / 60 )) min"; }
sorteia
triagem ac19-casos 2>/dev/null || oc get all -n ac19-casos
# ... diagnóstico e correção ...
resolvi
oc delete -f "manifests/casos/caso-$(cat /tmp/ac19-sorteado).yaml" -n ac19-casos --ignore-not-found
```

## Repetições

Repita o sorteio em D+1, D+3 e D+7, registrando caso, tempo e andares. Meta: todos os casos abaixo de 10 minutos.

## Desafio sem pista

Faça três sorteios seguidos sem consulta e encerre a trilha com a limpeza abaixo.

## Diagnóstico controlado

- **Sintoma:** o sorteio aplica um caso por cima de outro ainda não limpo e os sintomas se misturam.
- **Hipóteses:** caso anterior não removido.
- **Investigação:** `oc get all -n ac19-casos -l academy.openshift.dev/managed-by=academia --show-labels | grep caso`.
- **Reversão:** limpe o caso anterior antes de sortear outro.

## Validação

```bash
for p in ac19-casos ac19-rede; do oc get project $p 2>&1 | grep -q NotFound && echo "$p removido"; done
```

## Limpeza segura

```bash
scripts/safe-cleanup.sh -n ac19-casos --execute --delete-project
oc get project ac19-rede >/dev/null 2>&1 && scripts/safe-cleanup.sh -n ac19-rede --execute --delete-project
rm -rf /tmp/ac19 /tmp/ac19-*
```
