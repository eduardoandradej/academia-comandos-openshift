## Conceito

Em um SNO com 6 vCPU e 20 GiB compartilhados com o control plane, cada projeto de treino precisa de um teto:

- **ResourceQuota** limita a soma do projeto (pods, requests, limits, Services, PVCs).
- **LimitRange** dá requests/limits **padrão** a contêineres que não declaram nada e impõe máximos.

Com quota de `limits.memory`, todo pod precisa declarar limits — o LimitRange preenche isso automaticamente. A quota
da Academia proíbe `LoadBalancer`, `NodePort` e PVCs (não há StorageClass no HomeLab).

Ordem segura para qualquer mutação declarativa: **ler o arquivo → dry-run client → dry-run server → diff → apply → verificar**.

## Comandos guiados

```bash
F=manifests/baseline-seguro/quota-limitrange.yaml
less "$F"                                              # revise antes de aplicar (q para sair)
oc apply --dry-run=client -f "$F" -n ac00-orientacao   # validação local, sem contatar a API
oc apply --dry-run=server -f "$F" -n ac00-orientacao   # a API valida e roda admissão, sem gravar
oc diff -f "$F" -n ac00-orientacao; echo "rc=$?"       # rc=1 significa "há diferenças" (normal na 1ª vez)
oc apply -f "$F" -n ac00-orientacao                    # grava
oc label namespace ac00-orientacao \
  academy.openshift.dev/managed-by=academia academy.openshift.dev/trilha=00   # rótulos do namespace
oc get namespace ac00-orientacao --show-labels
oc get resourcequota,limitrange -n ac00-orientacao
```

## Repetições

1. `oc diff -f "$F" -n ac00-orientacao; echo "rc=$?"` após o apply — rc=0 e nenhuma saída.
2. `oc apply -f "$F" -n ac00-orientacao` de novo — a saída diz `unchanged`.
3. `oc get resourcequota ac-quota -n ac00-orientacao -o yaml | grep -A12 '^spec:'`.
4. `oc label namespace ac00-orientacao academy.openshift.dev/trilha-` — remove um rótulo; depois recoloque-o.
5. `oc get namespaces -l academy.openshift.dev/managed-by=academia` — todos os namespaces da Academia.

## Desafio sem pista

Altere **localmente** uma cópia do manifesto (em `/tmp`) para permitir 8 pods, mostre a diferença que o cluster
aplicaria **sem aplicá-la** e descarte a cópia.

## Diagnóstico controlado

- **Sintoma:** `oc diff` termina com código 1 e você interpreta como erro.
- **Hipóteses:** (a) é o código de "há diferenças"; (b) é falha real.
- **Investigação:** veja a saída: um diff com linhas `+`/`-` indica (a). Código maior que 1 ou mensagem `error:` indica (b).
- **Reversão:** nada a reverter.

## Validação

```bash
oc get resourcequota ac-quota -n ac00-orientacao -o name
oc get limitrange ac-limits -n ac00-orientacao -o name
oc get namespace ac00-orientacao -o jsonpath='{.metadata.labels.academy\.openshift\.dev/managed-by}{"\n"}'   # academia
```
