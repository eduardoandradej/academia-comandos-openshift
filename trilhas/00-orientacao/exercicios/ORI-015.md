## Identificação

- **ID:** ORI-015
- **Trilha:** [00 — Orientação e segurança](../README.md)
- **Referência didática:** Metodologia própria da Academia (limpeza previsível).
- **Fichas de comando:** [`oc-project`](../../../catalogo/fichas/oc-project.md), [`oc-get`](../../../catalogo/fichas/oc-get.md)

## Objetivo e indicador de sucesso

Encerrar a Trilha 00 deixando o cluster como estava: sem recursos rotulados, sem o projeto de treino e com saúde conferida.

**Indicador de sucesso:** `oc get project ac00-orientacao` responde `NotFound`, o preflight não tem `FALHA` e você explica cada recusa do `safe-cleanup.sh`.

## Nível

**Nível:** Iniciante

## Duração e repetições

- **Duração sugerida:** 15 min
- **Repetições:** 5× (ciclo completo criar → limpar em um projeto rascunho)

## Contexto

- **Terminal:** `student@ocp-admin`, na raiz do repositório clonado (`cd ~/academia-comandos-openshift`)
- **Perfil:** `developer`
- **Projeto:** `ac00-orientacao`
- **Impacto:** MUTAÇÃO LOCAL REVERSÍVEL (apaga o projeto de treino)

## Pré-flight

```bash
scripts/preflight.sh          # deve terminar sem FALHA; PULADO é normal para developer
oc whoami                     # esperado: developer
oc whoami --show-server       # esperado: https://api.ocp.example.lab:6443
```

## Conceito

O `scripts/safe-cleanup.sh` só aceita namespaces `ac-*`/`acNN-*`, só apaga recursos com o rótulo da Academia, nunca
usa `--all`/`-A` e por padrão **apenas simula**. Para apagar o próprio projeto, exige `--delete-project` e prova de
que ele é da Academia (rótulo no namespace ou você como `requester`).

A exclusão de projeto é assíncrona: o namespace passa por `Terminating` enquanto os controladores removem o conteúdo.
Nunca remova *finalizers* para "acelerar" — isso é VERMELHO.

## Comandos guiados

```bash
scripts/status.sh                                          # projetos de laboratório visíveis
scripts/status.sh -n ac00-orientacao                       # rotulados, não rotulados, quota
scripts/safe-cleanup.sh -n ac00-orientacao                 # simulação
scripts/safe-cleanup.sh -n ac00-orientacao --execute --delete-project   # pede para digitar o nome
oc get project ac00-orientacao                             # repita até NotFound
scripts/safe-cleanup.sh -n openshift-console; echo "rc=$?" # recusa esperada (rc=2)
scripts/safe-cleanup.sh -n ac00-orientacao -l app=demo; echo "rc=$?"   # recusa: seletor fora do padrão
scripts/preflight.sh                                       # saúde final
```

## Repetições

Ciclo completo em um projeto rascunho (5×):

```bash
oc new-project ac00-ciclo --skip-config-write
oc create configmap c1 --from-literal=a=1 -n ac00-ciclo --dry-run=client -o yaml \
  | oc label --local -f - academy.openshift.dev/managed-by=academia -o yaml | oc apply -n ac00-ciclo -f -
scripts/safe-cleanup.sh -n ac00-ciclo
scripts/safe-cleanup.sh -n ac00-ciclo --execute --delete-project --confirm ac00-ciclo
oc get project ac00-ciclo     # até NotFound
```

## Desafio sem pista

Sem consultar, escreva a sequência de encerramento de qualquer trilha: o que verificar antes, como simular, como
apagar e como provar que nada ficou para trás.

## Diagnóstico controlado

- **Sintoma:** `oc get project ac00-orientacao` mostra `Terminating` por vários minutos.
- **Hipóteses:** (a) remoção normal ainda em curso; (b) algum recurso com finalizer aguardando um controlador.
- **Investigação:** `oc get project ac00-orientacao -o jsonpath='{.status.phase}{"\n"}'`; no perfil admin:
  `oc get namespace ac00-orientacao -o jsonpath='{range .status.conditions[*]}{.type}={.status} {.message}{"\n"}{end}'`.
- **Reversão:** aguarde. Se passar de 15 minutos, registre as condições e não edite finalizers.

## Validação

```bash
oc get project ac00-orientacao 2>&1 | grep -q NotFound && echo "projeto removido"
scripts/status.sh
scripts/preflight.sh >/dev/null && echo "preflight sem FALHA"
```
