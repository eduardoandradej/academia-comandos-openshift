# ORI-011 — Criar o projeto de treino ac00-orientacao

## Identificação

- **ID:** ORI-011
- **Trilha:** [00 — Orientação e segurança](../README.md)
- **Referência didática:** DO180 — projetos e namespaces. DO280 — autoprovisionamento de projetos.
- **Fichas de comando:** [`oc-new-project`](../../../catalogo/fichas/oc-new-project.md), [`oc-project`](../../../catalogo/fichas/oc-project.md), [`oc-auth-can-i`](../../../catalogo/fichas/oc-auth-can-i.md)
- **Status:** proposto — escrito e revisado estaticamente; ainda não executado contra o cluster pelo autor

## Objetivo e indicador de sucesso

Criar, inspecionar e (para um projeto rascunho) apagar projetos de treino como `developer`.

**Indicador de sucesso:** `ac00-orientacao` existe, tem você como `requester` e um segundo projeto `ac00-rascunho` foi criado e removido até `NotFound`.

## Nível

**Nível:** Iniciante

## Duração e repetições

- **Duração sugerida:** 15 min
- **Repetições:** 5× (criar/apagar o rascunho)

## Contexto

- **Terminal:** `student@ocp-admin`, na raiz do repositório clonado (`cd ~/academia-comandos-openshift`)
- **Perfil:** `developer`
- **Projeto:** `ac00-orientacao` (permanece até o ORI-015) e `ac00-rascunho` (descartável)
- **Impacto:** MUTAÇÃO LOCAL REVERSÍVEL

## Pré-flight

```bash
scripts/preflight.sh          # deve terminar sem FALHA; PULADO é normal para developer
oc whoami                     # esperado: developer
oc whoami --show-server       # esperado: https://api.ocp.example.lab:6443
```

## Conceito

No OpenShift, um **Project** é um Namespace com metadados extras e um fluxo de autoprovisionamento: `oc new-project`
cria uma `ProjectRequest`, e o cluster gera o Namespace, dá ao solicitante o papel `admin` **dentro dele** e grava a
anotação `openshift.io/requester`.

O papel `admin` do projeto não permite alterar o objeto Namespace (que é de escopo de cluster). Por isso `developer`
não consegue rotular o próprio namespace — esse rótulo será colocado pelo perfil `admin` no ORI-012.

Convenção da Academia: projetos de treino se chamam `acNN-<tema>` e são apagados ao fim da trilha.

## Comandos guiados

```bash
oc auth can-i create projectrequests                  # yes = autoprovisionamento habilitado
oc new-project ac00-orientacao \
  --display-name='Academia 00 - Orientação' \
  --description='Trilha 00: projeto de treino descartável'   # também muda o projeto atual
oc project -q                                         # -q = só o nome do projeto atual
oc get project ac00-orientacao -o jsonpath='{.metadata.annotations.openshift\.io/requester}{"\n"}'
oc get rolebindings -n ac00-orientacao                # quem tem qual papel no projeto
oc auth can-i --list -n ac00-orientacao | head -25    # o que você pode fazer nele
oc label namespace ac00-orientacao academy.openshift.dev/managed-by=academia   # esperado: Forbidden
```

## Repetições

Ciclo do rascunho (5×, sem olhar após a segunda):

```bash
oc new-project ac00-rascunho --skip-config-write   # cria sem mudar o projeto atual
oc get project ac00-rascunho
oc delete project ac00-rascunho
oc get project ac00-rascunho                      # repita até NotFound (a exclusão é assíncrona)
oc project -q                                     # continua ac00-orientacao?
```

## Desafio sem pista

Torne a criação do projeto **idempotente**: uma linha que cria `ac00-orientacao` só se ele não existir e, em qualquer
caso, termina com ele como projeto atual. Rode-a duas vezes seguidas sem erro.

## Diagnóstico controlado

- **Sintoma:** `Error from server (Forbidden): namespaces "ac00-orientacao" is forbidden: User "developer" cannot patch resource "namespaces"...` (texto aproximado).
- **Hipóteses:** (a) o papel `admin` do projeto não cobre o objeto Namespace; (b) você não é o dono do projeto.
- **Investigação:** `oc auth can-i patch namespaces/ac00-orientacao`; `oc get rolebindings -n ac00-orientacao -o wide`.
- **Reversão:** nada foi alterado (a requisição foi negada). O rótulo será aplicado pelo `admin` no ORI-012.

## Validação

```bash
oc get project ac00-orientacao -o name                 # project.project.openshift.io/ac00-orientacao
oc get project ac00-rascunho 2>&1 | grep -q NotFound && echo "rascunho removido"
```

## Limpeza segura

Mantenha `ac00-orientacao` para os próximos exercícios (ele será removido no ORI-015). Garanta que o rascunho sumiu:
`oc get project ac00-rascunho` deve responder `NotFound`.
