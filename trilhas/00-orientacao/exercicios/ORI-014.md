## Objetivo e indicador de sucesso

Criar um ConfigMap rotulado em quatro etapas verificáveis (permissão, dry-run client, dry-run server, criação) e apagá-lo pelo rótulo.

**Indicador de sucesso:** o ConfigMap `ac00-cfg` é criado com o rótulo da Academia e apagado por seletor, sem afetar mais nada.

## Conceito

- `--dry-run=client`: o `oc` monta o objeto localmente; não fala com a API (não valida nomes duplicados nem quota).
- `--dry-run=server`: a API valida, aplica defaults e roda a admissão, mas **não grava**.
- Rótulo `academy.openshift.dev/managed-by=academia`: é a "etiqueta de propriedade" que permite limpar com
  `-l` sem atingir nada que não seja da Academia.

`oc create` não é idempotente (falha com `AlreadyExists`). O padrão gerar → rotular → aplicar via pipeline é.

## Comandos guiados

```bash
NS=ac00-orientacao
oc auth can-i create configmaps -n "$NS"
oc create configmap ac00-cfg --from-literal=MODO=treino -n "$NS" --dry-run=client -o yaml
oc create configmap ac00-cfg --from-literal=MODO=treino -n "$NS" --dry-run=server -o yaml
oc create configmap ac00-cfg --from-literal=MODO=treino -n "$NS"
oc label configmap ac00-cfg academy.openshift.dev/managed-by=academia -n "$NS"
oc get configmap -n "$NS" -l academy.openshift.dev/managed-by=academia --show-labels
oc get configmap ac00-cfg -n "$NS" -o jsonpath='{.data.MODO}{"\n"}'
oc delete configmap -l academy.openshift.dev/managed-by=academia -n "$NS" --dry-run=client   # o que seria apagado
oc delete configmap -l academy.openshift.dev/managed-by=academia -n "$NS"
```

## Repetições

1. Forma idempotente em uma linha (repita 3× seguidas; nenhuma falha):

   ```bash
   oc create configmap ac00-cfg --from-literal=MODO=treino --dry-run=client -o yaml \
     | oc label --local -f - academy.openshift.dev/managed-by=academia -o yaml \
     | oc apply -n ac00-orientacao -f -
   ```

2. Mude o valor para `MODO=revisao` na linha acima e reaplique: a saída diz `configured`.
3. `oc get configmap ac00-cfg -n ac00-orientacao -o yaml | grep -A3 '^data:'`.
4. Compare as saídas de `--dry-run=client` e `--dry-run=server`: quais campos só aparecem na segunda?
5. Apague por rótulo e confirme que `kube-root-ca.crt` e `openshift-service-ca.crt` continuam lá.

## Desafio sem pista

Crie três ConfigMaps (`ac00-a`, `ac00-b`, `ac00-c`) com o rótulo da Academia e um quarto (`ac00-sem-rotulo`) sem
rótulo. Apague apenas os três rotulados, prove que o quarto sobreviveu e depois remova-o pelo nome.

## Diagnóstico controlado

- **Sintoma:** `error: failed to create configmap: configmaps "ac00-cfg" already exists`.
- **Hipóteses:** (a) `oc create` repetido; (b) outro exercício deixou o objeto para trás.
- **Investigação:** `oc get configmap ac00-cfg -n ac00-orientacao -o jsonpath='{.metadata.creationTimestamp} {.metadata.labels}{"\n"}'`.
- **Reversão:** se for resíduo seu e tiver o rótulo, apague por rótulo; senão, use a forma idempotente (`apply`).
