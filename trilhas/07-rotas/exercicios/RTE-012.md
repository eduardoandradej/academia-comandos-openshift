## Objetivo e indicador de sucesso

Criar um objeto `Ingress` (padrão Kubernetes) e ver o OpenShift gerar uma Route automaticamente a partir dele.

**Indicador de sucesso:** `oc get routes` mostra uma Route com dono `Ingress/loja-ing`, e o host responde `azul`.

## Conceito

O OpenShift aceita `Ingress` (portabilidade com outros Kubernetes): um controlador converte cada regra em Route,
com `ownerReferences` apontando para o Ingress. Edite o **Ingress**, não a Route gerada — ela é reconciliada.
Recursos exclusivos de Route (pesos, passthrough, anotações HAProxy) são mais naturais na própria Route.

## Comandos guiados

```bash
oc create ingress loja-ing --rule="ing-ac07.apps.ocp.example.lab/*=web-azul:8080" -n ac07-rotas
oc get ingress loja-ing -n ac07-rotas
oc get routes -n ac07-rotas -o custom-columns=NOME:.metadata.name,HOST:.spec.host,DONO:.metadata.ownerReferences[0].kind
curl -sS http://ing-ac07.apps.ocp.example.lab/
R=$(oc get routes -n ac07-rotas -o json | jq -r '.items[] | select(.metadata.ownerReferences[0].name=="loja-ing") | .metadata.name')
oc delete route "$R" -n ac07-rotas; sleep 5; oc get route -n ac07-rotas | grep loja-ing   # recriada
```

## Repetições

1. Mude o Service do Ingress para `web-verde` com `oc patch ingress` e teste.
2. Edite a Route gerada (por exemplo, um rótulo) e veja se a mudança persiste.
3. `oc get ingress loja-ing -n ac07-rotas -o yaml | sed -n '/^spec:/,$p'`.
4. `oc explain ingress.spec.rules`.
5. Compare a quantidade de campos de um Ingress e de uma Route para o mesmo resultado.

## Desafio sem pista

Com um único Ingress, publique `/azul` para `web-azul` e `/verde` para `web-verde` no host `ing2-ac07.apps.ocp.example.lab`,
e verifique quantas Routes foram geradas.

## Diagnóstico controlado

- **Sintoma:** a mudança feita direto na Route gerada desaparece.
- **Hipóteses:** o controlador reconcilia a Route a partir do Ingress (dono).
- **Investigação:** `ownerReferences` da Route.
- **Reversão:** faça a mudança no Ingress.

## Validação

```bash
curl -sS http://ing-ac07.apps.ocp.example.lab/    # azul (ou verde, após a repetição 1)
```
