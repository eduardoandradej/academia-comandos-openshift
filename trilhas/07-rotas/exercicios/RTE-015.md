## Conceito

O circuito diz **o que** obter, não **como**. Itens que exigiram consulta vão para a revisão D+1.

## Comandos guiados

Circuito sem pistas:

1. Criar uma Route HTTP a partir de um Service.
2. Mostrar o host gerado e testar pela `ocp-admin`.
3. Testar a mesma Route sem DNS, só com o cabeçalho `Host`.
4. Criar uma Route com hostname próprio.
5. Duas Routes no mesmo host com caminhos diferentes e reescrita.
6. Ler a condição de admissão de uma Route.
7. Criar uma Route edge com redirecionamento de HTTP.
8. Ler emissor e SAN do certificado servido.
9. Criar uma Route edge com certificado próprio e validar com `--cacert`.
10. Criar uma Route passthrough para a 8443.
11. Gerar o YAML de uma reencrypt sem criá-la.
12. Dividir tráfego 70/30 entre azul e verde.
13. Desligar o cookie de afinidade de uma Route.
14. Criar um Ingress e localizar a Route gerada.
15. Rodar o roteiro de diagnóstico em uma Route com defeito.

## Repetições

Repita o circuito em D+1, D+3 e D+7, anotando tempo e itens que exigiram consulta.

## Desafio sem pista

Faça o circuito completo sem consulta. Em seguida, encerre a trilha com a limpeza abaixo e prove que nada ficou.

## Diagnóstico controlado

- **Sintoma:** depois de apagar o projeto, o navegador do Windows ainda "abre" o host antigo.
- **Hipóteses:** cache do navegador ou linha no `hosts` apontando para o router, que agora responde 503.
- **Investigação:** `curl -sS -o /dev/null -w '%{http_code}\n' http://loja-ac07.apps.ocp.example.lab/` (503).
- **Reversão:** remova as linhas `ac07` do `hosts` e limpe o cache.

## Validação

```bash
oc get project ac07-rotas 2>&1 | grep -q NotFound && echo "trilha 07 limpa"
curl -sS -o /dev/null -w '%{http_code}\n' http://loja-ac07.apps.ocp.example.lab/    # 503: nenhuma Route com esse host
```

```bash
scripts/safe-cleanup.sh -n ac07-rotas                              # simula

oc get project ac07-rotas                                          # até NotFound
rm -rf /tmp/ac07
```

No Windows, remova do `hosts` as linhas que contêm `ac07`.
