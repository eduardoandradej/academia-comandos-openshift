## Conceito

O **Ingress Operator** gerencia `IngressController`s. O `default`:

- define o domínio (`*.apps.ocp.example.lab`);
- publica o router com `endpointPublishingStrategy` (no SNO bare metal, em geral `HostNetwork`: o router escuta direto nas portas 80/443 do nó);
- usa um certificado padrão (Secret em `openshift-ingress`) assinado pela CA do operador, se nenhum outro foi configurado.

**Tudo aqui é somente leitura.** Alterar o Ingress Controller pode derrubar o acesso à Console e ao OAuth.

## Comandos guiados

```bash
oc get co ingress
oc get ingresscontroller -n openshift-ingress-operator
oc get ingresscontroller default -n openshift-ingress-operator -o jsonpath='{.status.domain} {.status.endpointPublishingStrategy.type} réplicas={.status.availableReplicas}{"\n"}'
oc get pods -n openshift-ingress -o wide
oc get svc -n openshift-ingress
oc get ingresscontroller default -n openshift-ingress-operator -o jsonpath='{.spec.defaultCertificate.name}{"\n"}'   # vazio = certificado gerado pelo operador
oc get secrets -n openshift-ingress -o name | grep -i -E 'cert|tls'                                                 # só nomes
oc get routes -A --no-headers | wc -l
ac-dev
```

## Repetições

1. `oc get ingresses.config.openshift.io cluster -o jsonpath='{.spec.domain}{"\n"}'`.
2. Liste as Routes da plataforma (Console, OAuth) e seus tipos de terminação.
3. `oc describe co ingress | sed -n '/Conditions:/,/Extension:/p'`.
4. Por que o router do SNO roda com 1 réplica?
5. Relacione o `hostNetwork` dos pods do router com a porta 80 aberta no IP do nó.

## Desafio sem pista

Produza um relatório de 4 linhas: domínio das Routes, estratégia de publicação, nó/IP onde o router roda e nome do Secret do certificado padrão — tudo com leitura.

## Diagnóstico controlado

- **Sintoma:** todas as Routes do cluster (inclusive a Console) deixaram de responder.
- **Hipóteses:** problema no router/Ingress Controller, não nas Routes do projeto.
- **Investigação:** `oc get co ingress`; pods em `openshift-ingress`; eventos.
- **Reversão:** **não** altere nada na plataforma; registre e siga os procedimentos de recuperação da apostila.
