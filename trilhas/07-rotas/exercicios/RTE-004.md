## Objetivo e indicador de sucesso

Publicar azul e verde no mesmo host em caminhos diferentes (`/azul` e `/verde`), com reescrita do caminho para `/`.

**Indicador de sucesso:** `http://cores-ac07.apps.ocp.example.lab/azul` → `azul` e `/verde` → `verde`.

## Conceito

Várias Routes podem compartilhar o mesmo host com `path` diferentes; o router escolhe o caminho mais específico. O
caminho é repassado ao backend como veio (`/azul`), e o httpd não tem esse arquivo → 404. A anotação
`haproxy.router.openshift.io/rewrite-target: /` reescreve o prefixo para `/` antes de entregar.

## Comandos guiados

```bash
H=cores-ac07.apps.ocp.example.lab
oc expose svc/web-azul  --name=cores-azul  --hostname=$H --path=/azul  -n ac07-rotas
oc expose svc/web-verde --name=cores-verde --hostname=$H --path=/verde -n ac07-rotas
curl -sS -o /dev/null -w '%{http_code}\n' "http://$H/azul"      # 404: o httpd recebeu /azul
oc annotate route cores-azul cores-verde haproxy.router.openshift.io/rewrite-target=/ -n ac07-rotas
sleep 5
curl -sS "http://$H/azul"; curl -sS "http://$H/verde"
oc get routes -n ac07-rotas -o custom-columns=NOME:.metadata.name,HOST:.spec.host,PATH:.spec.path,SVC:.spec.to.name
```

## Repetições

1. Acesse `http://$H/` (sem caminho): qual resposta e por quê?
2. Crie uma terceira Route `cores-raiz` com `--path=/` para o azul e repita o item 1.
3. Remova a anotação de uma das Routes e observe o 404 voltar.
4. Teste `http://$H/azul/` (barra final).
5. `oc get route cores-azul -n ac07-rotas -o jsonpath='{.metadata.annotations}{"\n"}'`.

## Desafio sem pista

No mesmo host, faça `/` responder `verde` e `/azul` responder `azul`, e prove que o caminho mais específico vence.

## Diagnóstico controlado

- **Sintoma:** `/azul` devolve 404, mas a Route existe e o Service responde.
- **Hipóteses:** o backend recebeu o caminho `/azul`, que não existe nele.
- **Investigação:** `oc logs deploy/web-azul -n ac07-rotas --tail=3` (se o httpd registrar acessos) ou teste o Service direto com `/`.
- **Reversão:** anotação `rewrite-target`.

## Validação

```bash
[ "$(curl -sS http://cores-ac07.apps.ocp.example.lab/verde)" = verde ] && echo OK
```

## Limpeza segura

```bash
oc delete route cores-azul cores-verde cores-raiz -n ac07-rotas --ignore-not-found
```
