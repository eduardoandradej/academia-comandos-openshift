## Conceito

Cada Ingress Controller que atende a Route registra em `status.ingress[]`: o `routerName` (`default`),
`routerCanonicalHostname` e condições. `Admitted=True` significa que o router publicou a Route. `False` traz um
motivo — o mais comum é `HostAlreadyClaimed` (outro objeto já usa o mesmo host e caminho).

## Comandos guiados

```bash
oc get route web-azul -n ac07-rotas -o jsonpath='{range .status.ingress[*]}{.routerName} {.host} {.conditions[0].type}={.conditions[0].status}{"\n"}{end}'
oc get route web-azul -n ac07-rotas -o jsonpath='{.status.ingress[0].routerCanonicalHostname}{"\n"}'
oc expose svc/web-verde --name=conflito --hostname="$(oc get route web-azul -n ac07-rotas -o jsonpath='{.spec.host}')" -n ac07-rotas
oc get route conflito -n ac07-rotas -o jsonpath='{.status.ingress[0].conditions[0].status} {.status.ingress[0].conditions[0].reason}: {.status.ingress[0].conditions[0].message}{"\n"}'
oc describe route conflito -n ac07-rotas | sed -n '/Requested Host/,/Path/p'
oc delete route conflito -n ac07-rotas
```

## Repetições

1. Liste todas as Routes do projeto com `Admitted` em uma coluna.
2. `oc get route web-azul -n ac07-rotas -o yaml | sed -n '/^status:/,$p'`.
3. Qual Route "ganha" um conflito: a mais antiga ou a mais nova?
4. Crie um conflito com `path` diferente: há conflito?
5. `oc explain route.status.ingress`.

## Desafio sem pista

Escreva uma linha que liste somente as Routes **não** admitidas do projeto, com o motivo.

## Diagnóstico controlado

- **Sintoma:** a Route existe, mas o `curl` cai em outra aplicação.
- **Hipóteses:** a sua Route não foi admitida (`HostAlreadyClaimed`) e o host pertence a outra.
- **Investigação:** `status.ingress[0].conditions`; procure outra Route com o mesmo host (`oc get routes -A` como admin).
- **Reversão:** use outro host ou remova a Route antiga, se for sua.

## Validação

```bash
oc get route web-azul -n ac07-rotas -o jsonpath='{.status.ingress[0].conditions[?(@.type=="Admitted")].status}{"\n"}'   # True
```
