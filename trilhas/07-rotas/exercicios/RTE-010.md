## Conceito

Uma Route pode ter um backend principal (`spec.to`) e `alternateBackends`, cada um com `weight` (0–256). O router
distribui as conexões na proporção dos pesos. Para medir, desative o cookie de afinidade do router — sem isso, um
navegador fica preso em um backend (o `curl` sem cookie já não fica).

## Comandos guiados

```bash
oc expose svc/web-azul --name=ab --hostname=ab-ac07.apps.ocp.example.lab -n ac07-rotas
oc annotate route ab haproxy.router.openshift.io/disable_cookies=true haproxy.router.openshift.io/balance=random -n ac07-rotas
oc set route-backends ab web-azul=80 web-verde=20 -n ac07-rotas
oc set route-backends ab -n ac07-rotas                        # mostra a divisão
sleep 5
for i in $(seq 50); do curl -sS http://ab-ac07.apps.ocp.example.lab/; done | sort | uniq -c
oc set route-backends ab web-azul=0 web-verde=100 -n ac07-rotas
sleep 5; for i in $(seq 10); do curl -sS http://ab-ac07.apps.ocp.example.lab/; done | sort | uniq -c
oc set route-backends ab --equal -n ac07-rotas
```

## Repetições

1. Teste 50/50, 90/10 e 0/100.
2. `oc get route ab -n ac07-rotas -o jsonpath='{.spec.to} {.spec.alternateBackends}{"\n"}'`.
3. Remova `disable_cookies` e repita com `curl -c /tmp/ac07/c.txt -b /tmp/ac07/c.txt`: o que muda?
4. `oc set route-backends ab --adjust web-verde=+10 -n ac07-rotas`.
5. Compare com a troca azul/verde por seletor da Trilha 06: qual é instantânea e qual é gradual?

## Desafio sem pista

Faça uma liberação gradual da verde em quatro passos (10%, 50%, 90%, 100%), medindo 40 respostas em cada passo.

## Diagnóstico controlado

- **Sintoma:** com 50/50, o navegador sempre mostra a mesma cor.
- **Hipóteses:** cookie de afinidade do router.
- **Investigação:** `curl -sI http://ab-ac07.apps.ocp.example.lab/ | grep -i set-cookie` (sem a anotação).
- **Reversão:** anotação `disable_cookies=true` ou limpe os cookies do navegador.
