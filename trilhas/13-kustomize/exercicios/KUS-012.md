## Objetivo e indicador de sucesso

Guardar o template como objeto do projeto, processá-lo pelo nome e instanciá-lo com `oc new-app --template`.

**Indicador de sucesso:** `oc get templates -n ac13-kustomize` mostra `ac13-web`, e `oc new-app --template=ac13-web -p NOME=ac13-tpl-c` cria a instância.

## Pré-flight

```bash
source scripts/perfis.sh && ac-dev
oc get project ac13-kustomize -o name   # se faltar: oc new-project ac13-kustomize
oc process -f manifests/templates/ac13-template.yaml --parameters
```

REQUER PREPARAÇÃO: pull de `registry.access.redhat.com/ubi9/httpd-24`.

## Conceito

| Forma | Fonte do template |
|---|---|
| `oc process -f arquivo` | arquivo local |
| `oc process nome` | Template do projeto atual |
| `oc process openshift//nome` | Template de outro namespace (ex.: `openshift`) |
| `oc new-app --template=nome -p ...` | processa e cria, mostrando o que foi criado |

Guardar no projeto permite que a equipe instancie sem ter o arquivo; editar o template exige `oc apply -f` dele.

## Comandos guiados

```bash
oc apply -f manifests/templates/ac13-template.yaml -n ac13-kustomize
oc get templates -n ac13-kustomize
oc process ac13-web -n ac13-kustomize --parameters
oc process ac13-web -n ac13-kustomize -p NOME=ac13-tpl-c -o yaml | grep -c '^- apiVersion'
oc new-app --template=ac13-web -p NOME=ac13-tpl-c -p MENSAGEM='via new-app' -n ac13-kustomize
oc get all -n ac13-kustomize -l app.kubernetes.io/part-of=ac13-template
```

## Repetições

1. Instancie `ac13-tpl-d` com `oc new-app --template` usando `--param-file`.
2. Mude o valor padrão de `MENSAGEM` no template guardado e instancie de novo.
3. Use `oc new-app --template=ac13-web --dry-run -o yaml` antes de criar.
4. O que o `new-app` acrescentou de rótulos além dos do template?
5. Apague só a instância `c` pelo rótulo `app=ac13-tpl-c`.

## Desafio sem pista

Instancie o template de **outro** projeto: guarde-o em `ac13-dev` e processe-o a partir do `ac13-kustomize`, criando a instância no `ac13-kustomize`.

## Diagnóstico controlado

- **Sintoma:** `error: unable to locate any templates loaded in accessible projects with name "ac13-wbe"`.
- **Hipóteses:** nome errado ou template em projeto sem acesso.
- **Investigação:** `oc get templates -n <projeto>`.
- **Reversão:** corrija o nome ou use `<projeto>//<nome>`.

## Validação

```bash
oc get deployment ac13-tpl-c -n ac13-kustomize -o name
```

## Limpeza segura

```bash
oc delete all,cm,secret -n ac13-kustomize -l app.kubernetes.io/part-of=ac13-template
oc delete deployment,service,cm,secret -n ac13-kustomize -l app.kubernetes.io/part-of=ac13-template --ignore-not-found
oc delete template ac13-web -n ac13-kustomize --ignore-not-found
oc delete template ac13-web -n ac13-dev --ignore-not-found
```
