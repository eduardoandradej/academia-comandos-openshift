## Conceito

Um **Template** (`template.openshift.io/v1`) é um objeto com `objects` (manifestos com `${PARAMETRO}`), `parameters`
(com `value` padrão, `required` ou `generate: expression`) e `labels` aplicados a tudo.

| Sintaxe | Resultado |
|---|---|
| `${NOME}` | substituição como **texto** |
| `${{REPLICAS}}` | substituição como **valor JSON** (número, booleano) |

Kustomize × Template: Kustomize transforma YAML existente (sem variáveis); Template substitui variáveis (estilo modelo).

## Comandos guiados

```bash
oc process -f manifests/templates/ac13-template.yaml --parameters
grep -n -E '\$\{\{?[A-Z_]+\}\}?' manifests/templates/ac13-template.yaml
oc get templates -n openshift | head -15                       # templates de exemplo do cluster (leitura)
oc get templates -n openshift --no-headers | wc -l
oc describe template -n openshift "$(oc get templates -n openshift -o name | head -1 | cut -d/ -f2)" | sed -n '1,30p'
oc explain template.parameters
```

## Repetições

1. Quais parâmetros do `ac13-web` são obrigatórios? Quais têm valor gerado?
2. Leia os parâmetros de um template do namespace `openshift` com `oc process -n openshift <nome> --parameters`.
3. O que aconteceria com `replicas: ${REPLICAS}` (sem chaves duplas)? (TS-042)
4. Onde ficam os rótulos aplicados a todos os objetos?
5. Por que os templates de `openshift` podem não existir no seu cluster? (depende do operador Samples)

## Desafio sem pista

Liste os 5 templates de `openshift` com mais parâmetros obrigatórios, com o número de cada um.

## Diagnóstico controlado

- **Sintoma:** `oc get templates -n openshift` responde vazio.
- **Hipóteses:** o operador de exemplos (Samples) está `Removed` ou não instalou templates nesta instalação.
- **Investigação:** (admin, leitura) `oc get configs.samples.operator.openshift.io cluster -o jsonpath='{.spec.managementState}'`.
- **Reversão:** nada a reverter; use o template do repositório.

## Validação

oc process -f manifests/templates/ac13-template.yaml --parameters | grep -c -E '^(NOME|MENSAGEM|REPLICAS|SENHA)'   # 4
