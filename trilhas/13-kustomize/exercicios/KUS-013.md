## Conceito

| | Kustomize | Template | Helm (Trilha 14) |
|---|---|---|---|
| Modelo | transformação de YAML | substituição de variáveis | modelos Go + valores |
| Base legível como manifesto | sim | não (tem `${}`) | não (tem `{{ }}`) |
| Estado no cluster | nenhum | objeto Template (opcional) | release com histórico |
| Embutido no `oc` | sim | sim | não (cliente `helm`) |
| Bom para | ambientes da mesma aplicação | catálogo de autoatendimento | distribuir aplicações a terceiros |

## Comandos guiados

```bash
mkdir -p /tmp/ac13/kustomize/overlays/qa
cat > /tmp/ac13/kustomize/overlays/qa/kustomization.yaml <<'EOF'
apiVersion: kustomize.config.k8s.io/v1beta1
kind: Kustomization
resources:
  - ../../base
namespace: ac13-qa
replicas:
  - name: ac13-loja
    count: 2
configMapGenerator:
  - name: ac13-pagina
    behavior: replace
    literals:
      - index.html=qa
EOF
oc kustomize /tmp/ac13/kustomize/overlays/qa | grep -E 'replicas|index.html|namespace' | sort | uniq -c
oc process -f manifests/templates/ac13-template.yaml -p NOME=ac13-qa -p MENSAGEM=qa -p REPLICAS=2 -o yaml | grep -E 'replicas|index.html'
```

## Diagnóstico controlado

- **Sintoma:** o overlay `qa` renderiza, mas `oc apply -k` falha com `namespaces "ac13-qa" not found`.
- **Hipóteses:** o namespace do overlay não existe (Kustomize não cria projetos).
- **Investigação:** `oc get project ac13-qa`.
- **Reversão:** crie o projeto (`oc new-project`) ou só renderize (este exercício não aplica).
