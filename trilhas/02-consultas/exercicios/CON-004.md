## Conceito

Sintaxe: `oc get TIPO[,TIPO...] [NOME...] [-n NS] [-o FORMATO] [flags]`, ou `oc get TIPO/NOME`.

| Flag | Efeito |
|---|---|
| `-o wide` | colunas extras (IP, nó, imagens) |
| `-o name` | `tipo.grupo/nome` — ideal para encadear em scripts |
| `--show-labels` | coluna com todos os rótulos |
| `--no-headers` | sem cabeçalho (bom para `wc -l`, `awk`) |
| `-A` | todos os namespaces (exige permissão de cluster) |
| `--ignore-not-found` | não falha se o nome não existir |

## Comandos guiados

```bash
oc get pods -n ac02-consultas
oc get pods -n ac02-consultas -o wide                 # IP do pod e nó
oc get deploy,rs,pods,svc -n ac02-consultas           # vários tipos
oc get deployment/obs-web service/obs-web -n ac02-consultas
oc get pods -n ac02-consultas -o name
oc get pods -n ac02-consultas --show-labels
oc get pods -n ac02-consultas --no-headers | wc -l    # 2
oc get configmap nao-existe -n ac02-consultas --ignore-not-found; echo "rc=$?"
oc get pods -A 2>&1 | head -2                         # developer: Forbidden no escopo de cluster
```

## Repetições

1. `oc get deploy -n ac02-consultas -o wide` — quais colunas extras aparecem?
2. `oc get all -n ac02-consultas` — quais tipos o `all` inclui e quais não (ConfigMap?).
3. `oc get rs -n ac02-consultas` — quantos ReplicaSets e por quê?
4. `oc get svc obs-web -n ac02-consultas -o wide` — qual o seletor?
5. Repita 1–4 com `kubectl`.

## Desafio sem pista

Em uma linha, imprima apenas os nomes (sem prefixo de tipo) dos pods do alvo, um por linha, sem usar `jsonpath`.

## Diagnóstico controlado

- **Sintoma:** `Error from server (Forbidden): pods is forbidden: User "developer" cannot list resource "pods" in API group "" at the cluster scope`.
- **Hipóteses:** `-A` exige permissão de listar em todos os namespaces.
- **Investigação:** `oc auth can-i list pods --all-namespaces`; `oc auth can-i list pods -n ac02-consultas`.
- **Reversão:** nada a reverter; use `-n`.

## Validação

```bash
[ "$(oc get pods -n ac02-consultas -l app=obs-web --no-headers | wc -l)" -eq 2 ] && echo OK
```
