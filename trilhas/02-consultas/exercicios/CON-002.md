## Conceito

`oc explain <tipo>[.<campo>...]` mostra a documentação do esquema publicada pela API (OpenAPI). Para listas, o
caminho não usa índice: `pod.spec.containers.ports`. `--recursive` mostra a árvore inteira de campos (sem descrições).
`--api-version` escolhe a versão quando há mais de uma.

`oc api-versions` lista todos os grupos/versões servidos. `explain` responde "o que posso escrever no YAML";
`get -o yaml` responde "o que está escrito agora".

## Comandos guiados

```bash
oc api-versions | head -20
oc api-versions | grep -E '^(apps|route|project)'
oc explain deployment                                      # visão geral do tipo
oc explain deployment.spec.replicas                        # um campo
oc explain deployment.spec.template.spec.containers.resources.limits
oc explain pod.spec.containers --recursive | head -40      # árvore de campos
oc explain deployment --api-version=apps/v1
oc explain route.spec.tls                                  # tipo do OpenShift
```
