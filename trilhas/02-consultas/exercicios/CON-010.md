## Objetivo e indicador de sucesso

Usar `-o go-template` para saídas com condição (`if`), laço (`range`), índice de mapas (`index`) e contagem (`len`).

**Indicador de sucesso:** uma saída que marca com `!` os pods que não estão `Running`.

## Conceito

Go templates são mais expressivos que jsonpath: têm `if/else`, comparações (`eq`, `ne`), `index` para chaves com
caracteres especiais e `len`. Campos começam com `.` relativo ao contexto atual; dentro de `range`, o `.` é o item.

```text
{{range .items}}{{.metadata.name}}{{"\n"}}{{end}}
{{if eq .status.phase "Running"}}ok{{else}}!{{end}}
{{index .metadata.labels "academy.openshift.dev/trilha"}}
{{len .items}}
```

## Comandos guiados

```bash
oc get pods -n ac02-consultas -o go-template='{{range .items}}{{.metadata.name}}{{"\n"}}{{end}}'
oc get pods -n ac02-consultas -o go-template='{{len .items}}{{"\n"}}'
oc get pods -n ac02-consultas -o go-template='{{range .items}}{{if eq .status.phase "Running"}}  {{else}}! {{end}}{{.metadata.name}}{{"\n"}}{{end}}'
oc get deploy obs-web -n ac02-consultas -o go-template='{{index .metadata.labels "academy.openshift.dev/trilha"}}{{"\n"}}'
oc get configmap obs-config -n ac02-consultas -o go-template='{{range $k, $v := .data}}{{$k}}={{$v}}{{"\n"}}{{end}}'
```

## Repetições

1. Conte as chaves do ConfigMap com `len`.
2. Imprima `sem-ip` para pods sem `status.podIP` (use `if`).
3. Para cada pod, liste os nomes dos contêineres (laço dentro de laço).
4. Grave um template em `/tmp/ac.tmpl` e use `-o go-template-file=/tmp/ac.tmpl`.
5. Reescreva o item 3 em jsonpath e compare a legibilidade.

## Desafio sem pista

Para cada pod, imprima `nome: N contêiner(es), reinícios totais=R`, somando os reinícios de todos os contêineres.
(Dica: go-template não soma facilmente — decida se usa go-template, jsonpath+awk ou jq e justifique.)

## Diagnóstico controlado

- **Sintoma:** `error: error executing template ... map has no entry for key "academy"`, ou saída quebrada.
- **Como reproduzir sem risco:** `-o go-template='{{.metadata.labels.academy.openshift.dev/trilha}}'` no Deployment.
- **Hipóteses:** chave com pontos e barra exige `index`.
- **Investigação:** troque por `{{index .metadata.labels "academy.openshift.dev/trilha"}}`.
- **Reversão:** nada a reverter.
