## Conceito

Rótulos são pares chave/valor usados para **selecionar**. Seletores:

| Forma | Exemplo | Seleciona |
|---|---|---|
| igualdade | `-l app=obs-web` | valor igual |
| desigualdade | `-l 'tier!=db'` | valor diferente (ou chave ausente) |
| existência | `-l tier` | chave presente |
| ausência | `-l '!tier'` | chave ausente |
| conjunto | `-l 'tier in (web,api)'` | valor em um conjunto |
| exclusão | `-l 'tier notin (db)'` | valor fora do conjunto |
| combinação | `-l 'app=obs-web,tier=web'` | E lógico |

`-L chave1,chave2` exibe rótulos como colunas. Services e Deployments usam seletores para encontrar seus pods.

## Comandos guiados

```bash
oc get pods -n ac02-consultas -l app=obs-web
oc get pods -n ac02-consultas -l 'app=obs-web,tier=web'
oc get pods -n ac02-consultas -l 'tier in (web,api)'
oc get pods -n ac02-consultas -l '!tier'                   # nenhum: todos têm tier
oc get all -n ac02-consultas -l academy.openshift.dev/managed-by=academia
oc get pods -n ac02-consultas -L app,tier                  # rótulos como colunas
oc get svc obs-web -n ac02-consultas -o jsonpath='{.spec.selector}{"\n"}'   # seletor do Service
oc get pods -n ac02-consultas -l "$(oc get svc obs-web -n ac02-consultas -o jsonpath='{.spec.selector.app}' | sed 's/^/app=/')"
```

## Repetições

## Diagnóstico controlado

- **Sintoma:** `error: name cannot be provided when a selector is specified`.
- **Como reproduzir sem risco:** `oc get pods obs-web -l app=obs-web -n ac02-consultas`.
- **Hipóteses:** mistura de nome e seletor na mesma consulta.
- **Investigação:** releia o comando: escolha **nome** ou **seletor**.
- **Reversão:** nada a reverter.
