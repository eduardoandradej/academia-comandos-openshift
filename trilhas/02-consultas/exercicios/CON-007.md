## Conceito

Todo objeto tem a mesma forma:

- `apiVersion`, `kind` — o tipo;
- `metadata` — nome, namespace, rótulos, anotações, `uid`, `resourceVersion`, `ownerReferences`, `creationTimestamp`;
- `spec` — o estado **desejado** (o que você escreve);
- `status` — o estado **observado** (o que os controladores escrevem).

`ownerReferences` diz quem "possui" o objeto: apagar o dono apaga os dependentes (coleta de lixo). `managedFields`
registra quem gravou cada campo; o `oc get -o yaml` o oculta por padrão (`--show-managed-fields` o mostra).

## Comandos guiados

```bash
oc get deployment obs-web -n ac02-consultas -o yaml | less
oc get deployment obs-web -n ac02-consultas -o yaml | sed -n '/^spec:/,/^status:/p' | head -40
oc get deployment obs-web -n ac02-consultas -o json | jq '.status'
oc get deployment obs-web -n ac02-consultas -o json | jq '.metadata | {name, uid, resourceVersion, labels}'
POD=$(oc get pods -n ac02-consultas -l app=obs-web -o name | head -1)
oc get "$POD" -n ac02-consultas -o json | jq '.metadata.ownerReferences'
RS=$(oc get "$POD" -n ac02-consultas -o jsonpath='{.metadata.ownerReferences[0].name}')
oc get rs "$RS" -n ac02-consultas -o json | jq '.metadata.ownerReferences[0] | {kind, name}'
oc get deployment obs-web -n ac02-consultas -o yaml --show-managed-fields | grep -A3 'manager:'
```

## Repetições

1. Compare `spec.replicas` e `status.replicas` do Deployment.
2. Encontre a anotação `academy.openshift.dev/proposito`.
3. `oc get svc obs-web -n ac02-consultas -o yaml` — o que há em `status`?
4. `oc get configmap obs-config -n ac02-consultas -o yaml` — onde estão os dados?
5. Rode `oc get deployment obs-web -n ac02-consultas -o jsonpath='{.metadata.resourceVersion}'` antes e depois de
   `oc rollout restart` hipotético — **não execute o restart**; responda o que mudaria.

## Desafio sem pista

Partindo **só do nome de um pod**, chegue ao nome do Deployment dono dele e imprima a cadeia `Pod -> ReplicaSet -> Deployment`.

## Diagnóstico controlado

- **Sintoma:** `jq: error: Cannot iterate over null`.
- **Hipóteses:** (a) campo inexistente naquele objeto; (b) caminho com nome errado (`ownerReference` no singular).
- **Investigação:** `jq 'keys'` em cada nível; `jq '.metadata | keys'`.
- **Reversão:** nada a reverter.

## Validação

```bash
oc get deployment obs-web -n ac02-consultas -o json | jq -e '.spec.replicas == .status.readyReplicas' && echo OK
```
