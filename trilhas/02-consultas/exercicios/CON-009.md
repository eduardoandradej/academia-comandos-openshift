## Conceito

`-o custom-columns=TITULO:caminho,TITULO2:caminho2` usa a mesma sintaxe de caminho do jsonpath (sem chaves e sem
`range`). Campos inexistentes aparecem como `<none>`. Para reutilizar, `-o custom-columns-file=arquivo`, com os
títulos na primeira linha e os caminhos na segunda.

Use custom-columns para **leitura humana**; para scripts, prefira `-o name`, jsonpath ou jq.

## Comandos guiados

```bash
oc get pods -n ac02-consultas -o custom-columns=NOME:.metadata.name,FASE:.status.phase,IP:.status.podIP
oc get pods -n ac02-consultas -o custom-columns=NOME:.metadata.name,IMAGEM:.spec.containers[0].image
oc get pods -n ac02-consultas -o custom-columns=NOME:.metadata.name,REINICIOS:.status.containerStatuses[0].restartCount
oc get deploy -n ac02-consultas -o custom-columns=NOME:.metadata.name,DESEJADO:.spec.replicas,PRONTO:.status.readyReplicas
cat > /tmp/ac-pods.cols <<'EOF'
NOME          FASE          IP             IMAGEM                          REINICIOS
.metadata.name .status.phase .status.podIP .spec.containers[0].image .status.containerStatuses[0].restartCount
EOF
oc get pods -n ac02-consultas -o custom-columns-file=/tmp/ac-pods.cols
```

## Repetições

1. Coluna com o rótulo `tier` (`.metadata.labels.tier`).
2. Coluna com o `requester` do projeto (`oc get project ac02-consultas`).
3. Coluna com o seletor do Service.
4. Tabela de ConfigMaps com nome e número de chaves? (Dica: custom-columns não conta — explique a limitação.)
5. Ordene a tabela do arquivo por data de criação (`--sort-by`).

## Desafio sem pista

Crie uma tabela de eventos do projeto com as colunas `QUANDO`, `TIPO`, `OBJETO` (`kind/nome`) e `MOTIVO`, ordenada por data.

## Diagnóstico controlado

- **Sintoma:** `error: unexpected path string, expected a 'name1.name2' or '.name1.name2' or '{name1.name2}' or '{.name1.name2}'`.
- **Como reproduzir sem risco:** `oc get pods -n ac02-consultas -o custom-columns=NOME:metadata.name,X:{range}`.
- **Hipóteses:** sintaxe de jsonpath completa (com `range`) não é aceita em custom-columns.
- **Investigação:** remova `range`/`end` e use caminhos simples.
- **Reversão:** nada a reverter.
