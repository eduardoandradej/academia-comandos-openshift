## Objetivo e indicador de sucesso

Filtrar por campos do objeto (fase, nome, nó, tipo de evento) com `--field-selector`.

**Indicador de sucesso:** você lista só os pods `Running`, só os eventos `Warning` e só os eventos de um objeto específico.

## Conceito

`--field-selector` filtra **no servidor** por campos — mas só por um conjunto limitado, que varia por tipo:

| Tipo | Campos comuns |
|---|---|
| todos | `metadata.name`, `metadata.namespace` |
| Pod | `status.phase`, `spec.nodeName`, `spec.restartPolicy`, `status.podIP`, `spec.serviceAccountName` |
| Event | `type`, `reason`, `involvedObject.kind`, `involvedObject.name` |

Operadores: `=`, `==`, `!=`; vários critérios separados por vírgula (E lógico). Diferente de rótulos, não há `in`/`notin`.

## Comandos guiados

```bash
oc get pods -n ac02-consultas --field-selector=status.phase=Running
oc get pods -n ac02-consultas --field-selector=status.phase!=Running        # vazio, se tudo saudável
POD=$(oc get pods -n ac02-consultas -l app=obs-web -o name | head -1 | cut -d/ -f2)
oc get pods -n ac02-consultas --field-selector=metadata.name="$POD"
oc get events -n ac02-consultas --field-selector type=Warning
oc get events -n ac02-consultas --field-selector involvedObject.kind=Deployment,involvedObject.name=obs-web
oc get events -n ac02-consultas --field-selector reason=Scheduled
oc get pods -n ac02-consultas --field-selector=status.phase=Running -l app=obs-web    # campo + rótulo
```

## Repetições

1. Eventos `Normal` do pod `$POD`.
2. Pods com `spec.restartPolicy=Always`.
3. Eventos com `reason=Pulled`.
4. Combine `--field-selector` e `-l` para os ConfigMaps da Academia com nome `obs-config`.
5. Tente `--field-selector=metadata.labels.app=obs-web` e explique o erro.

## Desafio sem pista

Mostre, em ordem cronológica, apenas os eventos que se referem a **pods** do projeto, exibindo motivo e mensagem.

## Diagnóstico controlado

- **Sintoma:** `Error from server (BadRequest): Unable to find "/v1, Resource=pods" that match label selector "", field selector "status.ready=True": field label not supported: status.ready`.
- **Como reproduzir sem risco:** `oc get pods -n ac02-consultas --field-selector=status.ready=True`.
- **Hipóteses:** campo não indexado para seleção.
- **Investigação:** use `status.phase` ou filtre no cliente com jsonpath/jq.
- **Reversão:** nada a reverter.
