## Conceito

Todo `oc get` é um GET em uma URL: `/api/v1/...` para o grupo core e `/apis/<grupo>/<versão>/...` para os demais.
`oc get --raw <caminho>` faz a chamada com suas credenciais e devolve o JSON cru — ótimo para entender a API e para
endpoints sem comando próprio. Só use `--raw` com GET nesta Academia.

## Comandos guiados

```bash
oc get --raw /api | jq .                                          # versões do grupo core
oc get --raw /apis | jq -r '.groups[].name' | head -20            # grupos
oc get --raw /apis/apps/v1 | jq -r '.resources[].name'            # recursos de apps/v1
oc get --raw /api/v1/namespaces/ac02-consultas/pods | jq -r '.items[].metadata.name'
oc get --raw "/api/v1/namespaces/ac02-consultas/pods?labelSelector=app%3Dobs-web" | jq '.items | length'
```

Circuito sem pistas (escreva o comando de cada item):

1. Tipos do grupo `apps` com nome curto.
2. Documentação do campo de réplicas de um Deployment.
3. Pods do alvo com IP e nó.
4. Só os nomes dos pods, sem prefixo.
5. Pods com `tier=web` e rótulo `app` como coluna.
6. Eventos `Warning` do projeto.
7. Imagem do contêiner do Deployment (jsonpath).
8. Nome, fase e reinícios em tabela (custom-columns).
9. Pods marcados com `!` se não `Running` (go-template).
10. Número de chaves do ConfigMap (jq).
11. Eventos em ordem cronológica.
12. Endpoints do Service.
13. (admin) Condição `Ready` do nó com jsonpath.
14. (admin) Operadores degradados com jq.
15. Pods do alvo via `oc get --raw` com seletor de rótulo.

- **Sintoma:** `Error from server (NotFound): the server could not find the requested resource`.

- **Hipóteses:** caminho errado (singular, grupo ou versão).
- **Investigação:** `oc get --raw /apis/apps/v1 | jq -r '.resources[].name'`.
- **Reversão:** nada a reverter.
