## Conceito

| | `oc describe` | `oc get -o yaml` |
|---|---|---|
| Formato | texto para humanos | o objeto como a API guarda |
| Eventos relacionados | **sim** | não |
| Informação agregada | sim (ex.: Endpoints do Service) | não |
| Reaproveitável como manifesto | não | sim (após limpar `status` e campos do servidor) |
| Ideal para | "o que está acontecendo?" | "qual é exatamente o valor?" |

## Comandos guiados

```bash
oc describe deployment obs-web -n ac02-consultas
oc get deployment obs-web -n ac02-consultas -o yaml
oc describe svc obs-web -n ac02-consultas            # mostra Endpoints (IPs dos pods)
oc get svc obs-web -n ac02-consultas -o yaml         # não mostra os endpoints
POD=$(oc get pods -n ac02-consultas -l app=obs-web -o name | head -1)
oc describe "$POD" -n ac02-consultas | sed -n '/Conditions:/,/Volumes:/p'
oc describe "$POD" -n ac02-consultas | sed -n '/Events:/,$p'
oc describe pods -n ac02-consultas -l app=obs-web | grep -E '^Name:|^Status:'   # describe com seletor
```

## Repetições

Escolha o comando para cada pergunta (gabarito na solução):

1. Por que o pod reiniciou?
2. Qual o valor exato do `maxSurge`?
3. Quais IPs o Service está balanceando?
4. Qual o `resourceVersion` do ConfigMap?
5. Em que nó o pod foi agendado e quando?
6. Quero um manifesto para recriar o Service em outro projeto.
7. Quais variáveis o contêiner recebe e de onde?
8. Há eventos de falha de probe?

## Desafio sem pista

A partir de `oc get svc obs-web -o yaml`, produza um manifesto **reaplicável** (sem `status`, `uid`, `resourceVersion`,
`creationTimestamp`, `clusterIP(s)`) e valide-o com `oc apply --dry-run=server` em `ac02-consultas`.

## Diagnóstico controlado

- **Sintoma:** ao reaplicar um YAML exportado: `the object has been modified; please apply your changes to the latest version`.
- **Hipóteses:** o manifesto carrega `resourceVersion` antigo.
- **Investigação:** `grep -n resourceVersion <arquivo>`.
- **Reversão:** nada foi gravado (o servidor recusou). Remova os campos do servidor e repita com `--dry-run=server`.

## Validação

```bash
oc describe svc obs-web -n ac02-consultas | grep -E '^Endpoints:'
```
