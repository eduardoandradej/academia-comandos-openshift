## Objetivo e indicador de sucesso

## Conceito

| Expressão | Significado |
|---|---|
| `{.metadata.name}` | campo de um objeto |
| `{.items[0].metadata.name}` | primeiro item de uma lista |
| `{.items[*].metadata.name}` | todos, separados por espaço |
| `{range .items[*]}...{end}` | laço, com controle de formato |
| `{"\n"}` / `{"\t"}` | quebra de linha / tabulação |
| `{.items[?(@.status.phase=="Running")].metadata.name}` | filtro |
| `{.metadata.labels.academy\.openshift\.dev/trilha}` | chave com ponto: escape `\.` |

Sempre use **aspas simples** em volta da expressão no shell.

## Comandos guiados

```bash
oc get deployment obs-web -n ac02-consultas -o jsonpath='{.spec.replicas}{"\n"}'
oc get pods -n ac02-consultas -o jsonpath='{.items[*].metadata.name}{"\n"}'
oc get pods -n ac02-consultas -o jsonpath='{range .items[*]}{.metadata.name}{"\t"}{.status.podIP}{"\n"}{end}'
oc get pods -n ac02-consultas -o jsonpath='{range .items[*]}{.metadata.name}{" ready="}{.status.conditions[?(@.type=="Ready")].status}{"\n"}{end}'
oc get pods -n ac02-consultas -o jsonpath='{.items[0].spec.containers[0].image}{"\n"}'
oc get deployment obs-web -n ac02-consultas -o jsonpath='{.metadata.labels.academy\.openshift\.dev/trilha}{"\n"}'
oc get pods -n ac02-consultas -o jsonpath='{.items[?(@.status.phase=="Running")].metadata.name}{"\n"}'
oc get svc obs-web -n ac02-consultas -o jsonpath='{.spec.clusterIP}:{.spec.ports[0].port}{"\n"}'
```

## Repetições

1. Nome do nó de cada pod.
2. `restartCount` do primeiro contêiner de cada pod.
3. Requests de memória do contêiner do Deployment.
4. Todas as variáveis vindas do ConfigMap (`envFrom`).
5. Data de criação de cada pod.
6. A chave `MODO` do ConfigMap.
7. O tipo do Service.
8. A imagem do contêiner do Deployment (não do pod).
9. O valor da anotação `academy.openshift.dev/proposito`.
10. As portas do contêiner com nome e número.

## Desafio sem pista

Uma linha por pod no formato `nome | ip | nó | ready=<True/False> | reinícios=<n>`, usando apenas jsonpath.

## Diagnóstico controlado

- **Sintoma:** saída vazia, sem erro.
- **Como reproduzir sem risco:** `oc get pods -n ac02-consultas -o jsonpath='{.items[*].metadata.Name}'` (maiúscula).
- **Hipóteses:** (a) nome de campo com caixa errada; (b) faltou `.items` em uma lista; (c) filtro sem correspondência.
- **Investigação:** compare com `-o json | jq '.items[0].metadata | keys'`.
- **Reversão:** nada a reverter.

## Validação

```bash
oc get pods -n ac02-consultas -o jsonpath='{range .items[*]}{.status.conditions[?(@.type=="Ready")].status}{"\n"}{end}' | sort -u   # True
```
