## Objetivo e indicador de sucesso

## Conceito

| Filtro | Faz |
|---|---|
| `.items[]` | itera a lista |
| `.metadata.name` | navega |
| `select(.status.phase=="Running")` | mantém só o que atende |
| `{nome: .metadata.name}` | constrói objeto |
| `map(...)`, `length`, `keys` | transforma, conta, lista chaves |
| `-r` | saída crua (sem aspas) |
| `-e` | código de saída conforme o resultado (útil em `if`) |
| `.["chave.com.pontos"]` | chave com caracteres especiais |

## Comandos guiados

```bash
oc get pods -n ac02-consultas -o json | jq '.items | length'
oc get pods -n ac02-consultas -o json | jq -r '.items[].metadata.name'
oc get pods -n ac02-consultas -o json | jq -r '.items[] | select(.status.phase=="Running") | .metadata.name'
oc get pods -n ac02-consultas -o json | jq '[.items[] | {nome: .metadata.name, ip: .status.podIP}]'
oc get deploy obs-web -n ac02-consultas -o json | jq '.metadata.labels["academy.openshift.dev/trilha"]'
oc get configmap obs-config -n ac02-consultas -o json | jq '.data | keys'
oc get pods -n ac02-consultas -o json | jq -e 'all(.items[]; .status.phase=="Running")' && echo "todos Running"
```

## Repetições

1. Pods ordenados por data: `jq -r '.items | sort_by(.metadata.creationTimestamp)[] | .metadata.name'`.
2. Objeto `{nome: reinícios}` com `map` e `from_entries`.
3. Lista de imagens únicas do projeto (`unique`).
4. Eventos `Warning` contados por motivo (`group_by`).
5. `oc get --raw /apis/apps/v1/namespaces/ac02-consultas/deployments | jq '.items[].metadata.name'`.

## Desafio sem pista

Gere `{"nome":..., "desejado":..., "pronto":..., "imagem":..., "rotulos":{...}}` do Deployment `obs-web` em uma linha (`-c`).

## Diagnóstico controlado

- **Sintoma:** `jq: error (at <stdin>:...): Cannot index array with "metadata"`.
- **Como reproduzir sem risco:** `oc get pods -n ac02-consultas -o json | jq '.items.metadata'`.
- **Hipóteses:** tentou navegar dentro de uma lista sem iterar.
- **Investigação:** `jq '.items | type'` → `"array"`; use `.items[]` ou `.items[0]`.
- **Reversão:** nada a reverter.
