## Objetivo e indicador de sucesso

Ler o consumo real de CPU e memória de pods e contêineres e compará-lo com requests e limits.

**Indicador de sucesso:** você mostra uso × request × limit do `ac11-app` em uma tabela e diz se o request está superdimensionado.

## Conceito

`oc adm top` lê a **Metrics API** (`metrics.k8s.io`), servida no OpenShift pelo componente de monitoramento. São
amostras recentes (janela de ~1 min), não histórico. O HPA (RES-011) usa a mesma fonte.

| Comando | Mostra |
|---|---|
| `oc adm top pods -n NS` | uso por pod |
| `oc adm top pods -n NS --containers` | uso por contêiner |
| `oc adm top nodes` (admin) | uso do nó × capacidade |

## Comandos guiados

```bash
oc adm top pods -n ac11-resiliencia
oc adm top pods -n ac11-resiliencia --containers
oc get --raw "/apis/metrics.k8s.io/v1beta1/namespaces/ac11-resiliencia/pods" | jq -r '.items[] | "\(.metadata.name)\t\(.containers[0].usage.cpu)\t\(.containers[0].usage.memory)"'
oc get pods -n ac11-resiliencia -o custom-columns=POD:.metadata.name,REQ_CPU:.spec.containers[0].resources.requests.cpu,LIM_CPU:.spec.containers[0].resources.limits.cpu,REQ_MEM:.spec.containers[0].resources.requests.memory,LIM_MEM:.spec.containers[0].resources.limits.memory
KUBECONFIG="$HOME/.kube/ac-admin.kubeconfig" oc adm top nodes
```

## Repetições

1. Ordene por memória: `oc adm top pods -n ac11-resiliencia --sort-by=memory`.
2. Converta o valor da API (`nanocores`, `Ki`) para `m` e `Mi`.
3. Compare com `memory.current` do cgroup (`oc exec ... -- cat /sys/fs/cgroup/memory.current`).
4. (admin) Qual porcentagem de CPU e memória do SNO está em uso? Abaixo de 85%?
5. O que significa `error: metrics not available yet`?

## Desafio sem pista

Monte uma tabela por pod com: uso de CPU em `m`, request de CPU em `m` e a razão uso/request em %.

## Diagnóstico controlado

- **Sintoma:** `error: Metrics API not available`.
- **Hipóteses:** componente de métricas indisponível ou ainda iniciando; Prometheus sem dados após reinício.
- **Investigação:** (admin, leitura) `oc get apiservice v1beta1.metrics.k8s.io -o jsonpath='{.status.conditions[0]}'`; `oc get co monitoring`.
- **Reversão:** nada a reverter; aguarde. Não reinicie componentes de monitoramento.
