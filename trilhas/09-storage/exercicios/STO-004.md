# STO-004 — emptyDir em memória: rápido e contado como RAM

## Identificação

- **ID:** STO-004
- **Trilha:** [09 — Storage](../README.md)
- **Referência didática:** DO180 — armazenamento para aplicações (volumes efêmeros).
- **Fichas de comando:** [`oc-set-volume`](../../../catalogo/fichas/oc-set-volume.md)

## Objetivo e indicador de sucesso

Montar um `emptyDir` com `medium: Memory` (tmpfs) e mostrar que o que se grava nele conta no uso de memória do contêiner.

**Indicador de sucesso:** `df` mostra `tmpfs` e o consumo de memória do contêiner sobe depois de gravar 8 MiB.

## Conceito

`emptyDir: {medium: Memory}` monta um tmpfs: leitura e escrita em RAM, nada vai para o disco. O conteúdo conta no
uso de memória do contêiner — gravar além do `limits.memory` leva a OOMKill (TS-015). Defina sempre `sizeLimit`.
Bom para arquivos temporários pequenos e sensíveis que não devem tocar o disco.

## Comandos guiados

```bash
oc patch deployment ac09-app -n ac09-storage --type=json -p '[
 {"op":"add","path":"/spec/template/spec/volumes/-","value":{"name":"ram","emptyDir":{"medium":"Memory","sizeLimit":"16Mi"}}},
 {"op":"add","path":"/spec/template/spec/containers/0/volumeMounts/-","value":{"name":"ram","mountPath":"/ram"}}]'
oc rollout status deployment/ac09-app -n ac09-storage
oc exec deploy/ac09-app -n ac09-storage -- df -h /ram /cache
oc exec deploy/ac09-app -n ac09-storage -- cat /sys/fs/cgroup/memory.current
oc exec deploy/ac09-app -n ac09-storage -- dd if=/dev/zero of=/ram/bloco bs=1M count=8 status=none
oc exec deploy/ac09-app -n ac09-storage -- cat /sys/fs/cgroup/memory.current          # ~8 MiB a mais
oc exec deploy/ac09-app -n ac09-storage -- rm /ram/bloco
```

## Repetições

1. Converta as duas leituras de `memory.current` para MiB e calcule a diferença.
2. Compare com `oc adm top pod` (se a Metrics API responder).
3. Qual é o `limits.memory` do contêiner? (LimitRange padrão: 256Mi.)
4. Tente gravar 20 MiB com `sizeLimit` 16Mi e observe o que acontece (pode levar alguns segundos: despejo do pod).
5. Explique quando usar `medium: Memory` em vez do disco.

## Desafio sem pista

Sem gravar nada, calcule qual seria o máximo seguro a gravar em `/ram` antes de arriscar OOMKill, a partir do
`limits.memory` e do `memory.current` atuais.

## Diagnóstico controlado

- **Sintoma:** após gravar em `/ram`, o pod é recriado e `oc get pod` mostra o anterior `Evicted` ou o contêiner `OOMKilled`.
- **Hipóteses:** (a) passou do `sizeLimit` (despejo); (b) passou do `limits.memory` (OOMKill).
- **Investigação:** `oc get pods -n ac09-storage`; `oc describe pod <antigo>` (motivo); `lastState` do contêiner.
- **Reversão:** apague pods `Evicted` (`oc delete pod <nome>`); grave menos ou ajuste o limite com critério.

## Validação

```bash
oc exec deploy/ac09-app -n ac09-storage -- sh -c "df /ram | tail -1" | grep -q tmpfs && echo "tmpfs em /ram"
```

## Limpeza segura

```bash
oc exec deploy/ac09-app -n ac09-storage -- rm -f /ram/bloco
oc delete pods -n ac09-storage --field-selector=status.phase=Failed
```
