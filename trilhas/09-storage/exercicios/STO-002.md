# STO-002 — emptyDir compartilhado entre contêineres

## Identificação

- **ID:** STO-002
- **Trilha:** [09 — Storage](../README.md)
- **Referência didática:** DO180 — armazenamento para aplicações (volumes efêmeros).
- **Fichas de comando:** [`oc-set-volume`](../../../catalogo/fichas/oc-set-volume.md), [`oc-pvc-storage`](../../../catalogo/fichas/oc-pvc-storage.md)

## Objetivo e indicador de sucesso

Fazer dois contêineres do mesmo pod trocarem dados por um `emptyDir`: um gera a página, o outro (httpd) a serve.

**Indicador de sucesso:** a página servida pelo httpd muda a cada 5 segundos, escrita pelo outro contêiner.

## Conceito

> **SSD do HomeLab.** `emptyDir` e armazenamento efêmero gravam no disco do único nó (QCOW2 no SSD). Os exercícios
> usam no máximo algumas dezenas de MiB; não aumente esses valores.

Um `emptyDir` nasce vazio quando o pod é agendado e é removido junto com o pod. Todos os contêineres do pod que o
montam veem os mesmos arquivos, mesmo em caminhos diferentes. É a forma padrão de um sidecar entregar arquivos ao
contêiner principal.

O manifesto `manifests/apps-exemplo/emptydir-compartilhado.yaml` tem um contêiner `gerador` que escreve
`/saida/index.html` a cada 5 s e um contêiner `web` (httpd) que monta o mesmo volume em `/var/www/html`.

## Comandos guiados

```bash
oc new-project ac09-storage --display-name='Academia 09 - Storage'
oc apply --dry-run=server -f manifests/apps-exemplo/emptydir-compartilhado.yaml -n ac09-storage
oc apply -f manifests/apps-exemplo/emptydir-compartilhado.yaml -n ac09-storage
oc wait --for=condition=Ready pod/ac09-compartilhado -n ac09-storage --timeout=120s
oc get pod ac09-compartilhado -n ac09-storage -o jsonpath='{.spec.volumes[0]}{"\n"}'
oc exec ac09-compartilhado -c gerador -n ac09-storage -- ls -l /saida
oc exec ac09-compartilhado -c web -n ac09-storage -- ls -l /var/www/html
oc port-forward pod/ac09-compartilhado 18090:8080 -n ac09-storage >/dev/null 2>&1 & PF=$!; sleep 3
curl -sS http://127.0.0.1:18090/; sleep 6; curl -sS http://127.0.0.1:18090/
kill $PF
```

## Repetições

1. Crie um arquivo pelo contêiner `web` em `/var/www/html` e leia-o pelo `gerador` em `/saida`.
2. `oc exec ... -c web -- df -h /var/www/html` — em que sistema de arquivos o `emptyDir` está?
3. Apague o pod e recrie-o: o contador recomeçou?
4. Encontre o `emptyDir` no YAML (`oc get pod ... -o yaml | grep -A2 emptyDir`).
5. Recrie o pod de memória a partir do manifesto, sem olhar.

## Desafio sem pista

Mostre que o volume é o **mesmo** nos dois contêineres comparando o número de inode do diretório visto por cada um.

## Diagnóstico controlado

- **Sintoma:** o httpd responde 403 logo após a criação do pod.
- **Hipóteses:** o `gerador` ainda não escreveu o primeiro `index.html`; o diretório está vazio.
- **Investigação:** `oc exec ac09-compartilhado -c web -n ac09-storage -- ls -la /var/www/html`.
- **Reversão:** aguarde 5 s; para evitar a janela, um init container pode criar a primeira página.

## Validação

```bash
oc exec ac09-compartilhado -c web -n ac09-storage -- grep -q 'gerado em' /var/www/html/index.html && echo OK
```

## Limpeza segura

```bash
pkill -f 'oc port-forward pod/ac09-compartilhado' || true
oc delete -f manifests/apps-exemplo/emptydir-compartilhado.yaml -n ac09-storage --ignore-not-found
```
