## Objetivo e indicador de sucesso

Criar um StatefulSet com `volumeClaimTemplates` e mostrar que cada réplica tem nome estável e PVC próprio, que
sobrevive à remoção do pod e à redução de réplicas.

**Indicador de sucesso:** `dados-ac09-sts-0` e `dados-ac09-sts-1` existem; após apagar `ac09-sts-1`, o pod novo lê o mesmo arquivo.

## Conceito

| | Deployment | StatefulSet |
|---|---|---|
| Nome dos pods | aleatório | ordinal estável (`-0`, `-1`) |
| Volume | um PVC compartilhado (ou nenhum) | um PVC por réplica (`volumeClaimTemplates`) |
| Ordem de criação | paralela | sequencial (`-0` antes de `-1`) |
| DNS | via Service | nome por pod com Service headless (SVC-008) |
| Redução de réplicas | apaga pods | apaga pods, **mantém os PVCs** |

O manifesto `manifests/apps-exemplo/statefulset-mini.yaml` usa `storageClassName: AC09_SC`, trocado pelo valor de `$SC` no `sed`.

## Comandos guiados

```bash
sed "s/AC09_SC/$SC/" manifests/apps-exemplo/statefulset-mini.yaml | oc apply --dry-run=server -n ac09-storage -f -
sed "s/AC09_SC/$SC/" manifests/apps-exemplo/statefulset-mini.yaml | oc apply -n ac09-storage -f -
oc rollout status statefulset/ac09-sts -n ac09-storage
oc get pods,pvc -n ac09-storage -l app=ac09-sts
oc get pvc -n ac09-storage | grep dados-ac09-sts
for i in 0 1; do oc exec ac09-sts-$i -n ac09-storage -- sh -c 'hostname > /dados/eu.txt'; done
oc delete pod ac09-sts-1 -n ac09-storage
oc wait --for=condition=Ready pod/ac09-sts-1 -n ac09-storage --timeout=120s
oc exec ac09-sts-1 -n ac09-storage -- cat /dados/eu.txt                  # ac09-sts-1: mesmo PVC
oc scale statefulset/ac09-sts --replicas=1 -n ac09-storage
oc get pvc -n ac09-storage | grep dados-ac09-sts                          # os dois PVCs continuam
```

## Repetições

1. Volte para 2 réplicas: o `ac09-sts-1` reencontrou o arquivo?
2. Resolva o nome DNS de um pod: `oc exec ac09-sts-0 -- getent hosts ac09-sts-1.ac09-sts`.
3. `oc get statefulset ac09-sts -o jsonpath='{.spec.persistentVolumeClaimRetentionPolicy}'`.
4. Compare a ordem de criação dos pods com a de um Deployment.
5. Apague o StatefulSet: o que acontece com os PVCs?

## Desafio sem pista

Faça o StatefulSet apagar os PVCs automaticamente quando for reduzido (`whenScaled: Delete`), prove reduzindo para 1
e explique o risco dessa escolha.

## Diagnóstico controlado

- **Sintoma:** `ac09-sts-1` fica `Pending` e o PVC `dados-ac09-sts-1` também.
- **Hipóteses:** (a) quota de PVCs esgotada; (b) não há PV livre (opção A); (c) `-0` ainda não ficou pronto (criação ordenada).
- **Investigação:** `oc describe pvc dados-ac09-sts-1`; `oc describe quota`; eventos do StatefulSet.
- **Reversão:** libere PVCs antigos do projeto ou reduza para 1 réplica.

## Validação

oc get pvc dados-ac09-sts-0 -n ac09-storage -o jsonpath='{.status.phase}{"\n"}'    # Bound
