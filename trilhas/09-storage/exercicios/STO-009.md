## Conceito

`oc set volume --add --type=pvc --claim-name=X --claim-size=S [--claim-mode=rwo|rwm|rom] [--claim-class=C]` cria o
PVC se ele não existir e já o monta. É prático, mas o PVC nasce **sem o rótulo da Academia** — rotule em seguida.

## Comandos guiados

```bash
oc set volume deployment/ac09-app --add --name=logs --type=pvc --claim-name=ac09-logs \
  --claim-size=300Mi --claim-mode=rwo --claim-class="$SC" --mount-path=/logs --dry-run=client -o yaml | grep -B2 -A12 'kind: PersistentVolumeClaim'
oc set volume deployment/ac09-app --add --name=logs --type=pvc --claim-name=ac09-logs \
  --claim-size=300Mi --claim-mode=rwo --claim-class="$SC" --mount-path=/logs -n ac09-storage
oc label pvc ac09-logs academy.openshift.dev/managed-by=academia -n ac09-storage
oc rollout status deployment/ac09-app -n ac09-storage
oc get pvc -n ac09-storage
oc set volume deployment/ac09-app -n ac09-storage
```

## Repetições

1. Remova a montagem (`--remove --name=logs`): o PVC continua existindo?
2. Remonte o PVC existente só com `--claim-name` (sem `--claim-size`).
3. Liste os PVCs que nenhum pod usa (`oc describe pvc | grep 'Used By'`).
4. Qual a diferença entre `--claim-mode=rwo` e `rwm`? O seu armazenamento suporta `rwm`?
5. Faça o fluxo em dois passos (YAML + `oc set volume`) e compare.

## Desafio sem pista

Liste os PVCs do projeto que estão `Bound` mas não são usados por nenhum pod, com um único comando (jq).

## Diagnóstico controlado

- **Sintoma:** a montagem foi removida, mas a quota continua acusando o PVC.
- **Hipóteses:** remover a montagem não apaga o PVC (proteção contra perda de dados).
- **Investigação:** `oc get pvc -n ac09-storage`; `oc describe quota -n ac09-storage`.
- **Reversão:** se os dados não servem mais, `oc delete pvc ac09-logs -n ac09-storage`.

## Validação

```bash
oc get pvc ac09-logs -n ac09-storage -o jsonpath='{.status.phase}{"\n"}'    # Bound
```

## Limpeza segura

```bash
oc set volume deployment/ac09-app --remove --name=logs -n ac09-storage
oc delete pvc ac09-logs -n ac09-storage --ignore-not-found
```
