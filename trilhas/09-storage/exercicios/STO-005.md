# STO-005 — Armazenamento efêmero: requests, limits e despejo

## Identificação

- **ID:** STO-005
- **Trilha:** [09 — Storage](../README.md)
- **Referência didática:** DO180/DO280 — limites de recursos (ephemeral-storage).
- **Fichas de comando:** [`oc-set`](../../../catalogo/fichas/oc-set.md)

## Objetivo e indicador de sucesso

Declarar `ephemeral-storage` em requests/limits e provocar, com poucos MiB, o despejo de um pod que passa do limite.

**Indicador de sucesso:** o pod fica `Evicted` com mensagem citando `ephemeral-storage`, e você explica a diferença para OOMKill.

## Conceito

> **SSD do HomeLab.** `emptyDir` e armazenamento efêmero gravam no disco do único nó (QCOW2 no SSD). Os exercícios
> usam no máximo algumas dezenas de MiB; não aumente esses valores.

Além de CPU e memória, o contêiner consome **armazenamento efêmero**: camada gravável, logs e `emptyDir` em disco.
`resources.limits.ephemeral-storage` define o teto; ao ultrapassá-lo, o kubelet **despeja** o pod (`Evicted`) — não
há OOMKill para disco. O agendador usa `requests.ephemeral-storage` para escolher o nó.

O manifesto `manifests/apps-exemplo/cenario-evicted-efemero.yaml` cria um pod com limite de 16Mi que grava 32 MiB.

## Comandos guiados

```bash
oc set resources deployment/ac09-app --requests=ephemeral-storage=32Mi --limits=ephemeral-storage=64Mi -n ac09-storage
oc rollout status deployment/ac09-app -n ac09-storage
oc get deployment ac09-app -n ac09-storage -o jsonpath='{.spec.template.spec.containers[0].resources}{"\n"}'
oc apply -f manifests/apps-exemplo/cenario-evicted-efemero.yaml -n ac09-storage
oc get pod ac09-guloso -n ac09-storage -w            # Ctrl+C quando aparecer Evicted/Failed (até ~1 min)
oc get pod ac09-guloso -n ac09-storage -o jsonpath='{.status.reason}{": "}{.status.message}{"\n"}'
oc get events -n ac09-storage --field-selector involvedObject.name=ac09-guloso --sort-by=.lastTimestamp | tail -5
```

## Repetições

1. Compare `.status.reason` deste pod com o de um OOMKill (TS-015): onde fica cada informação?
2. Um pod `Evicted` é recriado? (Ele é um pod solto; e se fosse de um Deployment?)
3. `oc describe node` (admin, leitura): procure `ephemeral-storage` em `Allocatable`.
4. Quanto do limite o `ac09-app` usa? `oc exec deploy/ac09-app -- du -sh /tmp /cache`.
5. Explique por que logs muito verbosos também contam como armazenamento efêmero.

## Desafio sem pista

Faça o despejo acontecer por `sizeLimit` de um `emptyDir` (não pelo limite do contêiner) e mostre que a mensagem é diferente.

## Diagnóstico controlado

- **Sintoma:** `Status: Failed`, `Reason: Evicted`, `Message: Pod ephemeral local storage usage exceeds the total limit of containers 16Mi.`
- **Hipóteses:** o contêiner gravou mais que `limits.ephemeral-storage`.
- **Investigação:** a própria mensagem; `oc get pod -o jsonpath='{.spec.containers[0].resources}'`.
- **Reversão:** `oc delete pod ac09-guloso`; corrija a aplicação (logs, temporários) antes de subir o limite. Veja TS-030.

## Validação

```bash
oc get pod ac09-guloso -n ac09-storage -o jsonpath='{.status.reason}{"\n"}'    # Evicted
```
