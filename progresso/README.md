# Progresso

Esta pasta contém **apenas modelos vazios**. Seu progresso é pessoal: copie o modelo para fora do repositório e
preencha lá.

```bash
mkdir -p ~/academia-progresso
cp progresso/modelo-revisoes.md ~/academia-progresso/ORI-001.md
```

O `.gitignore` ignora qualquer outro arquivo colocado aqui, para evitar commits acidentais de diários pessoais.
